### Overview

Scales artboards relative to their current size, with a live preview while the dialog stays open.

### Features

- Target: the current artboard, all of them, or a specified set (for example 3, 4 or 3-5, validated strictly)
- Scale: width and height are linked by a single ratio, recalculated around one of nine reference points
- Width and height are entered as a percentage of the active artboard; with several targets, every artboard scales by the same ratio rather than being forced to the same absolute size
- The live preview covers the artboard rectangles only and is fully reversible; the objects are scaled once, on OK, with stroke weights scaled correctly

### Usage

1. Run the script.
2. Choose the target artboards and the reference point.
3. Enter the scale and confirm with OK.
