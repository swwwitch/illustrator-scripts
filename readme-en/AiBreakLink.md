## Overview

This script breaks the links of the selected symbol instances and turns them into regular editable objects.

Illustrator's Break Link to Symbol produces a different structure for static and dynamic symbols, leaving sublayers or nested groups behind. This script normalizes both cases into a single manageable group (or a standalone object) and names the result.

## Main features

- Processes selected symbols in batch, including symbols inside groups
- Organizes static and dynamic break results into a group or a standalone object
- Automatically ungroups groups that contain only one item
- Fully ungroups the result group, including nested groups
- Carries the original symbol name over to the result
- Adds a prefix such as `symbol_unlinked_` to the name
- Uses the text content as the name when the result is a single text object (takes priority over the symbol name)
- Keeps the generated objects selected after processing
- Tooltips on every control
- Japanese and English UI

## Usage

1. Select the symbol instances (symbols inside groups are picked up as well).
2. Run `AiBreakLink.jsx`.
3. Set the options in the dialog.
4. Click OK to run.

## Options panel

| Item | Description |
| --- | --- |
| Ungroup one-item groups | If breaking produces a group containing only one item, removes that group and keeps the item standalone. |
| Ungroup completely | Fully ungroups the result, including nested groups. Any name given to a group is lost. |

- Ungroup one-item groups is dimmed while Ungroup completely is on.

## Result Name panel

| Item | Description |
| --- | --- |
| Use original symbol name | Carries the original symbol name over to the unlinked object. |
| Name prefix | Text added before the symbol name. The default is `symbol_unlinked_` (for example, `symbol_unlinked_Button`). |
| Use single text content as name | When the result is a single text object, uses its content as the name. It takes priority over the symbol name. |

- While Ungroup completely is on, no container is left to name, so Use original symbol name and Name prefix are dimmed.
- Line breaks in the text content are replaced with spaces.

## Settings

The defaults can be changed in the User settings section at the top of the script.

| Variable | Default | Description |
| --- | --- | --- |
| `SHOW_OPTIONS_DIALOG` | `true` | Whether the options dialog is shown on launch. Set it to `false` to run with the defaults below. |
| `UNGROUP_SINGLE_ITEM_GROUP_DEFAULT` | `true` | Default for Ungroup one-item groups |
| `UNGROUP_ALL_DEFAULT` | `false` | Default for Ungroup completely |
| `INHERIT_SYMBOL_NAME_DEFAULT` | `true` | Default for Use original symbol name |
| `USE_PREFIX_DEFAULT` | `true` | Default for Name prefix |
| `UNLINKED_ITEM_NAME_PREFIX_DEFAULT` | `"symbol_unlinked_"` | Default prefix |
| `USE_TEXT_CONTENT_AS_NAME_DEFAULT` | `true` | Default for Use single text content as name |
| `MAX_UNGROUP_ITERATIONS` | `50` | Cap on ungroup iterations for nested groups |

## Notes

- The script exits silently when no document is open, nothing is selected, or the selection contains no symbols.
- Locked and hidden symbol instances are skipped.
- **The original selection is not restored.** The objects generated by breaking the links are left selected instead.
- Breaking a static symbol generates sublayers. The script converts those sublayers into groups directly under the parent layer before organizing them, so **the sublayer names are lost.**
- Dynamic break results are flattened by repeating Ungroup before being collected into a group. The number of iterations is capped by `MAX_UNGROUP_ITERATIONS` to guard against deeply nested groups.
- When breaking produces several objects they are collected into a group; a single object is kept as-is. The name is applied to that group or object.
- While Ungroup completely is on, the group is dissolved after naming, so **the individual objects keep no name.**
- Errors during processing are written to the ExtendScript console, and the remaining symbols are processed as far as possible.
