### Overview

Selects the whole paragraph the text cursor is sitting in. A simplified version of AiSelectParagraph.jsx.

### Usage

1. Place the text cursor inside the text with the Type tool.
2. Run the script.

### Notes

- Paragraphs are split on hard returns (`\r`) only; a soft return (Shift+Return) counts as a line break within the paragraph.
