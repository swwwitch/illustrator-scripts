### Overview

Selects the whole paragraph the text cursor is sitting in.

### Features

- A selection already inside a paragraph is expanded to cover the whole paragraph, even when the trailing return is included
- Paragraphs are split on hard returns (`\r`) only

### Usage

1. Place the text cursor inside the text with the Type tool.
2. Run the script.
