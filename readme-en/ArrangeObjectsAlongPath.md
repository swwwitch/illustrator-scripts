### Overview

Distributes several objects evenly along a single path taken from the selection.

### Features

- The reference path is chosen automatically (largest area), or as the frontmost or backmost object
- The duplicate panel sets how many copies are laid out

### Usage

1. Select the objects to distribute together with the path.
2. Run the script.
3. Choose how the path is picked and how many copies to make, then run it.

### Notes

- "Automatic (largest area)" uses the bounding-box area for open paths.
- The duplicate panel is enabled by default only when exactly two objects are selected, and the count starts at 2.
