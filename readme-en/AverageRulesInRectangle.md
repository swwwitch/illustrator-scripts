### Overview

Evenly redistributes the vertical and horizontal rules inside the selected outer rectangle.

### Features

- Horizontal and vertical rules can be toggled independently
- Live preview switch

### Usage

1. Select the outer rectangle together with the rules inside it.
2. Run the script.
3. Choose which rule directions to process and confirm while watching the preview.

### Notes

- The largest rectangle in the selection is used as the outer frame.
- Vertical rules are spaced horizontally and horizontal rules vertically.
