### Overview

Enters mask-edit mode when the selection is a clipping group, and otherwise builds a clipping mask for each cluster of overlapping objects.

### Usage

1. Select a clipping group, or the objects you want to mask.
2. Run the script.

### Notes

- When the selection is not a clipping group, objects are clustered by overlap and one mask is made per cluster.
