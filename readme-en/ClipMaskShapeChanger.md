### Overview

Replaces the clipping shape of the selected images (placed or embedded), or of an existing clipping group, with a square, circle or hexagon (A/B).

### Features

- Clip shape selectable as square, circle, hexagon A or hexagon B
- Add stroke: adds a stroke once the group is built
- Round corners: applies a rounded-corner live effect to the new clipping group (disabled for circles)
- Multiple objects > match size: sizes everything to the largest or smallest item by area

### Usage

1. Select the images, or an existing clipping group.
2. Run the script.
3. Choose the shape and the options, then click OK.
