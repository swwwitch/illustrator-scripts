### Overview

Generates color palettes, draws them on the artboard and registers them as a swatch group.

### Features

- Algorithms: Tailwind / Lightness / Saturation / Complementary / LCH / All
- Draws the generated palette on the artboard
- Registers the same colors as a swatch group

### Usage

1. Run the script.
2. Choose the algorithm and the base color.
3. Run it, and the palette is drawn and the swatches registered.
