### Overview

Adjusts the brightness of the selected objects with a slider.

### Features

- Slider range -50 to +50, text field range -100 to +100
- R resets, arrow keys step the value
- Commits as a single undo step so the history stays clean
- Japanese / English UI

### Usage

1. Select the objects.
2. Run the script.
3. Adjust the brightness with the slider and click OK.
