### Overview

Generates confetti across the area of the selected objects.

### Features

- Shapes: circle, rectangle, square, triangle, star, sparkle A, sparkle B, heart, ribbon and symbol
- Preview inside the dialog
- OK commits the result onto a `Confetti` layer
- Japanese / English UI

### Usage

1. Select the object that defines the area to scatter over.
2. Run the script.
3. Choose the shape and amount, check the preview, and click OK.
