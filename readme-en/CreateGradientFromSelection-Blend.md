### Overview

Extracts the fill and stroke colors of the selection in layout order, registers them as a swatch group, and builds a gradient from them. This is the blend variant.

### Usage

1. Select the objects to take the colors from.
2. Run the script.

### Notes

- It runs in its own `#targetengine` so that values persist for the session; restarting Illustrator resets them.
- CreateGradientFromSelection.jsx is the standard version.
