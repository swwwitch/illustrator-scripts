### Overview

Finds dates in the text frames of the document and replaces only the ones you tick.

### Usage

1. Optionally select objects to narrow the search.
2. Run the script.
3. Choose which of the dates found to replace, set the new date, and run it.

### Notes

- When objects are selected, only the text frames within that selection — groups included — are searched.
