### Overview

Converts the selected type on a path back into point type, preserving the contents, paragraph attributes and character attributes as far as possible.
A dialog appears for the text formatting and the path options.
The original text path shape is duplicated, and stroke attributes (1pt black, or no stroke) are applied according to the dialog.

### Usage

1. Select the type on a path
2. Run the script
