### Overview

- Keeps the leftmost of the horizontally arranged selection fixed and moves the rest left by the Keyboard Increment, tightening the spacing.
- The counterpart to DistributeLR.jsx, which widens the spacing instead.

### Usage

1. Select two or more objects
2. Run the script

### Notes

- The step comes from the Keyboard Increment preference (`cursorKeyLength`), stored in points, so no unit conversion is needed.
- Does nothing when fewer than two objects are selected.
