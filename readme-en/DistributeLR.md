### Overview

- Keeps the leftmost of the horizontally arranged selection fixed and redistributes the rest to the right at even intervals.
- The step comes from the Keyboard Increment preference (`cursorKeyLength`).

### Usage

1. Select two or more horizontally arranged objects
2. Run the script

### Notes

- `cursorKeyLength` is stored in points, so no unit conversion is needed.
- Does nothing when fewer than two objects are selected.
