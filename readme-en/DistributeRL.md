### Overview

- Keeps the rightmost of the horizontally arranged selection fixed and redistributes the rest to the left at even intervals of the Keyboard Increment.

### Usage

1. Select two or more objects
2. Run the script

### Notes

- The step comes from the Keyboard Increment preference (`cursorKeyLength`), stored in points, so no unit conversion is needed.
- Does nothing when fewer than two objects are selected.
