### Overview

Measures each line of a selected text frame by its outline width and scales the per-line font size so every line matches the longest one.

### Features

- Preview the result with the dialog still open
- Optionally switch the leading to automatic (100% by default)

### Usage

1. Select a single text frame.
2. Run the script.
3. Check the preview and click OK.

### Notes

- Use DynamicTextGenerator.jsx when you also want the text placed on a path.
