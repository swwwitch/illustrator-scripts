### Overview

- Re-selects each selected object in turn and expands its appearance individually.
- Useful when expanding everything at once would merge the results into a group.

### Usage

1. Select the target objects
2. Run the script

### Notes

- Shows an alert and stops when no document is open or nothing is selected.
