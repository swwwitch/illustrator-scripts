### Overview

- Exports every registered action set to an `Illustrator_Actions` folder on the Desktop as `.aia` files.
- The folder is created automatically when missing.

### Usage

1. Run the script
2. The exported action sets are listed in an alert

### Notes

- Cannot run on Illustrator versions where `app.actionSets` is unavailable.
- Characters that are illegal in filenames are replaced with `_`.
