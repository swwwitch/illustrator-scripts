### Overview

Clears the appearance of the selected objects, then sets the stroke to None, the fill to white and the opacity to 100%.

### Features

- Clears the appearance, removing effects and any added fills and strokes
- Sets the stroke to None, the fill to white (K0 in CMYK, R255 G255 B255 in RGB) and the opacity to 100%
- Also sets the document's default fill and stroke the same way, so objects you draw next use them too

### Usage

1. Select the objects.
2. Run the script.

### Notes

- Because the appearance is cleared, effects, added fills and strokes, and graphic styles are lost.
- Groups and text objects get no fill (only their opacity is set to 100%).
