### Overview

Quickly creates and adjusts a backing shape that fits a text frame or a group.

### Features

- One object selected: a rectangle is created behind the text or group automatically
- Two objects selected: the existing shape is reused as the backing shape
- Padding width and height are adjusted with a live preview

### Usage

1. Select the text or group (add the shape too if you want to reuse an existing one).
2. Run the script.
3. Adjust the padding and click OK.
