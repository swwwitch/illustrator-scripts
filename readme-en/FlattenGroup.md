### Overview

- Ungroups the selection completely, including nested groups, then groups it again as one flat group.
- Useful for collapsing deeply nested groups into a single level.

### Usage

1. Select the target objects
2. Run the script

### Notes

- Does nothing when nothing is selected.
- There is no dialog.
