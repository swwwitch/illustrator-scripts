### Overview

- Loads and runs a temporary action that applies Flatten Transparency to the selection.
- The temporary action is unloaded afterwards.

### Usage

1. Select the target objects
2. Run the script

### Notes

- Settings such as the flattening resolution come from the parameters baked into the action definition.
