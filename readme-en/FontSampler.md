### Overview

- Renders the text you type in every installed font
- Applies 30 fonts, as many as fit the artboard, or all fonts, depending on the chosen mode
- In All mode, new artboards are added automatically when the fonts no longer fit

### Main Features

- Enter the sample text in a dialog
- Choose the display mode with radio buttons
- Lay the fonts out in a grid
- Show a progress bar in All mode
