### Overview

- Wraps each selected object in its own group.
- Instead of one group for the whole selection, you get one group per object.

### Usage

1. Select the target objects
2. Run the script

### Notes

- Each new group is created in the same parent container as its object, and the stacking order is preserved.
- Shows an alert and stops when no document is open or nothing is selected.
