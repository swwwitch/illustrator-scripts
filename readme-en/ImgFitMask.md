### Overview

With one shape and one image selected, scales the image to the shape and then creates a clipping mask.

### Usage

1. Select one shape to use as the mask and one image.
2. Run the script.

### Notes

- Shows an error and exits unless exactly two objects are selected.
- Use ImgFitMaskMultiple.jsx to process several images and shapes at once.
