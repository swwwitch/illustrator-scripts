### Overview

With several images and shapes selected, scales each image to its matching shape and creates a clipping mask for each pair.

### Usage

1. Select the shapes and the images together.
2. Run the script.

### Notes

- Shows an error and exits when fewer than two objects are selected.
- ImgFitMask.jsx does the same job for a single shape-and-image pair.
