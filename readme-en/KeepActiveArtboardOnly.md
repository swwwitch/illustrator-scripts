### Overview

Deletes every artboard except the active one, along with the objects that fall outside it.

### Usage

1. Make the artboard you want to keep active.
2. Run the script.

### Notes

- The change cannot be undone cleanly, so duplicating the file first is recommended.
- RemoveOtherArtboards.jsx is a related script.
