### Overview

Generates a long shadow from a distance, an angle and a scale you specify.

### Features

- Dialog with a preview
- Optional Simplify Path pass
- The shadow sides are built by sampling, then united and hole-filled with Pathfinder when needed

### Usage

1. Select the objects.
2. Run the script.
3. Set the distance, angle and scale, check the preview, and click OK.

### Notes

- Works on closed PathItem, CompoundPathItem, GroupItem and TextFrame objects.
