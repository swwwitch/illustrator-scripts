### Overview

Creates or releases a clipping mask, depending on what is selected.

### Features

- Releases and deletes an existing clipping mask, ungrouping as needed
- Creates a new clipping mask for placed and raster images
- With one placed image and one path selected, uses that path as the mask
- With several paths selected, uses the frontmost one as the mask
- Leaves the resulting clipping mask selected

### Usage

1. Select the objects.
2. Run the script.
