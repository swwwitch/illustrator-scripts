### Overview

Groups the selection, converts strokes to fills, applies Pathfinder Merge as a live effect, and then expands the appearance.

### Usage

1. Select the objects.
2. Run the script.

### Notes

- Whether the group is released at the end is controlled by `UNGROUP_AT_END` in the script (default `false`).
