### Overview

Merges several text objects into a single area text, or splits one back out.

### Features

- Merge: select two or more text objects and combine their contents into a new area text

### Usage

1. Select the text.
2. Run the script.

### Notes

- Use TextBreakSplitMergePalette.jsx to split and join on tabs or paragraphs.
