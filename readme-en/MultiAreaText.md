### Overview

Merges several text frames into a single area text, or splits one back out.

### Features

- Merge: select two or more text frames and combine their contents into a new area text frame

### Usage

1. Select the text frames.
2. Run the script.

### Notes

- Use TextBreakSplitMerge.jsx to split and join on tabs or paragraphs.
