### Overview

A toolkit that creates, detaches and adjusts point type and type on a path.

- Attach to a path: place the text along the selected path (or along the path of existing type on a path)
- Generate an arch: build an arch path from the text automatically and create type on a path
- Generate a circle: build a circular path from the text width automatically and create type on a path
- Detach text: split type on a path into its text and its path (with options to keep or drop the formatting, and to delete the path)
