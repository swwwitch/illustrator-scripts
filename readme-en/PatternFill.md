### Overview

With two objects selected, treats the larger as the container and the smaller as the tile, then fills the container's bounding box with an even grid of tiles.

### Features

- Only the tiles that fit entirely inside are kept; no mask is used
- Both original objects are left in place
- Spacing units follow the current ruler settings

### Usage

1. Select the container object and the tile object.
2. Run the script.
3. Set the spacing and run it.
