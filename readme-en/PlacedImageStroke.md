### Overview

Adds a stroke to the selected placed images as an appearance.

### Usage

1. Select the placed images you want to stroke.
2. Run the script.
3. Set the appearance options and click OK.

### Notes

- Shows a warning and exits when no document is open.
- ImageStrokeAdder.jsx is a related script.
