### Overview

- Lets you change a range of Illustrator preferences from a dialog.
- Units, text settings and transform/align settings are adjusted in a single panel.

### Main Features

- Set units (general, stroke, text, East Asian)
- Recent fonts count and font name localization
- Various transform and align options
- Align to glyph bounds setting
- Mode switch (Print pt / Print Q / Onscreen)
