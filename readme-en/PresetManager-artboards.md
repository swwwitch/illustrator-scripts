### Overview

Switches the artboard-name and artboard-border display preferences from a palette-style control panel.

### Features

- Preset switching
- Artboard name display
- Highlight color and stroke width
- A Video Ruler button as an extra

### Usage

1. Run the script to open the palette.
2. Every control takes effect as soon as you touch it.

### Notes

- Changes are written to the preferences immediately; there is no OK button.
- Use PresetManagerArtboard.jsx if you prefer a modal dialog.
