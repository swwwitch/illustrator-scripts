### Overview

Finds the placed images that reference the same linked file as the selected one and relinks them all to a file you choose.

### Usage

1. Select the reference placed image.
2. Run the script.
3. Choose the replacement file.

### Notes

- RelinkSameImages.jsx is a later version with better handling of groups and multiple files.
