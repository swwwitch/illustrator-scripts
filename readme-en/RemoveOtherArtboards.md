### Overview

Deletes every artboard except the active one, along with the objects — guides included — that fall outside it.

### Usage

1. Make the artboard you want to keep active.
2. Run the script.

### Notes

- The change cannot be undone cleanly, so duplicating the file first is recommended.
- `RemoveOtherArtboards-v2.jsx` is an identical file.
