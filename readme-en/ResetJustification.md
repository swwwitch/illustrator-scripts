### Overview

Resets the justification settings — word spacing, letter spacing and glyph scaling — of the selected paragraphs to their defaults.

### Features

- Word spacing: 80 / 100 / 133
- Letter spacing and glyph scaling are reset as well

### Usage

1. Select the text.
2. Run the script.
