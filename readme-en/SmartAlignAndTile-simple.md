### Overview

Redistributes stacked objects evenly along the horizontal axis. A simplified version of SmartAlignAndTile-yoko.jsx.

### Usage

1. Select the objects.
2. Run the script.

### Notes

- Runs on a resident `#targetengine`.
- Original idea: "Distribute Stacked Objects v1.1" by John Wundes ([js4ai](https://github.com/johnwun/js4ai/blob/master/distributeStackedObjects.jsx)) and [Gorolib Design](https://gorolib.blog.jp/archives/77282974.html)
