### Overview

A persistent palette that combines DistributeDownFromTop.jsx and DistributeUpFromTop.jsx.

Each press of the cross buttons (↑ / ← 0 → / ↓) applies one step to whatever is selected at that moment.

### Usage

1. Select the objects or text.
2. Run the script to open the palette.
3. Press the cross buttons to adjust.

### Notes

- The document work is sent to the main engine over BridgeTalk, so one click equals one undo.
- The palette is a resident script: after editing the code, close the palette before running it again.
- `SmartDistributer.jsx` is a near-identical file.
