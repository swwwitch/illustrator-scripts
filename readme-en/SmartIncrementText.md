### Overview

Finds the digits or letters in the selected text frame and duplicates it downwards the number of times you ask for, incrementing the value each time.

### Usage

1. Select the source text frame.
2. Run the script.
3. Set the number of copies and the increment, then run it.

### Notes

- Use SmartRenumber.jsx to renumber an existing sequence instead.
