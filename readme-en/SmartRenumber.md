### Overview

Sorts the selected numeric text in a chosen order and renumbers it as a sequence.

### Usage

1. Select the numeric text objects.
2. Run the script.
3. Choose the order and the starting number, then run it.

### Notes

- Use SmartIncrementText.jsx to duplicate while generating a new sequence.
