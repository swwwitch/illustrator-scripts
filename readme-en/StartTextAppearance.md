### Overview

Clears the appearance of the selected objects, sets the character fill to None, and adds a new fill.

Use it as the starting point for building a text appearance.

### Features

- Clears the appearance, removing effects and any added fills and strokes
- Sets the character fill to None
- Adds a new fill in the Appearance panel, so further fills, strokes and effects can be stacked from there

### Usage

1. Select text objects with the Selection tool.
2. Run the script.
3. In the Appearance panel, set the color and effects of the added fill.

### Notes

- Because the appearance is cleared, effects, added fills and strokes, and graphic styles are lost.
- The steps run through a temporarily loaded action; the action set is unloaded automatically afterwards.
