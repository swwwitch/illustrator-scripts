### Overview

Registers the selected objects as symbols — individually or as one — and optionally replaces the originals with instances.

### Features

- Selection handling: one symbol for the whole selection, or one symbol per object
- Registration method
- Symbol naming: prefix, sequence width, and use of text content
- Registration point
- Handling of linked images

### Usage

1. Select the objects you want to register as symbols.
2. Run the script.
3. Set the selection handling, registration method, naming, registration point and linked-image handling, then run it.

### Notes

- Choosing "one symbol for the whole selection" fixes the registration method to confirmation via the standard dialog.
- Use SymbolizeAndReplace.jsx when matching items elsewhere in the document should be replaced too.
