### Overview

Collects the text chores that are otherwise scattered around Illustrator — breaking, splitting, joining and tidying — into a single dialog.

### Usage

1. Select the text.
2. Run the script.
3. Pick the operation and apply it.

### Notes

- TextBreakSplitMergePallete.jsx is the persistent-palette version.
