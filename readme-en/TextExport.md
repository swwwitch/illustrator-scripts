### Overview

Collects the text in the document, lists it, and exports it to a file.

### Features

- Scope by artboard: the current one or all of them
- Filter by layer
- "Include entire document" widens the scope
- "Remove duplicates" folds identical strings together

### Usage

1. Run the script.
2. Set the scope and the filters, and review the list.
3. Export.

### Notes

- Use TextScopeEdit.jsx to edit the collected text in place instead.
