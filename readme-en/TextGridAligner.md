### Overview

- Aligns or groups Illustrator text frames row by row and column by column
- The row and column thresholds are adjusted independently

### Main Features

- Rows: center vertically, or group
- Columns: center horizontally, or group
- An option distributes the row and column gaps evenly

### Process Flow

1. Show the dialog and read the settings
2. Process the selected text frames
3. Align or group them per row and per column
