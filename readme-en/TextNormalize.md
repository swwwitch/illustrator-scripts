### Overview

Tidies the selected text according to the rules you set in the dialog.

### Features

- Trim leading and trailing spaces
- Remove and renumber list numbering
- Convert between soft and hard returns
- Collapse runs of blank lines
- Convert tabs to spaces
- Convert full-width alphanumerics to half-width

### Usage

1. Select the text.
2. Run the script.
3. Choose the operations in each panel, check the preview, and apply.

### Notes

- The numbering panel's Reset button restores the dialog defaults and re-runs the preview.
