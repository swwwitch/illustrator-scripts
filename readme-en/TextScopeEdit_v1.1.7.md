### Overview

Collects the text in the document, lists it, and lets you edit it in place and write it back. This is an older build of TextScopeEdit.jsx.

### Usage

1. Run the script.
2. Set the scope and review the list.
3. Edit the text in the list and apply it.

- TextScopeEdit.jsx is the current version.
