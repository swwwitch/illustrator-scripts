### Overview

Cuts a gap into a rule around the selected objects.

### Features

- Offset and stroke weight
- Cap (butt or round) and join (miter, round or bevel)
- Japanese / English UI

### Usage

1. Select the objects.
2. Run the script.
3. Set the offset and the stroke options, then click OK.

### Notes

- Use TitleBarLineCut.jsx when you want the bar rectangle as well.
