### Overview

- Sets the tsume of the selected text to 30%.
- A range selected with the Type tool is used as is; a text object selected with the Selection tool is processed in full.

### Usage

1. Select the target text
2. Run the script

### Notes

- There is no dialog. Edit the `Tsume` value in the script to change the amount.
