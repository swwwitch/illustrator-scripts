### Overview

- Generates a type scale from a base font size and a ratio
- Applies the sizes to the selected text, or builds a specimen
- A preview confirms the sizes immediately

### Main Features

- Builds the size list from the ratio
- Applies a font size to the selected text
- Generates specimen text at several sizes
- Shows labels in the current unit
