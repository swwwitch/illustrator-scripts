### Overview

Generates rain-like rules.

### Features

- Rain type selectable as raindrop, spring rain, early-summer rain or driving rain
- Drop shape selectable as raindrop or dot
- Stroke weight, angle, density and count
- Outward extension, child-rule offset, overall scale and fill
- Japanese / English UI

### Usage

1. Open a document.
2. Run the script.
3. Choose the rain type and the options, then run it.

### Notes

- Shows a warning and exits when no document is open.
