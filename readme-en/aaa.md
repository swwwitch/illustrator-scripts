### Overview

Walks the document's layers and sublayers in hierarchy order and lists each name with its locked and visible state in an alert.

### Usage

1. Open the document you want to inspect.
2. Run the script.

### Notes

- A quick tool for checking the layer structure. It never modifies the document.
- Shows a warning and exits when no document is open.
