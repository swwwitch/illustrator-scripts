### Overview

Applies the existing graphic style named "temp_style" to the selected objects.

### Usage

1. Register a graphic style named `temp_style` (register-temp-style.jsx can do this).
2. Select the objects you want to style.
3. Run the script.

### Notes

- When `temp_style` does not exist, the most recently used style is applied instead.
