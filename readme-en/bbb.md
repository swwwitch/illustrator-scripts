### Overview

Finds the "Guides Preview for Trim View" layer, unlocks and unhides it, removes it, and reports the result in an alert.

### Usage

1. Open the target document.
2. Run the script.

### Notes

- A quick tool for clearing the preview layer left behind by Trim View.
- A leading `*` and surrounding whitespace in the layer name are ignored when matching.
- If no match is found, or the removal fails, that is reported in the alert too.
