### Overview

- Exports the active artboard as PNG24.
- 200% resolution, clipped to the artboard, with anti-aliasing
- The background is fixed to white (no transparency)
- Saved next to the document as `<document name>.png`
- The "Guides Preview for Trim View" layer is hidden during the export and shown again afterwards
- On macOS the destination folder is revealed in Finder when the export finishes

### Usage

1. Make the artboard you want to export active
2. Run the script
