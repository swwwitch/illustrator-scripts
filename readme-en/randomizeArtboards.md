### Overview

Shuffles all artboards into a grid with a fixed number of columns.

### Usage

1. Open the document.
2. Run the script.

### Notes

- The column count is set by `COLUMNS` (default 4) and the spacing by `GAP` (default 100 pt).
- Shows a warning and exits when no document is open.
