### Overview

Lists the text on the current artboard, or in the whole document, and copies it all to the clipboard.

### Features

- Scope selectable as the current artboard or the whole document
- "Ignore outside artboards" excludes text that touches no artboard

### Usage

1. Run the script.
2. Choose the scope and review the list.
3. Copy the result.
