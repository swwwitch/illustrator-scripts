### Overview

- Swaps the center positions of two selected objects.
- Ordinary objects use `visibleBounds`; clip groups use the `geometricBounds` of their mask path.

### Usage

1. Select the two objects you want to swap
2. Run the script

### Notes

- Warns when the selection is not exactly two objects.
