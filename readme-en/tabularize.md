### Overview

Interprets the selection as a table grid and generates fills and rules, both horizontal and vertical.

### Features

- Fill: plain / zebra / joined along rows / header row only
- Options: gutter (in ruler units), treat the first row as a header
- Rules: vertical rules as none / between columns only / all; drawn joined when the gutter is 0
- Presets: apply a typical combination in one click

### Usage

1. Select the objects that form the table.
2. Run the script.
3. Set the fill and rule options, then run it.

### Notes

- Text is duplicated and outlined for measurement only; the original text stays editable.
- Dialog values are restored within a session and reset when Illustrator restarts.
