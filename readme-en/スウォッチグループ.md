### Overview

Extracts the fill colors of the selected objects in layout order (left to right, top to bottom) and registers them as a swatch group.

### Features

- Groups, compound paths and text are processed recursively
- Stroke colors are collected as well
- Every extracted color is registered as a global (process) color

### Usage

1. Select the objects whose colors you want to extract.
2. Run the script.

### Notes

- `SwatchGroupFromSelection.jsx`, `SwatchGroupFromSelection-v2.jsx` and `スウォッチグループ.jsx` are identical files.
