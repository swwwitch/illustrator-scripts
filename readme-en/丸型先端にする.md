### Overview

- Sets the stroke cap of the selected path items to Round Cap.
- Groups are walked recursively.

### Usage

1. Select the target paths (groups are fine)
2. Run the script

### Notes

- Paths without a stroke are skipped.
- Shows an alert and stops when no document is open or nothing is selected.
