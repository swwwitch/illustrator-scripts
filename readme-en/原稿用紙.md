### Overview

This script normalizes the character advance of the selected vertical text, draws horizontal rules at one-character intervals, and adds vertical rules along both sides of the grid.

A dialog sets the vertical rule extension, the horizontal rule style, the emphasis interval and whether to add crosshairs. The result is previewed on every change, so you can check it without closing the dialog.

### Main features

- Character attributes matched to the grid (tracking, tsume, proportional metrics, aki, horizontal and vertical scale, kerning)
- Horizontal text converted to vertical text
- Horizontal rules at one-character intervals, from the top of the first character to the bottom of the last
- Vertical rules along both sides of the text, with an adjustable extension
- Thicker horizontal rules at a fixed character interval
- Dashed crosshairs at the center of every cell
- Live preview that stays open while you adjust the settings
- Rules created on a dedicated layer (`Manuscript Grid`) and sent to the back
- Japanese and English UI

### How to use

1. Select a single vertical text object.
2. Run `原稿用紙.jsx`.
3. Set the vertical rule extension, the horizontal rule style, the emphasis interval and the crosshairs.
4. Check the result in the preview (turn off "Preview" to hide it).
5. Click "OK" to draw the rules.

### Options

| Option | Default | Description |
| --- | --- | --- |
| Vertical rule extension | 2mm | How far the vertical rules run past the grid |
| Horizontal rules | Solid | Draw the horizontal rules solid or dashed (1mm / 1mm) |
| Thicker every n characters | On / 5 | Thicken the horizontal rule at the given interval (0.25mm) |
| Add a crosshair to every cell | On | Add a dashed crosshair at the center of every cell |
| Preview | On | Show the result without closing the dialog |

Numeric fields step with the up and down arrow keys (Shift steps by 10 and snaps to multiples of 10).

### Rule specifications

| Rule | Weight | Density |
| --- | ---: | ---: |
| Vertical rules | 0.25mm | 50% |
| Horizontal rules | 0.1mm | 50% |
| Emphasized horizontal rules | 0.25mm | 50% |
| Crosshairs | 0.1mm (dashed 1mm / 1mm) | 30% |

In RGB documents, the equivalent gray RGB values are used.

### Character attributes

The following attributes are set so that the characters land on the grid.

| Attribute | Value |
| --- | --- |
| Tracking | 120 |
| Tsume | 0 |
| Proportional metrics | Off |
| Aki before and after | 0 |
| Horizontal and vertical scale | 90% |
| Kerning | Japanese monospaced |

### Notes

- Compatible with Illustrator 2024 to 2026.
- Select exactly one text object before running the script.
- The rule interval comes from the font size of the first character, so text with mixed font sizes will not line up with the rules.
- Running the script again rebuilds the `Rules` group on the `Manuscript Grid` layer.
- The preview temporarily shows a copy of the selected text. Cancelling restores the original state.
- Manual kerning cannot be set from the DOM, so automatic kerning is set to Japanese monospaced instead.
- After the run, the script reports only the attributes that could not be set.
