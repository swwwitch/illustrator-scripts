### Overview

Registers the formatting of the selected text as a paragraph style, or overwrites an existing style with it.

### Usage

1. Select the text (or the text object) to turn into a style.
2. Run the script.
3. Type a new style name, or pick the style to overwrite, and run it.

### Notes

- Shows a warning and exits when no document is open or nothing is selected.
- The list excludes the default Normal Paragraph Style.
