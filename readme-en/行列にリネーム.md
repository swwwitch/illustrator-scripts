### Overview

Renames the artboards into a "row-column" form in one pass.

### Features

- Rows and columns are derived from the artboards' positions on the canvas
- Japanese / English UI

### Usage

1. Open the document.
2. Run the script.
3. Enable "Update artboard names as row-column" and run it.

### Notes

- Shows a warning and exits when there are no artboards.
- Use ReorderArtboardsByPosition.jsx when you also want to reorder them.
