### Overview

- Updated: 2026-05-20
- Creates a rectangle matching the size of each selected object
- The unit of creation (per object or the whole selection), the measurement basis, fill and stroke presets, the stacking order and the treatment of the original object are all set in a dialog

### Main Features

- Create rectangles per object, or one for the whole selection
- Measure by preview bounds, or by outlining the text
- Choose a fill and stroke preset
- Choose the stacking order (front or back)
- Choose what happens to the original object (keep / clipping mask / delete)
