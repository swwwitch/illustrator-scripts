### 概要

既存のアートボードの並び（行・列）を解析し、その規則を維持したまま新しいアートボードを挿入します.

### 主な機能

- 追加方法: 空のアートボード／現在のアートボードを複製（初期値は `DEFAULT_ADD_METHOD`）
- 追加位置: 現在のアートボードの次／末尾。方向は右（横並び）／下（縦並び）
- 追加数: 空のアートボードのときのみ有効
- 間隔: 既存の並びから自動推定した値を定規単位で初期表示

### 使い方

1. 基準にするアートボードをアクティブにします。
2. スクリプトを実行します。
3. 追加方法・位置・数・間隔を指定して実行します。
