# 行頭に箇条書き記号・連番を付ける

### 概要

- 選択したテキストフレームの各行頭に、箇条書き記号または連番を付与するスクリプト。
- ダイアログを開いた時点で現在の行頭マーカーから種類・記号・番号スタイル・区切り文字を推定し、「現状の続き」として編集できる。
- 設定はすべてプレビューに反映され、キャンセルすれば元の状態に戻る。
- マーカーの送り位置はタブストップで制御するため、本文の折り返し位置をそろえられる。

### 主な機能

- 「リストの種類」を選択
  - **箇条書き** / **番号リスト** / **なし**（「なし」は行頭のマーカーとタブストップを削除）
- 「箇条書き記号」を選択
  - • - ● ○ ◎ ■ □ ◆ ◇ から選択
  - 記号ごとに拡大率と本文位置の既定値が切り替わる（•/- は本文位置が文字サイズの0.8倍）
- 「番号スタイル」を選択
  - **数字** / **白丸数字**（①〜⑳） / **黒丸数字**（❶〜⓴） / **ABC** / **abc**
  - 白丸・黒丸数字は範囲外（21以上）で素の数字になり、実行前に警告を表示
  - 「ゼロ埋め」で最大桁数に合わせて先頭を0で埋める（数字スタイルのみ）
  - 「開始番号」を指定（既定：1）
  - 「フレームごとにリセット」で、複数フレーム選択時に各フレームの先頭から番号を振り直す
- 「区切り文字」を選択
  - なし / . / ： / |（白丸・黒丸数字を選ぶと自動で「なし」に切り替わる）
- 「位置（タブストップ）」を指定
  - **マーカー**（番号を置く位置）と**本文**（本文の開始位置）を文字サイズ基準の既定値から調整
  - 既定値は種類ごとに自動設定（数字＝1.5/2.0倍、ABC・abc＝1.0/2.0倍、箇条書き・丸数字＝1.2倍）
  - マーカー位置の揃えを左／中央／右から選択（数字・ABC・abc のみ。既定は数字＝右、ABC・abc＝中央）
  - 箇条書きと丸数字はタブストップ1つ（本文位置のみ）で配置
- 「マーカーの書式」を指定
  - フォントファミリー・スタイル（「和文フォントのみ」で一覧を絞り込み）
  - 拡大率（水平・垂直に同率で適用）、ベースラインシフト
  - 記号／番号と区切り文字のカラーを個別に指定（四角をクリックでカラーピッカー）
- 「段落設定」を指定
  - 行送り・段落後のアキ（空欄なら変更しない）
  - 行送りは固定値ではなく、段落ごとに文字サイズに対する割合を求めて自動行送りの値（％）として設定するため、あとから文字サイズを変えても行送りが追従する
  - 「行揃え」をボタンで指定（左揃え／中央揃え／右揃え／均等配置（最終行左揃え）／両端揃え）
  - 行揃えの既定はテキストの種類に応じて自動選択（ポイント文字＝左揃え、エリア内文字＝均等配置（最終行左揃え））
  - 「折り返し位置を揃える」で、2行目以降の開始位置を本文位置にそろえる
  - インデント値は本文位置と自動で連動する
- 「行の並べ替え」で行を入れ替え
  - 一覧から複数行を選択して、先頭へ／上へ／下へ／末尾へ移動
  - 名前順・数値順・数値順（逆）で一括並べ替え（数値を含まない行は末尾）
- 「制御文字を表示」でタブや改行の表示を切り替え
- 「リセット」で拡大率・ベースライン・カラー・インデント・タブストップをまとめて初期化
- 数値入力欄は ↑↓ キーで増減（Shift＝±10、Option＝±0.1）
- 日本語／英語の自動切り替え

### 処理の流れ

1. 選択オブジェクト（グループ内も再帰）からテキストフレームを収集し、上→下（同じ高さなら左→右）に並べ替え
2. テキスト・文字属性・段落設定・タブストップの現状を控える
3. ダイアログを表示し、現在の行頭マーカーから初期状態を推定して反映
4. 設定を変更するたびに、直前のプレビューを取り消して控えを書き戻し、現在の設定で付与し直す
5. OKで確定（プレビュー分は取り消したうえで1回だけ適用するため、取り消し履歴は1つ）
6. キャンセルまたはダイアログを閉じた場合は、控えから元の状態に戻す

### 対象外

- ドキュメントが開かれていない場合、選択がない場合、選択にテキストフレームがない場合（警告を表示して終了）
- 空行（空白のみの行）：マーカーも番号も付けない
- 行の並べ替え：確定後の取り消しはIllustratorの取り消し操作によるもので、「リセット」やキャンセルでは元の並び順に戻らない
- 合成フォント・OpenType機能・文字回転などの文字属性：本文の再構築時に復元する対象に含まれない

### 補足

実行時、行頭の中黒（・ ･ ·）と、後ろにタブ・空白を伴うハイフン（-）は自動的に除去します。
手入力の「1. 」「A) 」のような行頭も、区切り文字を伴う場合は除去の対象です。
「12.5」のように区切り文字の直後が数字の場合は本文とみなして残します。
