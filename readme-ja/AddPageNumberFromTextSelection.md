# ページ番号を一括配置

[![Direct](https://img.shields.io/badge/Direct%20Link-AddPageNumberFromTextSelection.jsx-ffcc00.svg)](https://github.com/swwwitch/illustrator-scripts/blob/master/jsx/artboard/AddPageNumberFromTextSelection.jsx)

---

### 概要

- 選択中のポイントテキストを雛形に、すべてのアートボードへページ番号テキストを複製・配置するIllustrator用スクリプトです。
- 開始番号、接頭辞、接尾辞、ゼロ埋め、総ページ数表示をカスタマイズでき、変更は即座にプレビューへ反映されます。
- 配置先は `_pagenumber` レイヤーです。存在しない場合は自動作成されます。

<img alt="" src="https://www.dtp-transit.jp/images/ss-672-346-72-20250713-081024.png" width="50%" />

### 主な機能

- 選択したポイントテキストの体裁を引き継いでページ番号を生成
- 開始番号、接頭辞、接尾辞の指定
- ゼロ埋め（総ページ数の桁数に合わせて `1` → `01`）
- 総ページ数の表示（`3/12` 形式）
- ライブプレビューと、キャンセル時の復元
- `_pagenumber` レイヤーの自動作成・一時解除・状態復元
- 各コントロールのツールチップ表示
- 日本語／英語インターフェース対応

### 処理の流れ

1. ページ番号の雛形にするポイントテキストを1つ選択（レイヤーは問いません）
2. ダイアログで開始番号・接頭辞・接尾辞などを設定
3. プレビューを確認
4. OKで全アートボードへページ番号を配置（キャンセルでプレビューを破棄）

### ダイアログ

| 項目 | 説明 |
| --- | --- |
| 接頭辞 | 番号の前に付ける文字列（例：`P.`） |
| 開始番号 | 先頭のアートボードに付ける番号 |
| ゼロ埋め | 総ページ数の桁数に合わせて `0` を補う（例：`1` → `01`） |
| 接尾辞 | 番号の後ろに付ける文字列（例：`ページ`） |
| 総ページ数を表示 | 「番号/総ページ数」の形式で表示（例：`3/12`） |

### キーボード操作

| キー | 動作 |
| --- | --- |
| ↑ / ↓ | 開始番号を1ずつ増減 |
| Shift + ↑ / ↓ | 開始番号を10の倍数へスナップ |
| Z | ゼロ埋めのON/OFF |
| A | 総ページ数を表示のON/OFF |

Z・Aは、接頭辞などの入力欄にフォーカスがあるときは文字入力が優先され、切り替わりません。

### 注意事項

- 対象はポイントテキストです。段落揃えなどの体裁変更は行いません。
- 接頭辞・接尾辞・開始番号の直接入力は、Tabキーや他のコントロールへのフォーカス移動で確定した時点でプレビューへ反映されます。
- プレビューおよび確定時、`_pagenumber` レイヤー上の既存テキストは雛形の複製で置き換えられます。
- `_pagenumber` レイヤーが元々存在しなかった場合、キャンセル時には削除されます。OK時はそのまま残ります。
