### 概要

- 選択した2つ以上のオブジェクトをいったんグループ解除してから、あらためて1つのグループにまとめます。
- 既存のグループに別のオブジェクトを足したいときに使います。

### 使い方

1. まとめたいオブジェクトと、追加先のグループを一緒に選択する
2. スクリプトを実行する

### 注意点

- 選択が2つ未満のときは何もしません。
- ダイアログはありません。
