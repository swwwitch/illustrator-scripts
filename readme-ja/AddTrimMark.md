アートボードまたは選択オブジェクトに対してトリムマークを作成し、「トンボ」レイヤーに配置してロックします。あわせて対象オブジェクトを複製し、ガイドに変換します。

### 紹介記事

- [【Illustrator】現在のアートボードにトンボを作成する｜DTP Transit 別館](https://note.com/dtp_tranist/n/n40e3e39cf9f2)
