# フォントサイズの調整

[![Direct](https://img.shields.io/badge/Direct%20Link-AdjustFontSize.jsx-ffcc00.svg)](https://github.com/swwwitch/illustrator-scripts/blob/master/jsx/text/AdjustFontSize.jsx)

[![Direct](https://img.shields.io/badge/Back%20to%20home-All%20scripts-cccccc.svg)](https://github.com/swwwitch/illustrator-scripts/blob/master/README.md)

---

### 概要

- 選択している文字を対象に、フォントサイズと水平比率／垂直比率を調整するスクリプト。
- 調整結果はライブプレビューで確認でき、キャンセルすれば開く前の状態に戻る。
- 「リセット」で調整を取り消せるほか、optionキー併用でサイズがばらついた文字列を先頭文字のサイズに統一できる。
- 文字ツールで範囲選択した場合はその文字だけ、選択ツールでテキストオブジェクトを選択した場合はその全文字が対象になる。

### 主な機能

- 「フォントサイズの調整」で数値を指定
  - フォントサイズ：ルーラー単位（環境設定の文字単位）で指定
  - 水平比率／垂直比率：1つの数値で両方をまとめて指定（%）
  - 見かけ：フォントサイズ×比率で計算した実際の見た目のサイズを表示（比率100%のときはディム表示）
  - 上下キーで数値を増減（shiftキーで10刻み、optionキーで0.1刻み／比率は5刻み）
- 「実サイズ↔見かけ」ボタンでサイズと比率を相互変換
  - 押すたびに、サイズ×比率を実フォントサイズへ焼き込んで比率100%にする／焼き込み前の比率付きの状態に戻す、を切り替え
  - サイズまたは比率を手入力すると、焼き込み前の状態は破棄される
- 「リセット」で調整を取り消し、開いた直後の状態に戻す
  - optionキーを押しながらクリックすると、選択している文字すべてを先頭文字のフォントサイズに統一し、水平比率・垂直比率を100%に揃えて適用
- 起動時は、選択している文字の先頭の実サイズ・比率を初期値として表示
- ポイント文字・エリア内文字、複数選択、文字ツールでの範囲選択に対応
- 日本語／英語の自動切り替え

### 処理の流れ

1. 選択している文字を取得し、先頭文字のフォントサイズ・比率を初期値としてダイアログを表示
2. 数値の変更に応じて、選択している文字にフォントサイズ・比率を適用してプレビュー
3. OKで確定（1回の操作としてUndo履歴に残る）、キャンセルで開く前の状態に戻す

### 対象外

- ドキュメントが開かれていない場合（何もせず終了）
- テキストが選択されていない場合（警告を表示して終了）
- ベースラインシフト・カーニング・トラッキング・文字揃え・自動カーニングの調整（AdjustTextScaleBaseline を使用）
