### 概要

- 選択している文字を対象に、フォントサイズと水平比率／垂直比率を調整する
- ライブプレビューで結果を確認しながら調整でき、キャンセルで開く前の状態に戻る
- 「実サイズ↔見かけ」でサイズ×比率の焼き込みと復元を切り替えられる
