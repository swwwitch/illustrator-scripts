# 基準にする側を決めて、間隔と位置をそろえる

[![Direct](https://img.shields.io/badge/Direct%20Link-AdjustPairGap.jsx-ffcc00.svg)](https://github.com/swwwitch/illustrator-scripts/blob/master/jsx/alignment/AdjustPairGap.jsx)

### 概要

選択したオブジェクトの間隔と位置を、指定した値にそろえます。［固定］で選んだ側は動かさず、残りだけを動かします。数値やオプションを変えるたびにアートボード上のプレビューが更新され、［OK］で表示どおりに確定します。

### 主な機能

- 3つのモード：グループ内の等間隔配置／最も近いもの同士のペア／アートボード端からのマージン
- ［固定］は上・左・右・下を十字に配置。左右を選ぶと水平方向、上下を選ぶと垂直方向の調整になります
- 間隔はマイナス値も指定でき、オブジェクトを重ねられます
- ［位置調整］パネルは1枚。［固定］で選んだ側に応じて水平／垂直が切り替わり、ラベルが左・右／上・下に入れ替わります
- 間隔の向きと直交する方向の整列（なし／左（上）／中央／右（下））と、整列後にさらにずらす［位置］
- テキストの行揃え（自動／左／中央／右／均等配置）をアイコンボタンで指定
- 「プレビュー境界」で、線幅や効果を含む見た目の境界と幾何境界を切り替え
- 数値欄は ↑↓ キーで増減（Shift で10単位、Option で0.1刻み）
- 整列のキーボードショートカット（水平方向のとき L / C / R、垂直方向のとき T / M / B）
- 単位はルーラーの単位に追従
- ダイアログの状態を記憶し、次回実行時に復元
- 日本語／英語UI

### 使い方

1. 対象のオブジェクトを2つ以上選択します。
2. スクリプトを実行します。
3. モード・［固定］・間隔を指定し、プレビューを確認して［OK］をクリックします。

### モード

| モード | 内容 |
| --- | --- |
| グループ | 選択した各グループの中身を、隣り合う間隔がすべて同じになるように並べます（3個以上も対応） |
| 自動ペア認識 | 選択オブジェクトを最も近いもの同士でペアにし、各ペアの間隔をそろえます |
| アートボード | ［固定］で選んだアートボードの端（上／左／右／下）を基準に、各選択オブジェクトとの間隔（マージン）をそろえます |

選択がすべてグループのときは「グループ」、それ以外は「自動ペア認識」が初期選択です（前回の設定が残っているときはそちらが優先されます）。

### オプション

**固定**

上・左・右・下を十字に並べたラジオです。選んだ側のオブジェクトは動かさず、そこを基準に残りを動かします。

| 選んだ側 | 間隔の向き | ［位置調整］の向き |
| --- | --- | --- |
| 左・右 | 水平 | 垂直 |
| 上・下 | 垂直 | 水平 |

**オフセット**

パネル名の括弧内は現在のルーラー単位です（`オフセット（mm）` など）。［位置調整］も同じ形式です。

| 項目 | 内容 |
| --- | --- |
| 間隔 | オブジェクト間の間隔。マイナスにすると重なります。初期値は選択オブジェクトの現在の平均間隔です |
| プレビュー境界 | ONで線幅や効果を含む見た目の境界、OFFで幾何境界を基準に測ります |

**位置調整**

パネルは1枚で、［固定］で選んだ向きと直交するほうに切り替わります。どちらの向きかは、ラジオのラベルが左・右（水平）か上・下（垂直）かで分かります。パネル名の括弧内は現在のルーラー単位です。水平と垂直の設定はそれぞれ別に覚えているので、［固定］を切り替えて戻すと元の内容に戻ります。

| 項目 | 内容 |
| --- | --- |
| 整列 | 動く側を、キーオブジェクトの左（上）／中央／右（下）にそろえます。「なし」で整列しません |
| 位置 | 整列後に、動く側をさらにずらす量（水平は正が右、垂直は正が下）。「中央」を選んでいるあいだは0固定です |

**テキストの行揃え**

5つのアイコンボタンで指定します。選択中のボタンは反転表示になります。

| ボタン | 内容 |
| --- | --- |
| A（自動） | エリア内文字は均等配置。ポイント文字は、縦並びなら［位置調整］の整列に、横並びなら［固定］の側（左／右）に合わせます |
| 左／中央／右／均等配置 | 選択したテキストすべてに同じ行揃えを適用します（均等配置は最終行左） |

### 注意点

- オブジェクトを2つ以上選択していないと実行できません。
- ［グループ］モードでは、グループでないオブジェクトと、子が2個未満のグループは対象外です。
- ［自動ペア認識］モードで選択数が奇数のときは、相手のいない1つが対象から外れます。
- ペアの組み合わせは常に幾何境界の中心で判定します。「プレビュー境界」は間隔の測り方だけを変えるもので、どれとどれを組むかには影響しません。
- クリップグループは、マスクで隠れた部分を含めないよう、クリッピングパスを基準に測ります。
- 行揃えを変えても、テキストの見た目の位置は保たれます（ポイント文字がアンカー基準でずれないよう、位置を戻しています）。
- ライブプレビューがそのまま結果になります。キャンセルすると、位置とテキストの行揃えを元に戻します。
- 整列のショートカット（L / C / R・T / M / B）は、⌘などの修飾キーと一緒に押したときは反応しません（⌘Cによるコピーなどを妨げないため）。
- 設定はIllustratorのセッション中はすべて記憶します。モードと間隔は選択内容に依存するため、Illustratorを再起動したときは選択から決め直します。
