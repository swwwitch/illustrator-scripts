### 概要

選択したオブジェクトを、アートボードを対象に整列する常駐パレットです。

- 整列: 7つのアイコンをクリックで即時実行。水平方向（左 / 中央 / 右）、水平垂直の中央、垂直方向（上 / 中央 / 下）。複数選択は一時的にグループ化して塊のまま動かします
- マージン: アートボードの四辺から内側へ均一に取る余白（単位は定規に追従）。上下左右の整列だけが影響を受け、中央揃えの3つは位置が変わりません
	- Option＋クリックでマージンを無視し、アートボードの辺にぴったり寄せます
	- 入力欄は ↑↓ で増減（Shift＝±10で10の倍数にスナップ／Option＝±0.1）。負の値は0に丸めます
- オプション
	- プレビュー境界: 線幅や効果を含む見た目の境界で整列（初期値OFF）
	- 字形の境界に整列: ポイント文字・エリア内文字をまとめてON/OFF（初期値ON）。Option＋クリックのときはOFFでもON扱い
	- 行揃えを変更: 水平方向の中央揃えのとき、1行だけのテキスト1つなら行揃えも中央揃えにする（初期値ON）。テキスト以外を選択しているとディムになります
- キーボード: Esc でパレットを閉じる
- パレット下部に実行結果（整列しました／未選択／エラーなど）を表示します

DOM を触る処理（選択取得・整列・マージンの移動・環境設定の書き込み）はメインエンジンへ BridgeTalk で委譲します。

### 処理の流れ

1. ドキュメントと選択を確認
2. 文字を選択している場合は、テキストオブジェクトを選択し直す
3. 選択が複数レイヤーにまたがっていないか確認
4. ［プレビュー境界］［字形の境界に整列］をチェックの状態どおりに環境設定へ書き込む
5. 選択を含むアートボードを現在のアートボードにする
6. 水平方向の中央揃えで、1行だけのテキスト1つなら、行揃えを中央揃えにする
7. 複数選択ならグループ化 → 整列コマンド → マージンぶん内側へ移動 → グループ解除

### メモ

- 整列の基準（選択範囲／キーオブジェクト／アートボード）は［整列］パネルの設定に従います。**［選択範囲に整列］のままだと、グループ化によって対象が1つになるため何も動きません。** ［アートボードに整列］に設定してから実行してください。
- マージンは、整列コマンドでアートボードの辺に寄せたあと、その位置から内側へ移動する方式です。移動量は固定値なので、プレビュー境界／幾何境界のどちらでもズレません。
- ［プレビュー境界］［字形の境界に整列］は起動時に環境設定を読みません。パレットのチェック状態を、整列のたびに環境設定へ書き込みます。常駐パレットからは環境設定の読み取りが信頼できないためです。
- 複数のレイヤーにまたがる選択で中止するのは、グループ化すると全オブジェクトが最前面オブジェクトのレイヤーへ移動し、グループ解除しても元のレイヤーに戻らないためです。
- グループ化とグループ解除の分だけ、取り消し（command + Z）のステップが増えます。
- 連結（スレッド）されたテキストの文字を選択して実行すると、そのストーリーに属するすべてのテキストオブジェクトが対象になります。
- 行揃えを中央揃えにするのは1行だけのテキストに限定しています。複数行のテキストで行揃えを変えると各行の位置が動き、見た目が大きく変わってしまうためです。エリア内文字で折り返して2行以上になっている場合も対象外です。
- ［行揃えを変更］のディムは「選択がテキストかどうか」で切り替えます。Illustrator にタイマーAPIがないため、パレットにフォーカスが戻ったときとパレット上でマウスを動かしたときに選択を取り直します。
- アートボードが複数あるドキュメントでは、選択と最も広く重なるアートボードに切り替えます。どのアートボードとも重ならない場合は、選択の中心に最も近いアートボードを使います。
- スクリプトを再実行すると、開いているパレットを閉じてから開き直します（多重起動防止）。修正したコードを反映するときもそのまま再実行できます。
- 中央揃えだけを単発で実行したい場合は [CenterAlignAsGroup](CenterAlignAsGroup.md)、天地中央だけなら [VerticalCenterAlignAsGroup](VerticalCenterAlignAsGroup.md) を使ってください。
