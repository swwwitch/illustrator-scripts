# ガイドやアートボードのエッジに整列

### 概要

選択したオブジェクトを、アートボードを対象に整列する常駐パレットです。方向ボタンで、ぶつかるガイドやアートボードの端へ寄せることもできます。［整列］パネルの整列先が［アートボード］でないときは、それを検出して何も動かさずに知らせます。

- 整列: 7つのアイコンをクリックで即時実行。水平方向（左 / 中央 / 右）、水平垂直の中央、垂直方向（上 / 中央 / 下）。複数選択は一時的にグループ化して塊のまま動かします
- 移動: 十字に並べた4つの方向ボタンで、その向きにあってぶつかるガイド、無ければアートボードの端へ寄せます。整列と違ってグループ化しないので、重ね順やレイヤーは変わりません
- マージンガイド: アートボードの四辺から内側へ均一に取る余白（単位は定規に追従）。上下左右の整列だけが影響を受け、中央揃えの3つと方向ボタンの移動では使いません
	- Option＋クリックでマージンを無視し、アートボードの辺にぴったり寄せます
	- 入力欄は ↑↓ で増減（Shift＝±10で10の倍数にスナップ／Option＝±0.1）。負の値は0に丸めます
	- ガイドを追加: マージンのぶんアートボードの内側に長方形のガイドを作ります。このガイドも方向ボタンの移動先になります
	- ガイドを保持: ONにするとパレットを閉じてもガイドを残します（初期値OFF）。［ガイドを追加］がOFFのあいだはディムしますが、チェックの状態は保たれます
- オプション
	- プレビュー境界: 線幅や効果を含む見た目の境界で整列（初期値OFF）
	- 字形の境界に整列: ポイント文字・エリア内文字をまとめてON/OFF（初期値ON）。Option＋クリックのときはOFFでもON扱い
	- この2つは整列のあいだだけ環境設定へ書き込み、終わったら元の設定に戻します
	- 行揃えを変更: 水平方向の整列に合わせて、1行だけのテキスト1つなら行揃えも変える（初期値ON）。左揃え→左揃え、水平方向中央→中央揃え、右揃え→右揃え。垂直方向の整列では変えません。テキストを選択していないときはディムになります
- キーボード: Esc でパレットを閉じる
- パレット下部に実行結果（整列しました／移動しました／未選択／整列先が違う／エラーなど）を表示します。幅に収まらない文言はマウスオーバーで全文を読めます

DOM を触る処理（選択取得・整列・移動・マージンの移動・環境設定の読み書き）はメインエンジンへ BridgeTalk で委譲します。

### 処理の流れ

整列アイコン:

1. ドキュメントと選択を確認
2. 文字を選択している場合は、テキストオブジェクトを選択し直す
3. 選択が複数レイヤーにまたがっていないか確認
4. 選択を含むアートボードを現在のアートボードにする
5. 現在の環境設定を控えたうえで、［プレビュー境界］［字形の境界に整列］をチェックの状態どおりに書き込み、再描画して整列コマンドに反映させる
6. 水平方向の整列で、1行だけのテキスト1つなら、行揃えを整列に合わせる
7. 複数選択ならグループ化 → 整列コマンド → 整列先の判定（アートボードでなければ行揃えを戻して中止）→ マージンぶん内側へ移動 → グループ解除
8. 再描画してから、控えておいた環境設定を元に戻す
9. ［字形の境界に整列］がONで、選択にテキストオブジェクトが含まれるなら、字形を実測して目標位置とのズレを打ち消す
10. ［ガイドを追加］がONなら、マージンの位置に長方形のガイドを作り直す

方向ボタン:

1. ドキュメントと選択を確認（文字を選択している場合はテキストオブジェクトを選択し直す）
2. 選択を含むアートボードを現在のアートボードにする
3. ［プレビュー境界］［字形の境界に整列］のチェックどおりに選択範囲の境界を測る（環境設定は書き換えない）
4. 動かす向きにあってぶつかるガイドを探し、見つかればそこ、無ければアートボードの端を移動先にする
5. その辺が移動先に乗るぶんだけ、選択したオブジェクトをそのまま動かす

### メモ

- 整列の基準（選択範囲／キーオブジェクト／アートボード）は［整列］パネルの設定に従います。**［選択範囲に整列］のままだと、グループ化によって対象が1つになるため何も動きません。** ［アートボードに整列］に設定してから実行してください。
- 整列先が［アートボード］以外のときは、それを検出して「整列先を［アートボード］にしてください。」と表示し、**マージンの移動も字形の境界の補正も行いません**（オブジェクトは動かず、変更した行揃えも元に戻します）。整列してもオブジェクトが動かなかったときだけ、いったん4ptずらして整列し直し、戻ってくるかどうかで判定しています。すでに正しい位置にあるオブジェクトは、この判定の前後で位置が変わりません。
- マージンは、整列コマンドでアートボードの辺に寄せたあと、その位置から内側へ移動する方式です。移動量は固定値なので、プレビュー境界／幾何境界のどちらでもズレません。
- ［プレビュー境界］［字形の境界に整列］は起動時に環境設定を読みません（常駐パレットからは読み取りが信頼できないため）。パレットのチェック状態は整列のあいだだけ環境設定へ書き込み、**終わったら元の設定に戻します**。とくに［プレビュー境界］は Illustrator 全体に効く設定なので、整列を実行しただけで環境設定が変わってしまわないようにしています。
- 環境設定を書いた直後と、元に戻す直前に `app.redraw()` を挟んでいます。整列コマンドが書き換え前の設定のまま実行されるのを避けるためです。
- ［字形の境界に整列］がONで、選択にテキストオブジェクトが含まれるときは、整列コマンドまかせにせず、**整列後に字形を実測して目標位置とのズレを打ち消します**。テキストオブジェクトは複製して `createOutline()` でアウトライン化した境界を測り（測ったら複製は削除）、それ以外は通常の境界を測って、選択全体を囲む境界とアートボードの辺＋マージンとの差だけ動かします。整列コマンド側で設定が効いていれば差は0になるので、二重に動くことはありません。
	- この補正のおかげで、**複数選択（一時グループ化で字形の境界が効かなくなるケース）でも字形の境界で寄ります**。
	- 対象はトップレベルのテキストオブジェクトだけです。グループの中に入っているテキストは通常の境界で測ります。
	- ［プレビュー境界］がONのときはアウトラインの `visibleBounds`、OFFのときは `geometricBounds` で測ります。
- 複数のレイヤーにまたがる選択で中止するのは、グループ化すると全オブジェクトが最前面オブジェクトのレイヤーへ移動し、グループ解除しても元のレイヤーに戻らないためです。
- グループ化とグループ解除の分だけ、取り消し（command + Z）のステップが増えます。グループ化と解除をはさむため、複数選択したオブジェクトの重ね順は、実行後に隣り合った並びへ詰められます（最前面のオブジェクトの位置に集まります）。
- 連結（スレッド）されたテキストの文字を選択して実行すると、そのストーリーに属するすべてのテキストオブジェクトが対象になります。
- 行揃えを変えるのは1行だけのテキストに限定しています。複数行のテキストで行揃えを変えると各行の位置が動き、見た目が大きく変わってしまうためです。エリア内文字で折り返して2行以上になっている場合も対象外です。
- ［行揃えを変更］のディムは「選択がテキストかどうか」で切り替えます。Illustrator にタイマーAPIがないため、パレットにフォーカスが戻ったときとパレット上でマウスを動かしたときに選択を取り直します。このとき選択の内容が変わっていれば、前回の実行結果の表示も消します。
- アートボードが複数あるドキュメントでは、選択と最も広く重なるアートボードに切り替えます。どのアートボードとも重ならない場合は、選択の中心に最も近いアートボードを使います。
- 方向ボタンの移動先は、選択範囲のその辺をガイドに合わせる位置です。ガイドが無ければアートボードの端まで動かします。マージンは使いません。
- 対象になるガイドは、**アクティブなアートボードの内側にあるもの**だけです。ルーラーから引いたガイドのほか、長方形などのガイドは向かい合う2辺（左右の移動なら左辺と右辺、上下なら上辺と下辺）を候補にします。
- **動かす向きと直交する方向で選択範囲と重ならないガイドは対象外です**（そのまま動かしてもぶつからないため）。左右に動かすときは上下の範囲が重なる縦のガイドだけ、上下に動かすときは左右の範囲が重なる横のガイドだけが候補になります。ルーラーのガイドはアートボードの外まで伸びているので、常に候補です。端が触れているだけ（重なりが0）のときは候補になりません。
- すでにその辺が乗っているガイドは移動先にしません（0.001pt以内は同じ位置とみなします）。手で吸着させた辺とガイドの座標は 1e-12 ほどずれていることがあり、そのままだと自分がいる位置を移動先に選んで動かなくなるためです。
- 動かす向きにガイドが無いときはアートボードの端まで動かします。ただし**選択範囲がガイド全体をまたいでいる（ガイドの間隔よりオブジェクトが大きい）ときだけ**は、戻る向きの最も近いガイドに合わせます。マージンガイドより大きいオブジェクトを、マージンの位置にそろえられるようにするためです。
- 移動でも境界の測り方は［プレビュー境界］［字形の境界に整列］のチェックに従います（テキストは複製をアウトライン化して実測）。ただし整列と違って環境設定は書き換えず、グループ化もしないので、取り消しは1ステップです。
- ガイドは「_guide」レイヤー（無ければ作成、ロック／非表示は解除）に、名前 `AiAlignToArtboard-margin` の長方形として作られます。作り直すたびに同じ名前の既存ガイドを消してから引き直すので、**アクティブなアートボードに常に1つ**です。アートボードを切り替えて整列すると、ガイドもそちらへ移ります。
- ガイドが描き直されるのは、［ガイドを追加］を切り替えたとき／マージン欄を確定したとき（Enter・フォーカス移動）／整列を実行したときです。↑↓キーで値を変えている最中は、ディムの切り替えだけを追従させています（1打鍵ごとにIllustratorへ問い合わせないため）。
- ［ガイドを追加］のチェックを外すとガイドは削除されます。**パレットを閉じるときにも削除します**（Escで閉じたとき、スクリプトの再実行で開き直すときも同じ）。残したい場合は［ガイドを保持］をONにしてください。「_guide」レイヤーの外へ移動したガイドは対象外です。
- 選択の種類・定規の単位・選択数は1往復でまとめて受け取ります。Illustrator から応答がなかったときやエラーが返ったときは、当てにならない値でディムや単位ラベルを書き換えず、そのままにします。
- DOM を触る処理は BridgeTalk でメインエンジンへ委譲しますが、BridgeTalk が使えない環境では、パレット側のエンジンでそのまま実行します。
- スクリプトを再実行すると、開いているパレットを閉じてから開き直します（多重起動防止）。修正したコードを反映するときもそのまま再実行できます。
- 中央揃えだけを単発で実行したい場合は [CenterAlignAsGroup](CenterAlignAsGroup.md)、天地中央だけなら [VerticalCenterAlignAsGroup](VerticalCenterAlignAsGroup.md) を使ってください。
