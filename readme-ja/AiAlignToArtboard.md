# ガイドやアートボードのエッジに整列

[![Direct](https://img.shields.io/badge/Direct%20Link-AiAlignToArtboard.jsx-ffcc00.svg)](https://github.com/swwwitch/illustrator-scripts/blob/master/jsx/alignment/AiAlignToArtboard.jsx)

### 概要

選択したオブジェクトを、アートボードを対象に整列する常駐パレットです。3×3のボタンで8方向へ寄せ、押すたびにガイド・アートボードのエッジ・裁ち落としへと寄せ先が進みます。マージンや分割のガイドも引けます。［整列］パネルの整列先が［アートボード］でないときは、それを検出して何も動かさずに知らせます。

- ボタン: 3×3のボタン（外周8つ＋中央）と、その下の中央揃え2つ。すべてクリックで即時実行します
	- 外周8つ: その向きにあってぶつかるガイド → アートボードのエッジ → 裁ち落とし の順に、押すたびに寄せ先が外へ進みます。斜めは水平・垂直の2辺へ同時に寄せます。複数選択は一時的にグループ化して塊のまま動かし、［行揃えを変更］も効きます
	- 中央: 水平・垂直方向中央に整列します。**Option＋クリックでアートボードの中央ではなく、マージンの内側の中央**に寄せます
	- 下の2つ: 水平方向中央 / 垂直方向中央に整列します。Option＋クリックはその軸だけマージンの内側の中央になります
	- アイコンは「寄せ先の辺のケイ線＋そこへ寄せたオブジェクト」で表しています。中央揃えの3つだけ、ケイ線がオブジェクトの中央を貫きます
- マージン: アートボードの四辺から内側へ取る余白を、上下左右それぞれ指定します（単位は定規に追従）。上下左右の整列だけが影響を受け、中央揃えの3つと方向ボタンの移動では使いません
	- Option＋クリックでマージンを無視し、アートボードの辺にぴったり寄せます
	- すでにマージンの位置に寄っているときにもう一度押すと、その外のアートボードのエッジまで寄せます（端まで出たあとは、押し直してもそこに留まります）
	- 入力欄は ↑↓ で増減（Shift＝±10で10の倍数にスナップ／Option＝±0.1）。負の値は0に丸めます
	- 4つの欄は十字（3×3）に並び、真ん中が［連動］です。ONのあいだは［上］の1つで4辺が決まるので、残りの3つはディムになります（初期値ON）。OFFにすると個別に指定できます
	- ［ガイドを追加］がOFFのあいだは、4つの欄と［連動］をまとめてディムにします（値はそのまま残ります）
	- 初期値は定規の単位ごとに決まっています（mm＝5、pt／px／Q＝20、cm＝0.5、inch＝0.25）。値を一度でも入力するまでは、定規の単位を変えるとその単位の初期値に入れ替わります
	- ［ガイドを追加］をONにすると［連動］も自動でONになり、4つの値がそろいます（四辺を均等に取ることが多いため）
	- 定規の単位は欄ごとではなく、パネル名（「マージン（mm）」）に出します
	- ガイドを追加: マージンのぶんアートボードの内側に長方形のガイドを作ります。このガイドも方向ボタンの移動先になります。**パレットを閉じてもガイドは残ります**
- 分割とエッジのガイド: マージンの内側を行・列に等分する位置と、アートボードの4辺にガイドを引きます。分割は［なし］［十字］［カスタム］から選びます
	- なし: 分割のガイドを引きません（初期値）
	- 十字: マージンの内側の中央に、縦横1本ずつの十字のガイドを引きます
	- カスタム: ［行数］［列数］のぶんだけ等分します。1のときは、その向きのガイドを引きません
	- 行間 / 列間: 段と段、列と列のあいだに空ける距離です。0より大きいと、区切りごとに2本のガイドを引きます（単位は定規に追従、［カスタム］のときだけ使えます）
	- 伸張: 分割のガイドをアートボードの外へ伸ばす距離です。0のときはアートボードの幅・高さいっぱいに引きます
	- アートボードのエッジ: アートボードの上下左右4辺にもガイドを引きます（伸張のぶんだけ外へ伸ばします）。分割の指定とは別に使えます
	- ガイドは「_guide」レイヤーに、名前 `AiAlignToArtboard-divide` で作られます。マージンガイドと同じく、描き直すたびに同じ名前の既存ガイドを消してから引き直します。方向ボタンの移動先にもなります
- オプション
	- プレビュー境界: 線幅や効果を含む見た目の境界で整列（初期値OFF）
	- 字形の境界に整列: ポイント文字・エリア内文字をまとめてON/OFF（初期値ON）。Option＋クリックのときはOFFでもON扱い。シンボルインスタンスも、中の文字を実測して字形の境界で寄せます
	- この2つは整列のあいだだけ環境設定へ書き込み、終わったら元の設定に戻します
	- 行揃えを変更: 水平方向の整列に合わせて、1行だけのテキスト1つなら行揃えも変える（初期値ON）。左揃え→左揃え、水平方向中央→中央揃え、右揃え→右揃え。垂直方向の整列では変えません。テキストを選択していないときはディムになります
	- 裁ち落としに整列: ONにすると、アートボードのエッジの**次の寄せ先**として、その外側の裁ち落としの位置が加わります（初期値OFF）。量はスクリプト冒頭の `BLEED_MM`（初期値3mm）で指定します。印刷の値なので定規の単位には追従しません
	- アートボードごと: ONにすると、選択したオブジェクトを**それぞれが乗っているアートボード**に整列します（初期値OFF）。同じアートボードにあるものどうしは、これまでどおり塊のまま動きます。外周ボタンにも効きます。アートボードが1つしかないドキュメントではディムになります
- キーボード: Esc でパレットを閉じる／↑↓←→ で上下左右の方向ボタンを実行（斜めの4つにキーはありません）／C で左右中央・M で上下中央・X で上下左右中央に整列／B で［裁ち落としに整列］をON/OFF
- パレット下部に実行結果（整列しました／寄せました／未選択／整列先が違う／エラーなど）を表示します。幅に収まらない文言はマウスオーバーで全文を読めます

DOM を触る処理（選択取得・整列・移動・マージンの移動・環境設定の読み書き）はメインエンジンへ BridgeTalk で委譲します。

### 処理の流れ

中央揃えのボタン:

1. ドキュメントと選択を確認
2. 文字を選択している場合は、テキストオブジェクトを選択し直す
3. 選択が複数レイヤーにまたがっていないか確認
4. 選択を含むアートボードを現在のアートボードにする
5. いま乗っている寄せ先（マージン → アートボードのエッジ → 裁ち落とし）の次を、この回の寄せ先にする
6. 現在の環境設定を控えたうえで、［プレビュー境界］［字形の境界に整列］をチェックの状態どおりに書き込み、再描画して整列コマンドに反映させる
7. 水平方向の整列で、1行だけのテキスト1つなら、行揃えを整列に合わせる
8. 複数選択ならグループ化 → 整列コマンド → 整列先の判定（アートボードでなければ行揃えを戻して中止）→ マージンぶん内側へ移動 → グループ解除
9. 再描画してから、控えておいた環境設定を元に戻す
10. ［字形の境界に整列］がONで、選択にテキストオブジェクトかシンボルが含まれるなら、字形を実測して目標位置とのズレを打ち消す
11. ［ガイドを追加］がONなら、マージンの位置に長方形のガイドを作り直す

方向ボタン:

1. ドキュメントと選択を確認（文字を選択している場合はテキストオブジェクトを選択し直す）
2. 選択が複数レイヤーにまたがっていないか確認
3. 選択を含むアートボードを現在のアートボードにする
4. 左右へ寄せるときで、1行だけのテキスト1つなら、行揃えを寄せる向きに合わせる（境界を測る前に変える。ポイント文字は行揃えを変えると文字が動くため）
5. ［プレビュー境界］［字形の境界に整列］のチェックどおりに選択範囲の境界を測る（環境設定は書き換えない）
6. 動かす向きにあってぶつかるガイドを探し、見つかればそこ、無ければアートボードのエッジ（すでに端に乗っていて［裁ち落としに整列］がONなら、その外の裁ち落とし）を移動先にする（斜めは水平・垂直それぞれで探す）
7. 複数選択ならグループ化 → その辺が移動先に乗るぶんだけ動かす（斜めは2軸ぶんをまとめて1回）→ グループ解除

### メモ

- 整列の基準（選択範囲／キーオブジェクト／アートボード）は［整列］パネルの設定に従います。**［選択範囲に整列］のままだと、グループ化によって対象が1つになるため何も動きません。** ［アートボードに整列］に設定してから実行してください。
- 整列先が［アートボード］以外のときは、それを検出して「整列先を［アートボード］にしてください。」と表示し、**マージンの移動も字形の境界の補正も行いません**（オブジェクトは動かず、変更した行揃えも元に戻します）。整列してもオブジェクトが動かなかったときだけ、いったん4ptずらして整列し直し、戻ってくるかどうかで判定しています。すでに正しい位置にあるオブジェクトは、この判定の前後で位置が変わりません。
- マージンは、整列コマンドでアートボードの辺に寄せたあと、その位置から内側へ移動する方式です。移動量は固定値なので、プレビュー境界／幾何境界のどちらでもズレません。
- 使うマージンは、寄せる辺で決まります。左揃えは［左］、右揃えは［右］、上揃えは［上］、下揃えは［下］です。中央揃えの3つはどれも使いません。
- 上下左右の整列と方向ボタンは、押すたびに**内側から外側へ順に寄せ先が進みます**。ガイド（マージンガイドを含む）→ アートボードのエッジ → 裁ち落とし、の順です。値を入れていない段は飛ばし、いちばん外まで出たあとは押し直してもそこに留まります。判定は［プレビュー境界］［字形の境界に整列］と同じ測り方で行います。マージンを使わない中央揃えの3つは変わらず、Option＋クリックは段階を踏まずアートボードのエッジへ寄せます。
- ［裁ち落としに整列］はガイドを作りません。寄せ先の段が1つ増えるだけです。
- ［アートボードごと］がONのときは、選択を**アートボードごとに束ねて**、束ごとに整列・移動します。束の中では従来どおり一時グループ化して塊のまま動かし、最後に元の選択へ戻します。1つの束で失敗したら、そこで止めて理由を表示します。
- **裁ち落としの値は Illustrator から読み取れません。** ドキュメント設定の裁ち落としは DOM に公開されておらず（`Document` のプロパティにも `Artboard` にも無く、XMPにも記録されません）、手入力で持つしかないためです。
- ［プレビュー境界］［字形の境界に整列］は起動時に環境設定を読みません（常駐パレットからは読み取りが信頼できないため）。パレットのチェック状態は整列のあいだだけ環境設定へ書き込み、**終わったら元の設定に戻します**。とくに［プレビュー境界］は Illustrator 全体に効く設定なので、整列を実行しただけで環境設定が変わってしまわないようにしています。
- 環境設定を書いた直後と、元に戻す直前に `app.redraw()` を挟んでいます。整列コマンドが書き換え前の設定のまま実行されるのを避けるためです。
- ［字形の境界に整列］がONで、選択にテキストオブジェクトかシンボルが含まれるときは、整列コマンドまかせにせず、**整列後に字形を実測して目標位置とのズレを打ち消します**。テキストオブジェクトは複製して `createOutline()` でアウトライン化した境界を測り（測ったら複製は削除）、それ以外は通常の境界を測って、選択全体を囲む境界とアートボードの辺＋マージンとの差だけ動かします。整列コマンド側で設定が効いていれば差は0になるので、二重に動くことはありません。
	- この補正のおかげで、**複数選択（一時グループ化で字形の境界が効かなくなるケース）でも字形の境界で寄ります**。
	- **シンボルインスタンスも対象です。** Illustrator の［字形の境界に整列］はシンボルに効かないため、シンボルをレイヤー直下に複製してリンクを解除し、中のテキストを `createOutline()` でアウトライン化して境界を測ります（測ったら複製は削除し、選択も元に戻します）。中に文字が無ければ、シンボルの通常の境界をそのまま使います。
	- 対象はトップレベルのテキストオブジェクトとシンボルインスタンスだけです。グループの中に入っているテキストは通常の境界で測ります。
	- ［プレビュー境界］がONのときはアウトラインの `visibleBounds`、OFFのときは `geometricBounds` で測ります。
- 複数のレイヤーにまたがる選択で中止するのは、グループ化すると全オブジェクトが最前面オブジェクトのレイヤーへ移動し、グループ解除しても元のレイヤーに戻らないためです。
- グループ化とグループ解除の分だけ、取り消し（command + Z）のステップが増えます。グループ化と解除をはさむため、複数選択したオブジェクトの重ね順は、実行後に隣り合った並びへ詰められます（最前面のオブジェクトの位置に集まります）。
- 連結（スレッド）されたテキストの文字を選択して実行すると、そのストーリーに属するすべてのテキストオブジェクトが対象になります。
- 行揃えを変えるのは1行だけのテキストに限定しています。複数行のテキストで行揃えを変えると各行の位置が動き、見た目が大きく変わってしまうためです。エリア内文字で折り返して2行以上になっている場合も対象外です。
- ［行揃えを変更］のディムは「選択がテキストかどうか」、［アートボードごと］のディムは「アートボードが2つ以上あるかどうか」で切り替えます。Illustrator にタイマーAPIがないため、パレットにフォーカスが戻ったときとパレット上でマウスを動かしたときに選択を取り直します。このとき選択の内容が変わっていれば、前回の実行結果の表示も消します。
- アートボードが複数あるドキュメントでは、選択と最も広く重なるアートボードに切り替えます。どのアートボードとも重ならない場合は、選択の中心に最も近いアートボードを使います。
- ↑↓←→ キーは上下左右の方向ボタンを、C・M・X キーは中央揃えのアイコンを押したのと同じ動きをします。B キーは［裁ち落としに整列］のチェックを切り替えます。**入力欄にフォーカスがあるときは打鍵が優先**されるので、マージンや裁ち落としを打ち込んでいる最中に動いてしまうことはありません。command（Ctrl）を押しているあいだも横取りしません。
- 外周ボタンの移動先は、選択範囲のその辺をガイドに合わせる位置です。ガイドが無ければアートボードのエッジまで動かします。マージン欄の値そのものは使いません。［ガイドを追加］がONなら、まずマージンガイドで止まり、もう一度押すとその外のアートボードのエッジ、［裁ち落としに整列］がONならさらにその外の裁ち落としまで動きます。
- 斜めの4つは、水平・垂直の2辺ぶんの移動量を**どちらも動かす前の境界から**求めて、1回で動かします。先に片方だけ動かすと、もう一方のガイド探しが動いたあとの位置で走ってしまうためです。
- 対象になるガイドは、**アクティブなアートボードの内側にあるもの**だけです。ルーラーから引いたガイドのほか、長方形などのガイドは向かい合う2辺（左右の移動なら左辺と右辺、上下なら上辺と下辺）を候補にします。
- **動かす向きと直交する方向で選択範囲と重ならないガイドは対象外です**（そのまま動かしてもぶつからないため）。左右に動かすときは上下の範囲が重なる縦のガイドだけ、上下に動かすときは左右の範囲が重なる横のガイドだけが候補になります。ルーラーのガイドはアートボードの外まで伸びているので、常に候補です。端が触れているだけ（重なりが0）のときは候補になりません。
- すでにその辺が乗っているガイドは移動先にしません（0.001pt以内は同じ位置とみなします）。手で吸着させた辺とガイドの座標は 1e-12 ほどずれていることがあり、そのままだと自分がいる位置を移動先に選んで動かなくなるためです。
- 動かす向きにガイドが無いときはアートボードのエッジまで動かします。ただし**選択範囲がガイド全体をまたいでいる（ガイドの間隔よりオブジェクトが大きい）ときだけ**は、戻る向きの最も近いガイドに合わせます。マージンガイドより大きいオブジェクトを、マージンの位置にそろえられるようにするためです。
- クリップグループは、**マスクのパスの境界で測ります**。Illustrator の DOM が返すクリップグループの境界はマスクを無視した中身全体になるため、そのままだと方向ボタンの移動先がずれます（中央揃えの3つは整列コマンドがマスクで揃えるので、もともとパスに合っています）。マスクが複合パスの場合も対象です。マスクが見つからないときは通常の境界を使います。
- 外周ボタンでも境界の測り方は［プレビュー境界］［字形の境界に整列］のチェックに従います（テキストは複製をアウトライン化して実測）。中央揃えと違って環境設定は書き換えませんが、複数選択のときは同じように一時的にグループ化します。
- ガイドは「_guide」レイヤー（無ければ作成、ロック／非表示は解除）に、名前 `AiAlignToArtboard-margin` の長方形として作られます。ガイドに変換できなかったときは、塗りや線を持ったオブジェクトとして残さずに削除します。作り直すたびに同じ名前の既存ガイドを消してから引き直すので、**アクティブなアートボードに常に1つ**です。アートボードを切り替えて整列すると、ガイドもそちらへ移ります。
- ガイドが描き直されるのは、［ガイドを追加］を切り替えたとき／マージン欄や分割ガイドの欄を確定したとき（Enter・フォーカス移動）／分割の仕方や［アートボードのエッジ］を切り替えたとき／整列を実行したときです。↑↓キーで値を変えている最中は、ディムの切り替えだけを追従させています（1打鍵ごとにIllustratorへ問い合わせないため）。
- ガイドは**パレットを閉じても残ります**（Escで閉じたときも、スクリプトを再実行して開き直したときも同じ）。消したいときは［ガイドを追加］のチェックを外す、分割を［なし］にする、［アートボードのエッジ］を外す、のいずれかで消えます。「_guide」レイヤーの外へ移動したガイドは対象外です。
- 選択の種類・定規の単位・選択数は1往復でまとめて受け取ります。Illustrator から応答がなかったときやエラーが返ったときは、当てにならない値でディムや単位ラベルを書き換えず、そのままにします。
- DOM を触る処理は BridgeTalk でメインエンジンへ委譲しますが、BridgeTalk が使えない環境では、パレット側のエンジンでそのまま実行します。
- スクリプトを再実行すると、開いているパレットを閉じてから開き直します（多重起動防止）。修正したコードを反映するときもそのまま再実行できます。
- 中央揃えだけを単発で実行したい場合は [CenterAlignAsGroup](CenterAlignAsGroup.md)、天地中央だけなら [VerticalCenterAlignAsGroup](VerticalCenterAlignAsGroup.md) を使ってください。
