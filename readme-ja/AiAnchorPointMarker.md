パスの解説図をつくるとき、アンカーポイントの位置を「見せる」必要が出てきます。Illustrator の画面上では小さな四角が表示されていても、それはあくまで編集用の表示なので、書き出した画像やプリントには残りません。結局、四角形をひとつ描いてコピーし、アンカーの上に手で並べていくことになります。

このスクリプトは、その並べる作業を引き受けます。選択したオブジェクトのアンカーポイントをすべて拾い、指定した大きさ・カラーの正方形（あるいは自分で用意したオブジェクトやシンボル）を1つずつ配置します。

置くものと置き方はダイアログで決めますが、**設定を変えるたびに実際のアートボード上へ描画される**ので、閉じる前に仕上がりを確認できます。

## 使い方

1. 対象のオブジェクトを選択（グループや複合パスのままでOK）
2. スクリプトを実行
3. プレビューを見ながら、置くもの・大きさ・カラー・オプションを調整
4. ［OK］

パスを含まないオブジェクト（テキストや画像だけ）を選択している場合は、その旨を表示して終了します。

実行中はエッジ（アンカーポイントの表示）とライブコーナー注釈が一時的に隠れます。プレビューの正方形とIllustrator側の表示が重なって見分けがつかなくなるためで、終了時に元へ戻ります。

## 追加するオブジェクト

| 種類 | 置かれるもの |
| --- | --- |
| アンカーポイントを自動生成 | 指定した大きさ・カラーの正方形 |
| 最前面のオブジェクト | 選択範囲内でいちばん前面にあるオブジェクトの複製 |
| シンボル | ドキュメント内のシンボルのインスタンス |

「最前面のオブジェクト」は、**選択範囲の中で**最前面のものを探します。ドキュメントを前面から走査して最初に見つかった「選択されている」アイテムを複製元とするため、たまたま手前にある未選択のオブジェクトが使われることはありません。非表示・ロックされたレイヤーも走査から外れます。

複製元になったオブジェクト自身のアンカーポイントは、配置先から除外されます。四角形とパスを2つ選んで実行したとき、四角形の4隅にまで四角形が乗ってしまわないようにするためです。オブジェクトが1つしか選択されていないときは、複製元を除くと配置先が無くなるので、この項目は選べません。

「シンボル」は、ドキュメントにシンボルが1つも登録されていなければ選べません。

## アンカーポイント（正方形の設定）

「アンカーポイントを自動生成」を選んだときの設定です。

**大きさ**は pt で指定します。小数も入力でき、↑↓キーで ±1、Shift + ↑↓ で ±10（10単位にスナップ）、⌘ + ↑↓ で ±0.1 動きます。

**カラー**は［選択...］ボタンから、R / G / B のスライダーと数値入力で決めます。Illustrator/OS 標準のカラーピッカーではなくスクリプト内蔵のダイアログを使っているのは、モーダルダイアログの上から標準のカラーパレットを開くと、親ダイアログの操作が戻らなくなる環境があるためです。初期値は RGB(79, 128, 255) です。

**シンボル化**（初期状態でオン）をオンにすると、その設定の正方形をシンボルとして登録し、インスタンスを配置します。あとから「アンカーポイントの色を変えたい」というときに、シンボルを編集するだけで全部が変わります。

シンボルは実行のたびに新規登録されます。既存の同名シンボルを再利用しないので、前回と違う大きさ・カラーで実行しても、以前のマーカーが巻き添えで変わることはありません。同名のシンボル（「アンカーポイント」）が既にある場合は、名前だけIllustratorの既定名のままになります。

## オプション

| 項目 | 内容 |
| --- | --- |
| スケール | 「最前面のオブジェクト」「シンボル」の拡大縮小率（%） |
| レイヤーに移動 | 配置したマーカーを「_anchorpoint」レイヤーへ移動（無ければ作成） |
| グループ化 | 配置したマーカーを1つのグループにまとめる（初期状態でオン） |
| 基準点 | マーカーのどの位置をアンカーポイントに合わせるか（3×3） |

「アンカーポイントを自動生成」のときは、**スケールと基準点がディム**になります。大きさを pt で直接指定しているのでスケールは常に100%であり、基準点も中央に固定されます（正方形の中心をアンカーに合わせる、以外の選択肢に意味がないため）。

基準点は、たとえば左上のセルを選べば、マーカーの左上角がアンカーポイントに来ます。矢印やラベルのように「アンカーの右上に添えたい」オブジェクトを配置するときに使います。

グループ化とレイヤー移動を両方オンにした場合は、**グループにまとめてからレイヤーへ移動**します。バラバラのオブジェクトが個別に移動していくことはありません。

実行後は、配置したマーカー（グループ化していればそのグループ）が選択された状態になります。そのまま移動や整列に移れます。

## ライブプレビュー

プレビューは専用のレイヤー（`__ANCHOR_MARKER_PREVIEW__`）に描かれます。ダイアログの値を変えるたびに、このレイヤーごと破棄して描き直す仕組みです。

削除はレイヤー名ではなく**生成したレイヤーの参照**を持っておこないます。同じ名前のレイヤーがドキュメントに残っていたとしても、スクリプトが作ったもの以外を消すことはありません。OK でもキャンセルでも、本処理の前に必ず片付けます。

なお、プレビュー中は「シンボル化」がオフとして描かれます。プレビューのたびにシンボルを登録するとシンボルパネルが一時ファイルだらけになるためで、見た目（大きさ・カラー・位置）は本適用と同じです。

## 対象

PathItem、CompoundPathItem、GroupItem（いずれも再帰的にアンカーポイントを収集）

グループや複合パスは中身まで辿ります。テキストや配置画像は、パスを持たないためアンカーの収集対象になりません。

## 補足

ダイアログは日本語／英語のUIに追従します。3×3の基準点ウィジェットはラジオボタンではなく自前で描画しており、Illustrator のUI輝度設定を見てライト／ダークで配色を切り替えます。
