## 概要

選択したシンボルインスタンスのリンクを解除し、通常のオブジェクトとして扱える状態にするスクリプトです。

Illustratorの［シンボルへのリンクを解除］は、staticシンボルとdynamicシンボルで結果の構造が変わり、サブレイヤーやネストしたグループが残ります。このスクリプトは、どちらの場合も扱いやすいグループまたは単体オブジェクトに整えたうえで、名前を付けます。

## 主な機能

- 選択範囲内のシンボルを、グループ内も含めてまとめて処理
- staticシンボル／dynamicシンボルの解除結果を、グループまたは単体オブジェクトに整理
- 1アイテムだけのグループを自動的に解除
- 解除結果グループを、ネストごと完全に解除
- 解除後の名前に、元のシンボル名を引き継ぎ
- 名前に `symbol_unlinked_` などの接頭辞を付与
- 解除結果が単一テキストの場合、その内容を名前に（シンボル名より優先）
- 処理後は、解除後に生成されたオブジェクトを選択状態に
- 全コントロールにツールチップ
- 日本語／英語UI

## 使い方

1. シンボルインスタンスを選択します（グループの中にあるシンボルも対象になります）。
2. `AiBreakLink.jsx` を実行します。
3. ダイアログでオプションを設定します。
4. ［OK］をクリックして実行します。

## ［オプション］パネル

| 項目 | 内容 |
| --- | --- |
| 1アイテムだけのグループを解除 | 解除後に中身が1つだけのグループができた場合、そのグループを外して単体オブジェクトにします。 |
| グループを完全に解除 | 解除結果のグループを、ネストも含めて完全に解除します。グループに付けた名前は失われます。 |

- ［グループを完全に解除］がONのときは、［1アイテムだけのグループを解除］はディム表示になります。

## ［解除後の名前］パネル

| 項目 | 内容 |
| --- | --- |
| 元のシンボル名を使う | 解除後のオブジェクト名に、元のシンボル名を引き継ぎます。 |
| 名前の接頭辞 | シンボル名の前に付ける文字列。初期値は `symbol_unlinked_` です（例: `symbol_unlinked_ボタン`）。 |
| 単一テキストは内容を名前にする | 解除結果が1つのテキストのとき、その内容をオブジェクト名にします。元のシンボル名より優先されます。 |

- ［グループを完全に解除］がONのときは、名前を付けるコンテナ自体が残らないため、［元のシンボル名を使う］と［名前の接頭辞］はディム表示になります。
- テキストの内容に改行が含まれる場合は、半角スペースに置き換えます。

## 設定変数

スクリプト冒頭の「ユーザー設定」で初期値を変更できます。

| 変数 | 初期値 | 内容 |
| --- | --- | --- |
| `SHOW_OPTIONS_DIALOG` | `true` | 起動時にオプションダイアログを表示するかどうか。`false` にすると以下の初期値のまま実行します。 |
| `UNGROUP_SINGLE_ITEM_GROUP_DEFAULT` | `true` | ［1アイテムだけのグループを解除］の初期値 |
| `UNGROUP_ALL_DEFAULT` | `false` | ［グループを完全に解除］の初期値 |
| `INHERIT_SYMBOL_NAME_DEFAULT` | `true` | ［元のシンボル名を使う］の初期値 |
| `USE_PREFIX_DEFAULT` | `true` | ［名前の接頭辞］の初期値 |
| `UNLINKED_ITEM_NAME_PREFIX_DEFAULT` | `"symbol_unlinked_"` | 接頭辞の初期値 |
| `USE_TEXT_CONTENT_AS_NAME_DEFAULT` | `true` | ［単一テキストは内容を名前にする］の初期値 |
| `MAX_UNGROUP_ITERATIONS` | `50` | ネストしたグループを解除する際の反復回数の上限 |

## 注意事項

- ドキュメントが開かれていない場合、オブジェクトが選択されていない場合、選択範囲にシンボルが含まれていない場合は、何もせずに終了します。
- ロックまたは非表示のシンボルインスタンスはスキップします。
- 処理後は**元の選択は復元されません**。解除後に生成されたオブジェクトが選択状態になります。
- staticシンボルの解除ではサブレイヤーが生成されます。このスクリプトは、そのサブレイヤーを親レイヤー直下のグループに変換してから整理します。**サブレイヤーの名前は失われます。**
- dynamicシンボルの解除結果は、［ungroup］を繰り返してネストを平坦化してからグループにまとめます。ネストが深い場合に備えて、反復回数の上限（`MAX_UNGROUP_ITERATIONS`）を設けています。
- 解除結果が複数のオブジェクトになる場合はグループにまとめ、1つの場合はそのまま扱います。名前はそのグループまたはオブジェクトに付きます。
- ［グループを完全に解除］がONのときは、名前を付けたあとにグループを解除するため、**個々のオブジェクトには名前が残りません。**
- 処理中にエラーが起きた場合は、ExtendScript のコンソールにログを出力し、可能な範囲でほかのシンボルの処理を続行します。
