# キーオブジェクトから各図形へコネクターを引く

### 概要

キーオブジェクトを起点に、ほかの選択オブジェクトそれぞれへコネクターを引きます。経路の形・線・線端・矢印を指定でき、変更するたびにアートボード上のプレビューが更新され、［OK］で表示どおりに確定します。作成したコネクターは「コネクター」レイヤーにまとめられます。

### 主な機能

- 5つの経路：直線／ワープ／カギ／分岐／カーブ
- 開始ポイント3種：各辺の中心／等分／中心
- ［開始点をまとめる］で全コネクターを同じ位置から出し、その位置を9分割ウィジェットで指定
- 分岐は幹1本と枝に分けて作成し、枝どうしが重ならない
- カギ・分岐の折れ位置は、選択オブジェクトにかからない位置へ自動でずらす
- 線幅・角の形状・破線（破線／ドット）・線端（なし／丸形／突出）
- ［線］パネルの矢印（矢印8・矢印11・黒丸・白丸）をアイコンで指定。倍率・先端・位置も設定
- 終点と相手の図形とのすき間（余白）
- キーオブジェクトが未設定のときは、起点にするオブジェクトを9分割の位置で選ぶダイアログ
- 現在の設定をプリセットとして保存・削除
- ライブプレビュー。キャンセルすると作成したコネクターを破棄
- セッション中は最後の設定を記憶
- 日本語／英語UI

### 使い方

1. 2つ以上のオブジェクトを選択し、基準にしたいものをもう一度クリックしてキーオブジェクトにします。
2. スクリプトを実行します。
3. 形状・線・矢印を指定し、プレビューを確認して［OK］をクリックします。

キーオブジェクトが未設定のときは、先に［起点にするオブジェクト］ダイアログが開きます。3×3のマスのどこかを押すと、選択範囲のその位置にいちばん近いオブジェクトが起点になります。［ダイアログを閉じて手動で選ぶ］でいったん閉じ、キーオブジェクトを設定してから実行し直すこともできます。選択が2つのときは、キーオブジェクトがなくても左側が起点になります。

### オプション

**コネクター**

| 項目 | 内容 |
| --- | --- |
| 形状 | 直線／ワープ／カギ／分岐／カーブ |
| 種類 | ワープの種類（でこぼこ／絞り込み） |
| カーブ | ワープの曲がり具合と、カーブのふくらみ（−100〜100%）。マイナスで向きが逆になります |
| 方向 | ワープの軸。「自動」は全コネクターをまとめて水平／垂直を選びます |
| 角丸 | カギ・分岐の角を丸める半径（pt）。0で角丸なし |
| 開始ポイント | 各辺の中心／等分／中心 |
| 開始点をまとめる | すべてのコネクターをキーオブジェクトの同じ位置から出します |
| 9分割ウィジェット | まとめるときの開始位置。［開始点をまとめる］がONのときだけ操作できます |

**開始ポイント**

| 項目 | 内容 |
| --- | --- |
| 各辺の中心 | キーオブジェクトの辺の中央から引きます |
| 等分 | 同じ辺から出るコネクターの本数＋1でその辺を等分し、起点をずらします |
| 中心 | キーオブジェクトの中心から相手へ向かう向きで、起点を辺の上に置きます |

［開始点をまとめる］をONにすると、すべてのコネクターをキーオブジェクトの同じ位置から出します。1本の幹から枝分かれする図になります。位置は右の9分割ウィジェットで選びます。

| 押した位置 | 使う辺 |
| --- | --- |
| 中央 | 本数のいちばん多い辺（自動） |
| 上中央／下中央 | 上辺／下辺 |
| 左中央／右中央 | 左辺／右辺 |
| 四隅 | その高さの左辺／右辺 |

**線**

| 項目 | 内容 |
| --- | --- |
| 線幅 | 線の太さ（pt） |
| 角の形状 | マイター／ラウンド／ベベル。カギ・分岐の折れ角に効きます |
| 破線 | なし／破線／ドット |
| 分割数 | 線分の数（破線のみ）。両端が線分で終わるように線分の長さを計算します |
| 間隔 | 線分（ドット）どうしのすき間。ドットでは両端にドットが乗るよう、指定に近い間隔へそろえます |

**線端と矢印**

| 項目 | 内容 |
| --- | --- |
| 形状 | アイコン5個：なし／矢印8／矢印11／黒丸／白丸 |
| 倍率 | 矢印の大きさ（%）。線幅に対する比率です |
| 先端 | 終点（キーオブジェクトと反対側）／両端 |
| 位置 | 終点に／終点から |
| 余白 | 終点と相手の図形とのすき間（pt） |
| 線端 | なし／丸形／突出 |

矢印を選び直すと、その矢印に合わせて倍率・位置・線端が切り替わります（黒丸・白丸は丸形、矢印はなし）。破線で「ドット」を選んだときも、点が出るよう線端が丸形になります。

**プリセット**

現在の設定に名前を付けて保存できます。保存先はユーザーの設定フォルダー（`AiConnectorBuilder/presets.json`）です。

### 注意点

- 2つ以上のオブジェクトを選択していないと実行できません。
- キーオブジェクトの検出は、整列コマンドを試して動かないものを探す方法です。判定中は画面を再描画しないので、オブジェクトが動く様子は表示されず、取り消し履歴にも残りません。位置は元に戻します。
- 実行中はスマートガイドを一時的にオフにし、終了時に元へ戻します。
- 矢印はDOMから設定できないため、一時的なアクションを作って実行しています。白丸は黒丸の矢印に白い円を重ねたもので、白い円は倍率に合わせて大きさが変わり、その線とグループになります。
- コネクターは「コネクター」レイヤー（英語UIでは Connector）に作成します。同名のレイヤーがあればロック・表示を一時的に解除して使い、キャンセル時は元の状態に戻します。
- ライブプレビューがそのまま結果になります。キャンセル／ESC／ウィンドウを閉じたときは、作成したコネクターを破棄します。
- 分岐では、幹の前後それぞれでいちばん遠い枝が背骨を兼ね、手前の枝は横線だけになります。
- ワープの方向を「自動」にすると全コネクターで同じ軸を選びます（線ごとに軸を変えるとアピアランスが混在するためです）。
- カギ・分岐の折れ位置は、選択オブジェクトにかからない位置へ自動でずらします。すき間の外まで押し出されるときは、よけずにもとの位置のままです。
- カーブは、中点を線と垂直な向きへふくらませた弧です。ふくらみは線の長さに比例するため、長いコネクターほど大きく曲がります。ふくらむ側は進行方向を基準にするので、キーオブジェクトから放射状に伸びる線は同じ回り方にそろいます。
