### 概要

波括弧（カーリーブラケット）のパスを作成します。半径・長さ・線の設定を変えるたびにアートボード上のプレビューが更新され、［作成］で表示どおりに確定します。オブジェクトを選択して実行すると、その大きさと向きを初期値にして選択範囲の辺に沿わせます。

### 主な機能

- 上下左右の4方向。中央の突起の向きを選ぶだけで、内部の座標をまとめて回転
- 半径を「中央（突起）」と「両端（折り返し）」に分けて指定。［連動］をONにすると両端が中央に追従（両端の欄はディム表示）
- 「直線の長さ」はブラケット全体の長さ。半径を変えても総長は変わらず、直線部分が自動で伸縮
- 「中央の位置」で中央の突起を長さ方向にずらせます（全長は保ったまま）
- 両端から外側へ伸ばす「延長」
- 線の太さ・線端（なし／丸型）・角の形状（マイター結合／ラウンド結合）。線端を切り替えると角の形状も追従
- 選択オブジェクトを基準にした自動配置と「余白」
- 作成したブラケットには目印を付け、選び直して実行すると同じ位置・同じ向きで描き直し
- 数値欄は ↑↓ キーで増減（Shift で10単位、Option で0.1刻み）
- ダイアログの状態をIllustratorのセッション中だけ記憶し、次回実行時に復元
- 日本語／英語UI

### 使い方

1. 基準にするオブジェクトを選択します（選択なしでも実行できます）。
2. スクリプトを実行します。
3. 数値やオプションを変更し、アートボード上のプレビューを確認して［作成］をクリックします。

### 選択と配置

実行時の選択によって、扱いが変わります。

| 選択 | 扱い |
| --- | --- |
| このスクリプトで作ったブラケット | 描き直し。同じ中央・同じ向きで作り直し、元のパスは［作成］で削除します（「余白」はディム表示） |
| 開いたパス1本だけ | 大きさの参照。ダイアログを開いた時点で隠し、［作成］で削除します |
| 複数オブジェクト、テキスト、閉じたパス | 囲む対象。削除せずそのまま残します |
| 選択なし | アートボード中央に作成します（「余白」はディム表示） |

向きの初期値も選択から決まります。ダイアログで向きを切り替えると、長さもその向きに合わせて取り直します（左右なら高さ、上下なら幅）。

| 選択 | 縦長のとき | 横長のとき |
| --- | --- | --- |
| 大きさの参照（開いたパス1本） | 左 | 上 |
| 囲む対象 | 右 | 下 |

ブラケットは、腕の先が選択範囲の辺に接する位置に置かれます。辺との間隔は「余白」で調整します。

### オプション

**形状と大きさ**

| 項目 | 内容 |
| --- | --- |
| 半径（中央） | 中央の突起を作る円弧の半径（mm） |
| 半径（両端） | 両端で外へ折れ返る円弧の半径（mm）。**0にすると円弧なしの直角**になります。［連動］がONのあいだは中央に追従し、編集できません |
| 向き | 中央の突起を向ける方向（上／下／左／右） |
| 中央の位置 | 中央の突起を長さ方向にずらす量（mm、0で中央）。左右の向きでは上へ、上下の向きでは右へ動きます（マイナスで逆）。全長は変わりません |
| 直線の長さ | ブラケット全体の長さ（mm）。直線部分は「全体の長さ ÷ 2 − 両端の半径 − 中央の半径」で自動計算 |
| 延長 | 両端から外側へ伸ばす直線の長さ（pt）。両端の半径が0のときは直角に折れます |
| 余白 | 選択オブジェクトとブラケットのあいだの間隔（mm） |

**線**

| 項目 | 内容 |
| --- | --- |
| 線の太さ | ブラケットの線幅（pt） |
| 線端 | なし（butt）／丸型（round） |
| 角の形状 | マイター結合／ラウンド結合 |

### 注意点

- 半径の初期値は「全体の長さ ÷ 15」です。ダイアログを開いたあとは、半径と長さは連動しません。
- 全体の長さが「両端の半径＋中央の半径」の2倍を下回ると、直線部分は0（円弧だけ）になります。
- ［作成］以外で閉じたとき（キャンセル・ESC）は、プレビューを削除し、隠していた参照パスを元に戻します。
- ダイアログの状態は閉じたタイミングで記憶します（キャンセルで閉じた場合も同じ）。Illustratorを終了すると消えます。選択して実行したときは、長さ・向き・半径を選択から決め直すため、記憶より選択が優先されます。
- アクティブレイヤーがロックまたは非表示のときは実行できません。
