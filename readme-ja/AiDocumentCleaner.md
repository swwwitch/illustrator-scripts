## 概要

ドキュメント内の不要な要素をまとめて削除するクリーンアップツールです。ダイアログで対象を選び、一度に整理できます。

スウォッチ・シンボル・ブラシ・グラフィックスタイルは、各パネルの「未使用をすべて選択 → 削除」アクションを一時生成・再生し、Illustrator 本体の判定で未使用のみを削除します。パス／オブジェクト、グループ／レイヤー、ガイド、アートボードもまとめて対象にできます。

処理対象は、最前面のドキュメント／開いているすべてのドキュメント／指定フォルダー内の .ai ファイルから選べます。

## 主な機能

- **処理対象**（ラジオで1つ選択）
  - 最前面のドキュメント（既定）
  - 開いているすべてのドキュメント（ラベルに現在の数を表示。保存はしない）
  - フォルダー指定：フォルダー直下の .ai ファイルを順に開いて処理し、**上書き保存**して閉じる
- **パネル項目**：スウォッチ、シンボル、ブラシ、グラフィックスタイル、段落スタイル、文字スタイル
  - スウォッチ／シンボル／ブラシ／グラフィックスタイルはアクション再生で未使用のみ削除
  - 段落・文字スタイルは使用状況を取得できないため、「使用中のパネル項目も削除」ON のときだけ既定（先頭）以外を削除
- **パス／オブジェクト**：孤立点、空のテキスト、塗りも線もない（不可視）パス、不透明度0%、非表示オブジェクト、リンク切れの配置画像
- **グループ／レイヤー**：空のグループ／空のレイヤー・サブレイヤーを再帰削除
- **ガイド**（ラジオで1つ選択）：ガイドを消去（ロック分は残る）／すべてのガイド（ロックも解除）／アクティブなアートボード以外
- **アートボード**：アートボード外・アクティブなアートボード外のオブジェクト、空のアートボード
- 「使用中のパネル項目も削除」で、ドキュメント内で使用されていてもパネル項目を削除（保護対象・既定は残る。アートボードには影響しない）
- 種類ごとに削除件数を集計して表示（0件の種類は省略。一括処理では全ファイルの合計）
- 「セット」ポップアップ（基本／すべてOFF／すべてON／パネル項目のみ／カスタム）。option（Alt）＋クリックでパネル単位の一括切り替え
- 前回の設定とダイアログ位置をセッション中だけ記憶（Illustrator を終了すると破棄。環境設定には書き込まない）
- 日本語／英語UI

## 使い方

1. 整理したいドキュメントを開きます（フォルダー指定の場合は不要）。
2. `AiDocumentCleaner.jsx` を実行します。
3. ダイアログ上部の「処理対象」で処理範囲を選びます。フォルダー指定の場合は［指定...］ボタンでフォルダーを選択します。
4. 削除したい対象にチェックを入れます。
5. 未使用のパネル項目だけでなく、使用中のパネル項目も削除したい場合は「使用中のパネル項目も削除」をONにします。
6. ガイドはラジオで1つ選択します（既定は「削除しない」）。
7. 「実行」をクリックすると処理が実行され、種類ごとの削除件数が表示されます。

## 処理対象の選択

| 対象 | 動作 | 保存 |
| --- | --- | --- |
| 最前面のドキュメント | 作業中のドキュメントだけを処理 | しない |
| 開いているすべてのドキュメント | 開いている全ドキュメントを順に処理 | しない |
| フォルダー指定 | フォルダー直下の .ai ファイルを順に開いて処理 | **上書き保存** |

フォルダーを選ぶと、ラジオのラベルが「フォルダー指定（13）」のように処理対象の .ai ファイル数を表示します。0件のときは実行前に気づけます。

選択したフォルダーのパスは［指定...］ボタンの下の行に表示されます。Dropbox 配下のフォルダーはマウントパス部分を省略し、それ以外はホーム以下を `~` で短縮して表示します（マウスオーバーで絶対パスを表示）。

## 削除対象

| 分類 | 対象 |
| --- | --- |
| パネル項目 | スウォッチ／シンボル／ブラシ／グラフィックスタイル／段落スタイル／文字スタイル |
| パス／オブジェクト | 孤立点／空のテキスト／塗りも線もないパス／不透明度0%／非表示オブジェクト／リンク切れの配置画像 |
| グループ／レイヤー | 空のグループ／空のレイヤー・サブレイヤー |
| ガイド | ガイドを消去（ロック分は残る）／すべてのガイド（ロックも解除）／アクティブなアートボード以外 |
| アートボード | アートボード外／アクティブなアートボード外のオブジェクト／空のアートボード |

## プリセットと一括切り替え

ボタンエリア左の「セット」ポップアップで、削除対象をまとめて切り替えられます。

| 項目 | 動作 |
| --- | --- |
| 基本 | 初期状態に戻す（誤削除しやすい4項目はOFF、ガイドは「削除しない」） |
| すべてOFF | すべてのチェックを外し、ガイドは「削除しない」 |
| すべてON | すべてにチェックを入れ、ガイドは「すべてのガイド（ロックも解除）」 |
| パネル項目のみ | パネル項目だけにチェックを入れ、それ以外はOFF（ガイドも「削除しない」） |
| カスタム | 手で変更したときに自動で表示される状態。選んでも何も起きない |

「使用中のパネル項目も削除」はプリセットの対象外です（破壊的なため、常に手動）。

チェックボックスを option（Alt）＋クリックすると、そのパネル内のチェックがクリック先の状態に揃います。

## 注意事項

- **フォルダー指定は元の .ai ファイルを上書き保存します。取り消せません。** 実行前に対象件数とフォルダーパスを示す確認ダイアログが表示されます。事前にバックアップを取ってください。
- フォルダー指定はフォルダー直下のみが対象で、サブフォルダーは含みません。
- フォルダー指定の処理中は、フォント欠落などのダイアログで止まらないよう警告表示を一時的に抑制します（処理後に元へ戻します）。処理に失敗したファイルは保存せずに閉じ、完了メッセージにファイル名を表示します。
- 「開いているすべてのドキュメント」では保存を行いません。結果を確認してから保存してください。
- 誤削除しやすい項目（非表示オブジェクト、リンク切れの配置画像、アートボード外／アクティブなアートボード外）は初期状態でOFFです。
- ガイドは既定で「削除しない」です。
- 「すべてのガイド（ロックも解除）」は、ロックされたレイヤー・サブレイヤー・ガイド自体のロックを一時的に解除して削除し、処理後にロック状態を元へ戻します。
- 段落スタイル・文字スタイルは使用状況を取得できないため、「使用中のパネル項目も削除」ON のときのみ既定以外を削除します。
- グループ／レイヤーの掃除は他の削除より後に実行されるため、パスやオブジェクトの削除で空になった親も同じ実行で削除されます。
- 一時アクションは処理後に必ず解放・削除されます。
- クリッピングパスやコンパウンドパスの構成要素、ガイドは「塗りも線もないパス」と「不透明度0%のオブジェクト」の対象外です（単体で消すと構造が壊れるため）。
- 未使用のパネル項目の削除は、日本語UIで録画したアクションを再生しています。英語版など他言語UIでの動作は未検証で、再生できなかった場合は完了メッセージにその旨が表示されます。
- スウォッチを削除したあと、中身が空になったスウォッチグループも片付けます（件数には含めません）。
- ガイドは「ガイド」セクションでのみ削除されます（「塗りも線もないパス」やアートボード外の削除では対象になりません）。
- 前回の設定・対象フォルダー・ダイアログ位置は Illustrator を終了するまで記憶され、次に起動したときは初期状態に戻ります（`#targetengine` による永続エンジンを使用）。記憶していたフォルダーが見つからない場合は復元しません。
- 実行前にファイルのバックアップを取ることをおすすめします。
