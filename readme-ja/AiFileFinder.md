# 複数のフォルダーを横断して .ai/.svg ファイルを探す

[![Direct](https://img.shields.io/badge/Direct%20Link-AiFileFinder.jsx-ffcc00.svg)](https://github.com/swwwitch/illustrator-scripts/blob/master/jsx/files/AiFileFinder.jsx)

[![Direct](https://img.shields.io/badge/Back%20to%20home-All%20scripts-cccccc.svg)](https://github.com/swwwitch/illustrator-scripts/blob/master/README.md)

### 概要

過去に作った `.ai` ファイルを開きたいのに、どの年のフォルダーに入れたか思い出せない。Finderの検索は開くまでが遠く、[ファイル］→［最近使用したファイルを開く］では数十件しかさかのぼれません。

このスクリプトは、あらかじめ登録した複数のフォルダーから `.ai` / `.svg` ファイルをキーワードで絞り込み、選んだファイルをその場で開くファインダーです。一度作った索引をキャッシュするので、数千件あっても待たされません。

### 主な機能

- 登録した複数フォルダーを横断して検索。サブフォルダーの中身も対象
- キーワードを打つそばから候補を絞り込み（インクリメンタルサーチ）
- スペース区切りのAND／OR検索。大文字小文字・全角半角・ひらがなカタカナ・濁点の違いを吸収
- `ai` / `svg` のチェックボックスで、一覧に出す種類を切り替え（`svg` は初期状態でオフ）
- よく使う語をボタンとして登録。クリックで置き換え、option + クリックで足し込み
- 左に検索フォルダー、右にファイル名＋更新日の2リスト構成
- 年別と期間（年・月）での絞り込み
- 更新日順／名前順 × 昇順／降順の並べ替え
- ファイル名は拡張子を省いて表示
- 除外条件（ファイル名・フォルダー名に含む語で一覧から外す）。除外語をキーワードに入れたときは、その語ぶんの除外を解除
- すでに開いているファイルは、二重に開かず前面に出す
- option + ダブルクリックでFinder表示、フォルダーのダブルクリックでそのフォルダーを開く
- 索引をキャッシュして次回以降の起動を短縮。設定はIllustratorの環境設定に記憶

### 使い方

1. 起動すると索引を作り、ファイル一覧が出ます（初回のみ時間がかかります）
2. キーワード欄に文字を入力すると、候補が絞り込まれます
3. 左のリストで検索フォルダーを選ぶと、右にそのフォルダーのファイルだけが並びます
4. 右のリストで選んで `Enter`、ダブルクリック、または［開く］

option + ダブルクリックすると、開かずにそのファイルの場所をFinderで表示します。左のリストでフォルダーをダブルクリックすると、その検索フォルダーをFinderで開きます。

キーボード操作:

| キー | 動作 |
|---|---|
| ↓ | キーワード欄からファイル名リストへ移動 |
| Enter | 選択中のファイルを開く（どこにフォーカスがあっても有効。日付欄を除く） |
| option + ダブルクリック | 開かずにFinderで場所を表示 |
| フォルダーをダブルクリック | その検索フォルダーをFinderで開く |
| キーワード欄の × をクリック | キーワードをクリアして絞り込みを解除 |

### オプション

**AND / OR**

キーワード欄の下の行にあるラジオボタンで、スペースで区切った語の扱いを切り替えます。初期値はANDです。

| 指定 | 動作 |
|---|---|
| AND | 語を**すべて**含むファイルだけを残す。絞り込むほど件数が減る |
| OR | 語を**どれか1つでも**含むファイルを残す。`ロゴ logo` のように表記ゆれをまとめて拾える |

語が1つのときは、どちらでも結果は同じです。

**拡張子（ai / svg）**

AND/ORと同じ行の右端に並ぶチェックボックスで、一覧に出すファイルの種類を切り替えます。初期値は `ai` だけがオンです。

索引には両方の拡張子が入っているので、`svg` にチェックを入れれば再スキャンなしですぐ一覧に出ます。両方のチェックを外すと0件になります。

対象を増やしたいときは、スクリプト冒頭の `FILE_EXTENSIONS` に足してください。チェックボックスもこの並びのとおりに増えます。

```js
var FILE_EXTENSIONS = [
    { ext: "ai",  isChecked: true },
    { ext: "svg", isChecked: false }
];
```

**キーワードボタン**

絞り込みパネルの一番下に並ぶボタンです。環境設定で1行に1語ずつ登録します。初期値は `icon` / `logo` / `font` / `keyboard` / `アイコン` / `ロゴ` / `カラー` / `フォント` / `アップデート` / `ツール` / `パネル` / `線` の12語。

| 操作 | 動作 |
|---|---|
| クリック | その語でキーワードを置き換える |
| option + クリック | 現在のキーワードに語を追加してさらに絞り込む |

ボタンはダイアログの幅で自動的に折り返します。

**年別・期間**

キーワードボタンの上の行に並ぶポップアップで、更新日から絞り込みます。

```
年別：[すべて▼]  期間：[なし▼][01▼] 〜 [なし▼][12▼]
```

**年別**は単独の年を選ぶ絞り込みです。**期間**は開始と終了の年・月を選ぶ絞り込みで、開始はその月の1日0時から、終了はその月の末日23:59:59までを含みます（末日はうるう年も判定）。

年のポップアップには、索引に実在する年だけが新しい順に並びます。ダイアログを開いた時点で顔ぶれを決めるので、キーワードを打っても選択肢は入れ替わりません。

月の初期値は開始側が `01`、終了側が `12` です。年を選ぶだけでその年まるごとが範囲になります。年が「なし」の間は、その側の月はディム表示になります。

| 指定 | 範囲 |
|---|---|
| 2024/01 〜 2026/08 | 2024年1月1日 0:00 から 2026年8月31日 23:59:59 |
| 2024/01 〜 なし | 2024年1月1日 0:00 から 制限なし |
| なし 〜 2026/08 | 制限なし から 2026年8月31日 23:59:59 |

**並び順**

リストの下の行で指定します。並べ替えの基準は `更新日` / `名前` のラジオボタン、向きは ▲（昇順）／▼（降順）のボタンです。

```
並び順： (•)更新日 ( )名前  [▲][▼]
```

初期値は「更新日・▼」＝新しい順です。更新日が同じファイルは名前で決まります。

▲▼ は自前描画のボタンで、選ばれている側が塗りつぶしになります。

なお、リストの見出しをクリックしての並べ替えはできません。ScriptUIの見出しはクリックを受け取れないためです。

**除外条件**

ファイル名またはフォルダー名にこの語を含むファイルを、一覧から外します。1行に1語で、どれか1つでも含めば除外されます（OR判定）。索引を作り直さずにその場で効きます。

初期値は `note-cover-` / `backup` / `_old` / `_outlined` / `test` / `copy` / `名称未設定`。バックアップ用フォルダーや、量が多くて検索の邪魔になる定型ファイルを隠す用途を想定しています。

除外語をキーワードに入れたときは、その語ぶんの除外だけを解除します。`backup` を除外していても、キーワードに `backup` と打てばバックアップだけを一覧に出せます。解除されるのは打った語に対応する除外語だけなので、`_old` を除外したまま `logo` で検索しても `logo_old.ai` は出てきません。

**環境設定**

［環境設定］ボタンから開きます。

| 項目 | 内容 |
|---|---|
| 検索フォルダー | 検索対象のフォルダー。［追加］［削除］［初期値に戻す］で編集 |
| キーワードボタン | 絞り込みパネルに並べる語（1行に1語） |
| 除外条件 | 一覧から外す語（1行に1語） |
| ［再スキャン］ | 入力中の設定を適用したうえで索引を作り直す |

検索フォルダーを変更してOKを押すと、新しい構成で索引を作り直します。並べた順がそのまま左のリストの順番になります。

### 索引キャッシュ

検索フォルダーを1回走査した結果は、`~/Library/Application Support/AiFileFinder-index.txt` に保存されます。24時間以内の再起動ではこれを読むだけなので、すぐに一覧が出ます。

次のいずれかで作り直します。

- 環境設定の［再スキャン］を押す
- 検索フォルダーを変更する
- 前回の索引から24時間以上経つ

### 注意点

- 索引を作った後に追加・移動・削除したファイルは、作り直すまで反映されません。見つからないファイルを開こうとすると、その旨のダイアログが出ます
- 一致件数が多い場合、ファイル名リストには先頭300件だけを並べます（打鍵のたびに数千行を組み直すと入力が引っかかるため）。パネルの見出しに「〇件中〇件を表示」と出るので、キーワードで絞り込んでください
- 左のリストは検索フォルダー単位です。サブフォルダーは常に検索対象ですが、リストの行としては出ません
- 除外条件はフォルダー名にも当たります。`backup` を入れると、その名前のフォルダー配下がまとめて消えます
- 更新日時を読み取れないファイルは、年別・期間の絞り込みの対象外になります
- 開始が終了より後になる指定をすると、該当なしになります（自動では入れ替えません）
- option + ダブルクリックは、Automatorで作成した `/Applications/RevealInFinder.app` があればファイルを選択した状態で表示します。アプリが無い場合やmacOS以外では、囲みフォルダーを開くだけになります
- 検索フォルダー・キーワードボタン・除外条件はIllustratorの環境設定に保存されます（`AiFileFinder.*`）
- 検索対象の拡張子は `.ai` と `.svg` です。変更する場合はスクリプト冒頭の `FILE_EXTENSIONS` を書き換えてください
- 一覧のファイル名は拡張子を省いて表示します。`.ai` と `.svg` に同じ名前があると見分けが付かないので、区別したいときはスクリプト冒頭の `SHOW_FILE_EXTENSION` を `true` にしてください
- 検索フォルダーの初期値はスクリプト冒頭の `SEARCH_FOLDER_DEFAULTS` にあります。ご自分の環境に合わせて書き換えるか、環境設定から登録してください
