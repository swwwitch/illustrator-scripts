### 概要

Illustrator 用のメモ入力フローティングパレットです。

- 選択オブジェクトやクリップボードのテキストを読み込んでためておけます。
- 空行・改行を整理してから、テキストファイルへの保存やクリップボードへのコピーができます。
- パレットなので、開いたままドキュメントの操作を続けられます。内容とウィンドウ位置は次回起動時に復元されます。

### 使い方

1. スクリプトを実行すると、フローティングパレットが開きます。
2. テキストを持つオブジェクトを選択して［読み込む］。選択が無いときはクリップボードから読み込みます。
3. 必要に応じて［空行削除］［改行削除］で整え、直接入力・編集もできます。
4. ［保存］でテキストファイルへ、［すべてをコピー］でクリップボードへ書き出します。

### ボタンの機能

| 項目 | 内容 |
| --- | --- |
| モード | ［追加］（既定）は既存テキストとの間に空行を1つ挟んで追記。［置き換え］はテキスト欄を差し替え |
| 読み込む | 選択オブジェクトのテキストを読み込む。選択が無いときはクリップボードのテキストを読み込む |
| 空行削除 | テキスト欄の空行（空白のみの行を含む）を削除 |
| 改行削除 | テキスト欄の改行をすべて削除して1行にまとめる |
| 保存 | テキスト欄の内容を UTF-8 のテキストファイル（.txt）として保存 |
| すべてをコピー | テキスト欄の内容をクリップボードへコピー |
| クリア | テキスト欄を空にして再起動 |

各ボタンにはツールチップ（helpTip）が付いています。対象が無いボタンは自動でディムになります（テキストが空、空行が無い、改行が無い場合）。

### 読み込みの詳細

- グループ・クリップグループ・シンボル内（入れ子も多段展開）のテキストも対象です。
- 複数取得したときは、カンバス上の位置で上から順（同じ高さは左から右）に並べます。
- 実質的に空のテキストフレームは無視します。
- 取り込み時に分解形の濁点・半濁点（か゛）を合成形（が）へ補正します。
- 選択が無いときはクリップボードをいったんドキュメントへ貼り付け（`pasteInAllArtboard`）てテキストを読み取り、貼り付けたオブジェクトは削除します。アートボードごとの複製は重複を除きます。

### 保存

- 保存本文の末尾に、保存元のドキュメント名と保存日時のフッターが付きます。
- 既定はデスクトップへ `memo-<ドキュメント名>-<yyyymmdd>.txt` として保存します（`SAVE_LOCATION_MODE`）。
- 保存してもパレットは閉じません。入力内容とウィンドウ位置はそのまま保持されます。

### 設定（スクリプト冒頭）

| 定数 | 既定値 | 内容 |
| --- | --- | --- |
| `PALETTE_OPACITY` | `0.97` | パレットの透明度 |
| `SAVE_LOCATION_MODE` | `'desktop'` | `'desktop'`＝常にデスクトップへ保存。`'dialog'`＝保存ダイアログで場所と名前を選ぶ |
| `CLEAR_ON_CLOSE` | `false` | パレットを閉じたときに内容をクリアするか。`false` は内容を保持して次回復元 |
| `SAME_ROW_TOLERANCE_PT` | `10` | 読み込み時に「同じ行」とみなす上端の差（pt） |

### 仕様・注意

- ドキュメントが開かれていないときは警告を表示します（メモの入力・保存は可能です）。
- ウィンドウ位置は `CLEAR_ON_CLOSE` の設定にかかわらず常に保持されます。Escape キーでも閉じられます。
- すでにパレットが開いている状態で再実行すると、二重に開かず前面に出します。
- ［クリア］はスクリプトを再起動して空の状態で開き直します。
- ［すべてをコピー］は一時テキストフレームを作ってコピーするため、クリップボードは Illustrator のオブジェクト形式になります。他アプリではテキストとして貼り付けられないことがあります。
- シンボル内のテキストは一時レイヤーへ複製してから展開して読み取ります。元のシンボルには手を加えません。

### 仕組み（補足）

パレットは常駐エンジン（`#targetengine`）で動くため、表示中はこのエンジンの `app` がドキュメントへの接続を失い `there is no document` を投げます。そのため、選択テキストの取得・クリップボードの読み書きといった DOM に触る処理は、すべて BridgeTalk でメインエンジンへ委譲し、結果を非同期で受け取っています。

Illustrator には `app.system` が無いため、クリップボードへの書き出しは一時テキストフレーム経由、読み取りは「いったん貼り付けて読み、貼り付けたものを削除する」手順で行っています。貼り付け前には必ず選択を解除し、文字ツールで編集中の文字（TextRange）を削除しないようにしています。
