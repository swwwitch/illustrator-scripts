### 概要

スクリプトが増えてくると、目的のひとつを探し出すだけで時間がかかります。このスクリプトは、指定したフォルダー内の `.jsx` / `.js` / `.jsxbin` をキーワードで絞り込み、選んだスクリプトをその場で実行するランチャーです。

フォルダーとファイル名を左右のリストに分けて表示するので、階層をたどらずに目的のスクリプトへ届きます。

### 主な機能

- キーワードを打つそばから候補を絞り込み（インクリメンタルサーチ）
- 左にフォルダー、右にファイル名の2リスト構成。左で選んだフォルダーの中身が右に出る
- スペース区切りのAND検索
- キーワード欄の右の × ボタンで入力をクリア（空のときはディム表示）
- 絞り込み結果によく出てくる語を自動でボタン化。押すたびに候補を掘り下げられる
- option + ダブルクリックでFinder表示、フォルダーのダブルクリックでフォルダーを開く
- サブディレクトリの入れ子（`artboard/backup` など）を一括で除外
- 対象フォルダーとキーワード設定をIllustratorの環境設定に記憶。再起動後も選び直し不要

### 使い方

1. 初回起動時にスクリプトフォルダーを選びます。次回からは記憶した場所が開きます
2. キーワード欄に文字を入力すると、候補が絞り込まれます
3. 左のリストでフォルダーを選ぶと、右にそのフォルダー内のファイル名だけが並びます
4. 右のリストで選んで `Enter`、ダブルクリック、または［実行］

option + ダブルクリックすると、実行せずにそのスクリプトの場所をFinderで開きます。左のリストでフォルダーをダブルクリックすると、そのフォルダーをFinderで開きます。

キーボード操作:

| キー | 動作 |
|---|---|
| ↓ | キーワード欄からファイル名リストへ移動 |
| Enter | 選択中のスクリプトを実行（どこにフォーカスがあっても有効） |
| option + ダブルクリック | 実行せずFinderで場所を開く |
| フォルダーをダブルクリック | そのフォルダーをFinderで開く |
| キーワード欄の × をクリック | キーワードをクリアして絞り込みを解除 |

### オプション

**キーワードボタン**

スクリプト名を単語に分解し、出現頻度の高い語をボタンとして自動で並べます。`SmartDistributor.jsx` なら `Smart` と `Distributor`。キャメルケース・ハイフン・アンダースコア・数字で区切って判定します。

ボタンの顔ぶれは**絞り込むたびに計算し直されます**。すでに入力済みの語は押しても絞り込めないため除かれ、残った候補だけが並びます。段階的に掘り下げる使い方ができます。

```
（キーワードなし）  469件  Text  Smart  Align  Artboard  Group …
  ↓ Text をクリック
text                126件  Auto  Type  Area  Leading  Kerning …
  ↓ option + Align
text align            2件  （候補なし）
```

| 操作 | 動作 |
|---|---|
| クリック | その語でキーワードを置き換える |
| option + クリック | 現在のキーワードに語を追加してさらに絞り込む |

［環境設定］から出現条件を変更できます。

| 項目 | 内容 | 初期値 |
|---|---|---|
| 出現数 | ボタンにする最小の出現ファイル数 | 4 |
| キーワード数 | 並べるボタンの最大個数 | 10 |

数値欄は ↑↓ キーで ±1、shift 併用で ±10 増減します。設定はIllustratorの環境設定に保存され、再起動後も引き継がれます。

**サブディレクトリを含む**

OFFにすると、対象フォルダーから2階層以上深いフォルダーを一覧から除きます。バックアップ用の入れ子フォルダーを隠す用途を想定しています。

```
root/
├ Foo.jsx              ○
├ artboard/            ← 表示
│  ├ Bar.jsx           ○
│  └ backup/           ← 除外
│     └ Bar-v2.jsx     ×
```

**環境設定ダイアログ**

［環境設定］ボタンから開きます。対象フォルダーの確認・変更と、キーワードボタンの条件をまとめて扱います。

| 項目 | 内容 |
|---|---|
| 対象フォルダー | 現在のパスを表示。［フォルダー変更］で選び直す |
| フルパス | OFFではホームフォルダーを `~` に略す |
| 出現数 / キーワード数 | 上記のキーワードボタンの条件 |

フォルダーを変更してOKを押すと、新しいフォルダーで一覧を作り直します。

### 注意点

- ランチャー本体には対象フォルダーの表示がありません。どこを見ているかは［環境設定］で確認します
- option + ダブルクリックは、Automatorで作成した `/Applications/RevealInFinder.app` があればファイルを選択した状態で表示します。アプリが無い場合やmacOS以外では、囲みフォルダーを開くだけになります
- 検索対象フォルダー内にこのランチャー自身がある場合、一覧には表示されません
- 日本語だけのファイル名からはキーワードボタンを生成できません（英単語を抽出する仕組みのため）
- 対象フォルダーとキーワード設定はIllustratorの環境設定に保存されます（`AiScriptLauncher.*`）。外部に設定ファイルは作りません
- 起動時に `ShowExternalJSXWarning` をオフにします。スクリプトフォルダー外のスクリプトを実行するたびに警告が出るのを避けるためで、この設定はIllustrator全体に効きます
