### 概要

テキストにカーソルを置いた状態で実行すると、その段落全体を選択します。AiSelectParagraph.jsx の簡易版です。

### 使い方

1. 文字ツールでテキスト内にカーソルを置きます。
2. スクリプトを実行します。

### 注意点

- 段落の区切りは改行（`\r`）のみです。強制改行（Shift+Return）は段落内の改行として扱います。
