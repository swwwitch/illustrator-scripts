### 概要

選択したテキストに、禁則処理のプリセットを適用します。

### 使い方

1. 対象のテキストを選択します。
2. スクリプトを実行します。
3. 禁則プリセットを選んで適用します。

### 注意点

- プリセットの表示順と、`paragraphAttributes.kinsoku` へ渡す値は、スクリプト冒頭のユーザー設定で変更できます。
