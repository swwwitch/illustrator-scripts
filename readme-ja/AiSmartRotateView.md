## 概要

アクティブビューの回転角度（表示の回転）と、環境設定の「角度の制限」（Shiftキーを押したときの角度）を、常駐パレットから確認・変更できるスクリプトです。

「ビューの回転に連動」をONにすると、たとえば表示を30度回転して作業しているとき、「角度の制限」にも同じ30度が自動的に入り、表示と操作の角度が一致して作業しやすくなります。

選択したオブジェクトの角度を読み取ってビューを回転したり、逆に選択したオブジェクトをビューの回転に合わせて回転したりもできます。

## 主な機能

- **アクティブビューの回転角度**
  - 現在の回転角度を表示
  - スライダーで -180°〜180° を調整（ドラッグ中は表示のみ更新、離した時点でビューへ適用）
  - Shiftキーを押しながらドラッグすると15°単位にスナップ
  - ［リセット］でビューの回転だけを0°に戻す（0°のときはディム表示）
- **角度の制限**
  - 数値入力（↑↓キーで±1、Shift＋↑↓で±10）とスライダーの両方で指定
  - スライダーはドラッグ中は入力欄だけを更新し、離した時点で環境設定へ適用（Shiftで15°単位）
  - ［-30°］［30°］のプリセットボタンでワンクリック適用
  - ［値の変更］で入力欄の値を環境設定へ適用
  - 「ビューの回転に連動」ONで、ビューの回転が変わるたびに同じ角度を自動適用
  - ［リセット］で「角度の制限」だけを0°に戻す（0°のときはディム表示）
- **選択したオブジェクト**
  - 選択したパスの角度（最初の2アンカーポイントを結ぶ線の傾き）を表示
  - ［選択したオブジェクトに合わせてビューを回転］
  - ［選択したオブジェクトをビューの回転に合わせて回転］（ビューの回転が0°のときはディム表示）
  - ［選択したオブジェクトの回転をリセット］（`BBAccumRotation` タグの累積回転を戻す）
- **リセット**
  - ［テキストの傾きをリセット］（`transform/ResetText.jsx` を実行）
  - ［画像の傾きをリセット］（`transform/ResetRotation.jsx` を実行）
- ［更新］ボタンと、パレットがアクティブになったタイミングで最新の状態を取得
- 日本語／英語UI

## 使い方

1. ドキュメントを開きます。
2. `AiSmartRotateView.jsx` を実行するとパレットが表示されます。
3. スライダーまたは各ボタンで、ビューの回転・「角度の制限」・選択オブジェクトの角度を調整します。
4. パレットは開いたまま作業できます。Illustrator側で操作した結果は、パレットをクリックしてアクティブにするか［更新］を押すと反映されます。

## 「角度の制限」について

「角度の制限」は環境設定＞一般の項目で、Shiftキーを押しながらの移動・回転・描画の基準になる角度です。

Illustratorは実際の拘束方向を `constrain/sin`・`constrain/cos` で保持しているため、本スクリプトは `constrain/angle`（環境設定ダイアログの表示用）と合わせて3つの値をすべて書き込みます。`constrain/angle` だけを変更しても拘束の挙動には反映されません。

## 補足

- パレット（常駐ウィンドウ）のため、DOMを参照する処理（ビュー回転角度の取得、環境設定の適用など）は操作のたびに BridgeTalk でメインエンジンへ委譲しています。
- ［テキストの傾きをリセット］［画像の傾きをリセット］は、同一リポジトリの `jsx/transform` フォルダーにあるスクリプトを実行します。フォルダー構成を保ったまま配置してください。
