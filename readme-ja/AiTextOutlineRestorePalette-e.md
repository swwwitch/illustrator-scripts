### 概要

テキストのアウトライン化と、アウトラインからのテキスト復元を常駐パレットから実行します。AiTextOutlineRestorePalette.jsx の英語版ビルドです。

アウトライン化の直前に文字・段落属性をオブジェクトのメモ（note）へ保存し、そのメモをもとにテキストフレームを再生成します。

### 注意点

- UI・コメント・note の保存形式はすべて英語です。日本語UIが必要な場合は AiTextOutlineRestorePalette.jsx を使用してください。
- 常駐パレット型のため、スクリプトを修正したあとは**パレットを閉じてから再実行**してください。開いたままだと修正前のコードが動き続けます。
- 詳しい仕様は英語版 README を参照してください。
