### 概要

選択したエリア内文字の垂直方向の配置（天地中央）と行揃え（中央揃え）を、まとめて設定します。

閉じたパスを選択している場合はエリア内文字に変換してから同じ処理を行うので、長方形からボタンやラベルの体裁を一気に作れます。

### 主な機能

- 選択したエリア内文字を、天地中央＋中央揃えにそろえる
- 閉じたパス（長方形など）をエリア内文字に変換し、サンプルテキストを流し込む
- 長方形1つとテキスト1つを選択した場合は、そのテキストの内容を流し込む
- 複数のオブジェクトをまとめて処理

### 使い方

1. エリア内文字、または閉じたパスを選択します。
2. スクリプトを実行します。

ダイアログはありません。処理後は、結果のエリア内文字が選択された状態になります。

### 選択内容ごとの動作

**エリア内文字**

垂直方向の配置と行揃えを中央にします。

**閉じたパス（長方形、楕円、複合パスなど）**

エリア内文字に変換し、サンプルテキスト（日本語環境は「山路を登りながら」、英語環境は「Typography」）を流し込んでから中央にそろえます。変換にともない、パスの塗りと線は解除されます。

**閉じたパス1つ＋テキスト1つ**

サンプルテキストの代わりに、選択したテキストの内容を流し込みます。フォント・サイズ・文字色は元のテキストから引き継ぎ、流し込みが済んだ元のテキストは削除します。ポイント文字・パス上文字のどちらでも構いません。

### ユーザー設定

スクリプト冒頭の「ユーザー設定」で、流し込むサンプルテキストと書式を変更できます。

- `DUMMY_TEXT_JA` / `DUMMY_TEXT_EN`: 流し込むサンプルテキスト（既定値は「山路を登りながら」／「Typography」）
- `DUMMY_FONT_JA` / `DUMMY_FONT_EN`: 優先して使うフォント名の候補。先頭から順に探し、見つかったものを使います
- `DUMMY_FONT_SIZE`: サンプルテキストの文字サイズ（既定値 10）

### 注意点

- 垂直方向の配置には DOM API がないため、内部で一時的な .aia アクションを生成・ロード・再生し、実行後にアンロードします。
- 複合パスは先頭のパスだけがエリア内文字の枠になります。空になった複合パスは削除します。
- 「閉じたパス1つ＋テキスト1つ」と判定するのは、選択が2つちょうどのときだけです。3つ以上選択している場合は、パスにはサンプルテキストが流し込まれます。
- 引き継ぐのはフォント・サイズ・文字色です。それ以外の文字設定は既定値になります。
