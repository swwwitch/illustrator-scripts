### 概要

外枠と罫線でセルのように区切った表で、各テキストをセルの中央に配置します。
罫線を均等に、またはテキストに合わせて並べ直すことも、行揃えを中央揃えにすることもできます。

### 主な機能

- テキストを、枠・罫線で区切られたセルの中央へ移動（字形の見た目で天地左右の中央にそろえる）
- ［縦罫を並べ直す］［横罫を並べ直す］で、外枠の中の罫線を並べ直す（見つからない向きはディム表示）
- ［間隔］で並べ方を選択
  - 均等：罫線を等間隔に並べる
  - テキストに合わせる：列の幅（行の高さ）を中のテキストに合わせ、テキストの両側の余白をそろえる
- ［長さを揃える］で、並べ直した2点の罫線の両端を外枠の辺に合わせる
- ［中央揃えにする］で、段落の行揃えを中央揃えにする
- プレビューの切り替え。［キャンセル］や Esc キーで閉じると、罫線もテキストも元に戻る
- Option（Alt）キーを押しながら縦罫・横罫のチェックボックスをクリックすると、両方をまとめて切り替え
- グループ・複合パスの中のテキスト・罫線も対象

### 使い方

1. テキストと、外枠・罫線をまとめて選択します。
2. スクリプトを実行します。ダイアログボックスが開き、プレビューが表示されます。
3. 罫線の並べ方とテキストのオプションを指定し、［OK］で確定します。

### 注意点

- セルの境界には、選択したパスの辺のうち垂直・水平のものを使います（長方形の4辺も、1本の罫線も同じ扱い）。各テキストの中心から上下左右でいちばん近い境界がセルになります。
- 囲むセルが見つからなかったテキストは移動せず、その数を最後に知らせます。
- 字形の範囲は、テキストの複製をアウトライン化して測ります。文字の上下の余白（アセンダ・ディセンダ）には左右されません。
- 罫線を並べ直すときの外枠は、選択のなかで面積が最も大きい閉じたパスです。罫線とみなすのは、細長い開いたパスで、外枠の辺の 20% 以上の長さがあり、中心が外枠の内側にあるものです。
- ［テキストに合わせる］では、列ごとにいちばん広いテキストの幅を使います。テキストの無い列は余白の分だけの幅になります。テキストが外枠に収まらないときは、余白なしでテキストの幅の比率に割り振ります。
- ［長さを揃える］は、アンカーポイントが2つの罫線にだけ効きます。
- 各項目の初期値は、スクリプト冒頭の `AVERAGE_RULES`・`DISTRIBUTE_MODE`・`MATCH_LINES_TO_RECT`・`CENTER_IN_CELLS`・`JUSTIFY_CENTER` で変更できます。
