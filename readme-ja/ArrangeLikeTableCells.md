# 罫線で区切った表を整え、テキストをセルの中央に配置

### 概要

外枠と罫線でセルのように区切った表で、外枠の大きさ・罫線の間隔・線幅を整え、各テキストをセルの中央に字形の見た目で配置します。
外枠の角を丸くしたり、セルをランダムな濃さのグレーで塗ったりすることもできます。

### 主な機能

#### 外枠

- ［幅］［高さ］で外枠の大きさを変える（開いた時点の大きさが入る。左上を基準に外枠と罫線を伸縮し、線幅とテキストの大きさは変えない）
- ［外枠を長方形に変換］で、罫線4本で囲んだ枠を、同じ位置の長方形1つに置き換える（線の設定は上辺の罫線から引き継ぐ）
- ［角を丸くする］で、外枠の長方形に、指定した半径の同名の効果を適用する

#### 罫線

- ［縦罫の間隔を調整］［横罫の間隔を調整］で、外枠の中の罫線の位置を調整する（見つからない向きはディム表示）
- ［間隔］で並べ方を選択
  - 均等：罫線を等間隔に並べる
  - テキストに合わせる：列の幅（行の高さ）を中のテキストに合わせ、テキストの両側の余白をそろえる
- ［長さを外枠に合わせる］で、間隔を調整した2点の罫線の両端を外枠の辺に合わせる
- ［線幅をそろえる］で、外枠と罫線の線幅を指定した値にそろえる（開いた時点はもっとも多い線幅が入る）

#### テキスト

- ［セルの中央に配置］で、テキストを、枠・罫線で区切られたセルの中央へ移動する（字形の見た目で天地左右の中央にそろえる）
- ［中央揃えにする］で、段落の行揃えを中央揃えにする

#### セル

- ［ランダムな濃さで塗る］で、各セルに K10〜K60 のランダムな濃さのグレーで塗った長方形を作り、最背面に置く
- ［グループ化］で、塗りの長方形を1つのグループにまとめる（オフならばらのまま）

#### 共通

- 数値欄は∧∨と↑↓キーで増減できる（shift で10の倍数へ、option で0.1ずつ）。単位は、幅・高さ・半径が定規の単位、線幅が線の単位
- 値を変えると、入力中もプレビューを更新する
- プレビューの切り替え。［キャンセル］や Esc キーで閉じると、すべて元に戻る
- Option（Alt）キーを押しながら縦罫・横罫のチェックボックスをクリックすると、両方をまとめて切り替え
- グループ・複合パスの中のテキスト・罫線も対象

### 使い方

1. テキストと、外枠・罫線をまとめて選択します。
2. スクリプトを実行します。ダイアログボックスが開き、プレビューが表示されます。
3. 外枠・罫線・テキスト・セルのオプションを指定し、［OK］で確定します。

### 注意点

- セルの境界には、選択したパスの辺のうち垂直・水平のものを使います（長方形の4辺も、1本の罫線も同じ扱い）。各テキストの中心から上下左右でいちばん近い境界がセルになります。
- 囲むセルが見つからなかったテキストは移動せず、その数を最後に知らせます。
- 字形の範囲は、テキストの複製をアウトライン化して測ります。文字の上下の余白（アセンダ・ディセンダ）には左右されません。
- 外枠は、選択のなかで面積が最も大きい閉じたパスです。罫線を長方形の外まで伸ばした表でも、長方形がセルの領域になります。閉じたパスが無いときは、罫線4本で囲んだ枠（左右は外側の縦罫、上下は外側の横罫の位置）を外枠にします。このとき外側の罫線は間隔の調整では動かさず、［長さを外枠に合わせる］で4辺も枠の角から角までの長さにそろえます。
- 罫線とみなすのは、細長い開いたパスで、外枠の辺の 20% 以上の長さがあり、線の幅ごと外枠の内側にあるものです（外枠の辺に重なる線は辺として扱います）。約1°までの傾きは、垂直・水平の線として扱います。
- ［幅］［高さ］を変えると、外枠と罫線のアンカーポイントを左上から伸縮します。テキストは伸縮せず、［セルの中央に配置］がオンなら伸縮後のセルの中央へ移動します。
- ［テキストに合わせる］では、列ごとにいちばん広いテキストの幅を使います。テキストの無い列は余白の分だけの幅になります。テキストが外枠に収まらないときは、余白なしでテキストの幅の比率に割り振ります。
- ［長さを外枠に合わせる］は、アンカーポイントが2つの罫線にだけ効きます。
- ［外枠を長方形に変換］は、閉じたパスが無く、罫線4本で囲んだ枠のときだけ使えます。長方形の塗りはなし、線の色・幅・破線は上辺の罫線から引き継ぎます（4辺の色が異なるときは上辺の色になります）。
- ［角を丸くする］は、外枠が長方形のとき（閉じたパスの外枠か、［外枠を長方形に変換］がオン）に使えます。パスの形は変えず、効果として適用します。セルの塗りも、外枠の角に当たる角だけ同じ半径で丸めます。
- ［線幅をそろえる］は、線のあるパスだけを変えます。
- ［ランダムな濃さで塗る］の色は、CMYK ドキュメントでは K だけの CMYK、RGB ドキュメントではグレースケールです。濃さはセルごとにランダムで、プレビューを切り替えても変わりません。塗りは、選択のいちばん背面のオブジェクトと同じレイヤー（グループの中ならそのグループ）の最背面に置きます。外枠の長方形に塗りがあると、セルの塗りはその背面に隠れます。
- 各項目の初期値は、スクリプト冒頭の `ADJUST_RULE_SPACING`・`DISTRIBUTE_MODE`・`MATCH_RULE_LENGTHS`・`CONVERT_FRAME_TO_RECT`・`ROUND_CORNERS`・`CORNER_RADIUS_PT`・`MATCH_STROKE_WIDTHS`・`FILL_CELLS`・`GROUP_CELL_FILLS`・`FILL_TINT_MIN`・`FILL_TINT_MAX`・`CENTER_IN_CELLS`・`JUSTIFY_CENTER` で変更できます。

### 更新履歴

- v1.2.0（2026-10-20）［外枠］パネルを追加し、［幅］［高さ］（外枠と罫線を左上を基準に伸縮）、［外枠を長方形に変換］（罫線4本で囲んだ枠を、同じ位置の長方形1つに置き換える）、［角を丸くする］（外枠の長方形に同名の効果を適用）を置いた。［罫線］パネルに［線幅をそろえる］、［セル］パネルに［ランダムな濃さで塗る］（各セルに K10〜K60 のランダムなグレー）と［グループ化］を追加。数値欄に∧∨を付け、入力中もプレビューを更新するようにした。項目名を［縦罫の間隔を調整］［横罫の間隔を調整］［長さを外枠に合わせる］に、ダイアログボックスのタイトルを「表のように整える」に変更。ダイアログボックスを、選択範囲を避けて左右にずらさず、前回閉じた位置で開くようにした。長方形を置き、罫線をその外まで伸ばした表で、長方形が外枠にならない問題を修正（閉じたパスがあるときは、それを外枠にする）。わずかに傾いた線（約1°まで）も、セルの境界や罫線4本の枠として扱うようにした。外枠の辺に重なる線を、並べ直す罫線から外すようにした
- v1.1.0（2026-10-20）長方形が無く、罫線4本で囲んだ枠でも罫線を並べ直せるようにした（外側の罫線の位置を外枠とみなし、［長さを揃える］で4辺の罫線も角から角までにそろえる）
- v1.0.0（2026-10-20）初版リリース
