# 罫線で区切った表を整え、テキストをセルの中央に配置

### 概要

外枠と罫線でセルのように区切った表で、外枠の大きさ・罫線の間隔・線幅を整え、各テキストをセルの中央に配置します（天地は欧文のベースラインをそろえる）。
外枠の角を丸くしたり、セルをランダムな濃さのグレーで塗ったりすることもできます。

### 主な機能

#### 大きさ

- ［幅］［高さ］で外枠の大きさを変える（開いた時点の大きさが入る。左上を基準に外枠と罫線を伸縮し、線幅とテキストの大きさは変えない）
- ［プレビュー境界］で、［幅］［高さ］を線幅を含めた大きさにする（初期値は Illustrator の環境設定［プレビュー境界を使用］。線幅を変えても、線を含めた大きさは変わらない）

#### 外枠

- ［外枠を長方形に変換］で、罫線4本で囲んだ枠を、同じ位置の長方形1つに置き換える（線の設定は上辺の罫線から引き継ぐ）
- ［角を丸くする］で、外枠の長方形に、指定した半径の同名の効果を適用する

#### 縦罫の間隔・横罫の間隔

- 外枠の中の罫線の並べ方を、向きごとのパネルで選択（見つからない向きはディム表示。option＋クリックでもう一方の向きも同じにする）
  - 均等：罫線を等間隔に並べる
  - テキストに合わせる：列の幅（行の高さ）を中のテキストに合わせ、テキストの両側の余白をそろえる
  - そのまま：罫線を動かさない（外枠の大きさを変えたときは、外枠と一緒に伸縮する）
- 間隔を調整した2点の罫線は、両端を外枠の辺に合わせる

#### 線のカラーと線幅

- ［線幅を調整］で、外枠と罫線の線幅をそろえる
  - 最大：いちばん太い線に合わせる
  - 最小：いちばん細い線に合わせる
  - 平均：線幅の平均に合わせる（平均の値を項目名の横に表示）
  - 指定：欄に入れた値にする（開いた時点はもっとも多い線幅が入る）
- ［線のカラー］で、外枠と罫線の線を色見本の色にする。色見本をクリックすると Illustrator 標準のカラーピッカーで色を選べる（開いた時点は最初の線の色。色を選ぶと［線のカラー］がオンになる）

#### テキスト

- ［セルの中央に配置］で、テキストを、枠・罫線で区切られたセルの中央へ移動する（左右は字形の見た目、天地は欧文のベースラインからキャップハイトまでで中央にそろえ、アセンダー・ディセンダーの有無でベースラインがずれないようにする）
- ［中央揃えにする］で、段落の行揃えを中央揃えにする

#### セル

- ［図形を作成］で、各セルにグレーで塗った長方形を作り、最背面に置く
- ［塗り］で、セルの図形の塗り方を選択
  - 同じ濃さ（K15）：すべてのセルを K15 で塗る
  - ランダムな濃さ：セルごとに K10〜K60 のランダムな濃さで塗る
- ［グループ化］で、セルの図形を1つのグループにまとめる（オフならばらのまま）

#### 共通

- 数値欄は∧∨と↑↓キーで増減できる（shift で10の倍数へ、option で0.1ずつ）。単位は、幅・高さ・半径が定規の単位、線幅が線の単位
- 値を変えると、入力中もプレビューを更新する
- プレビューは常にオン。［キャンセル］や Esc キーで閉じると、すべて元に戻る
- Option（Alt）キーを押しながら縦罫・横罫のチェックボックスをクリックすると、両方をまとめて切り替え
- グループ・複合パスの中のテキスト・罫線も対象

### 使い方

1. テキストと、外枠・罫線をまとめて選択します（外枠・罫線だけでも実行できます）。
2. スクリプトを実行します。ダイアログボックスが開き、プレビューが表示されます。
3. 外枠・罫線・テキスト・セルのオプションを指定し、［OK］で確定します。

### 注意点

- セルの境界には、選択したパスの辺のうち垂直・水平のものを使います（長方形の4辺も、1本の罫線も同じ扱い）。各テキストの中心から上下左右でいちばん近い境界がセルになります。
- 囲むセルが見つからなかったテキストは移動せず、その数を最後に知らせます。
- 字形の範囲は、テキストの複製をアウトライン化して測ります。文字の上下の余白（アセンダ・ディセンダ）には左右されません。
- 外枠は、選択のなかで面積が最も大きい閉じたパスです。罫線を長方形の外まで伸ばした表でも、長方形がセルの領域になります。閉じたパスが無いときは、罫線4本で囲んだ枠（左右は外側の縦罫、上下は外側の横罫の位置）を外枠にします。このとき外側の罫線は間隔の調整では動かさず、角が欠けないよう突出線端にします。また、罫線の間隔を調整するときは4辺も枠の角から角までの長さにそろえます。
- 罫線とみなすのは、細長い開いたパスで、外枠の辺の 20% 以上の長さがあり、線の幅ごと外枠の内側にあるものです（外枠の辺に重なる線は辺として扱います）。約1°までの傾きは、垂直・水平の線として扱います。
- ［幅］［高さ］を変えると、外枠と罫線のアンカーポイントを左上から伸縮します。テキストは伸縮せず、［セルの中央に配置］がオンなら伸縮後のセルの中央へ移動します。
- ［テキストに合わせる］では、列ごとにいちばん広いテキストの幅を使います。テキストの無い列は余白の分だけの幅になります。テキストが外枠に収まらないときは、余白なしでテキストの幅の比率に割り振ります。
- 罫線の長さを外枠に合わせるのは、アンカーポイントが2つの罫線だけです。罫線を外枠から離して描いた表などで長さを変えたくないときは、スクリプト冒頭の `MATCH_RULE_LENGTHS` を `false` にします。
- ［外枠を長方形に変換］は、閉じたパスが無く、罫線4本で囲んだ枠のときだけ使えます。長方形の塗りはなし、線の色・幅・破線は上辺の罫線から引き継ぎます（4辺の色が異なるときは上辺の色になります）。
- ［角を丸くする］は、外枠が長方形のとき（閉じたパスの外枠か、［外枠を長方形に変換］がオン）に使えます。パスの形は変えず、効果として適用します。セルの塗りも、外枠の角に当たる角だけ同じ半径で丸めます。
- ［線のカラー］と［線幅を調整］は、線のあるパスだけを変えます。最大・最小・平均は、開いた時点の外枠・罫線の線幅から求めます。
- セルの図形の色は、CMYK ドキュメントでは K だけの CMYK、RGB ドキュメントではグレースケールです。［ランダムな濃さ］では、濃さはセルごとにランダムで、プレビューを更新しても変わりません。塗りは、選択のいちばん背面のオブジェクトと同じレイヤー（グループの中ならそのグループ）の最背面に置きます。外枠の長方形に塗りがあると、セルの塗りはその背面に隠れます。
- 各項目の初期値は、スクリプト冒頭の `RULE_SPACING_MODE`・`CONVERT_FRAME_TO_RECT`・`ROUND_CORNERS`・`CORNER_RADIUS_PT`・`APPLY_STROKE_COLOR`・`MATCH_STROKE_WIDTHS`・`STROKE_WIDTH_MODE`・`CREATE_CELL_SHAPES`・`CELL_FILL_MODE`・`FILL_UNIFORM_TINT`・`GROUP_CELL_FILLS`・`FILL_TINT_MIN`・`FILL_TINT_MAX`・`CENTER_IN_CELLS`・`JUSTIFY_CENTER` で変更できます。
