# アートボード関連の環境設定マネージャー

[![Direct](https://img.shields.io/badge/Direct%20Link-ArtboardDisplayPresetManager.jsx-ffcc00.svg)](https://github.com/swwwitch/illustrator-scripts/blob/master/jsx/preference/ArtboardDisplayPresetManager.jsx)

[![Direct](https://img.shields.io/badge/Back%20to%20home-All%20scripts-cccccc.svg)](https://github.com/swwwitch/illustrator-scripts/blob/master/README.md)

---

アートボードまわりの設定は、Illustrator の環境設定ダイアログのあちこちに散らばっています。「アートボード名を表示」は［環境設定＞ガイド・グリッド］ではなく別の場所、枠線のカラーはさらに別のカテゴリ……と、変えたいたびにタブを探すことになります。

このスクリプトは、それらを**ひとつの常駐パレットにまとめ**ます。しかも OK ボタンはありません。チェックを入れた瞬間、カラーを選んだ瞬間に反映されるので、画面を見ながら詰められます。

## 使い方

スクリプトを実行するとパレットが開きます。常駐パレットなので、開いたまま作業を続けられます。パレットがアクティブなときは Esc キーで閉じられます。

すでに開いているときに再実行しても、二重には開かず、既存のパレットが前面に出ます。

## 現在のアートボード

パレット最上部に、アクティブなアートボードの「番号：名前」と、幅・高さが表示されます。

| 項目 | 動作 |
| --- | --- |
| 幅／高さ | 現在の定規単位で表示。値を書き換えて確定するとアートボードがリサイズされます（左上を基準に伸縮） |
| ピクセルグリッドに最適化 | アートボードの XYWH を整数値へ丸めます |
| 再読み込み | 現在のアートボード情報を取得し直します |

幅・高さに 0 以下や数値以外を入力した場合は、リサイズせず元の値に戻ります。

パレットを再度アクティブにしたタイミングでも情報を取り直すので、別のアートボードへ切り替えたあとにパレットをクリックすれば、表示は自動で追従します。

## アートボード名と枠線

| 項目 | 環境設定キー |
| --- | --- |
| アートボード名を表示 | showArtboardLabelOnCanvas |
| ハイライトのカラー | ArtboardBBColorRed / Green / Blue |
| ストロークの幅（1〜4） | ArtboardBBWidth |

カラーは9色（ライトブルー、サーモンピンク、グリーン、ミディアムブルー、マゼンタ、シアン、ライトグレー、ブラック、イエロー）から選びます。現在の設定値がプリセットと完全に一致しない場合は、**もっとも近い色**が選択された状態で開きます。

## オプション

| 項目 | 環境設定キー |
| --- | --- |
| ロックまたは非表示オブジェクトを一緒に移動 | moveLockedAndHiddenArt |

当初は「「裁ち落としを印刷」生成AIボタンを表示」（`enablePrintBleedWidget`）も置いていましたが、外しています。値そのものはスクリプトから確実に書き換えられ、環境設定ダイアログの表示にも反映されるのですが、**カンバス上のウィジェットが再評価されません**。再描画・ズーム・ツール切り替え・プレビュー／アウトライン切り替え・アートボードの再設定・ドキュメント切り替えのいずれでも反映せず、スクリプトから即時反映させる手段が見つかりませんでした。Illustrator 側の挙動が変わったときに戻せるよう、コードはコメントアウトで残してあります。

## プリセット

枠線パネルの下にある3つのラジオボタンで、上記の設定をまとめて切り替えられます。

| プリセット | アートボード名 | カラー | 幅 | 一緒に移動 |
| --- | --- | --- | --- | --- |
| デフォルト | 表示 | ブラック | 1 | OFF |
| 強調 | 非表示 | サーモンピンク | 3 | ON |
| ライト | 非表示 | ライトグレー | 1 | ON |

パレットを開いたとき、現在の環境設定がいずれかのプリセットと**すべて一致していれば**、そのラジオボタンが選択された状態になります。一致しなければ、どれも選択されません。

## 下部のボタン

| ボタン | 動作 |
| --- | --- |
| カンバスカラーの変更 | アートボード外のカンバスを、白とグレーで切り替えます（uiCanvasIsWhite） |
| ビデオ定規 | ビデオ定規の表示／非表示を切り替えます |

## 対象

Illustrator の環境設定（アプリケーション全体）と、アクティブドキュメントのアートボード（ピクセルグリッド最適化・リサイズのみ）。既存のオブジェクトには手を加えません。

## 補足

環境設定を書き換えても画面はすぐには描き直されないため、値の変更後にズームアウト／ズームインを実行して再描画しています。

Illustrator の常駐パレットは、表示している間に DOM への接続を失います。そのため、アートボード情報の取得とリサイズは BridgeTalk でメインエンジンへ委譲しています。ドキュメントが開かれていない場合、アートボード情報は「—」表示になります（［ピクセルグリッドに最適化］やリサイズを試みたときだけ、その旨をアラートで知らせます）。
