# アートボードを選んで PNG・JPEG・PDF で書き出し

[![Direct](https://img.shields.io/badge/Direct%20Link-ArtboardExporter.jsx-ffcc00.svg)](https://github.com/swwwitch/illustrator-scripts/blob/master/jsx/export/ArtboardExporter.jsx)

### 概要

  ダイアログで選んだアートボードを PNG・JPEG・PDF で書き出します。
  アートボードごとに形式・倍率（複数可）・背景（白・黒・透明）を指定でき、ファイル名・保存先・除外も設定できます。

### 書き出すアートボード

  - 一覧 … 番号・書き出すかどうか（✓／除外）・アートボード名・形式・倍率・背景を表示
  - ［すべて］［作業中のアートボード］［番号で指定］（例：1-3, 5）で、書き出すアートボードをまとめて切り替え
  - 一覧の行のダブルクリックでも、書き出す・書き出さないを切り替え
  - ［除外アートボード名］… 名前がこの文字で始まるアートボードは書き出さない（初期値 #）
  - ［除外レイヤー名］… 名前がこの文字で始まるレイヤーを隠して書き出し、書き出し後に元に戻す（初期値 //）

### 選択したアートボードの書き出し設定

  一覧で行を選んで設定します。複数行を選ぶとまとめて変わります。開いた時点ではすべての行が選ばれています。

  - ［書き出す］… OFF にした行は書き出さない
  - 形式 … PNG / JPEG / PDF（最後に選んだ形式が次回の初期値になる）
  - 倍率 … 「100, 200」のようにカンマで区切ると複数の倍率で書き出し。JPEG は 776% まで
  - 背景 … 白 / 黒 / 透明（色見本のクリックでも選べる。透明は PNG のみ）
  - 品質 … JPEG の品質（0〜100。初期値は `JPEG_QUALITY`）
  - PDF プリセット … PDF のときに選ぶ（最後に選んだプリセットが次回の初期値になる）
  - ［PDF を1つにまとめる］… 書き出す PDF をすべて1つのファイルにまとめる（全体の設定。プリセットは先頭のアートボードのもの）

### ファイル名

  - ［組み合わせ］… ☑ファイル名（書き換え可）＋アートボード部分（番号・名称とその区切り、または（なし））＋区切り（_ / -）＋☑日付（YYYYMMDD / YYMMDD / YYYY-MM-DD / MMDD）＋☑文字列
  - ［書式］… `{doc}_{name}_{date}` のように自由に書く。使える記号は {doc}（ドキュメント名）・{name}（アートボード名）・{num}（番号）・{scale}（倍率）・{date}（日付）
  - 置き換え … ファイル名に使えない文字（/ \ : * ? " < > | ¥）を _ か - に置き換え。［スペース］をオンにするとスペースも置き換え
  - パネルに書き出すファイル名の例を表示

### 保存先

  - ［元ファイルと同じ］か［指定］（［選択…］でフォルダーを選ぶ）。一度も保存していないドキュメントは［指定］のみ
  - ［フォルダーを作成］… 保存先の中にフォルダーを作って書き出す（{doc}・{date} が使える）
  - ［書き出し後にフォルダーを表示］… 書き出しが終わったら保存先のフォルダーを開く

### 形式ごとの違い

  - PNG … 倍率と背景を反映
  - JPEG … 倍率・背景（白・黒）・品質を反映
  - PDF … アートボードごと（またはまとめて1つ）のファイル。選んだ PDF プリセットで保存し、倍率・背景は使わない。保存されている内容から書き出すため、未保存の変更があるときは保存してよいか確認する（一度も保存していないドキュメントは PDF を書き出せない）

### 出力

  - ファイル名（［組み合わせ］）… "[ファイル名][アートボード部分][区切り倍率][区切り日付][区切り文字列].<拡張子>"（倍率は 100% 以外のときだけ付ける）
  - ファイル名（［書式］）… 記号を置き換えた名前。{scale} が無く倍率が 100% 以外のときは末尾に「-倍率」を付ける
  - PDF をまとめるとき … アートボード部分と倍率を入れない名前
  - 番号 … アートボードの数の桁数に 0 でそろえる（10枚以上なら 01, 02 …）
  - ファイル名が重なるときは書き出さずに知らせる
  - 同じ名前のファイルがあるときは、書き出す前にまとめて上書きを確認

### 記憶

  ［書き出し］で閉じると、アートボードごとの設定と、ファイル名・保存先・除外などの設定を Illustrator を終了するまで記憶します。同じドキュメントで次に開いたときは、同じ名前のアートボードに記憶した設定が入ります。［ファイル名］欄の書き換えは記憶しません。
