### 概要

「下絵」という名前のレイヤーを探し、そのレイヤーをテンプレート化します。

### 使い方

1. 「下絵」レイヤーがあるドキュメントを開きます。
2. スクリプトを実行します。

### 注意点

- ファイル名に反して、ArtboardLayerOrganizer.jsx とは別の処理を行います。内容は レイヤーをテンプレートに.jsx と同じです。
