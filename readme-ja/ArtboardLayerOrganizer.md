# アートボード単位でオブジェクトをレイヤーに整理

[![Direct](https://img.shields.io/badge/Direct%20Link-ArtboardLayerOrganizer.jsx-ffcc00.svg)](https://github.com/swwwitch/illustrator-scripts/blob/master/jsx/layers/ArtboardLayerOrganizer.jsx)

[![Direct](https://img.shields.io/badge/Back%20to%20home-All%20scripts-cccccc.svg)](https://github.com/swwwitch/illustrator-scripts/blob/master/README.md)

---

### 概要

- ドキュメント内のオブジェクトをアートボード単位で振り分け、「番号_アートボード名」のレイヤーに整理するスクリプト。
- 所属アートボードは各オブジェクトの重心位置で判定する。
- ガイドは「_guide」、どのアートボードにも属さないオブジェクトは「_pasteboard」へ集約する（必要時のみ生成）。
- 整理後のレイヤー順はアートボード順（上から 1→2→3…）に揃える。

### 主な機能

- 「対象のアートボード」を選択
  - **現在のアートボード** / **すべて**（アートボードが1つのときは「現在のアートボード」に固定）
- 「レイヤー名の構成」を指定
  - 「番号を含める」「名前を含める」の各要素をON/OFF（両方をOFFにはできない）
  - 「区切り文字」をアンダースコア（_）／ハイフン（-）／半角スペース／なしから選択（既定：アンダースコア）
  - 区切り文字は番号と名前の両方を含めるときのみ有効
  - 組み立て結果を「例：1_トップページ」としてダイアログ内にリアルタイム表示
  - アートボード名が空のときは「アートボード」を代替名として使用
- 「対象外にする」で除外条件を指定
  - ロック中：レイヤー／オブジェクト、非表示：レイヤー／オブジェクト（いずれも既定ON）
  - OFFにした対象は、ロック／非表示を一時解除したうえで移動し、処理後に元の状態へ戻す
  - 「レイヤー名で指定」欄にレイヤー名をカンマまたは「、」区切りで入力して整理対象外に（既定：bg）
  - ガイドは「レイヤー名で指定」を無視して _guide へ集約（ロック／非表示の祖先は尊重）
- 「整理後の処理」で空のレイヤー／サブレイヤーの削除をON/OFF（既定ON）
  - 除外条件に該当するサブレイヤーは、その配下も含めて削除しない
- 旧仕様レイヤー（アートボード名のみのレイヤー）を新仕様レイヤーへ統合して削除
- 移動先レイヤーがロック／非表示でも自動で解除して移動し、処理後に元の状態へ戻す
- 「_guide」「_pasteboard」は空でも削除しない保護レイヤー（サブレイヤーとして存在する場合も同様）。_guide は最前面へ移動
- 移動に失敗したオブジェクトがある場合は件数をアラート表示
- 日本語／英語の自動切り替え

### 処理の流れ

1. ダイアログで対象アートボード・レイヤー名の構成・除外条件・整理後の処理を指定
2. トップレベルのオブジェクトを収集し、各オブジェクトの重心をあらかじめ算出
3. 対象に含めるロック／非表示を一時解除し、重心位置から所属アートボードを判定してレイヤーへ移動
4. どのアートボードにも属さないオブジェクトを _pasteboard／_guide へ振り分け、旧仕様レイヤーを統合
5. レイヤー順をアートボード順に整え、ロック／非表示を元の状態へ戻す
6. 必要に応じて空のレイヤー／サブレイヤーを削除

### 対象外

- ドキュメントが開かれていない場合（警告を表示して終了）
- 除外設定ONのときのロック／非表示のレイヤー・オブジェクト、およびそれらを祖先に持つオブジェクト
- 「レイヤー名で指定」した名前のレイヤーとその配下（ガイドを除く）
- グループやシンボルの内部にあるオブジェクト（トップレベルのオブジェクトのみを対象とする）
- 「現在のアートボード」選択時の _pasteboard 振り分けと旧仕様レイヤーの統合（実行しない）
- 保護レイヤー（_guide／_pasteboard）は空でも削除しない
