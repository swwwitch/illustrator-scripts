### 概要

選択したオブジェクトを、指定した縦横比（元の比率・16:9・1:1・A4・カスタム）に合わせてサイズ変更します。幅か高さを固定して、もう一方を比率や長さ・％で決めるほか、［固定：なし（自由）］で幅・高さを別々に指定することもできます。何も選択していないときは、長方形をアートボードの中央に作ります。

<img alt="縦横比を指定してサイズ変更ダイアログの外観" src="../png/ss-914-734-144-20260927-044110.png" width="50%" />

### 主な機能

- 縦横比：元の比率（初期値）、16:9、1:1（スクエア）、A4（1:1.414）、カスタム（横:縦を入力）
- 向き：縦（ポートレート）／横（ランドスケープ）をアイコンで選択
- 基準点：9軸で、サイズを変えても動かない点を指定（初期値は中央）
- サイズ：［固定］で幅か高さを選ぶと、その辺は元の長さのまま。もう一方の辺は比率から決まり、長さか％を入力すると比率より優先
- ［固定：なし（自由）］：比率を使わず、幅・高さをそれぞれ長さか％で指定（入力しない辺は元のまま）
- 結果の縦横比：［カスタム］以外を選んでいる間は、カスタム比の欄に結果の比率を表示（［カスタム］に切り替えるとその値から編集）
- プレビュー：設定を変えるたびにアートボード上で結果を確認
- ［リセット］：設定を初期値にして、ダイアログを開く前の大きさに戻す
- 数値欄は ∧∨ ボタンと ↑↓ キーで次の整数へ（1.5→2）、shift 併用で次の10の倍数へ、option 併用で ±0.1

### 使い方

1. オブジェクトを選択して実行します（選択なしでも実行できます）
2. 縦横比と向きを選びます
3. ［固定］で元の長さのまま残す辺を選びます。もう一方の辺は、必要なら長さか％で指定します
4. 必要なら基準点を指定します
5. OK で確定します。キャンセルすると元に戻ります

### オプション

- **ピクセルグリッドに最適化**：確定時に［ピクセルグリッドに最適化］を実行します（初期値 ON）
- **アートボードを追加**：結果と同じ範囲にアートボードを追加します。オブジェクトは残ります

### 注意点

- サイズの単位は定規の単位に合わせ、パネル名に表示します（例：サイズ（mm））
- ％は各オブジェクトの元の長さに対する割合です
- 比率・向き・［固定］を選び直すと、入力した長さ・％は取り消され、比率どおりに戻ります（［固定：なし（自由）］では比率・向きを変えても入力を残します）
- 複数のオブジェクトを選択しているときは、長さは表示しません。％とカスタム比の欄は、すべてのオブジェクトで値がそろうときだけ表示します
- 選択なしで実行したときの長方形は、幅 100mm（定規が px なら 1000px、それ以外の単位では 200pt）、比率 16:9 で作ります
