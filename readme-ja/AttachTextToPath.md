### 概要

選択中の「ポイント文字」を、同時に選択しているパス（PathItem）上の文字に変換します。
- パスが一緒に選択されている場合：そのパスを複製して使用（複数テキストにも対応）
- パスが選択されていない場合：処理を実行せず終了します（パス必須）
