### 概要

選択したテキストの自動カーニング方式を「メトリクス」に設定する。
メトリクス = AUTO。この方式のときのみプロポーショナルメトリクスをONにする。文字ツメは0%。
選択範囲全体に即適用し、未選択時は何もしない。
