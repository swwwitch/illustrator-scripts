### 概要

選択したテキストの自動カーニング方式を「和文等幅（欧文のみメトリクス）」に設定する。
和文等幅 = METRICSROMANONLY。プロポーショナルメトリクスはOFF、文字ツメは0%。
選択範囲全体に即適用し、未選択時は何もしない。
