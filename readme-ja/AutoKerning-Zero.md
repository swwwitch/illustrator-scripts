### 概要

選択したテキストの自動カーニング方式を「0（カーニングなし）」に設定する。
0 = NOAUTOKERN。プロポーショナルメトリクスはOFF、文字ツメは0%。
選択範囲全体に即適用し、未選択時は何もしない。
