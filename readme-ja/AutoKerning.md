### 概要

選択したテキストの自動カーニング方式（和文等幅／0／メトリクス／オプティカル）を
まとめて設定するスクリプトです。

- ラジオボタンで方式を選ぶとライブプレビューで確認できる
- テキストオブジェクト全体（選択範囲全体）に適用する
- 「メトリクス」を選んだときだけプロポーショナルメトリクスをON、それ以外はOFF
- プロポーショナルメトリクスのチェックボックスは単独でも操作でき、
  その場合はカーニング方式を変えずに切り替える
- キャンセルで開く前の状態に戻す
