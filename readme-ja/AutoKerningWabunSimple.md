### 概要

- 選択したテキストの自動カーニング方式を「オプティカル」に設定します。
- ダイアログはなく、実行するとその場で適用されます。

### 使い方

1. 対象のテキストオブジェクトを選択する（文字ツールで文字を選択しているときは、その文字だけが対象）
2. スクリプトを実行する
