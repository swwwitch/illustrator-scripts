# 外枠の中で罫線を均等に再配置

### 概要

選択した外枠の長方形と、その内側にある縦罫・横罫を、外枠の中で均等に再配置します。
横罫・縦罫はそれぞれON/OFFでき、罫線の長さを外枠の辺に揃えることもできます。

### 主な機能

- 縦罫は外枠の幅を、横罫は外枠の高さを「本数＋1」で等分した位置に並べ直す
- ［横罫を平均化］［縦罫を平均化］で対象の向きを選択（見つからない向きはディム表示）
- ［長さを揃える］で、2点の罫線の両端を外枠の辺に合わせる（OFF なら長さはそのままで位置だけ動かす）
- プレビューの切り替え。［キャンセル］や Esc キーで閉じると元に戻る
- Option（Alt）キーを押しながら横罫・縦罫のチェックボックスをクリックすると、両方をまとめて切り替え
- グループ・複合パスの中の罫線も対象（ロック中・非表示のものは除く）

### 使い方

1. 外枠の長方形と、内側の罫線をまとめて選択します。
2. スクリプトを実行します。見つかった向きの罫線が ON の状態で開き、プレビューが表示されます。
3. 対象の向きと［長さを揃える］を指定し、プレビューを見ながら［OK］で確定します。

### 注意点

- 外枠として使うのは、選択のなかで面積が最も大きい閉じたパスです。
- 罫線とみなすのは、細長い開いたパスで、外枠の辺の 20% 以上の長さがあり、中心が外枠の内側にあるものです。塗りの細長い長方形（閉じたパス）は対象になりません。
- 罫線は左から右（横罫は上から下）の順を保ったまま並べ直します。
- ［長さを揃える］は、アンカーポイントが2つの罫線にだけ効きます。それ以外の罫線は位置だけ動かします。
- 初期状態の［長さを揃える］は、スクリプト冒頭の `MATCH_LINES_TO_RECT` で変更できます。
