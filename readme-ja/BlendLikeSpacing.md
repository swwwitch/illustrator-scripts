### 概要

並んだ線やオブジェクトの両端を動かさずに、間隔が一定の比率でだんだん広くなるように並べ直します。比率はスライダーで調整し、結果をプレビューで確認できます。

### 主な機能

- 最初と最後のオブジェクトは動かさず、そのあいだのオブジェクトを並びの方向にだけ動かします。
- 比率は「1つ前の間隔に対する、次の間隔の大きさ」です。130%なら、間隔が1つ進むごとに1.3倍になります。100%で等間隔です。
- 比率はスライダー、入力欄、∧∨ボタン、↑↓キーで変えられます（100〜300%）。
- 広げる向きは、［上下］［左右］の行ごとに選びます。
  - ［下へ］［右へ］：その向きへ行くほど間隔が広がります。
  - ［中央へ］：両端の間隔が最も狭く、中央へ行くほど広がります。
  - ［ランダム］：間隔をランダムにします。比率は「最も広い間隔と最も狭い間隔の比」になります。［シャッフル］で並びを作り直せます。
  - ［反転］をオンにすると広い側と狭い側が入れ替わり、［上へ］［左へ］［両端へ］（中央の間隔が最も狭く、両端へ行くほど広がる）になります。ラジオボタンの文言も入れ替わります。［ランダム］では使いません。
- ［オブジェクトの数］の［個数］に増やす数を入れると、上端（左右の並びでは左端）のオブジェクトを複製して足します。入力欄とスライダーのどちらでも変えられ、初期値は0、上限は64です。右の［総数］に、選択した数と合わせた数が出ます。
- ［カラーのブレンド］の［塗り］［線］をオンにすると、両端のオブジェクトのカラーから、あいだのオブジェクトの塗り・線のカラーを段階的に変えます。
  - グループどうしは、中のオブジェクトを前面から順に対応させます。
  - 同じスポットカラーどうしは濃度を変えます。カラーの種類が異なるときは、ドキュメントのカラーモードで混ぜます。
  - どちらかの端が塗りなし（線なし）・グラデーション・パターンのときは、その属性は変えません。
- ダイアログボックスを開いたときは、上下の並びなら［下へ］、左右の並びなら［右へ］になります。
- 大きさの異なるオブジェクトでも、オブジェクトどうしのアキが比率どおりになります。
- 確定後は1回の取り消しで元に戻せます。

### 使い方

1. 並んだ線やオブジェクトを2つ以上選択します。
2. スクリプトを実行します。
3. ［広げる向き］を選び、スライダーで比率を調整します。
4. ［OK］で確定します。［キャンセル］で元の位置に戻ります。

### 注意点

- グループは1つのオブジェクトとして動かします。
- 境界は環境設定の［プレビュー境界を使用］に従います。
- オブジェクトが重なっていて、両端のあいだにアキを取れないときは、各オブジェクトの手前の辺どうしの距離を比率で配分します。
- オブジェクトが左右（または上下）にそろっていて散らばりがない向きは選べません。
