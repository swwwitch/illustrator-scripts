# 文字の種類ごとに全角・半角を変換

[![Direct](https://img.shields.io/badge/Direct%20Link-CharacterWidthConverter.jsx-ffcc00.svg)](https://github.com/swwwitch/illustrator-scripts/blob/master/jsx/text/CharacterWidthConverter.jsx)

[![Direct](https://img.shields.io/badge/Back%20to%20home-All%20scripts-cccccc.svg)](https://github.com/swwwitch/illustrator-scripts/blob/master/README.md)

### 概要

カタカナ・英数字・スペース・句読点・括弧・記号を、文字の種類ごとに「そのまま／半角／全角」を選んで変換します。数字の桁数による切り替え、句読点の種類の統一、括弧のまわりのスペースの削除もでき、縦組み用・欧文組版用などのプリセットで設定をまとめて切り替えられます。設定は［横組み］［縦組み］のタブごとに持ち、開いているタブの設定で変換します。文字の書式（フォント・文字サイズ・色など）は1文字ずつ残ります。

InDesign 版（[IdCharacterWidthConverter](https://github.com/swwwitch/indesign-scripts/blob/main/readme-ja/IdCharacterWidthConverter.md)）と同じ設定・プリセットで使えます。

### 主な機能

- ［横組み］［縦組み］のタブごとに設定を持ち、開いているタブの設定で変換。縦組みにだけ使う機能は［縦組み］タブ、欧文向けの機能は［横組み］タブに置く
- 43 種類の行ごとに「そのまま／半角／全角」を選択。行は次のパネルに分けて表示
  - ［文字種］カタカナ・アルファベット・数字・スペース
  - ［句読点］和文の句読点、コンマ・ピリオド・コロン・セミコロン・感嘆符・疑問符、!?（?! も）、2個以上続く !
  - ［括弧］二重引用符・引用符、丸・角・波括弧、不等号、かぎかっこ
  - ［記号］ハイフン・アンダースコア・円マーク・中黒など 18 種
- 半角カタカナの濁音・半濁音（ｶﾞ・ﾊﾟ など）は 1 文字の全角（ガ・パ）にまとめて変換。全角から半角へは 2 文字に分けて変換
- !? と 2個以上続く ! はひとまとまりで扱い、「そのまま」なら感嘆符・疑問符の行の設定に関係なく元のまま残す
- 行のほかのオプション
  - ［文字種］数字は1桁を全角、2桁以上を半角にする／和文にはさまれたスペースだけを変換／和欧間のスペースを削除／欧文の,.:のあとにスペースを入れる（［横組み］タブ。apples,oranges → apples, oranges）
  - ［句読点］句読点の種類（，．と、。のどちらかにそろえる）／...に変換（・・・／...／。。。を三点リーダー「…」にする）
  - ［括弧］括弧の内側のスペースを削除／括弧の外側のスペースを削除／全角の引用符の字形（＂＇、“ ” ‘ ’、〝 〟）
  - ［記号］全角のハイフンの字形（－・‐・−）／全角のチルダの字形（～・〜）／全角のアスタリスクの字形（＊・※）
- 対象は［選択範囲］［ドキュメント］から選択
- ［縦組み用］（［縦組み］タブ）3桁以上の数字は全角にする（2026 → ２０２６）／数字の中の「,」を「、」にする（1,000 → 1、000）／数字の中の「.」を「・」にする（12.5 → 12・5）／3文字以内の大文字で構成する英単語は全角にする（PDF → ＰＤＦ）
- ［確認用の色分け］で、変換した文字の塗りを赤にする（削除したスペースには付かない）
- ［プリセット］で設定を切り替え。組み込みは「標準」「英数字・記号を半角」「英数字・記号を全角」「カタカナだけ全角」「縦組み用」「欧文組版用」の6つ。プリセットは開いているタブに反映する。ただし「縦組み用」は［縦組み］タブ、「欧文組版用」は［横組み］タブに切り替えて反映する。今の設定に名前を付けて［保存...］、自分で作ったプリセットは［削除］できる（保存したプリセットは、選ぶと保存したタブに切り替えて反映。今の設定に合うプリセットが無いときは「カスタム」と表示）
- Option キーを押しながらラジオボタンをクリックすると、そのパネルの行をすべて同じ選択肢にする
- ［デフォルトに戻す］で、開いているタブを初期設定（カタカナは全角、英数字は半角、句読点・かぎかっこは全角、ほかはそのまま）に戻す
- 変換後に、行ごとの変換した数を表示
- タブごとの設定・開いているタブ・対象は Illustrator を終了するまで記憶。保存したプリセットは Illustrator を再起動しても残る

### 使い方

1. 変換したいテキストオブジェクトを選択するか、文字ツールで文字を選択する（ドキュメント全体なら選択しなくてよい）
2. スクリプトを実行する
3. ［横組み］か［縦組み］のタブを開き、［プリセット］を選ぶか、行ごとに「そのまま／半角／全角」とオプションを選ぶ
4. ［対象］を選び、［変換する］をクリックする

### 注意点

- Illustrator には処理を1回の取り消しにまとめる仕組みがないため、元に戻すには複数回の取り消しが必要になることがあります。
- 変換には開いているタブの設定だけを使います。テキストの組み方向は見ないので、縦組みのテキストを［横組み］タブの設定で変換することもできます。
- v1.2.0 までに保存したプリセットは、開いているタブに反映します（タブに無いオプションは使いません）。
- 処理の順番は、三点リーダー（・・・ ... 。。。 → …） → 和欧間のスペース → 行の変換 → 句読点の種類 → 数字の桁数（1桁・2桁以上・3桁以上） → 3文字以内の大文字の英単語 → 数字の中の「,」「.」 → 欧文の,.:のあとのスペース → 括弧のまわりのスペースです。たとえば「,」を全角にし、句読点の種類を「、。にそろえる」にすると、「,」は「、」になります。
- 選択ツールで選んだときは、テキスト全体が対象です。グループの中のテキストも対象になります。文字ツールで文字を選択しているときは、選択した文字だけが対象です。
- 選べる［対象］は選択によって変わります。何も選択していないときは［ドキュメント］だけです。
- ［ドキュメント］では、ロック・非表示のテキスト（ロック・非表示のレイヤーやグループの中のものを含む）を変換しません。スレッドでつないだテキストは、つないだテキスト全体で1つとして扱い、どれか1つでもロック・非表示なら変換しません。
- カタカナの行には長音記号（ー／ｰ）と単独の濁点・半濁点も含みます。中黒（・／･）は［記号］の中黒の行で変換します。カタカナを半角にすると、ひらがなや漢字に続く「ー」も半角になります。
- 半角カタカナにない文字（ヰ・ヱ・ヮ・ヵ・ヶ）はそのまま残ります。
- 「数字は1桁を全角、2桁以上を半角」では、3.5 や 1,000 のように区切りをはさむ数字はひとつながりとして数え、英字に続く数字（A4 など）は半角にします。オンのあいだ、数字の行の選択肢は使いません。
- 「3桁以上の数字は全角にする」も、区切りをはさむ数字はひとつながりとして数えます（1,000 → １,０００。「,」「.」はそのまま）。英字に続く数字は変えません。1〜2桁の数字は数字の行（または「数字は1桁を全角、2桁以上を半角」）に従うので、両方オンにすると1桁は全角・2桁は半角・3桁以上は全角になります。
- 「3文字以内の大文字で構成する英単語は全角にする」は、半角・全角の大文字だけでできた1〜3文字の語が対象です（A → Ａ、NHK → ＮＨＫ）。小文字・数字・記号を含む語（Pc、A4、U.S.、AT&T）と4文字以上の語は変えません。アルファベットの行を「半角」にしていても、対象の語は全角にします。
- 「和文にはさまれたスペースだけを変換」の和文は、かな・漢字・和文の約物・全角文字です。
- 「括弧の内側のスペースを削除」は、向きの無い " ' と不等号、アポストロフィと紛れる ‘ ’ を対象にしません。「括弧の外側のスペースを削除」は全角の括弧・かぎかっこだけが対象で、欧文の「word (note)」の空きは残します。
- 全角の引用符を “ ” ‘ ’ にしたときは、段落の中の順番で開き・閉じを決めます（1つ目が開き、2つ目が閉じ）。英数字にはさまれた ' はアポストロフィ（’）にします。半角にするときは “ ” ‘ ’ を " ' に戻します。
- 文字ツールで文字を選択しているときは、選択の外側の文字は見ません。スペースの前後や引用符の順番は、選択した文字の中だけで判断します。
- アスタリスクの字形を「※（米印）」にすると、* と ※ を変換します（全角にすると * が ※ に、半角にすると ※ が * になります）。
- ハイフン・チルダ・アスタリスク・引用符を半角にするときは、選んでいる字形だけを半角にします（たとえば字形が「〜」なら、「～」は変換しません）。
- 句読点の行は「。」「｡」と「、」「､」の両方を変換し、かぎかっこの行は「「」「｢」と「」」「｣」を変換します。
- 「縦組み用」「欧文組版用」以外の組み込みのプリセットは、カタカナ・和文の句読点（。、）・かぎかっこを全角にし、スペースはそのままにします。「英数字・記号を半角／全角」は ASCII の句読点・引用符・括弧と円マークも同じ向きに変換します。
- 「縦組み用」は、数字を「1桁は全角、2桁以上は半角」（縦中横向け）、!? と 2個以上続く ! を半角、和文にはさまれたスペースを全角、チルダを波ダッシュ（〜）にし、カタカナ・句読点・括弧・記号を全角にします。英字・コンマ・ピリオド・引用符の行は欧文の単語を崩さないようそのままにし、数字の中の「,」「.」は「、」「・」にします（1,000 → 1、000、12.5 → 12・5）。和欧間のスペースは削除し、・・・ ... 。。。 は … にします。縦中横の設定はしません。
- 「欧文組版用」は、全角の英数字・記号・ASCII の句読点・括弧・スペース（U+3000）・円マークをすべて半角にし、カタカナ・和文の句読点（。、）・かぎかっこはそのままにします。... は … にし、欧文の,.:のあとにスペースを入れます。
- プリセットは `~/Library/Application Support/illustrator-scripts/CharacterWidthConverter.json`（Folder.userData の下）に保存します。
