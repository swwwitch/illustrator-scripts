# 全角・半角の英数字と等幅字形を色で塗り分け

### 概要

- 選択したテキストのうち、全角の英数字と「！？」を赤、半角の英数字と「!?」を青、等幅字形の文字を緑に塗ります。ほかの文字はベースの色（黒）にします。
- 半角・全角のスペースは塗れないので、専用のレイヤーに色付きの長方形を描きます。
- 全角・半角の混在や、等幅字形の指定を目で見て確かめるときに使います。

### 主な機能

- 対象の文字
  - 全角：０〜９、Ａ〜Ｚ、ａ〜ｚ、！、？
  - 半角：0〜9、A〜Z、a〜z、!、?
  - 等幅字形：OpenType の等幅全角字形・等幅半角字形・等幅1/3字形・等幅1/4字形を指定した文字（英数字以外も含む）
- 等幅字形は全角・半角より優先します。
- どれにも当たらない文字はベースの色で塗ります。
- スペース（初期値は半角・全角とも黒）は、最前面のレイヤー「ColorNumberByWidth Spaces」に不透明度 50% の長方形を重ねます。実行のたびに、このレイヤーの長方形を消してから描き直します。
- ［スペースを描画する］をOFFにすると、スペースの長方形は描かず、レイヤー「ColorNumberByWidth Spaces」にも手を付けません（前回の長方形は残ります）。OFFのあいだ、スペースパネルのほかの設定はディム表示になります（初期値はON）。
- ［スペースの長方形をグループ化］をONにすると、描いた長方形を1つのグループにまとめます（初期値はON）。
- 各設定のチェックボックスをOFFにすると、その種類は塗りません（スペースは長方形を描きません）。［ベース］がOFFなら、どれにも当たらない文字の色はそのままです。［等幅字形］がOFFなら、等幅字形の文字も全角・半角で判定します。
- 色はダイアログボックスの色見本をクリックし、Illustrator 標準のカラーピッカーで指定できます。
- 色はドキュメントのカラーモード（RGB／CMYK）に合わせて作ります。

### 使い方

1. 対象のテキストを選択する（文字ツールで範囲を選択しても可）
2. スクリプトを実行する
3. 必要なら［ベース］［全角］［半角］［等幅字形］［半角スペース］［全角スペース］の色見本をクリックして色を変える
4. ［OK］をクリックする

### 注意点

- 選択ツールで選んだときは、テキスト全体が対象です。グループの中のテキストも対象になります。
- 上記以外の記号（＃、％、# など）は、ベースの色になります。
- スペースの長方形は横組み・縦組みとも対象です。スレッドでつないだテキストには描きません。回転・シアーしたテキストでは位置がずれます。
- 長方形の天地は文字サイズの高さで、下線の位置を下端にしています。フォントによっては少し上下にずれることがあります。縦組みでは文字サイズの幅で、字の枠の右辺にそろえます。
- 色の初期値はスクリプト冒頭の `FULL_WIDTH_RGB` などで変えられます。選んだ色は次回には引き継がれません。
