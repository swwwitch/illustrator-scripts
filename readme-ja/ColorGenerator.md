### 概要

カラーパレットを生成してアートボードに描画し、スウォッチグループにも登録します。

### 主な機能

- 対応アルゴリズム: Tailwind / Lightness / Saturation / Complementary / LCH / すべて
- 生成したパレットをアートボードへ描画
- 同じ内容をスウォッチグループとして登録

### 使い方

1. スクリプトを実行します。
2. アルゴリズムと基準色を指定します。
3. 実行すると、パレットが描画されスウォッチが登録されます。
