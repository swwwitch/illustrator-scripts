## 概要

選択した配置画像・ラスター画像・ベクター・テキストから代表色を抽出し、16色／11色／8色／5色のカラーパレットを元オブジェクトの下に色玉で並べるスクリプトです。

オブジェクトを選択していない場合は、スウォッチパネルで選択中のスウォッチから色玉パレットを作成します。

5色の行は、スウォッチグループとしても登録できます。

## 主な機能

- 配置画像・ラスター画像から、画像トレース→拡張で色を抽出
- ベクターからは、ラスタライズせずに直接色を抽出（グラデーションはカラーストップを個別に抽出）
- フリーグラデーションなど色を読み取れない塗りがあれば、ラスタライズ＋トレース経由の抽出に自動で切り替え
- テキストは複製してアウトライン化した上で色を抽出
- 16色／11色／8色／5色のパレットを、元オブジェクトの幅に合わせて出力
- 面積重み付き最大距離法で代表色を選出（面積が大きい色ほど選ばれやすい）
- 最近傍法でグラデーション風に並べ替え
- 5色の行に HEX、5色（CMYK補正）の行に CMYK を表示
- ダイアログ表示中のライブプレビュー
- スウォッチパネルの選択からパレットを作成
- 5色・5色（CMYK補正）をスウォッチグループとして登録
- 日本語／英語UI

## 使い方

1. 色を抽出したいオブジェクトを選択します（選択しない場合はスウォッチパネルの選択が対象になります）。
2. `ColorPaletteFromImage.jsx` を実行します。
3. ラスター画像や配置画像が含まれる場合は、「標準」「ユーザー定義」の一覧から画像トレースのプリセットを選びます（既定では「[6色変換]」が選ばれています）。
4. 出力する行とカラー情報をダイアログで選び、OKをクリックします。

## ダイアログの項目

| 項目 | 内容 |
| --- | --- |
| すべての行／5色の行のみ | 「5色の行のみ」を選ぶと、16色・11色・8色の行を出力しません（既定は「5色の行のみ」） |
| 出力する行 | 出力する行（16色／11色／8色／5色／5色（CMYK補正））を選びます |
| カラー情報 | 5色の行に HEX、5色（CMYK補正）の行に CMYK を表示します |
| 画面にフィット | オンにすると、設定を変えるたびに元オブジェクトとプレビューが収まるようビューを合わせます（既定オン） |
| 選び直す | 画像トレースのプリセット選択からやり直します |

ボタンはダイアログ最下部に並びます。左が「選び直す」、右が「キャンセル」「OK」です。

## 処理の流れ

1. 選択にクリップグループが含まれる場合は、クリッピングパスの範囲でラスタライズします。
2. 一時的な作業用レイヤーを作成し、選択オブジェクトを複製します。
3. ラスター／配置画像はトレースして拡張し、ベクターはそのまま塗りのカラーを面積付きで集めます。テキストは複製をアウトライン化してから集めます。ベクターに読み取れない塗り（フリーグラデーションなど）が混ざっていた場合は、作業用レイヤー上の複製をラスタライズしてトレースし直します。
4. 同じ色をまとめて面積を合算し、16 → 11 → 8 → 5 の順に段階的に代表色を絞り込みます。
5. 最初に色を取得できた時点でダイアログを表示し、プレビューを更新しながら出力内容を決めます。
6. OKで、スウォッチグループの登録とパレットの描画を行います。作業用レイヤーは削除します。

## 対象

| 区分 | 対象 |
| --- | --- |
| 対象 | 配置画像、ラスター画像、パス、複合パス、グループ、クリップグループ、テキストフレーム、スウォッチパネルの選択 |
| 非対象 | ロックされたオブジェクト、非表示のオブジェクト |

## 注意事項

- スウォッチグループに登録されるのは、5色と5色（CMYK補正）の行だけです。16色・11色・8色は色玉の描画のみです。
- スウォッチ登録では毎回新しいスウォッチを作成します。同名のスウォッチが既にある場合は「C=0 M=100 Y=100 K=0 2」のように連番を付けます。既存のスウォッチは変更・移動しません。
- CMYKラベルはCMYKドキュメントでのみ利用できます。RGBドキュメントではチェックボックスが無効になります。
- CMYK補正は5%刻みで丸めます。0と5の境界は2.5、5と10の境界は7.5です。
- 11色の行では「ほぼ白」「ほぼ黒」を除外し、中間色を拾いやすくしています。しきい値はスクリプト冒頭の `NEAR_WHITE_*` / `NEAR_BLACK_*` で変更できます。
- 代表色は面積で重み付けして選びます（`pow(面積 / 平均面積, 0.75)`）。面積が平均の4倍なら重みは約2.83倍です。
- クリップグループは300ppi・背景白でラスタライズします。設定はスクリプト冒頭の `RASTERIZE_*` で変更できます。
- 処理中は `__workLayer__` という作業用レイヤーを一時的に作成し、終了時に削除します。
- フリーグラデーションは ExtendScript から色を読み取れません。Illustrator 30.7 で確認したところ、フリーグラデーションの塗りは `GrayColor`（gray=0）として返り、本物のグレー塗りと区別する手段がありません。そのため次のいずれかに当てはまる塗りを「正しく読めた保証がない」とみなします。
  - 塗りの取得自体が例外になった
  - グラデーションだがカラーストップを1つも読めなかった
  - `GrayColor` だった
- 上記が1つでもあった場合は、作業用レイヤー上の複製をラスタライズ（300ppi）してトレースし、その結果から色を拾い直します。元のオブジェクトは変更しません。ベクター選択ではプリセット選択ダイアログが表示されないため、このときのトレースには「[6色変換]」プリセットを使います。
- この判定の副作用として、グレースケールで塗ったアートワークもラスタライズ経由になります。トレース結果から拾える色もグレーなので、パレットの内容はほとんど変わりませんが、処理時間は増えます。
- ベクターとテキストは、複数選択していてもまとめて1つのパレットとして扱います。パレットは選択範囲全体の左上を基準に配置します。
- 画像トレースのプリセット選択は、ラスター画像や配置画像が選択に含まれるときだけ表示されます。既定では「[6色変換]」を選択した状態で開きます。標準の一覧に無い場合はユーザー定義の一覧からも探し、それでも見つからない場合は最後のユーザー定義プリセットを選びます。既定にするプリセットはスクリプト冒頭の `DEFAULT_TRACING_PRESETS` で変更できます（プリセット名はUIの言語によって変わるため、角カッコ・空白・大文字小文字・全角数字の違いを吸収したうえで、候補を順に完全一致で探します。「[16色変換]」への誤ヒットを避けるため部分一致は使いません）。
- ラベルには Myriad Pro を使います。見つからない場合は既定のフォントになります。
- Illustratorには取り消しをグループ化するAPIがないため、この処理の取り消しは複数ステップに分かれます。

- v1.7.4 (20260815): 不具合修正と、ハウスルールに沿った全面的な整理
  - フリーグラデーションから色を抽出できない問題を修正。Illustrator 30.7 ではフリーグラデーションの塗りが `GradientColor` ではなく `GrayColor`（gray=0）として返るため、例外も出ずグラデーションとしても扱われず、意味のないグレー1色だけを拾っていた。正しく読めた保証がない塗り（`GrayColor` ／ ストップを1つも読めないグラデーション ／ 取得が例外）を検出し、1つでもあれば作業用レイヤー上の複製をラスタライズしてトレースし直すフォールバックを追加

  - スウォッチ登録で、同名の既存スウォッチをパレット用グループへ移動してしまう問題を修正。Illustratorではスウォッチが1つのグループにしか属せないため `addSwatch()` が既存スウォッチを元のグループから引き抜き、ユーザー定義のスウォッチが消えたように見えていた。スウォッチ名の生成規則（`C=0 M=100 Y=100 K=0` 形式）が既定スウォッチと同じで衝突しやすいことが原因。既存スウォッチを流用せず、毎回新規作成するよう変更
  - UI文言を実状に合わせて変更（「色数」→「出力する行」、「すべての情報／5色のみ」→「すべての行／5色の行のみ」、「やり直し」→「選び直す」）。プリセット一覧に「標準」「ユーザー定義」の見出しを追加し、主要なチェックボックス・ボタン・一覧にツールチップを追加
