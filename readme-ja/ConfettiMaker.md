### 概要

選択オブジェクト（未選択のときはアクティブアートボード）の領域に、紙吹雪を散らします。形状・生成数・分布・ランダム量をダイアログ上のプレビューで確かめながら調整し、［OK］で `Confetti` レイヤーへ出力します。

### 主な機能

- 形状は 円／長方形／正方形／三角形／スター／キラキラA／キラキラB／ハート／リボン／シンボルから複数選択
- 分布は「全体に均等」「垂直方向（上を濃く）」「放射状（中心を空ける）」の3種類、強度も指定可能
- 大きさ・不透明度・歪み・回転をそれぞれランダム化（量をスライダーで調整）
- 選択オブジェクトの形でクリッピングマスクをかける「マスク処理」
- 生成エリアを外側へ広げる「マージン」
- ダイアログ上でプレビューを表示し、画面ズームもスライダーで操作
- ［OK］で確定し、`Confetti` レイヤーへ出力
- 日本語／英語UI

### 使い方

1. 紙吹雪を散らす範囲となるオブジェクトを選択します（未選択のままならアートボード全体が対象）。
2. スクリプトを実行します。
3. 形状や量を指定し、プレビューを確認して［OK］をクリックします。

### オプション

**基本設定**

| 項目 | 内容 |
| --- | --- |
| 基準サイズ | 紙吹雪1個の基準となる大きさ |
| 生成数 | 生成する個数（10〜500） |
| マスク処理 | 選択オブジェクトの形でクリッピングマスクをかける |
| マージン | 生成エリアを外側へ広げる量。上限は対象サイズから自動計算 |
| 分布 | 全体に均等／垂直方向／放射状。「強度」で偏りの度合いを調整 |

**形状**

チェックした形状からランダムに選ばれます。

- **Option（Alt）+クリック**：その形状だけをONにする
- **⌘+Option（Alt）+クリック**：その形状だけをOFFにする

円・キラキラB・ハートを Option+クリックで単独選択したときは、形が見えやすいよう回転（と歪み）を自動でOFFにします。

**ランダム**

| 項目 | 内容 |
| --- | --- |
| 大きさ | 基準サイズからの揺れ幅（100でほぼ固定、300で最大±150%） |
| 不透明度 | スライダーを右へ動かすほど薄い個体が混ざる |
| 歪み | 中心を基準にしたシアーの最大角度（0〜45°） |
| 回転 | ランダム回転の最大角度（0〜360°） |

### 注意点

- マージンをONにするとマスク処理は自動でOFFになります（両立しません）。
- テキストを選択した場合、およびアートボードを対象にした場合はマスク処理を使えません。
- シンボルは、ドキュメント内にシンボルが登録されているときだけ選べます。
- 出力はプレビューの見た目そのままで確定されるため、［OK］で作り直されることはありません。
- マスク処理OFFのときは生成物を1つのグループにまとめ、ONのときはクリップグループとして出力します。
