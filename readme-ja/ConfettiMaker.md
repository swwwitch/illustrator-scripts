### 概要

選択オブジェクトの領域を基準に、紙吹雪を生成します。

### 主な機能

- 形状は 円／長方形／正方形／三角形／スター／キラキラA／キラキラB／ハート／リボン／シンボル
- ダイアログ上でプレビューを表示
- ［OK］で確定し、`Confetti` レイヤーへ出力
- 日本語／英語UI

### 使い方

1. 紙吹雪を散らす範囲となるオブジェクトを選択します。
2. スクリプトを実行します。
3. 形状や量を指定し、プレビューを確認して［OK］をクリックします。
