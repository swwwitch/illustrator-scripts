# チケット・クーポン形状の作成

[![Direct](https://img.shields.io/badge/Direct%20Link-CouponTicketMaker.jsx-ffcc00.svg)](https://github.com/swwwitch/illustrator-scripts/blob/master/jsx/shape/CouponTicketMaker.jsx)

---

回数券やクーポンの「切り取り線」まわりは、作ろうとすると案外面倒です。ミシン目のドットを等間隔に並べて、切り取り線の両端に半円のノッチを入れて、四隅を角丸にして……という作業を、位置とサイズを合わせながら手で組むことになります。

このスクリプトは、**長方形をひとつ選んでおくだけ**で、その一連をまとめて作ります。ミシン目、ギザギザ、コーナー処理、スリット／ホールを組み合わせ、プレビューを見ながら数値を詰められます。

## 使い方

1. 長方形のパスを **1つだけ** 選択
2. スクリプトを実行
3. ダイアログで設定（プレビューが随時更新されます）
4. ［OK］で選択していたオブジェクトに適用

次の場合は実行できません。

| 状態 | メッセージ |
| --- | --- |
| ドキュメントが開いていない | ドキュメントを開いてください。 |
| 何も選択していない | 長方形を選択してください。 |
| 複数選択している | 複数選択時は実行できません。オブジェクトを1つだけ選択してください。 |
| グループを選択している | グループを選択しているときは実行できません。単体のオブジェクトを選択してください。 |
| 長方形ではない | 長方形のパスを1つだけ選択してください。 |

長方形の判定は、アンカーポイントが4つで、その4点がすべて外接矩形の四隅（許容誤差 0.01pt）に一致するかどうかで行います。回転した長方形や角丸長方形は対象外です。

## プリセット

ダイアログ最上部のドロップダウンから、10種類のプリセットを呼び出せます。

| プリセット | 内容 |
| --- | --- |
| 0: クリア | すべてオフ（作り始めの状態） |
| 1: W角丸＋分割線 | 分割線＋ダブル角丸 |
| 2: 左右に2ホール | 左右の辺に円のホール |
| 3: ミシン目 | 分割線（ドット）＋角丸 |
| 4: 四隅に逆角丸 | 四隅を逆向きの円弧で削る |
| 5: 左右に三角スリット | 左右の辺に三角スリット＋角丸 |
| 6: ミシン目＋ギザギザ上下 | 左右のミシン目＋上下のギザギザ |
| 7: 面取り＋分割線（破線） | 四隅を面取り＋破線の分割線 |
| 8: 分割線＋エッジ（円）＋ギザギザ | 分割線＋円のエッジ＋左右のギザギザ |
| 9: 分割線（破線）＋三角エッジ＋左ホール | 破線の分割線＋三角エッジ＋左側だけホール |

［保存］を押すと、現在の設定に名前を付けてドロップダウンへ追加します。**この保存はセッション内だけ**で、スクリプトを閉じると消えます。

ただし保存時に、そのままコードへ貼り付けられるスニペットがアラートで表示されます。スクリプト内の `PRESETS` 配列の末尾に貼り付ければ、次回以降も選べる恒久的なプリセットになります。

プリセット名は日英を切り替えられます。スニペットの `name: "..."` を `name: { ja: "...", en: "..." }` の形に書き換えると、ロケールに応じた名前が表示されます（文字列のままでも動きます）。

## コーナー

四隅の処理です。

| 項目 | 動作 |
| --- | --- |
| なし | 何もしない |
| 角丸 | ［角を丸くする］のライブエフェクトを適用 |
| 逆角丸 | 四隅を逆向きの円弧で削り取る |
| 面取り | 四隅を45°の直線で落とす |

［逆角丸］は、上辺と下辺に「サイズ」と同じ線幅の破線を敷き、それをアウトライン化して四隅の位置にだけ四角を残し、最後に型抜きするという作りです。間隔を十分に大きく（1000pt）とることで、角以外に破線が現れないようにしています。

## ギザギザ

辺にノコギリ状の切り欠きを入れます。［左右］は左右の辺に、［上下］は上下の辺に入ります。

| 項目 | 動作 |
| --- | --- |
| 大きさ | ひとつ分の**対角線の長さ**（45°回転した正方形として配置します） |
| 繰り返し | 1辺あたりの個数 |
| 間隔 | ギザギザ同士の間隔。**繰り返しが2以上のときだけ**有効 |

配置は辺の中央を基準にします。繰り返しの合計長が辺の長さを超えても止めないので、辺からはみ出したいときはそのまま伸ばせます。

なお、［左右］のギザギザと後述の［左右］ミシン目は同じ辺を使うため併用できません。ミシン目を有効にすると、ギザギザは自動的に［なし］へ戻ります。

## 左右

### ミシン目

左右の辺に沿って、ドット状のミシン目を入れます。

| 項目 | 動作 |
| --- | --- |
| 有効 | 左右のミシン目を作る |
| 分割線に連動 | 線幅・間隔・長さを分割線からコピーする |
| 線幅 | ドットの直径 |
| 間隔 | ドットの間隔 |
| 長さ | 上下の端からの食い込み量（**0以下のみ**） |

［分割線に連動］は、**分割線が［ドット］のときだけ**効きます。連動している間、線幅・間隔・長さの入力欄はディムになり、分割線側の値がそのまま使われます。

［長さ］は「両端をどれだけ内側に引っ込めるか」です。正の値は入力できず、入力すると 0 に戻ります。

### スリット／ホール

左右の辺の中央に、切り込みを入れます。

| 項目 | 動作 |
| --- | --- |
| なし／円／三角 | 切り込みの形 |
| 左／右 | どちらの辺に入れるか（両方オフなら何も入りません） |
| サイズ | 円なら直径、三角なら対角線の長さ |

辺の上に中心が来るように配置されるので、実際に見えるのは半分（半円・三角）です。

## 左右分割

チケットを2つに割る「切り取り線」まわりの設定です。［有効］をオフにすると、分割線・エッジの設定もまとめてディムになります。

［有効］の右にある数値欄とスライダーが、分割線の位置（中央からのオフセット）です。スライダーの可動域は選択した長方形の**幅の半分**までで、その範囲を超えないよう制限されます。

### 分割線

| 項目 | 動作 |
| --- | --- |
| ドット | 丸いミシン目 |
| 破線 | 直線の破線 |
| 線幅 | ドットの直径／破線の太さ |
| 間隔 | ドット・破線の間隔 |
| 長さ | 上下の端からの食い込み量（**0以下のみ**） |

［破線］を選び、かつ［長さ］が 0 でないときは、**破線の長さが間隔にできるだけ近づくように本数を自動調整**します。両端が半端な位置で切れないので、切り取り線らしい見た目になります。［長さ］が 0 のときは、間隔と同じ長さの破線を単純に繰り返します。

### エッジ

分割線の両端（上辺・下辺との交点）に置く飾りです。切り取り線の端に半円のノッチを入れる、といった用途を想定しています。

| 項目 | 動作 |
| --- | --- |
| なし／円／三角 | エッジの形 |
| ダブル角丸 | 分割線の位置で長方形を2つに割り、それぞれを角丸にする |
| サイズ | 円なら直径、三角なら対角線の長さ |
| エッジのみ | エッジ形状だけを作り、分割線は引かない |

**エッジを設定すると、分割線の［長さ］が自動計算されます。** エッジの半分だけ分割線を引っ込めることで、線とエッジがきれいにつながります。倍率は形によって変わります。

| エッジ | ［長さ］に入る値 |
| --- | --- |
| 円 | サイズ × 1.0 のマイナス値 |
| 三角 | サイズ × 1.2 のマイナス値 |
| ダブル角丸 | サイズ × 2.0 のマイナス値 |

［ダブル角丸］は他と少し毛色が違い、**エッジ形状ではなく長方形そのものを作り替えます**。分割線の位置で長方形を2つに割り、それぞれに角丸をかけてから合体するので、切り取り線の両側が丸くくびれた形になります。オンのあいだはコーナーパネルがディムになり、エッジの形は［なし］に固定されます（オフに戻すと、コーナーは［角丸］に戻ります）。

［エッジのみ］をオンにすると分割線パネルがディムになり、分割線を引かずにエッジ形状だけを配置します。

## プレビューと確定

［プレビュー］がオンのあいだ、結果は「プレビュー」という専用レイヤーに作られ、**元のオブジェクトは一時的に非表示**になります。元のオブジェクトには一切手を加えないので、設定を変えながら安心して試せます。

［OK］を押すと、プレビューレイヤーを片付けてから、元のオブジェクトに対して同じ処理をやり直します。［キャンセル］なら何も残りません。

［アピアランスを分割］をオンにすると、適用後に［オブジェクト］→［アピアランスを分割］を実行します。角丸などのライブエフェクトが実パスに変換されます。

左下の［アウトライン表示］は、Illustrator の表示モードを切り替えるボタンです。ミシン目の位置を確認したいときに使います。

## 単位

数値はすべて**定規の単位**（環境設定 →［単位］→［一般］）で扱います。例外は分割線の［線幅］だけで、こちらは[線]の単位に従います。単位表記は各入力欄の右に表示されます。

数値欄では ↑↓ キーで値を増減できます。

| キー | 増減幅 |
| --- | --- |
| ↑ / ↓ | 1 |
| Shift + ↑ / ↓ | 10（10の倍数へスナップ） |
| Option + ↑ / ↓ | 0.1 |

## 補足

生成される形状は、すべて**元の長方形からの型抜き**（［パスファインダー］→［前面オブジェクトで型抜き］のライブ効果）です。ミシン目もギザギザもホールも、いったん「抜くための図形」として作られ、最後にまとめて長方形から抜かれます。

そのため、元のオブジェクトの見た目は**塗りだけの状態に正規化**されます。

| 元の状態 | 正規化後 |
| --- | --- |
| 塗りがある | 線を外して塗りだけにする |
| 線だけ | 線の色を塗りに移す |
| どちらもない | K100%の60%（CMYK）またはグレー60%を塗る |

ドット状のミシン目は「線の位置：中央」でなければ意図した形になりません。Illustrator の DOM からは線の位置を指定できないため、実行時に一時的なアクション（`StrokeDot`）を読み込んで適用しています。アクションは `~/StrokeDot.aia` として書き出したあとすぐ削除され、スクリプト終了時にアンロードされます。

実行中はアンカーポイントの表示とバウンディングボックスの表示を一時的に切り替え、終了時に元へ戻します。
