# 破線計算機（DashGapCalculator）

### 概要

- 選択したパスの長さから、「何分割するか」と「間隔をいくつにするか」を指定して、破線の線分長を計算して適用します。
- 線分長から間隔を逆算するモード、ランダムな線分を割り当てるモードも選べます。
- 開始位置（破線の位相）、線端、パスの方向反転もダイアログから指定できます。
- プレビューを見ながら調整でき、キャンセルすれば元の状態に戻ります。

「点線を5等分でぴったり一周させたい」「破線の切れ目を角に合わせたい」といったときに、線分長を手計算せずに済ませるためのスクリプトです。

### 使い方

1. 破線にしたいパス（オープン／クローズ）を選択します。複数選択できます。
2. スクリプトを実行します。
3. ダイアログで設定します（変更するたびにプレビューが更新されます）。
4. OK で確定します。

次の場合は実行できません。

| 状態 | メッセージ |
| --- | --- |
| ドキュメントが開いていない | ドキュメントが開かれていません。 |
| 何も選択していない | 対象となるパス（線や円など）を選択してください。 |
| 選択にパスが含まれない | パス（オープン/クローズ）を1つ選択してください。 |

選択のうち **パスだけ** が対象です。テキストやシンボルなどが混ざっていても、パスだけが処理されます。

### ダイアログの設定

| 項目 | 内容 |
| --- | --- |
| 選択中のパス情報 | 先頭のパスの長さ。複数選択しているときは括弧内に本数を表示 |
| 分割数 | パスをいくつに分けるか（1以上の整数） |
| 間隔 | 破線のすき間の長さ |
| 線分 | 破線の線の長さ |
| 計算方法 | 間隔→線分／線分→間隔／ランダム |
| 開始位置 | 破線の開始位置（位相）。チェックをONにすると入力できます |
| 部分表示 | 分割した1本分だけを表示します |
| 線端 | なし／丸型／突出 |
| 両端を調整 | オープンパスで、両端が線分で終わるように配分します |
| パスの方向反転 | パスの向きを反転します（破線の開始位置が変わります） |

入力欄と結果表示は同じ位置に重なっていて、計算方法に応じて入れ替わります。「間隔→線分」なら間隔が入力欄・線分が結果表示、「線分→間隔」ならその逆になります。

### 計算方法

#### 間隔→線分

間隔を入力すると、線分長を計算します。

#### 線分→間隔

線分長を入力すると、間隔を計算します。

いずれも計算結果がゼロ以下になる場合は確定できず、設定可能な最大値をアラートで知らせます。

#### ランダム

線分3つ・間隔3つの計6要素からなるランダムな破線パターンを作ります。

- 線分はランダム、間隔は入力した値（3つとも同じ値）になります。
- **パスごとに別の乱数**を使うため、複数のパスを選んでおくとそれぞれ違う破線になります。
- ラジオボタンをクリックするたびにパターンを作り直します。気に入らなければ再度クリックしてください。
- 分割数・線分・部分表示・両端を調整はディムになります（このモードでは使いません）。
- 線端が［なし］のときは、線分が消えてしまわないよう単位ごとの最小値（mm=1／pt=2／Q・H=4／その他=2）を下限にします。丸型・突出のときは下限0です。

### 両端を調整

オープンパス専用のオプションです。クローズパスを選択しているときはディムになります。

| 状態 | 1周期の考え方 |
| --- | --- |
| ON（オープンパス） | 両端が線分で終わるように配分します。線分の本数＝分割数、間隔は（分割数−1）回 |
| OFF、またはクローズパス | 1周期（線分＋間隔）＝パス長 ÷ 分割数。末尾は端数になり得ます |

ONかつ分割数が1のときは、線分がパス全長になります。

### 開始位置

チェックをONにすると、破線の開始位置（位相）を指定できます。数値のほか、1周期（線分＋間隔）に対する比率のプリセットが選べます。

| プリセット | 開始位置 |
| --- | --- |
| 1/4 | 1周期 × 0.25 |
| 1/2 | 1周期 × 0.5 |
| 3/4 | 1周期 × 0.75 |

手入力した値が上のいずれかと一致していれば、対応するプリセットが自動的に選択されます。

### 部分表示

分割した1本分の線分だけを表示し、残りを隠します。パスの一部だけを見せたいときに使います。

ONにすると間隔は0になり、線分長は「パス長 ÷ 分割数」（両端を調整ONのオープンパスでは、その配分に従った長さ）になります。ランダムとは併用できません。

### 破線クリア

［破線クリア］を押すと、破線の設定を解除した状態がプレビューされます。そのまま OK を押せば解除が確定します。どれかの値を変更すると、通常のプレビューに戻ります。

### 単位

数値はすべて環境設定 →［単位］→［線］の単位で扱います。Q／H の表記は、環境設定の東アジア言語のオプションに従います。

数値欄では ↑↓ キーで値を増減できます。

| キー | 増減幅 |
| --- | --- |
| ↑ / ↓ | 1 |
| Shift + ↑ / ↓ | 10（10の倍数へスナップ） |
| Option + ↑ / ↓ | 0.1 |

### 複数選択したとき

ダイアログに表示される長さと計算結果は **先頭のパス** のものですが、適用時は各パスの長さで個別に計算します。長さの違うパスをまとめて選んでも、それぞれが指定した分割数で割られます。

### 注意点

- キャンセル（および ×／Esc）では、破線・線端・パスの方向をダイアログを開く前の状態に戻します。
- パスの方向反転は［オブジェクト］→［パス］→［パスの方向反転］と同じ処理です。ダイアログ内で切り替えた場合、キャンセルすると元に戻ります。
- 破線の開始位置はパスの始点から数えます。思った位置から始まらないときは、開始位置か方向反転で調整してください。
- 分割数・間隔・線分・開始位置・線端・計算方法・両端を調整・パスの方向反転・ランダムパターンは記憶され、次回実行時に復元されます。
