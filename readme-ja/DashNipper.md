# 破線を1本ずつの線分に分割

[![Direct](https://img.shields.io/badge/Direct%20Link-DashNipper.jsx-ffcc00.svg)](https://github.com/swwwitch/illustrator-scripts/blob/master/jsx/path/DashNipper.jsx)

### 概要

- 破線を選択して実行すると、アウトライン化して1つずつの線分に分け、それぞれを同じ見た目の線（中心線）に置き換えて、破線ごとにグループにまとめます。見た目は元の破線のまま、線分ごとに別々のパスになります。
- 選択に破線が含まれていないときは、警告を出して終了します。

### 主な機能

- 線端：線端なしの破線の線分は線端なし、丸型線端の破線の線分（両端が半円のピル形状）は丸型線端の線にします。
- 線幅と色：線幅は元の破線の線幅、線の色はアウトライン化した線分の塗りの色にします。
- 曲線：曲線の破線でも、線分の曲がりに沿った中心線にします。破線がアンカーポイントや角（マイター結合）をまたぐ線分は、途中にアンカーポイントを持つ中心線になります。
- 線分の向き：太さが元の線幅と一致する向きで判定するので、線分が線幅より短くても線が横倒しになりません。
- グループ化：破線ごとに、できた線を1つのグループにまとめます。中心線にできなかった線分も、アウトラインのまま同じグループに入れます。線が1本だけのときはグループにしません。
- 重ね順：グループは元の破線があった位置（同じレイヤー・グループ）に置き、実行後は作ったグループを選択します。
- 複数の破線：選択した破線（グループの中の破線も含む）を1本ずつ順に処理します。線幅は破線ごとに判定します。
- 再実行：中心線にできなかった線分があると、その線分だけを選択した状態で終わります。そのままもう一度実行すると、元の線幅で中心線に置き換え直します。

### 使い方

1. 破線を選択する（複数可。破線を含むグループを選択してもかまいません）
2. スクリプトを実行する
3. 「中心線にできなかったパーツ」の警告が出たときは、選択されている線分のまま、もう一度実行する

### 注意点

- 対象は［線］パネルの［破線］を設定したパスです。ブラシやアピアランスの2本目の線で作った破線、複合パスの破線は対象外です。
- グループの中の非表示・ロック中のパス、クリッピングパス、ガイドは対象外です。
- 破線に塗りがあるときは、塗りを削除します（塗りが線の前面に残り、線を隠すのを防ぐため）。
- 破線と一緒に選択したほかのオブジェクト（グループの中の破線以外のオブジェクトも含む）は、そのまま残ります。
- 次の線分は中心線にできず、アウトラインのまま残ります（残った個数を警告で知らせます）。
  - 線分の長さが0の丸型線端（点線の「点」）
  - ベベル結合・ラウンド結合の角をまたぐ線分
  - 左右でアンカーポイントの数がそろわない線分
  - 線幅プロファイルで太さが変わる線分
- 中心線にできなかった線分には、元の線幅を［属性］パネルのメモ（`DashNipper:strokeWidth=…`）に書き残します。再実行ではこのメモを使うので、消さないでください。
- 閉じたパスの破線では、アウトライン化で継ぎ目の近くにごく短いセグメントや小さな破片ができることがあります。短いセグメントは取り除いてから中心線にし、破片は削除します。
- 突出線端の破線は、線端なしの線に置き換わります（見た目の長さは同じです）。

- v1.0.0 (20260922) : 初回リリース
- v1.1.0 (20260922) : 破線ごとにグループにまとめるよう変更。グループの中の破線も処理するよう変更し、非表示・ロック中のパス、クリッピングパス、ガイドは除外。破線が無いときは警告を出して終了するよう変更し、アウトライン化済みの図形を1つ選択して変換する機能を廃止。閉じたパスの破線で継ぎ目の近くの線分が変換できない不具合を修正し、アウトライン化で生じた破片は削除するよう変更。塗りのある破線で、塗りが線の前面に残る不具合を修正（塗りは削除）。線幅の5%未満の短い線分が削除される不具合を修正。線分の長さと線幅がほぼ同じとき、線の向きと線幅がずれることがある不具合を修正。丸型線端の破線で、線幅が細いと一部の線分が中心線にならない不具合を修正。中心線にできなかった線分だけを選択して終わるよう変更し、そのまま再実行すると元の線幅で置き換え直せるよう変更
- v1.1.1 (20260922) : 円周などの丸型線端の破線で、継ぎ目の近くの線分が中心線にならないことがある不具合を修正
