# 破線を1本ずつの線分に分割

### 概要

- 破線を選択して実行すると、アウトライン化して1つずつの線分に分け、それぞれを同じ見た目の線（中心線）に置き換えます。見た目は元の破線のまま、線分ごとに別々のパスになります。
- アウトライン化済みの図形（アンカーポイントが4つの閉じたパス）を1つ選択したときは、その図形を中心線に置き換えます。

### 主な機能

- 線端：線端なしの破線の線分は線端なし、丸型線端の破線の線分（両端が半円のピル形状）は丸型線端の線にします。
- 線幅と色：線幅は元の破線の線幅、線の色はアウトライン化した線分の塗りの色にします。
- 曲線：曲線の破線でも、線分の曲がりに沿った中心線にします。破線がアンカーポイントや角（マイター結合）をまたぐ線分は、途中にアンカーポイントを持つ中心線になります。
- 線分の向き：太さが元の線幅と一致する向きで判定するので、線分が線幅より短くても線が横倒しになりません。
- 重ね順：中心線は元の線分のすぐ前面（同じレイヤー・グループ）に置き、実行後は作った線をすべて選択します。
- 複数の破線をまとめて処理できます。線幅は破線ごとに判定します。
- 単体の図形：長方形のほか、長辺が曲線の帯や回転した長方形も、短辺の中点どうしを結ぶ中心線にします。線幅は短辺の長さです。

### 使い方

1. 破線を選択する（複数可）
2. スクリプトを実行する

アウトライン化済みの図形を変換するときは、図形を1つだけ選択して実行します。

### 注意点

- 対象は［線］パネルの［破線］を設定したパスです。ブラシやアピアランスの2本目の線で作った破線は対象外です。
- グループを選択しただけでは、中の破線は対象になりません。破線そのものを選択してください。
- 破線と一緒に選択したほかのオブジェクトは、そのまま残ります。
- 次の線分は中心線にできず、アウトラインのまま残ります（残った個数を警告で知らせます）。
  - 線分の長さが0の丸型線端（点線の「点」）
  - ベベル結合・ラウンド結合の角をまたぐ線分
  - 左右でアンカーポイントの数がそろわない線分
  - 線幅プロファイルで太さが変わる線分
- 突出線端の破線は、線端なしの線に置き換わります（見た目の長さは同じです）。
- 単体の図形で太さが縦横同じ（正方形など）ときは、縦の線にします。
