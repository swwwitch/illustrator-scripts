### 概要

ドキュメント内のテキストフレームから日付を検索し、選択した項目だけを置換します。

### 使い方

1. （必要に応じて）検索対象を絞るためにオブジェクトを選択します。
2. スクリプトを実行します。
3. 見つかった日付から置換するものを選び、新しい日付を指定して実行します。

### 注意点

- オブジェクトが選択されている場合は、その選択範囲（グループ内を含む）のテキストフレームだけを検索対象にします。
