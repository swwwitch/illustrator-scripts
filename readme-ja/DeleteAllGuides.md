### 概要

- ドキュメント内のすべてのガイドを削除します。
- ロックされたレイヤーも一時的にアンロックしてガイドを削除します。

### 処理の流れ

1. ドキュメントを確認（開いていない場合は終了）
2. すべてのレイヤーのロック状態を保存し、アンロック
3. ガイドロックを解除
4. すべてのガイドを削除
5. レイヤーのロック状態を元に戻す
