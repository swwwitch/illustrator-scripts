### 概要

環境設定の「角度の制限」（Shiftキーを押したときの角度）と「キー増加」（矢印キーの移動量）の変更、
およびガイド・グリッドの表示やロックの切り替えをパレットから行うスクリプトです。詳細はREADMEを参照。
