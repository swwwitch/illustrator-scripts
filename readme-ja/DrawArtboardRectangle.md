### 概要

- 現在のアートボードとまったく同じ大きさの長方形を作成します。
- 塗り・線は「なし」に設定され、アクティブレイヤーの最前面に追加されます。

### 使い方

1. 対象のアートボードをアクティブにする
2. スクリプトを実行する
