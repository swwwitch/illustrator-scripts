### 概要

選択したオブジェクト（図形／テキスト）を上から順に並べ、その間に水平の罫線を描画します。

### 主な機能

- 入力単位は環境設定の「線」（`strokeUnits`）に追従（表示ラベルと内部のpt換算の両方）
- ［延長］で罫線を左右方向に伸縮（＋で延長、−で短縮）

### 使い方

1. 罫線を挟みたいオブジェクトをまとめて選択します。
2. スクリプトを実行します。
3. 線幅や延長量を指定して実行します。
