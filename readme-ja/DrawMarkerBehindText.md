# 文字にマーカー・アンダーライン・取り消し線を引く

### 概要

- 文字ツールで選んだ文字、または選択したテキストオブジェクトの背面に、字面（文字のアウトラインの形）の範囲に合わせて線を引きます。
- 種類（マーカー・アンダーライン・取り消し線・塗りつぶしなど）、カラー、線幅はダイアログボックスで選び、プレビューで確かめられます。
- 線は効果を掛けたパスなので、あとからアピアランスパネルで調整できます。

### 主な機能

- 種類
  - アンダーライン：字面のすぐ下に、線の上端を合わせて引きます。
  - マーカー：字面の下端を線の中心にして引きます（初期値）。
  - 直線＋シアー：マーカーと同じ位置で、［パスの自由変形］効果で両端を斜めにします。傾きは［角度］で指定します（-80〜80°、プラスで右上がり）。
  - ギザギザ：マーカーと同じ位置で、［ジグザグ］効果を掛けます。［大きさ］（山の高さ）と［折り返し］（端から端までの数）で指定します。
  - 塗りつぶし：字面の範囲を塗りつぶします（線幅は字面の高さ）。
  - 長方形：字面を囲む長方形を、行ごとに1つ描きます。
  - 1文字ずつの長方形：1文字ずつ、字面を囲む長方形を描きます。高さは行の字面にそろえ、幅は字面の幅か高さの大きいほう（漢字・かなはほぼ正方形）です。
  - ［長方形］［1文字ずつの長方形］は、まわりの余白を［余白］で、角の丸みを［角丸の半径］（0 で角丸なし）で指定します。
  - 取り消し線：字面の上下中央に引きます。
- カラー
  - 黄色（Y100）・赤（M100Y100）
  - 文字色：対象の先頭の文字の塗りを使います。横の［不透明度］で線の不透明度を指定できます（初期値 30%）。
  - カスタム：色見本をクリックし、Illustrator 標準のカラーピッカーで指定します。
- 線幅：初期値は字面の高さの 40% です。単位は環境設定の［線］の単位です。
- 上下位置：種類ごとの位置から、線を上下にずらします（プラスで上、マイナスで下）。
- 線：［直線］［破線］［ドット点線］から選びます。破線は線幅の2倍の線分を線幅の間隔で、ドット点線は線幅の大きさの丸い点を線幅の2倍の間隔で並べます（ドット点線は線端が丸型になります）。
- 線端：［なし］［丸型］から選びます。
- 文字を白抜きに：オンにすると、描いたあとで対象の文字の塗りを白にします（プレビューにも反映）。
- ［長方形］［1文字ずつの長方形］以外は、線に［パスのアウトライン］効果を掛けます。［長方形］［1文字ずつの長方形］は塗りの長方形をグループにします。
- プリセット：今の設定に名前を付けて保存し、ドロップダウンから呼び出せます。保存したプリセットは Illustrator を再起動しても残ります。
  - 最初から用意したプリセット：黄色のマーカー、斜めの蛍光ペン、赤のアンダーライン、赤の波線、うすい文字色の塗りつぶし、1文字ずつの長方形（ピンク）、角丸の長方形（青）、文字色の取り消し線。線幅などの長さは先頭の対象の字面の高さに合わせます。［1文字ずつの長方形（ピンク）］［角丸の長方形（青）］は［文字を白抜きに］がオンです。削除はできず、同じ名前で保存すると保存したほうを使います。
- プレビュー：オンのあいだは選択を外して線を表示します。ダイアログボックスを閉じると、元の選択に戻します。

### 使い方

1. 文字ツールで文字を選択する（またはテキストオブジェクトを選択する）
2. スクリプトを実行する
3. 種類・カラー・線幅などを選ぶ（プリセットから呼び出しても可）
4. ［OK］をクリックする

### 注意点

- テキストオブジェクトを選んだときは、それぞれのすべての文字に1本ずつ引きます。グループの中のテキストも対象です。ロック・非表示のテキストは除きます。
- 複数行のテキストでは、すべての行をまとめた範囲に対して1本引きます。行ごとには分けません。
- 線は元のテキストのすぐ背面に置きます。
- スペースや改行だけを選んだときは、字形が無いので引けません。
- ［文字色］は、対象の先頭の文字が塗りなしのときは選べません。
- プリセットに保存できるカスタムの色は RGB・CMYK・グレーだけです。
- 線幅・上下位置・ギザギザの大きさ・余白・角丸の半径は、文字の大きさに関係なく指定した長さです。
