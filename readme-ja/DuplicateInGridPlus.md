## 概要

選択したオブジェクトを、指定した繰り返し数と間隔で複製・配置するスクリプトです。グリッド（行×列）のほか、行だけ・列だけ・ランダム配置の4方式に対応しています。

ダイアログは2カラム構成で、左に「繰り返し数」と「繰り返し方式」、右に「間隔」「方向」「敷き詰め」を配置しています。設定を変えるたびにライブプレビューが更新されるので、確定前に結果を確認できます。プレビューは専用の「_preview」レイヤー上に描かれ、OK／キャンセルのどちらでも後片付けされます。

間隔は現在の定規単位（環境設定の単位）で入力し、内部ではポイントに変換して処理します。パネル名の「間隔（pt）」の括弧内が現在の単位です。

## 主な機能

- **繰り返し方式**（ラジオで1つ選択）
  - グリッド：行×列で配置（繰り返し数は［連動］ONが基本）
  - 行：横の数だけ1行に配置（縦は常に1、上下方向と上下の間隔は無効）
  - 列：縦の数だけ1列に配置（横は常に1、左右方向と左右の間隔は無効）
  - ランダム配置：元オブジェクトの中心を基準にランダムに配置
- **繰り返し数**：横・縦を個別に入力。［連動］ONで縦＝横。スライダー（1〜20）でも操作でき、ドラッグ中はプレビュー更新を間引いてチラつきを抑えます
- **間隔**：左右・上下を現在の定規単位で入力。［連動］ONで上下＝左右
- **方向**：右／左・上／下を指定（繰り返し方式によって無効化されます）
- **敷き詰め**
  - アートボードの端まで：選択オブジェクトの位置を起点に、アートボードの端まで入る行列数を自動計算
  - アートボードいっぱいに：アートボードに収まる最大の行列数を自動計算し、OK時に複製を含む全体をアートボード中央へ移動
- **画面ズーム**：ダイアログを開いたままIllustratorの表示倍率を変更。［軽量モード］ONではドラッグ中は反映せず、離したときだけ適用します
- 数値入力欄は↑↓キーで増減（shiftで10単位、option/altで0.1単位）
- クリッピングマスクがある場合はマスクの境界を基準に配置（なければ可視境界）
- 複数選択時は自動でグループ化してから処理
- 日本語／英語UI

## 使い方

1. 複製したいオブジェクトを選択します。
2. `DuplicateInGridPlus.jsx` を実行します。
3. 「繰り返し方式」を選び、繰り返し数と間隔を入力します。
4. 必要に応じて方向や「敷き詰め」を指定します。
5. プレビューで結果を確認し、［OK］をクリックします。

## 繰り返し方式

| 方式 | 繰り返し数 | 間隔 | 方向 |
| --- | --- | --- | --- |
| グリッド | 横×縦（［連動］可） | 左右・上下（［連動］可） | 右／左・上／下 |
| 行 | 横のみ（縦は1） | 左右のみ | 右／左 |
| 列 | 縦のみ（横は1） | 上下のみ | 上／下 |
| ランダム配置 | 横のみ（縦は1） | 左右・上下（常に連動） | 無効 |

ランダム配置では、間隔の値がそのまま散らばりの範囲になります。間隔を0にすると、その軸のランダムを完全にOFFにできます（縦横どちらか一方だけ散らすことも可能です）。プレビューで作られた配置はキャッシュされるので、［OK］を押しても見たとおりの配置になります。

## 敷き詰め

| 項目 | 動作 |
| --- | --- |
| アートボードの端まで | 選択オブジェクトの現在位置を起点に、指定方向のアートボード端まで入る行列数を自動計算します。方向は変更できます |
| アートボードいっぱいに | 方向を無視して、アートボードに収まる最大の行列数を自動計算します。方向ラジオはディムになり、OK時に複製を含む全体をアートボード中央へ移動します |

2つの項目は排他で、どちらかをONにするともう一方はOFFになります。［アートボードの端まで］がONのときに方向を［左］または［上］にすると、自動的にOFFになります。

## キーボードショートカット

| キー | 動作 |
| --- | --- |
| G | 繰り返し方式：グリッド |
| R | 繰り返し方式：行 |
| C | 繰り返し方式：列 |
| A | 繰り返し方式：ランダム配置 |
| shift + R | 方向：右 |
| L | 方向：左 |
| T | 方向：上 |
| B | 方向：下 |

## 注意事項

- プレビューは「_preview」レイヤーに描かれます。このレイヤーがない場合は自動で作成され、最前面に移動します。
- プレビューの後片付けでは、スクリプトが作成した一時オブジェクト（note に識別タグを持つもの）だけを削除します。同じレイヤーに置かれている他の要素は削除しません。
- 複数のオブジェクトを選択して実行すると、［OK］を押した時点で自動的に1つのグループにまとめてから複製します。グループ化は取り消されないため、元の構造を保ちたい場合は実行後に取り消してください。キャンセルした場合はグループ化も行われず、ドキュメントは変更されません。
- 間隔は現在の定規単位で入力します。単位を切り替えた場合は、ダイアログを開き直すと新しい単位で表示されます。
- 繰り返し数スライダーの範囲は1〜20です。キー入力ではそれ以上の値も指定できます。
- 「敷き詰め」がONのあいだは行列数を自動計算するため、スライダーは無効になります（自動計算した20を超える値がスライダーで潰れないようにするためです）。
- ［画面ズーム］で変更した表示倍率は、［キャンセル］またはダイアログを閉じたときに元へ戻ります。［OK］で確定した場合は変更後の倍率が残ります。
- 複製数が多いと処理に時間がかかります。プレビューが重いと感じる場合は［軽量モード］をONにしてください。
