### 概要

選択した1つのテキストフレームの各行をアウトライン幅で測定し、最長行の幅にそろうよう行ごとの文字サイズを変倍します。

### 主な機能

- ダイアログを開いたまま結果をプレビュー
- 行送りを自動（既定100%）に切り替えるかどうかを選択

### 使い方

1. テキストフレームを1つ選択します。
2. スクリプトを実行します。
3. プレビューを確認して［OK］をクリックします。

### 注意点

- パス上文字への変換まで行いたい場合は DynamicTextGenerator.jsx を使用してください。
