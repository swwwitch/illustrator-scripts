# 角丸長方形の角の半径を変更

[![Direct](https://img.shields.io/badge/Direct%20Link-EditCornerRadius.jsx-ffcc00.svg)](https://github.com/swwwitch/illustrator-scripts/blob/master/jsx/path/EditCornerRadius.jsx)

### 概要

- 角丸長方形の角の半径をダイアログで変更
- 対象は［選択したオブジェクトのみ］［現在のアートボードのみ］［ドキュメント全体］から選ぶ
- ダイアログには現在の半径を計測して表示し、OK で角を指定の半径にそろえてパスを作り直す
- 吹き出し形状と、グループ・複合パス・複合シェイプの中の長方形も対象

### 主な機能

- 単位は定規の単位に従う
- 対象の初期値は、選択があれば［選択したオブジェクトのみ］、なければ［現在のアートボードのみ］（選択が無いときは［選択したオブジェクトのみ］は選べない）
- ［現在のアートボードのみ］は、アートボードに一部でも重なっていれば対象
- 入力欄の左の∧∨か↑↓キーで次の整数へ増減（1.5→2。Shift：次の10の倍数へ、Option：0.1）
- ［プレビュー］で結果を確認しながら調整
- 複数選択に対応（すべての長方形に同じ半径を適用）
- アンカーポイントの向き（時計回り／反時計回り）は元のパスのまま
- 対象になる形
  - 水平・垂直に置かれた長方形（角丸を含む）
  - 辺に吹き出しの口などが付いた長方形。口の部分はそのまま残し、4 つの角だけ変更する（半径は口の付け根までに制限）
  - グループの中の長方形（サブグループも含む。［選択したオブジェクトのみ］ではグループを選べばよい）
  - 複合パスの中の長方形（複合パスを選べばよい）
  - 複合シェイプの中の長方形（下記）
- 複合シェイプ
  - 複合シェイプは「グループ＋［効果＞パスファインダー＞合体］」に変換し、中の長方形を変更する（選択・アートボード・ドキュメント全体のいずれでも対象）
  - 変換すると、各パスのモード（前面オブジェクトで型抜きなど）はすべて合体になる。名前・不透明度・描画モードは引き継ぐ
  - 中に長方形が無い複合シェイプは変換しない
  - 中の長方形に［角を丸くする］効果が付いていたら、効果を外して同じ半径をパスの角丸にする（外すときは［アピアランスを消去］を使うので、そのパスのほかの効果も外れる。塗り・線・不透明度は戻す）
  - ダイレクト選択ツールで中の長方形を直接選んだときは、変換せずにそのパスを書き換える（モードはそのまま）

### 使い方

1. 角丸を変更したい長方形（またはそれを含むグループ・複合パス・複合シェイプ）を選択（アートボード・ドキュメント全体が対象なら不要）
2. スクリプトを実行
3. 対象を選び、半径を入力して OK

### オプション

- ［0の半径は0のままに］（初期値オン）：角丸の無い角は角のまま残し、角丸のある角だけ半径を変更。オフにすると 4 つの角すべてを指定の半径にする（角丸の無い長方形に角丸を付けるときはオフにする）
- ［「角を丸くする」効果を含む］（初期値オフ）：［効果＞スタイライズ＞角を丸くする］で角丸になっている長方形も対象にし、効果を新しい半径で付け直す。付け直す前に［アピアランスを消去］を実行するため、その長方形のほかの効果や追加の塗り・線は外れる（基本の塗り・線・不透明度は戻す）
- ［「角を丸くする」効果に変換］（初期値オフ）：4 つの角がすべて角丸の長方形を角のない長方形に戻し、［角を丸くする］効果で角丸を付ける（ほかのアピアランスはそのまま）。［0の半径は0のままに］がオンのあいだは選べない
- 2 つの効果のオプションは、吹き出し形状と、複合パス・複合シェイプの中の長方形には効かない

### 注意点

- 回転した長方形、長方形以外のパス、ロック・非表示のオブジェクト、ガイドは変更しない
- 複合シェイプを変換すると元の複合シェイプには戻せない（取り消しは可能）
- ［選択したオブジェクトのみ］で対象外のオブジェクトが含まれているときは、その数をダイアログに表示。選択に対象が 1 つも無いときは「選択に対象がありません」と表示
- 対象の長方形が無いときは OK を押せない
- 半径の初期値は、ダイアログを開いたときの対象にある角丸（半径 0 の角を除く）の平均
- 短辺の半分を超える値は、短辺の半分に制限される（吹き出し形状は口の付け根までの距離にも制限される）
- ［「角を丸くする」効果を含む］がオンのとき、および複合シェイプを変換するときは、複製してアピアランスを分割して計測するため、対象が多いと時間がかかる
