### 概要

- よく使うフォントを分類と規格で絞り込んだ一覧から選び、選択中のテキストに適用する Illustrator スクリプト
- 同じ書体の規格違い（Pr6N・Pr5 など）は、チェックした規格の中で優先順位がいちばん高いものだけを一覧に残す
- 中華・ハングル・タイ・その他マルチリンガルのフォントは、初期状態で一覧から外す
- 一覧で選んだフォントは、選択中のテキストにすぐプレビューされる
- KOUJI & 相棒（Gem）さんの「よく使うフォントパネル」（favoriteFont_AI.jsx v1.1.2、MIT License）をもとに改変

### 主な機能

**一覧**

- 左に絞り込みのチェックボックス、右にフォント一覧の2カラム
- ファミリー名の見出しの下にウェイトを字下げして並べる（スタイルが1つだけのファミリーと合成フォントは1行）
- ［PostScript名で表示］：PostScript 名（RyuminPr6N-Light など）を1フォント1行で並べる
- 開いたときは、選択中のテキストのフォントを選んだ状態にする

**絞り込み**

- ［分類］：チェックしたものを合わせて表示
  - カスタム：［カスタムに追加］で加えたフォント。規格違いの間引きと除外（［日本語以外を除外］を含む）はしない
  - ドキュメント：ドキュメントと同じフォルダーの `_ProjectFonts.txt` に記録したフォント。規格違いの間引きと除外（［日本語以外を除外］を含む）はしない
  - モリサワ／TB（タイプバンク）／FOT（フォントワークス）／ヒラギノ：ファミリー名・PostScript 名の先頭で判定
  - Adobe（小塚・源ノ・りょう）：Adobe 自社の和文書体（かづらきを含む）。Adobe Fonts の配信フォントはフォント名で見分けられないため対象外
  - 合成フォント：［書式］→［合成フォント］で作ったもの。規格の絞り込みと間引きはしない
- ［すべて表示］：［分類］・規格違いの間引き・`EXCLUDE_FONTS` の除外をやめ、すべてのフォントを表示する（合成フォントも含めて［規格］の絞り込みと［日本語以外を除外］は効く）
- ［規格］：左に無印（Std・Pro・Pr5・Pr6）、右に N 付きを並べる。チェックした規格（と［規格なし］）だけを表示し、同じ書体はチェックした中で優先順位がいちばん高い規格を残す（Pr6N を外せば Pr6 や Pr5 が残る）
- ［規格で絞り込む］：オフにすると［規格］のチェックを無視する（同じ書体は、すべての規格の中で優先順位がいちばん高いものを残す）。初期値オン
- ［分類］［規格］のチェックボックスは、option（Alt）＋クリックで「クリックしたものだけオン」と「すべてオン」を切り替える
- ［絞り込み］：ファミリー名・スタイル名・PostScript 名の部分一致
- ［日本語以外を除外］：中華／ハングル／タイ／その他マルチリンガルのフォントを一覧から外す（初期値はすべてオン。［すべて表示］でも効き、カスタム・ドキュメントに挙げたフォントは残す）。言語はフォント名で判定

**フォントの管理**

- ［カスタムに追加］［カスタムから外す］：一覧で選んだフォントのファミリーを［カスタム］に出し入れする。ほかのフォントにも当たる名前（「DIN」など）を外すときは確認する
- ［使用フォントをフォルダーに記録］：ドキュメントで使っているフォントを `_ProjectFonts.txt` に追記する（InDesign 版と同じファイル）
- ［再スキャン］：インストールされているフォントを読み直す

**適用**

- ［プレビュー］：一覧で選んだフォントを選択中のテキストに仮に当てる（初期値オン、［キャンセル］で元に戻る）
- ダブルクリック、Enter キー、［適用］で適用して閉じる
- チェックの状態（［日本語以外を除外］を含む）・［カスタム］のフォント・絞り込みの文字列は、次回も同じ状態で開く

### 使い方

1. テキストフレームまたはグループを選択する（文字ツールで一部の文字を選択してもよい）
2. スクリプトを実行する
3. 左のチェックボックスと［絞り込み］で一覧を絞る
4. 一覧でフォントを選んでプレビューを確かめ、ダブルクリック、Enter キー、または［適用］で適用する

［絞り込み］は、結果が800件以下なら入力のたびに一覧を更新し、それより多いときは件数だけを表示して Enter キーで一覧を更新します（件数は `LIVE_SEARCH_MAX_FONTS` で変更可）。

### オプション（スクリプト冒頭のユーザー設定）

| 項目 | 内容 | 初期値 |
|---|---|---|
| CUSTOM_FONTS | ［カスタム］の初期値。以後はダイアログで変更し、設定ファイルに保存 | Graphik, DIN |
| EXCLUDE_FONTS | 一覧から外すフォント（部分一致。［すべて表示］・カスタム・ドキュメントでは外さない） | NT |
| RESCUE_FONTS | EXCLUDE_FONTS に当たっても残すフォント（部分一致） | なし |
| PRIORITY_PREFIXES | 残す接頭辞の優先順位（先頭ほど優先） | A-OTF, A P-OTF, AP-OTF, G-OTF, U-OTF |
| PRIORITY_SUFFIXES | 残す規格の優先順位。［規格］のチェックボックスにも並ぶ | Pr6N, Pr6, Pr5N, Pr5, ProN, Pro, StdN, Std |
| FOUNDRY_FILTERS | メーカー別の分類（ファミリー名・PostScript 名の前方一致） | モリサワ・TB・FOT・ヒラギノ・Adobe |
| LANGUAGE_GROUPS | ［日本語以外を除外］の言語と、名前での判定の規則（前方一致・正規表現） | 中華・ハングル・タイ・その他マルチリンガル |
| LIVE_SEARCH_MAX_FONTS | 入力のたびに一覧を更新する件数の上限 | 800 |

カスタム・ドキュメントの名前は語の単位で照合します（「Pr5」は「Pr5N」に当たらず、「DIN」は「DIN 2014」に当たる）。

### 注意点

- 初回と、フォントの構成が変わったとき（総数と、一覧から等間隔に取った32件の名前で判定）は、フォント情報を読み込んでから開きます（進み具合を表示）。判定をすり抜けたときは［再スキャン］を押してください。キャッシュは `~/Library/Application Support/illustrator-scripts/FavoriteFontPicker-fonts.txt`
- 適用先は、ダイアログを開いたときに選択していたテキストです。ダイアログを開いたままでは選択を変えられないため、適用すると閉じます
- プレビューは、テキストを複製して元を一時的に隠して見せます。文字ツールで一部の文字を選んだときと、連結したテキストはプレビューしません（［適用］では適用します）
- 環境にないフォントは一覧に出ません
- ロック・非表示のテキストには適用しません
- ［使用フォントをフォルダーに記録］は、一度保存したドキュメントで使えます
