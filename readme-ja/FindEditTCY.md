### 概要

- 選択したテキストから、縦中横が適用されている文字を集めて、ダイアログボックスに1箇所ずつ一覧で表示する。
- 一覧で行を選ぶと、ドキュメント上でその箇所を選択する。そのまま文字列の書き換え、字形の幅、トラッキングを調整できる。

### 主な機能

- 「縦中横の文字」（左）
  - **一覧**：続けて縦中横になっている文字を1つの箇所として、見つかった順に並べる。同じ文字列でも1箇所ずつ別の行にする。上に件数を表示
  - **箇所の選択**：行を選ぶと、ドキュメント上でその箇所を文字選択する。テキストフレームが画面の外にあるときは表示を移す
  - **置換後**：選んだ箇所の書き換え後の文字列。打っている間は一覧の行が「12 → 10」のように変わる。空にするとその箇所を削除する（縦中横は残る）
  - **［適用］**：選んだ箇所の書き換えをその場で反映する。押さなかった書き換えは［OK］で反映する
- 「文字種」（右上）
  - **字形の幅**：標準字形・等幅全角字形・等幅半角字形・等幅三分字形・等幅四分字形。行を選ぶと今の字形が選ばれ、クリックするとすぐに反映する
  - **［自動適用］**：一覧のすべての箇所に、文字数に応じた字形をすぐに掛ける（1文字→標準字形、2文字→等幅半角字形、3文字→等幅三分字形、4文字→等幅四分字形。5文字以上はそのまま）
- 「トラッキング」（右下）
  - **トラッキング**：▲▼ボタン・↑↓キーで1ずつ、shift＋クリックで10の倍数へ。値を変えるとすぐに反映する
  - **［リセット］**：選んだ箇所のトラッキングを 0 に戻す
- ダイアログボックスを閉じると、実行前の選択に戻す
- 日本語／英語の自動切り替え

### 使い方

1. 縦中横を含むテキストオブジェクトを選択する（文字ツールで範囲を選んでもよい）
2. スクリプトを実行する
3. 一覧で行を選び、書き換え・字形・トラッキングを調整する
4. ［OK］をクリックする

### 注意点

- 字形・トラッキング・［自動適用］・［適用］はその場で反映するため、［キャンセル］を押しても元に戻らない。戻すときは、ダイアログボックスを閉じてから取り消す
- 文字数が変わる書き換えでは、書き換えた部分は先頭の文字の書式になる
- 連結したテキストはストーリー全体をまとめて調べる。ロック中・非表示のテキストは対象にしない
- 一覧に表示するのは先頭の500行まで
