# オブジェクトに合わせてアートボードのサイズを調整

### 概要

アートボードのサイズを「操作」（オブジェクトに合わせる／アートボードを拡張）、「対象」（現在／すべて）、「サイズ」（幅・高さ）の組み合わせで調整します。マージンや丸めを変更するたびにアートボード上のプレビューが更新され、［OK］で表示どおりに確定します。

<img alt="アートボードサイズを調整ダイアログの外観" src="../png/ss-574-1008-144-20260910-173627.png" width="50%" />

### 主な機能

- 2つの操作：選択オブジェクトの外接に合わせる／アートボード自身のサイズを加減する
- 対象は現在のアートボードとすべてのアートボードから選択
- 幅だけ・高さだけの調整（OFFにした側は実行時のサイズのまま固定）
- 選択なしで「合わせる」を実行すると、各アートボード内のオブジェクトに合わせて全アートボードを個別に調整
- 上下・左右のマージンを個別に指定。［連動］で上下の値を左右にも反映
- マージンの単位は定規単位に追随し、単位ごとに初期値を用意（mm=5、px=20、pt=10）
- プレビュー境界（線・効果を含む見た目）と幾何境界の切り替え
- アートボードの座標・サイズの丸め：ピクセルグリッドに最適化／現在の単位で整数に／何もしない
- ライブプレビュー。キャンセルすると開いた時点の状態へ戻します
- ↑↓キーによる数値の増減。Shiftで10の倍数へスナップ、Optionで0.1刻み
- セッション中は最後の設定とダイアログ位置を記憶
- 日本語／英語UI

### 使い方

1. アートボードを選ぶか、基準にしたいオブジェクトを選択します。
2. スクリプトを実行します。
3. ［調整基準］で操作・対象・サイズを選び、マージンを入力します。
4. プレビューを確認して［OK］をクリックします。

「アートボードを拡張」ではマージンがアートボード自身のサイズに加算されます。マイナス値を入れると縮小します。

［幅］［高さ］はどちらか一方だけをONにできます。Option＋クリックすると、クリックした側だけをONにしてもう一方をOFFにします。

### オプション

**調整基準**

| 項目 | 内容 |
| --- | --- |
| 操作 | オブジェクトに合わせる／アートボードを拡張 |
| 対象 | 現在のアートボード／すべてのアートボード |
| サイズ | 変更する方向（幅・高さ）。OFFにした側は実行時のサイズのまま固定されます |

**マージン**

| 項目 | 内容 |
| --- | --- |
| 上下 | 上下方向に加減する値（［高さ］ONのときだけ入力できます） |
| 左右 | 左右方向に加減する値（［幅］ONのときだけ入力できます） |
| 連動 | 上下の値を左右にも自動で適用します |
| プレビュー境界 | ONで線・効果を含む見た目の境界、OFFでパスの幾何境界を計測します（「合わせる」のときだけ有効） |

**アートボードサイズの微調整**

| 項目 | 内容 |
| --- | --- |
| ピクセルグリッドに最適化 | 座標とサイズを整数ピクセルに丸めます |
| 現在の単位で値を整数値に | 現在の定規単位で座標とサイズを整数に丸めます |
| 何もしない | 丸めずに計測値のまま設定します |

丸めは X・Y・幅・高さの4値をそれぞれ1回だけ整数化し、右下は X＋幅／Y−高さ で組み立てます（二重に丸めません）。

### 注意点

- 「オブジェクトに合わせる」×「現在のアートボード」は選択が必要です。選択が無いときは対象が「すべてのアートボード」に固定されます。
- 「オブジェクトに合わせる」×「すべてのアートボード」では選択を無視し、各アートボードに重なるオブジェクトを対象にします。ロック・非表示・ガイド、およびロック／非表示レイヤーのオブジェクトは除外し、対象が無いアートボードはそのままにします。
- テキストは複製をアウトライン化して計測するため、元のテキストには触れません（ID・重ね順・名前・タグなどが保持されます）。
- クリップグループはクリッピングパスの範囲で計測します。
- マージンが大きすぎて幅または高さが0以下になるアートボードは、適用をスキップしてメッセージを表示します。
- 設定はセッション中のみ記憶します（Illustratorを再起動するとリセットされます）。

### オリジナルからの変更点

- ダイアログボックスを閉じずにプレビュー更新
- 単位系（mm、px など）によってデフォルト値を切り替え
- アートボードの座標・サイズをピクセルベースで整数値に
- オブジェクトを選択していない場合には、すべてのオブジェクトを対象に
- ↑↓キー、shift + ↑↓キーによる入力
