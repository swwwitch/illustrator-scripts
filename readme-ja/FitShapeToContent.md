### 概要

テキストやグループに合わせて、背面の座布団形状を手早く作成・調整します。パディングと角丸をダイアログで調整でき、値を変えるたびに結果がその場でプレビューされます。

### 主な機能

- 【テキスト／グループを1つ選択】背面に座布団用の長方形を自動作成します
- 【テキスト／グループ＋図形を選択】選んだ図形を座布団として使い、コンテンツの中心に合わせます
- 【テキストと図形のグループを1つ選択】グループを保ったまま、中の図形を座布団として使います
- パディング（幅・高さ）と角丸（半径・ピル形状）をプレビューしながら調整できます

### 使い方

1. テキストまたはグループを選択します（既存の図形を使う場合は図形も一緒に選択、またはテキストと図形のグループを選択）。
2. スクリプトを実行します。
3. パディングと角丸を調整して［OK］をクリックします。

### オプション

| 項目 | 動作 |
| --- | --- |
| 座布団の調整 | オフにすると、サイズを変えずにコンテンツの中心に合わせるだけになります |
| パディング（幅・高さ） | コンテンツの周囲に加える余白 |
| 連動 | 幅と高さを同じ値にそろえます |
| 角丸（半径） | 角丸の半径。オフにすると角丸なしになります |
| ピル形状 | 半径を高さの半分にし、両端を半円にします。幅は自動計算されます |

パディングと半径の入力欄は、ドキュメントの定規単位で表示・入力します。↑↓キーで数値を増減できます。

| キー | 増減 |
| --- | --- |
| ↑↓ | ±1 |
| Shift + ↑↓ | ±10（10の倍数にスナップ） |
| Option + ↑↓ | ±0.1 |

「座布団の調整」の初期状態は、長方形を自動作成するとき（テキスト／グループだけを選んだとき）はオン、既存の図形を使うときはオフです。

### 注意点

- パディングはパスの実寸を基準にします。線幅を変えても余白の見た目は変わりません。
- 既存の図形を座布団として使うとき、「座布団の調整」をオンにすると、拡大縮小で崩れないよう図形のアピアランスを消去し、塗り・線・不透明度だけを引き継ぎます。
- ピル形状はライブパスファインダーで角丸効果を実体化してから確定します。
- クリッピンググループの計測には対応していません。クリッピングを解除してから実行してください。
- プレビューは操作のたびに取り消し・再作成を繰り返します。［キャンセル］または Esc で元の状態に戻ります。
