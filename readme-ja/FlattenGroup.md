### 概要

- 選択したオブジェクトのグループを入れ子ごとすべて解除し、あらためて1つのグループにまとめます。
- 何重にもネストしたグループを、階層のないひとつのグループに整理したいときに使います。

### 使い方

1. 対象のオブジェクトを選択する
2. スクリプトを実行する

### 注意点

- 選択がないときは何もしません。
- ダイアログはありません。
