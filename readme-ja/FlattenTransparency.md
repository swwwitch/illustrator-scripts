### 概要

- 一時的なアクションを読み込んで実行し、選択オブジェクトの「透明部分を分割・統合」を適用します。
- 実行後、一時アクションはアンロードされます。

### 使い方

1. 対象のオブジェクトを選択する
2. スクリプトを実行する

### 注意点

- 分割・統合の解像度などの設定は、アクション定義内のパラメーターで決まります。
