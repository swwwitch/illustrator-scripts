# ドキュメント内の段落書式を一覧にして、まとめて変更・置換

### 概要

アクティブなドキュメントで使われている書式（フォント・フォントサイズ・行送り・トラッキング・文字ツメ・カーニング・行揃え・段落前後のアキ）を段落ごとに調べ、同じ書式の段落をまとめて一覧にします。

一覧で選んだ書式の値を編集したり、別の書式に置き換えたりすると、その書式の段落がまとめて更新されます。段落スタイルを使わずに「スタイルを再定義する」感覚で、ばらついた書式を整理できます。

### 主な機能

- ドキュメント内のすべてのテキストを段落ごとに調べ、書式ごとに一覧表示（使われている文字数の多い順）
- 一覧の各行は「フォント名　フォントサイズ / 行送り　(段落数)」の形式で表示
- 起動時に選択していたテキストの書式を、最初から一覧で選んだ状態で開く
- 一覧で書式を1つ選ぶと、右側の［書式の編集］で値を編集でき、［更新］でその書式の段落へすぐに反映
- 一覧で書式を選び（複数可）、ポップアップで選んだ書式に［置換］でまとめて置き換える
- 更新・置換のたびにドキュメントを調べ直し、同じ書式になった段落は1行に統合して段落数も数え直す
- ［OK］で確定、［キャンセル］でダイアログを開いたときの状態へすべて戻す
- 数値欄は ↑↓ キーで増減できる（shift で ±10、option で ±0.1）
- フォントサイズ・行送り・段落前後のアキは、環境設定の文字の単位（pt・Q・mm など）で表示

### 使い方

1. 書式を整理したいドキュメントを開きます（特定のテキストを選んでおくと、その書式が最初に選ばれます）。
2. スクリプトを実行すると、左側に書式の一覧が出ます。
3. 値を変えたいときは、一覧で書式を1つ選び、右側の欄を編集して［更新］を押します。
4. ほかの書式にそろえたいときは、一覧で書式を選び（shift／command＋クリックで複数可）、下のポップアップでそろえ先の書式を選んで［置換］を押します。
5. 結果はその場でカンバスに反映されます。よければ［OK］、やめるなら［キャンセル］で閉じます。

### オプション

- **書式の一覧** — ドキュメントで使われている書式です。かっこ内はその書式の段落数です。
  - 1つだけ選ぶと、右側の［書式の編集］が使えます。
  - 複数選ぶと［書式の編集］はディム表示になり、［置換］だけが使えます。
- **置換** — 一覧で選んでいる書式の段落を、ポップアップで選んだ書式に置き換えます。
  - ポップアップでは、一覧で選んでいる書式はディム表示になり選べません。
  - 置き換え先の書式の値をすべて写します。行送りも、自動か固定か（自動なら自動行送り量の％も）をそのまま写します。
  - 置き換えたあとは、置き換え先の書式が一覧で選ばれた状態になります。
- **書式の編集**
  - **フォント** — ドキュメントで使われているフォントから選びます。
  - **フォントサイズ**
  - **行送り／自動** — ［自動］がオンなら、行送りはフォントサイズに追従します（自動行送り量の％はそのまま）。オフにすると固定値を入力できます。
  - **トラッキング** — 単位は 1/1000 em です。
  - **文字ツメ** — ％で指定します。
  - **カーニング** — メトリクス／オプティカル／和文等幅／0 から選びます。
  - **行揃え** — 左揃え・中央揃え・右揃え・均等配置（最終行左／中央／右揃え）・両端揃えから選びます。
  - **段落前のアキ／段落後のアキ**
  - **更新** — 欄で編集した値を、その書式の段落へすぐに反映します。
  - まだ［更新］していない編集があるときは、パネルの見出しが「書式の編集（未反映の変更あり）」になります。
- **OK** — 変更を確定して閉じます。［更新］していない編集もここで反映します。
- **キャンセル** — ［更新］［置換］で反映した変更もすべて元に戻して閉じます。

### 注意点

- 段落スタイルは使いません。段落の文字・段落属性を直接書き換えます。
- 書式は段落の先頭の文字から読みます。段落の途中で書式が変わっている場合も、その段落は先頭の文字の書式として一覧に入ります。
- 書き込むのは値を変えた項目だけです。変えていない項目や、一覧で扱わない属性（水平比率・ベースラインシフトなど）はそのまま残ります。ただし書き込む項目は段落全体に入るので、段落の途中で違っていた値もそろいます。
- 空の段落は一覧に入りません。
- 書式を編集すると、行送りは既定で［自動］になります。固定の行送りを残したいときは［自動］をオフにして値を確かめてから［更新］してください。行送り以外の値を変えずに［自動］だけ残した場合は、行送りは書き換えません。
- 自動行送り量（％）は欄では編集できません。変えたいときは、目的の％を持つ書式へ［置換］します。
- ロックされたレイヤーのテキストなど、書き込めない段落は飛ばします。
- ［フォント］の選択肢は、ドキュメントで使われているフォントだけです。ほかのフォントに変えるときは、あらかじめそのフォントのテキストをドキュメントに置いておきます。
- 環境に無いフォントは PostScript 名で表示され、そのフォントへは変更できません（ほかの値は反映されます）。
- 値は小数第2位までに丸めて扱います。
