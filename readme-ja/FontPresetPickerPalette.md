# 文字設定を「定番」として登録し、選択テキストへ一括適用

### 概要

よく使うフォントを、フォントサイズ・行送り・段落前後のアキ・自動カーニング・文字ツメ・トラッキング・文字揃え・行揃え・禁則・文字組みアキ量設定とセットで「定番」として登録しておき、一覧から選ぶだけで選択中のテキストへまとめて適用する常駐パレットです。

適用する設定はグループ単位で絞り込めます。水平比率・垂直比率、文字前後のアキ、ベースラインシフトは、適用と同時に標準の状態へ戻せます。

UnifiedTypePalette.jsx の「定番」タブを、単独のスクリプトとして切り出したものです。

### 主な機能

- 登録した定番を一覧表示し、クリックすると選択中のテキストへ設定一式をまとめて適用
- 上段にフォント一覧、下段に選択中の定番の内訳（フォントサイズ／行送り／行送り（%）／行送りの基準位置／段落前のアキ／段落後のアキ／自動カーニング／文字ツメ／プロポーショナルメトリクス／トラッキング／文字揃え／行揃え／禁則／文字組みアキ量設定）を「項目名／値」の2列で表示
- ［適用する設定］パネルで、フォント／フォントサイズ／行送り／カーニング・ツメ・トラッキング／揃え・禁則・文字組み／段落前後のアキのうち、どれを適用するかを選べる
- ［クリア］パネルで、水平比率・垂直比率／文字前後のアキ／ベースラインシフトを、適用と同時に標準の状態へ戻せる
- どちらのパネルも option（alt）＋クリックで「その項目だけオン」と「すべてオン」を切り替えられる
- 適用しないグループは、下段の詳細一覧でもディム表示になる
- 行送りは pt ではなく自動行送り量（％）として登録し、適用先も常に「自動」（フォントサイズ追従）にする
- 開いたまま作業でき、テキストを選び直すたびに［追加］［上書き］の可否が切り替わる
- ［追加］で、選択中のテキストの現在値をそのまま定番として登録（同じフォントがすでにあれば設定を上書き）
- ［上書き］で、一覧で選択中の定番を、選択中のテキストの現在値で更新
- ［削除］で、一覧で選択中の定番を削除
- 一覧のフォント名は PostScript 名ではなく、和文名を含む表示名（ファミリー＋スタイル）で表示

### 使い方

1. スクリプトを実行してパレットを開きます。
2. 適用したいテキスト（テキストオブジェクト、または文字の選択）を選びます。
3. 上段の一覧から定番をクリックすると、その場で選択中のテキストへ適用されます。
4. 下段に、その定番の内訳が出ます。
5. 使い終わったらパレットを閉じます（Esc でも閉じられます）。

現在の設定を登録したいときは、そのテキストを選んだ状態で［追加］を押します。
パレットは開いたままなので、選択を変えながら次々に適用できます。

### オプション

- **適用する設定** — チェックを入れたグループだけを適用します。外したグループは、適用先のテキストの設定がそのまま残ります。
  - **フォント** — フォント（書体）
  - **フォントサイズ** — フォントサイズ
  - **行送り** — 自動行送り量（％）と行送りの基準位置
  - **カーニング・ツメ・トラッキング** — 自動カーニング・文字ツメ・トラッキング
  - **揃え・禁則・文字組み** — 文字揃え・行揃え・禁則・文字組みアキ量設定
  - **段落前後のアキ** — 段落前のアキ・段落後のアキ（pt）
  - option（alt）＋クリックで、その項目だけオンと、すべてオンを切り替えます。
- **クリア** — チェックした項目を、定番の適用と同時に標準の状態へ戻します。定番には保存されない、その場かぎりの初期化です。
  - **水平比率・垂直比率** — 100% に戻します
  - **文字前後のアキ** — 文字前のアキ・文字後のアキを「自動」に戻します（0＝アキなしとは別の状態です）
  - **ベースラインシフト** — 0 に戻します
  - こちらも option（alt）＋クリックで切り替えられます。
- **下段の詳細一覧** — 上段で選んだ定番の内訳を「項目名／値」の2列で表示するだけの欄です。ここをクリックしても何も起きません。
- **プロポーショナルメトリクス** — 自動カーニングが「メトリクス」の定番だけ ON になります（自動カーニングに連動する値なので、単独では設定できません）。
- **行送り／行送り（%）** — 定番が持っているのは％（自動行送り量）のほうです。「行送り」の行は、フォントサイズ×％で出した実質の値を参考に表示しています。フォントサイズに対する比率なので、サイズを変えても行送りは追従します。

### 注意点

- テキストを選択していないときも［削除］は使えますが、［追加］［上書き］は使えず、一覧をクリックしても適用されません。
- 選択の有無は、パレットを開いたときとパレットを前面に戻したときに取り直します。テキストを選び直したら、いちどパレットをクリックしてください。
- 適用・読み取りは BridgeTalk で Illustrator のメインエンジンへ委譲しているため、クリックしてから反映されるまでわずかに間があります。
- 常駐パレットなので、スクリプトを書き換えたときは一度パレットを閉じてから実行し直してください（開いたままだと修正前のコードが動き続けます）。
- パレットの位置は移動のたびに `FontPresetPicker_location.txt` へ保存し、次回は同じ位置で開きます。
- 定番は `Folder.userData` 直下の `FontPresetPicker_presets.json` に保存します。UnifiedTypePalette.jsx のプリセット（`UnifiedTypePanel_presets.json`）とは別のファイルです。
- 保存ファイルが壊れていた場合は `.bak` に退避してから初期状態に戻します。
- 定番に登録したフォントが未インストールの場合、一覧には PostScript 名のまま表示され、クリックしてもフォントは適用されません（ほかの設定は適用されます）。
- 行揃え・禁則・文字組みアキ量設定・段落前後のアキは段落単位の設定です。行の一部だけを選んで適用しても、その段落全体が変わります。
- v1.0.0 で登録した定番は段落前後のアキを持っていないため、適用しても適用先の段落前後のアキは変わりません（詳細一覧は空欄）。［上書き］で登録し直すと保存されます。
- 禁則の「なし」はスクリプトから設定できません（Illustrator の仕様）。定番が「なし」でも、適用先の禁則は変わりません。
- 文字組みアキ量設定はドキュメントの設定一覧（`mojikumiSet`）を参照します。カスタムの設定を含むドキュメントでは、想定と違う設定が当たることがあります。
- 文字組みアキ量設定の「行末約物半角」は、読み取ると「約物半角」と同じ値で返るため区別できません。このテキストから［追加］すると「約物半角」として登録されます。
- ［クリア］の「文字前後のアキ」は「自動」（DOM 上は `-1`）に戻します。`0` は「アキなし」を明示した別の状態なので、そちらには戻しません。
- 行揃えを変えると、ポイント文字は見た目の位置が動きます（基準点が変わるため）。
- フォントサイズ・行送り％は小数第2位まで保存します（10.5pt などの端数もそのまま登録できます）。
- 行送りは pt で焼き込まず、自動行送り量（`autoLeadingAmount`）として入れます。Illustrator の［文字］パネルでは常に「自動」表示になります。
- 自動行送り量は段落単位の設定です。行の一部だけを選んで適用しても、その段落全体の行送りが変わります。
- 行送りが pt で固定されているテキストから［追加］した場合は、フォントサイズとの比から％を逆算して登録します。
