### 概要

選択したテキストの1文字ごとに、ランダムなフォントを適用します。

### 主な機能

- ダイアログでプレビューを確認
- ［再実行］ボタンで抽選し直し

### 使い方

1. 対象のテキストを選択します。
2. スクリプトを実行します。
3. ［再実行］で気に入る結果になるまで試し、［OK］で確定します。
