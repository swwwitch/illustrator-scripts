# 数字に桁区切りのカンマを付ける

### 概要

テキスト内の4桁以上の数値に、3桁ごとの桁区切りのカンマを付けます。位置の誤ったカンマ（`12,34,567` など）も直します。

西暦・郵便番号・電話番号など、カンマを付けるべきでない数値は除外します。どの数値を書き換えるかはプレビューで選べます。書き換えるのはカンマだけなので、文字の書式や文中のカンマはそのまま残ります。

<img alt="桁区切りのカンマを付けるダイアログの外観" src="../png/ss-478-792-144-20260921-200739.png" width="50%" />

### 使い方

1. カンマを付けたいテキストを選択します。ドキュメント全体を対象にする場合、選択は不要です。
2. スクリプトを実行します。
3. ［対象］と［除外］を設定して［OK］を押します。
4. プレビューに、カンマを付ける（直す）数値が並びます。
   - ✓ の付いた行の数値だけにカンマが付きます。
   - 行をクリックすると ✓ を付け外しできます。［すべて選択］で全行に ✓ を戻せます。
   - ［#］は、テキストを上から順（同じ高さは左から）に数えた番号です。
5. ［OK］を押すと書き換えます。

### オプション

**対象**

| 項目 | 内容 |
| --- | --- |
| 選択したオブジェクトのみ | 選択中のテキストと、選択したグループ（クリップグループを含む）内のテキスト |
| ドキュメントすべて | ドキュメント内のすべてのテキスト |

**除外**（初期状態はすべてオン）

| 項目 | 除外する数値 |
| --- | --- |
| 西暦 | 1000〜2999 の4桁で、直後に「年」があるか前後に日付の区切り（/ . -）があるもの。`2024.12`、`2024.12.31` のような日付の西暦 |
| 郵便番号 | `123-4567` の形のもの（〒の有無は問わない） |
| スラッシュの前後 | 直前か直後にスラッシュ（/ ／）があるもの |
| 電話番号 | 0・+・括弧で始まり、ハイフン・スペース・括弧で区切ったもの |
| クレジットカード番号 | ハイフンやスペースの区切りを含めて13〜19桁で、Luhn チェックを通るもの |
| MACアドレス | `00:1A:2B:3C:4D:5E` のように、コロンかハイフンで区切ったもの |

### 注意点

- 次の数値は、除外の設定に関係なく常に除外します。
  - 0で始まる数値（`00123456`、`0312345678` など）
  - 英字や # のすぐ後に続く数値（`SKU12345`、`#112233`）
  - 「数字.」に続く数値（`10.0.19045` の `19045` など）
- 数値の後ろに続く英字は単位とみなし、カンマを付けます（`12000mm` → `12,000mm`）。
- 全角数字には全角のカンマ「，」を付け、符号と小数点も全角にそろえます。半角数字では、符号・小数点・カンマを半角にそろえます。
- 1000〜2999 の整数に 01〜12 の2桁の小数が付いた数値（`1500.10` など）は、年月とみなして除外します。
- ロックされたテキストなど、書き換えられないテキストは飛ばします。
