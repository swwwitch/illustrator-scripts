### 概要

- アートボードまたは選択オブジェクトの外接矩形を、指定した行数・列数に分割してグリッド用のガイドを作成するスクリプト。
- アートボードのエッジ、セルの長方形化（角丸・中心点の表示）、プリセットの読み込み／書き出しにも対応。

### 主な機能

- 対象を「選択オブジェクト」「アートボード」「すべてのアートボード」から選択
- 行数・列数と、行間・列間（ガター）の指定。ガターは連動も可能
- 上下左右のマージンを個別に指定。連動チェックで一括適用
- ガイドをアートボードの外へ伸ばす「伸張」の指定
- アートボードの上下左右4辺にガイドを引く「アートボードのエッジ」（マージン0の辺は外周ガイドと重複するため引きません）
- 各セルの左右中央に縦ガイドを引く「各セルを左右分割」
- セルの長方形化（別レイヤー・不透明度・角丸・中心点の表示）
- 既存ガイドの削除（チェックした時点でプレビューに反映）
- プリセットの読み込みと、現在の設定の書き出し
- 設定変更に追従するライブプレビュー
- アウトライン表示／プレビュー表示の切り替え
- 日本語／英語UIの自動切り替え

### 使い方

1. 対象にするオブジェクトを選択（またはアートボードをアクティブに）してスクリプトを実行
2. ダイアログで行数・列数、マージンなどを設定（変更はライブプレビューに反映）
3. ［OK］で確定

### オプション

- **対象**：選択オブジェクト／アートボード／すべてのアートボード（選択がないときは「選択オブジェクト」、アートボードが1つのときは「すべてのアートボード」がディム）
- **元のオブジェクト**（対象が選択オブジェクトのとき）：削除する／残す／ガイド化する
- **長方形化**：セルを長方形として描画。不透明度はスライダーで指定
- **角丸**：各長方形に角丸（ライブエフェクト）を適用。半径は数値で指定
- **中心点を表示**：作成した長方形の中心点を属性パネルで表示（［OK］時に適用）
- **ガイドを引く**：グリッドのガイドを描画
- **ガイドの伸張**：アートボードの外へ伸ばす距離
- **アートボードのエッジ**：アートボードの4辺にガイドを描画（対象が選択オブジェクトのときはディム）
- **各セルを左右分割**：各セルの左右中央に縦ガイドを追加
- **既存ガイドを削除**：`grid_guides` レイヤー内の既存ガイドを削除（「ガイドを引く」がOFFのときはディム）

### 注意点

- ガイドは `grid_guides` レイヤー、セルの長方形は `cell-rectangle` レイヤーに作成され、［OK］後にガイドのレイヤーはロックされます。
- 「既存ガイドを削除」は `grid_guides` レイヤー内のガイドだけが対象です。対象が「すべてのアートボード」のときはすべて、それ以外はアクティブなアートボード上のガイドのみを削除します。
- マージンやガターが大きすぎてセルの幅・高さが0以下になる対象はスキップされます。
- 行数・列数が空欄や不正な値のときは1として扱います。グリッドを描けない設定のときは、「既存ガイドを削除」にチェックが入っていても削除しません。
- 文字を編集中（文字を選択している状態）は、選択オブジェクトとして扱いません。

### 標準ツールでなく、このスクリプトを使うメリット

- アートボードを対象にする場合、アートボードサイズの長方形を描く手間が省ける
- すべてのアートボードを対象にできる
- アートボードに対して上下左右、個別にマージンを設定できる
- アートボードからどれだけ伸ばすか、指定できる

### 段組設定との違い

スクリプトの方は次のような特徴があります。

- アートボードが対象（段組設定はパスが対象）
- ガイドの長さを調整できる（段組設定はガイドが長い）
- 上下左右のマージンを個別に設定できる
- プリセットを登録できる
- 生成される長方形が別レイヤーに、不透明度を15%に設定
