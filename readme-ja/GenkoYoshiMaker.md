# テキストを原稿用紙に組む

[![Direct](https://img.shields.io/badge/Direct%20Link-GenkoYoshiMaker.jsx-ffcc00.svg)](https://github.com/swwwitch/illustrator-scripts/blob/master/jsx/fx/GenkoYoshiMaker.jsx)

### 概要

選択したテキストを1文字＝1マスに組み直し、マス目の罫線を引くスクリプトです。文字の比率・送り・行送りをマスに合わせたうえで、マスの区切りと行の両側の罫線、十字線を作成します。

縦組み・横組み、ポイント文字・エリア内文字のいずれにも対応し、組み方向は変換しません。ダイアログの設定はそのままプレビューに反映され、閉じずに確認できます。

### 主な機能

- 1文字＝1マスになるよう文字属性を調整（比率、トラッキング、ツメ、プロポーショナルメトリクス、自動行送り、行揃え、カーニング）
- 比率はダイアログで指定（初期値90%）。オフにすると比率は変えず、送りだけを今の比率に合わせる
- 各行の行頭にトラッキングの1/4のカーニングを入れ、字面をマスの中央へ
- 縦組み・横組みの両方に対応（ダイアログのパネル名も組み方向に合わせて変わる）
- 複数行に対応。行と行のアキは自動行送りで決まる（初期値125%＝マスの1/4のアキ）
- エリア内文字は「自動サイズ調整」で枠を文字に合わせてから罫線を引く
- マスは文字サイズの正方形（字面を縮めた分は含めない）
- マスの区切りを実線または破線で作成し、指定した文字数ごとに太く
- 罫線の代わりに、1マスにつき1つの長方形を作ることも可能
- 行の両側に罫線を作成（書字方向の前後へはみ出す量を指定可能、突出線端）
- いちばん外側の行のさらに外へ、行と行のアキと同じ距離でもう1本
- 太罫の太さを比率で指定し、対象（行の罫線／マスの区切り）も選べる
- 各マスの中央に十字線（なし／実線／破線）。破線は分割数だけで指定し、線分と間隔はマス1辺を等分
- 文字の前後にマス、行の外側に行を足せる
- 罫線の濃度を0〜100%のスライダーで調整（shiftで10%刻み）
- 設定をまとめて切り替えるプリセット。［追加］で今の設定を一覧へ追加
- OKで決めた設定は、Illustratorを終了するまで次回の初期値として引き継がれる
- ダイアログを閉じずに結果を確認できるプレビュー（原本には触らず、複製で表示）
- 罫線は専用レイヤー（`原稿用紙罫線`）に作成し、最背面へ配置
- 日本語／英語UI

### 使い方

1. 罫線を引くテキストを1つ選択します（縦組み・横組みのどちらでも可）。
2. `GenkoYoshiMaker.jsx` を実行します。
3. プリセットを選ぶか、［全体］［文字］［縦罫／横罫］［十字線］の各パネルで設定します。
4. プレビューで結果を確認します（「プレビュー」をオフにすると非表示）。
5. 「OK」をクリックして罫線を作成します。

### オプション

| 項目 | 初期値 | 内容 |
| --- | --- | --- |
| プリセット | 標準 | 標準／外側の罫線なし／十字線なし／シンプル／カスタム。手で値を変えるとカスタムに切り替わる |
| ［追加］ | - | いまの設定に名前を付けてプリセットへ追加し、組み込み用のコードを表示 |
| 文字ごとに長方形を作成 | オフ | マスの区切りと行の両側の罫線の代わりに、1マスにつき長方形を1つ作成。太罫と行の両側の罫線の設定はディムになる |
| 罫線の濃度 | 50% | 罫線の濃度をスライダーで指定（shiftで10%刻み） |
| 太罫の比率 | 250% | 太くする罫線の太さ。ふつうの罫線（0.1mm）に対する比率 |
| 太罫の対象 | 縦罫・横罫の両方 | 太罫の比率を使う罫線。縦罫＝行の両側の罫線、横罫＝n文字ごとの区切り（横組みでは名前が入れ替わる） |
| マスを追加 | 0文字 | 文字の前後に足す空のマスの数 |
| 行を追加 | 0行 | 行の外側に足す空の行の数 |
| 文字の比率を調整 | オン | 比率を変えてマスに合わせる。オフでも送りはそろえる |
| 比率 | 90% | 文字の水平比率・垂直比率 |
| 自動行送り | 125% | 行と行の送り。100%を超えた分が行と行のアキになり、外側の罫線もその位置に引かれる |
| はみ出し | 文字サイズの1/4 | 行の両側の罫線を書字方向へ伸ばす量。初期値は文字サイズの1/4をmmに換算し、小数第1位に丸めた値 |
| いちばん外に1本追加 | オン | いちばん外側の行の外、行と行のアキと同じ距離に罫線を追加 |
| 線種（マスの区切り） | 実線 | 実線または破線（1mm／1mm） |
| 強調（n文字ごとに太く） | オン／5 | 指定した文字数ごとにマスの区切りを太く（1文字目から数える） |
| 線種（十字線） | 破線 | なし／実線／破線から選択 |
| 分割数（十字線） | 9 | 破線にしたときの線分の本数。0か3以上の奇数に丸められる |
| プレビュー | オン | ダイアログを閉じずに結果を表示 |

数値欄は↑↓キーで増減できます（Shiftで±10かつ10の倍数にスナップ）。分割数だけは 0 → 3 → 5 → 7 と動きます。

### 罫線の仕様

| 罫線 | 太さ | 濃度 |
| --- | ---: | ---: |
| 行の両側の罫線 | 太罫の対象なら0.25mm（0.1mm × 太罫の比率）、外すと0.1mm | 罫線の濃度 |
| マスの区切り | 0.1mm | 罫線の濃度 |
| 太くしたマスの区切り | 太罫の対象なら0.25mm（0.1mm × 太罫の比率）、外すと0.1mm | 罫線の濃度 |
| 外側の罫線 | 行の両側の罫線と同じ | 罫線の濃度 |
| マスの長方形 | 0.1mm | 罫線の濃度 |
| 十字線 | 0.1mm | 30%（`LAYOUT.crossGray`） |

縦組みでは「行の両側の罫線」が縦罫、「マスの区切り」が横罫になります。横組みでは逆になり、ダイアログのパネル名も入れ替わります。行の両側の罫線と外側の罫線は「突出線端」です。

RGBドキュメントでは、同じ濃度に相当するグレーのRGB値を使用します。

### 文字属性の調整

マス目に文字を合わせるため、次の属性を設定します。

| 属性 | 値 |
| --- | --- |
| 水平比率・垂直比率 | ダイアログの比率（初期値90%） |
| トラッキング | 比率から計算（`100000 ÷ 比率 − 1000`。90%なら約111） |
| カーニング（各行の行頭） | トラッキングの1/4（1/1000em） |
| 自動行送り | ダイアログの値（初期値125%＝マス1つ＋マスの1/4のアキ） |
| 行揃え | 書字方向の先頭（縦組みは上、横組みは左）。位置がずれないよう戻す |
| ツメ | 0 |
| プロポーショナルメトリクス | オフ |
| 文字前後のアキ | 自動 |
| 自動カーニング | 和文等幅 |

ツメ・プロポーショナルメトリクス・自動カーニングは段落単位で設定します（テキスト全体へ書いても反映されないため）。

### グリッドの基準位置

| テキストの種類 | 書字方向の基準 | 行が並ぶ向きの基準 |
| --- | --- | --- |
| ポイント文字 | 字面の先頭（縦組みは上端、横組みは左端） | 字面の中央 |
| エリア内文字 | 枠の先頭（縦組みは上端、横組みは左端） | 枠の左（横組みは上） |

エリア内文字は、実行時とOK時に「自動サイズ調整」を適用して枠を文字に合わせます（一時的に読み込むアクションで実行）。

### 注意点

- Illustrator 2024〜2026に対応しています。
- テキストオブジェクトを1つだけ選択して実行してください。
- マスの大きさは先頭文字の文字サイズを基準にします。文字サイズが混在するテキストでは、意図した位置に罫線が引かれません。
- 半角文字が混ざると1文字が1マスに収まらないため、マスと文字がずれます。
- 行送りは「自動行送り」で合わせます（ダイアログで比率を指定）。文字サイズを変えても行送りが追従しますが、元の行送りの設定は保持されません。
- 行頭のカーニングは寸法を測ったあとに入れます（先に入れると罫線ごとずれるため）。
- トラッキングは1/1000em指定のため、文字サイズを変えても比率は変わりません。比率を変えたときだけ計算し直されます。
- エリア内文字の枠は、実行した時点で「自動サイズ調整」により文字に合わせられます。キャンセルしても枠の大きさは戻りません。
- 「文字ごとに長方形を作成」をオンにすると、マスの区切りと行の両側の罫線（外側の1本を含む）は引かず、塗りなし・線だけの長方形を1マスにつき1つ作ります。線種（実線／破線）と濃度は罫線の設定に従い、十字線は［十字線］パネルの設定どおりです。
- 再実行すると、そのテキストに前回引いた`罫線`グループだけを作り直します。ほかのテキストに引いた罫線は残ります。
- プレビュー中は選択したテキストを一時的に複製して表示し、実行中は選択のエッジ表示を切り替えます。キャンセルすると元の状態に戻ります。
- ［追加］で加えたプリセットは、その実行のあいだだけ有効です。次回も使うには、表示されるコードを `PRESETS` に貼り付けてください。
- 設定できなかった文字属性があるときだけ、実行後に属性名を通知します。
