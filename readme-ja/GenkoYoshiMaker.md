# テキストを原稿用紙に組む

### 概要

選択したテキストの文字送りをマス目にそろえ、1文字分の間隔で罫線を引き、行の両側に罫線を添えるスクリプトです。縦組み・横組みのどちらにも対応します（組み方向は変換しません）。

縦罫の伸張、横罫の線種、太くする間隔、十字線の有無をダイアログで指定します。設定を変えるたびに結果がプレビューされ、ダイアログを閉じずに確認できます。

### 主な機能

- 文字属性をマス目に合わせて自動調整（比率、トラッキング、ツメ、プロポーショナルメトリクス、文字前後のアキ、カーニング）
- 比率はダイアログで指定（初期値90%）。オフにすると比率は変えず、送りだけを今の比率に合わせる
- 1文字目の上にトラッキングの1/4のカーニングを入れ、字面をマスの中央へ
- 縦組み・横組みの両方に対応（ダイアログの項目名も組み方向に合わせて変わる）
- 1文字分の間隔で横罫線を作成（先頭文字の上から最後の文字の下まで）
- マスは文字サイズの正方形（字面を縮めた分を含めず、幅も文字サイズで作成）
- テキスト全体の左右に縦罫線を作成（上下へ伸ばす量を指定可能）
- 文字サイズの1/4だけ外側に、左右の縦罫線を追加
- 指定した文字数ごとに横罫線を太く
- 各マスの中央に十字線（実線／破線）を追加。破線は分割数だけで指定し、線分と間隔はマス1辺から等分
- 文字の前後に空のマスを足せる
- テキストの左右に空の行を足せる（マスの1/4だけアキを空けた独立した行）
- 罫線の濃度をK0〜K100のスライダーで調整（shiftで10%刻み）
- 設定をまとめて切り替えるプリセット。［保存］で今の設定を一覧へ追加
- OKで決めた設定は、Illustratorを終了するまで次回の初期値として引き継がれる
- ダイアログを閉じずに結果を確認できるプレビュー
- 罫線は専用レイヤー（`原稿用紙罫線`）に作成し、最背面へ配置
- 日本語／英語UI

### 使い方

1. 罫線を引く縦組みテキストを1つ選択します。
2. `GenkoYoshiMaker.jsx` を実行します。
3. プリセットを選ぶか、［全体］［文字］［縦罫］［横罫］［十字線］の各パネルで設定します。
4. プレビューで結果を確認します（「プレビュー」をオフにすると非表示）。
5. 「OK」をクリックして罫線を作成します。

### オプション

| 項目 | 初期値 | 内容 |
| --- | --- | --- |
| プリセット | 標準 | 標準／左右の縦罫なし／十字線なし／シンプル／カスタム。手で値を変えるとカスタムに切り替わる |
| 罫線の濃度 | K50 | 罫線の濃度をスライダーで指定（shiftで10%刻み） |
| 前後のマス | 0 | 文字の前後（上下）に足す空のマスの数 |
| 左右の行数 | 0 | テキストの左右に足す空の行の数。マスの1/4だけアキを空けて並べる |
| 文字の比率を調整 | オン | 比率を変えてマスに合わせる。オフでも送りはそろえる |
| 比率 | 90% | 文字の水平比率・垂直比率 |
| 伸張 | 文字サイズの1/4 | 行の両側の罫線を書字方向へ伸ばす量。初期値は文字サイズの1/4をmmに換算して小数第1位に丸めた値 |
| 外側にもう1本追加 | オン | いちばん外側の行の外、文字サイズの1/4の位置に縦罫線を追加 |
| 横罫 | 実線 | 横罫線を実線または破線（1mm／1mm）で作成 |
| n文字ごとに太く | オン／5 | 指定した文字数ごとに横罫線を太く（0.25mm） |
| 十字線の線種 | 破線 | なし／実線／破線から選択 |
| 保存 | - | いまの設定に名前を付けてプリセットへ追加（コードを表示） |
| 十字線の分割数 | 9 | 破線にしたときの線分の本数。線分と間隔は同じ長さで、マス1辺を等分する |
| プレビュー | オン | ダイアログを閉じずに結果を表示 |

数値欄は↑↓キーで増減できます（Shiftで±10かつ10の倍数にスナップ）。

### 罫線の仕様

| 罫線 | 太さ | 濃度 |
| --- | ---: | ---: |
| 行の両側の罫線 | 0.25mm | 罫線の濃度 |
| マスの区切り | 0.1mm | 罫線の濃度 |
| 太くしたマスの区切り | 0.25mm | 罫線の濃度 |
| 外側の罫線 | 0.25mm | 罫線の濃度 |
| 十字線 | 0.1mm | 30%（`LAYOUT.crossGray`） |

縦組みでは「行の両側の罫線」が縦罫、「マスの区切り」が横罫になります。横組みでは逆になり、ダイアログのパネル名も入れ替わります。

RGBドキュメントでは、同じ濃度に相当するグレーのRGB値を使用します。

### 文字属性の調整

マス目に文字を合わせるため、次の属性を設定します。

| 属性 | 値 |
| --- | --- |
| トラッキング | 比率から計算（`100000 ÷ 比率 − 1000`。90%なら約111） |
| ツメ | 0 |
| プロポーショナルメトリクス | オフ |
| 文字前後のアキ | 自動 |
| 水平比率・垂直比率 | ダイアログの比率（初期値90%） |
| カーニング（1文字目のみ） | トラッキングの1/4（1/1000em） |
| 行揃え | 書字方向の先頭（縦組みは上、横組みは左）。位置がずれないよう戻します |
| 行送り | マス1つ＋マスの1/4のアキ |
| 自動カーニング | 和文等幅 |

### 注意点

- Illustrator 2024〜2026に対応しています。
- テキストオブジェクトを1つだけ選択して実行してください。
- マスの大きさは先頭文字の文字サイズを基準にします。文字サイズが混在するテキストでは、意図した位置に罫線が引かれません。
- トラッキングは1/1000em指定のため、文字サイズを変えても比率は変わりません。比率を変えたときだけ計算し直されます。
- 1文字目のカーニングは寸法を測ったあとに入れます（先に入れると罫線ごと下がるため）。
- 複数行のときは、各行がマスの1/4だけアキを空けて並びます。行送りもその値に揃えるため、元の行送りは保持されません。
- 再実行すると、そのテキストに前回引いた`罫線`グループだけを作り直します。ほかのテキストに引いた罫線は残ります。
- プレビュー中は選択したテキストを一時的に複製して表示します。キャンセルすると元の状態に戻ります。
- 自動カーニングは「和文等幅」にし、手動カーニングは1文字目にだけ入れます。
- 行の両側の罫線と外側の罫線は「突出線端」で作成します。
- 半角文字が混ざると1文字が1マスに収まらないため、マスと文字がずれます。
- 設定できなかった文字属性があるときだけ、実行後に属性名を通知します。
