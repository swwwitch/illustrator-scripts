### 概要

- 複数選択したテキストフレームの背面に K15% の長方形を作成し、「_bg-rectangle」レイヤーに配置します。
- 行間・列間・領域サイズを調整しながらリアルタイムにプレビュー可能です。

### 主な機能

- 選択テキストフレームを基にグリッドを自動算出
- 行間・列間（ガター）の調整
- 領域サイズのカスタマイズ
- プレビューで即時反映
- 不要な長方形の削除オプション

### 処理の流れ

1. テキストフレームを選択
2. 行数・列数を自動判定
3. ダイアログでガターや領域を設定
4. プレビューで確認
5. OK時に確定処理を実行
