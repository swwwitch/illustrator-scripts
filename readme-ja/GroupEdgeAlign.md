### 概要

選択オブジェクトの端または中心を、アクティブアートボードの端・中央、または条件に合うガイドへ整列します。

### 主な機能

- 3×3のラジオボタンで整列方向を指定
- ファイル名による整列方向の自動判定に対応
- ガイドへのスナップ（`USE_GUIDES` / `GUIDE_SEARCH_MODE`）

### 使い方

1. 揃えたいオブジェクトを選択します。
2. スクリプトを実行します。
3. 整列方向を指定して実行します。

### 注意点

- 方向ごとに単独で実行したい場合は `GroupEdgeAlign-7/` の7本を使用してください。
