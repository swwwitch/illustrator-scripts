### 概要

選択されているオブジェクト群の端または中心を、`ALIGNMENT_SIDE` で指定した方向へ揃えます。GroupEdgeAlign.jsx からファイル名による方向判定を外した版です。

### 主な機能

- 方向は `left` / `right` / `top` / `bottom` / `CENTER_X` / `CENTER_Y` / `CENTER`（既定は `right`）
- `USE_GUIDES` が true のとき、条件に合うガイドへスナップ

### 使い方

1. 揃えたいオブジェクトを選択します。
2. スクリプトを実行します。

### 注意点

- 中央揃えではガイドを使わず、常にアートボード中央に揃えます。
