# 縦組み用のテキストを横組み用に戻す

[![Direct](https://img.shields.io/badge/Direct%20Link-HorizontalTextFormatter.jsx-ffcc00.svg)](https://github.com/swwwitch/illustrator-scripts/blob/master/jsx/text/HorizontalTextFormatter.jsx)

[![Direct](https://img.shields.io/badge/Back%20to%20home-All%20scripts-cccccc.svg)](https://github.com/swwwitch/illustrator-scripts/blob/master/README.md)

### 概要

- [縦組みの欧文回転・縦中横・数字の書き換えをまとめて適用](VerticalTextFormatter.md)（VerticalTextFormatter）の逆の処理をするスクリプト。
- 縦組みを横組みにし、欧文回転・縦中横を外して、縦組み用に書き換えた文字を横組みの書き方に戻す。
- ダイアログボックスで項目を選び、「変換の確認」の一覧で結果を確かめてから実行する。
- ［縦組み中の欧文回転］と［縦中横］は DOM から設定できないため、一時アクション（ダイナミックアクション）で文字パネルの項目だけを外す。

### 主な機能

- 「組み方向・回転」
  - **縦組みを横組みに**：縦組みのテキストを横組みにする（連結したテキストはすべてのフレーム、既定ON）
  - **欧文回転を外す**：［縦組み中の欧文回転］をテキスト全体で外す（既定ON）
  - **縦中横を外す**：［縦中横］をテキスト全体で外す（既定ON）
  - **等幅字形を標準に戻す**：縦中横の等幅半角・三分・四分字形などを、テキスト全体で標準の字形に戻す（既定ON）
- 「文字の変換」
  - **全角英数字を半角に**：ＰＤＦ → PDF、５ → 5。「！」「？」も半角に（既定ON）
  - **桁区切り「、」→「,」**：3、000 → 3,000（既定ON）
  - **小数点「・」→「.」**：12・5 → 12.5（既定ON）
  - **記号を半角に**：％ ＆ ＃ ＠ ＊ ＋ ＝ ＜ ＞ ／ を半角に。括弧と「：」「；」は全角のまま（既定ON）
  - **引用符〝〟→“”**（既定ON）
  - **番号のハイフンを「-」に**：電話番号・郵便番号の「‐」「ー」「－」を「-」に（03‐1234‐5678 → 03-1234-5678、既定ON）
  - **組文字の単位を英字に**：㍉ ㌢ ㌖ ㍍ ㍉㌘ ㌘ ㌕ ㌧ ㍉㍑ ㍑ → mm cm km m mg g kg t ml L（既定ON）
  - **範囲の「〜」→「-」**：10〜20 → 10-20（既定OFF）
  - **和暦を西暦に**：令和8年 → 2026年、令和元年 → 2019年（既定OFF）
  - **漢数字を算用数字に**：2字以上の漢数字の並びを算用数字に（二〇二六 → 2026、二千二十六 → 2026、二万五〇〇〇 → 25000、三、〇〇〇 → 3,000、一二・五 → 12.5）。1字の「一」「十」などは変えない（既定OFF）
- **変換の確認**：「３、０００ → 3,000」のように、変わる箇所を一覧で表示。項目を変えるたびに更新する
- 実行中はプログレスバーで進み具合を表示
- 設定は保存され、次に開いたときに戻る
- 日本語／英語の自動切り替え

### 使い方

1. 縦組みのテキストオブジェクトを選択する（文字ツールで範囲を選んでもよい）
2. スクリプトを実行し、ダイアログボックスで項目を選ぶ
3. 「変換の確認」で結果を確かめ、［OK］をクリックする

### 処理の順序

1. 縦組みを横組みに
2. ［縦組み中の欧文回転］［縦中横］をテキスト全体から外す
3. 文字の書き換え
4. 等幅字形を標準に戻す

### 注意点

- ［漢数字を算用数字に］は、「万一」のように2字以上の漢数字を含む言葉も変えることがある。「変換の確認」で確かめてから実行する
- ［等幅字形を標準に戻す］は、テキスト全体の字形（JIS78字形などを含む）を標準に戻す
- 文字数が変わる書き換え（令和8年 → 2026年 など）では、書き換えた部分は先頭の文字の書式になる
- ロック中・非表示のテキストは対象にしない
