### 概要

選択した配置画像に、アピアランスとしてケイ線を追加します。

### 使い方

1. ケイ線を付けたい配置画像を選択します。
2. スクリプトを実行します。
3. アピアランスの設定を指定して［OK］をクリックします。

### 注意点

- ドキュメントが開かれていない場合は警告を表示して終了します。
