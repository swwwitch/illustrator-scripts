### 概要

複数の画像と図形を選択して実行すると、対応する図形の大きさに合わせて各画像を拡大・縮小し、それぞれクリッピングマスクを作成します。

### 使い方

1. マスクに使う図形と画像をまとめて選択します。
2. スクリプトを実行します。

### 注意点

- 選択が2つ未満の場合はエラーを表示して終了します。
- 図形と画像が1つずつの場合は ImgFitMask.jsx でも同じことができます。
