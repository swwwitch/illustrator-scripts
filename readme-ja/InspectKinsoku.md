### 概要

選択している段落で使われている禁則処理の値を列挙して表示します。

### 使い方

1. 調べたいテキストを選択します（文字ツールでの文字選択、選択ツールでのオブジェクト選択のどちらでも可）。
2. スクリプトを実行します。

### 注意点

- テキストフレームだけを対象にする簡易版として InspectKinsokuSimple.jsx があります。
