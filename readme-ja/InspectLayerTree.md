### 概要

ドキュメント内のレイヤーとサブレイヤーを階層順にたどり、名前・ロック状態・表示状態をアラートで一覧表示します。

### 使い方

1. 調べたいドキュメントを開きます。
2. スクリプトを実行します。

### 注意点

- レイヤー構造を確認するための簡易ツールです。ドキュメントには一切変更を加えません。
- ドキュメントが開いていないときは警告を表示して終了します。
