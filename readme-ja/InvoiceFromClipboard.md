## 概要

申し込みフォームの回答をコピーした状態でスクリプトを実行すると、領収書・請求書・納品書のPDFを1枚書き出す作例スクリプトです。

クリップボードの「見出し行＋値行」を空行で区切った形式のテキストを読み取り、Illustratorテンプレート内の `<タグ>` を置き換えてPDFを書き出します。書き出したあとは保存先フォルダーを開き、宛先・件名・本文を入れた状態でメールソフトの下書きまで開きます。

テンプレートは作業用に複製してから流し込むため、テンプレート自体は変更されません。

`VariableDataImport.jsx` が「1つのデータで多数のアートボードを作る」のに対し、こちらは「1件ぶんのデータで1枚のPDFを作る」用途です。

## 主な機能

- クリップボードのテキストから、見出しごとの値を読み取り
- 読み取った内容を確認・修正できるダイアログ（差し替えて［更新］で読み直し）
- 書類名（領収書／請求書／納品書）を選択。初期選択はテンプレートのファイル名から判定
- 税込金額から税抜金額・消費税額を自動計算（単一税率）
- 適用（但し書き）の書き方をラジオボタンで選択
- テンプレート内の `<タグ>` をデータ値へ置換（タグに設定した文字書式は保持）
- テンプレートのパスを記憶（Illustratorを再起動しても保持）
- 「最小ファイルサイズ」相当・PDF 1.6 でテンプレートと同じフォルダーへ書き出し
- 同名ファイルがあるときの動き（上書き／連番）を選択
- 返信メールの文面をクリップボードへコピー
- 宛先・件名・本文を入れた状態で、メールソフトの下書きを開く
- 書き出し後に保存先フォルダーを開く
- Dropboxパスを短縮して表示（フルパス表示にも切り替え可能）

## 使い方

1. 領収書のデザインをIllustratorで作成し、差し替えたい箇所を `<日付>` `<御中>` のようにタグで書いておきます。**ファイルは保存しておきます。**
2. 申し込みフォームの回答など、「見出し行＋値行」形式のテキストをコピーします。
3. `InvoiceFromClipboard.jsx` を実行します。
4. ［テンプレート］の［指定］でテンプレートファイルを選びます。一度選ぶと記憶されるため、次回以降は［変更］で切り替えるときだけ操作します。
5. ［読み取り内容］で値を確認します。必要なら直接修正できます。金額を書き換えると、税抜と消費税もその場で計算し直されます。「適用」の下のラジオボタンで、但し書きの書き方を選びます。
6. ［書き出し］に、作成されるPDFのファイル名と保存先が表示されます。同名のファイルがあるときの動きも、ここで選べます。
7. ［PDFを作成］をクリックします。PDFが書き出され、保存先フォルダーとメールの下書きが開きます。開いたフォルダーからPDFをドラッグして、下書きに添付してください。

クリップボードの内容を差し替えてから［更新］を押すと、ダイアログを開いたまま次の1件を読み込めます。

クリップボードから項目を読み取れなかった場合も、空欄のままダイアログが開きます。手で入力するか、コピーし直して［更新］を押してください。

## クリップボードの書式

見出しの行、値の行、空行の繰り返しです。

```
お名前
山田 太郎

メールアドレス
sample@example.com

金額
11,000

購入くださった窓口
STORES

領収書の宛先
株式会社サンプル

該当イベント名
【法人向け】はじめてのIllustrator講座

日付
2026/08/14
```

- 空行が項目の区切りです。
- 対応表にない見出し（上の例の「購入くださった窓口」など）のブロックは読み飛ばします。
- 値が複数行にわたる場合は、空白でつないで1行にまとめます。
- 各値の前後の空白は自動で除去されます。

## タグと値の対応

`FIELD_MAPPINGS` で定義します。初期値は次のとおりです。

| テンプレートのタグ | 見出し | 入る値 |
| --- | --- | --- |
| `<タイトル>` | （ダイアログで選択） | `領収書` |
| `<日付>` | 日付 | `2026年8月14日` |
| `<御中>` | 領収書の宛先 | `株式会社サンプル` |
| `<適用>` | 該当イベント名 | `セミナーアーカイブ（はじめてのIllustrator講座）` |
| `<Price>` | 金額 | `11,000`（税込） |
| `<PriceWithoutTax>` | 金額 | `10,000`（税抜・自動計算） |
| `<Tax>` | 金額 | `1,000`（消費税・自動計算） |

金額は税込で入力します。税抜は端数を切り捨て、消費税は「税込 − 税抜」で求めるため、3つの数値は必ず一致します。

## 適用（但し書き）

テンプレートには但し書き一文をまるごとタグにしておきます。

```
但  <適用>
```

ダイアログの「適用」欄の下にあるラジオボタンで、文面の書き方を選びます。

| 選択 | `<適用>` に入る値 |
| --- | --- |
| セミナーイベント（既定） | `セミナーアーカイブ（はじめてのIllustrator講座）` |
| その他 | `はじめてのIllustrator講座` |

選択肢と書き方は `APPLICATION_PRESETS` で増減できます。`#見出し#` はその見出しの入力値に置き換わり、配列の先頭が既定の選択になります。

## 生成されるファイル

| ファイル | 例 |
| --- | --- |
| PDF | `領収書-CeeBeeDee-20260814-株式会社サンプル.pdf` |

ファイル名は「書類名 − 発行元 − 日付8桁 − 宛先」の順です。日付を宛先より前に置いているため、名前順に並べると発行日順に揃います。

書類名は**テンプレートのファイル名から決まります**。

日付は**領収書の日付**（データの「日付」欄）を使うため、同じ内容から作り直しても同じ名前になります。日付を読み取れない場合のみ実行日を使います。

保存先はテンプレートと同じフォルダーです。同名のファイルがあるときの動きは、書き出しパネルの［同名ファイル］で選べます。

| 選択 | 動作 |
| --- | --- |
| 上書き | 既存のPDFを置き換えます |
| 連番を付ける（既定） | `-2` `-3` … と後ろに足して別ファイルにします |

選ぶとファイル名の表示もその場で変わるので、書き出す前に結果を確認できます。初期選択は `OVERWRITE_EXISTING_PDF` で変えられます。

書き出しは**「最小ファイルサイズ」相当**の設定です。

| 項目 | 設定 |
| --- | --- |
| 互換性 | PDF 1.6（Acrobat 7） |
| Illustratorの編集機能を保持 | オフ |
| ページサムネールを埋め込み | オフ |
| Web表示用に最適化 | オン |
| カラー・グレースケール画像 | 150ppiを超えるものを100ppiへ、JPEG（低画質） |
| 白黒画像 | 450ppiを超えるものを300ppiへ、CCITT Group 4 |
| テキストとラインアートを圧縮 | オン |

Illustratorのプリセット「最小ファイルサイズ」を読み込み、互換性だけをPDF 1.6に上書きしています（プリセット自体はPDF 1.5のため）。

プリセット名は環境の言語で変わる（「[最小ファイルサイズ]」／「[Smallest File Size]」）ので、`PDF_PRESET_CANDIDATES` に候補を並べ、`app.PDFPresetsList` と突き合わせて実在するものを使います。どれも見つからない環境では、同等の設定を個別に組み立てて書き出します。

作業用の複製（`領収書テンプレート_work_YYYYMMDD_HHMMSS.ai`）は書き出し後に削除されるため、残りません。

## 書類名（タイトル）

読み取り内容パネルの一番上にあるラジオボタンで選びます。選んだ書類名は次のすべてに反映されます。

- テンプレートの `<タイトル>`
- ダイアログのタイトル
- PDFのファイル名の先頭
- メールの件名・本文の `#書類名#`

**初期選択は、テンプレートのファイル名から決まります。**

| テンプレート | 初期選択 |
| --- | --- |
| `領収書テンプレート.ai` | 領収書 |
| `請求書_2026.ai` | 請求書 |
| `納品書ひな形.ai` | 納品書 |
| `template.ai`（どれも含まない） | 領収書（配列の先頭） |

［変更］でテンプレートを選び直すと、新しいファイル名に合わせて選択も付け直されます。選択肢は `DOCUMENT_TYPE_NAMES` で増減できます。

## 返信メール

書き出しが終わると、宛先・件名・本文を入れた状態でメールソフトの下書きが開きます。同じ文面はクリップボードにも入るため、下書きが開かない環境でも貼り付けて使えます。

```
宛先：sample@example.com
件名：領収書をお送りします

山田 太郎さん、
アーカイブ購入ありがとうございました！

領収書PDFを添付します。
（領収書-CeeBeeDee-20260814-株式会社サンプル.pdf）

よろしくお願いします。
```

- 宛先は `MAIL_ADDRESS_HEADING` の見出し（初期値「メールアドレス」）から取ります。
- 件名は `REPLY_MAIL_SUBJECT`、本文は `REPLY_MAIL_TEMPLATE` で変更できます。
- `#書類名#` は、テンプレートから判定した書類名に置き換わります。
- どちらも `#見出し#` はクリップボードから読み取った値に、`#ファイル名#` は作成したPDFの名前に置き換わります。ここで使った見出しは、タグに使っていなくても自動的に読み取り対象になります（上の例では「お名前」）。

**PDFは自動では添付されません。** `mailto:` の仕様で添付を指定できないためです。同時に開く保存先フォルダーから、PDFをドラッグして添付してください。

## 主な設定

スクリプト冒頭の「ユーザー設定」で変更します。

| 変数 | 内容 |
| --- | --- |
| `FIELD_MAPPINGS` | 見出しとタグの対応 |
| `APPLICATION_PRESETS` | 適用（但し書き）の書き方と、ラジオボタンの選択肢 |
| `FIELD_LABEL_OVERRIDES` | 入力欄のラベルを見出しと別名にする対応（初期値は該当イベント名→適用） |
| `IGNORED_HEADINGS` | 読み飛ばす見出し（値の区切りとしては使う） |
| `VALUE_REMOVAL_PATTERNS` | 値から取り除く文字（初期値は「【法人向け】」） |
| `REPLY_MAIL_SUBJECT` | 返信メールの件名 |
| `REPLY_MAIL_TEMPLATE` | 返信メールの本文 |
| `MAIL_ADDRESS_HEADING` | メールの宛先に使う見出し |
| `OPEN_MAIL_AFTER_EXPORT` | 書き出し後にメールの下書きを開くか |
| `DEFAULT_TEMPLATE_PATH` | テンプレートの初期パス（空文字にすると毎回［指定］から） |
| `DOCUMENT_TYPE_NAMES` | 書類名の選択肢（初期値は領収書／請求書／納品書） |
| `PDF_FILE_NAME_ISSUER` | ファイル名の発行元（空文字にすると省略） |
| `TAX_RATE` | 消費税率（初期値 0.1） |
| `TAX_FRACTION_MODE` | 税抜の端数処理（`floor` / `round` / `ceil`） |
| `PDF_PRESET_CANDIDATES` | 使うPDFプリセット名の候補（言語ごとの名前を並べる） |
| `PDF_COMPATIBILITY_NAME` | 互換性（`ACROBAT5`=1.4／`ACROBAT6`=1.5／`ACROBAT7`=1.6／`ACROBAT8`=1.7） |
| `PDF_PRESERVE_EDITABILITY` | Illustratorの編集機能を保持するか |
| `PDF_IMAGE_RESOLUTION` | 画像のダウンサンプル解像度（ppi、0で縮小しない） |
| `OVERWRITE_EXISTING_PDF` | ［同名ファイル］の初期選択（`true` で上書き） |
| `OPEN_FOLDER_AFTER_EXPORT` | 書き出し後にフォルダーを開くか |
| `DROPBOX_SKIP_FOLDERS` | パス表示でさらに省く共有フォルダー名 |

## 注意事項

- テンプレートは**保存済みのファイル**である必要があります。開いているドキュメントではなく、記憶したパスのファイルを複製して使います。
- 消費税は**単一税率**のみです。軽減税率（8%）の区分記載には対応していません。
- 各項目は1行に収める前提です。値に改行が含まれる場合は空白に置き換えます。
- タグの置換は、ドキュメント内のすべてのテキストフレーム（グループ内を含む）が対象です。シンボルや埋め込み画像内のテキストは対象外です。
- 置換の前に、作業用複製のレイヤーとオブジェクトのロックを解除します。ロックされたレイヤー上のタグも置換されますが、非表示の状態はそのまま保たれます。
- テンプレートに存在しなかったタグは、完了時にまとめて通知します。
- クリップボードの読み取りには、一時的な新規ドキュメントへのペーストを使います。開いているドキュメントには影響しません。
- 書類名の初期選択はテンプレートのファイル名で決まります。`DOCUMENT_TYPE_NAMES` のどれも含まれていない名前のときは、配列の先頭（初期値は「領収書」）が選ばれます。
- 書き出したPDFは `PDF_PRESERVE_EDITABILITY` がオフのため、Illustratorで開いても元通りには編集できません。編集用に残す必要がある場合はテンプレート側を使ってください。
- メールの下書きは、OSに設定された既定のメールソフトで開きます。`mailto:` では添付を指定できないため、PDFは手で添付してください。
