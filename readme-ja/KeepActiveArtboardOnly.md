### 概要

アクティブなアートボード以外を削除し、その外側にあるオブジェクトも取り除きます。

### 使い方

1. 残したいアートボードをアクティブにします。
2. スクリプトを実行します。

### 注意点

- 元に戻せない変更を加えるため、実行前にファイルを複製しておくことを推奨します。
- 同種のスクリプトとして RemoveOtherArtboards.jsx があります。
