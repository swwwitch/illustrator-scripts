### 概要

選択オブジェクトに［効果］＞［スタイライズ］＞［ぼかし］のライブエフェクトを適用します。

### 使い方

1. ぼかしたいオブジェクトを選択します。
2. スクリプトを実行します。
3. 半径を入力して［OK］をクリックします。

### 注意点

- 半径は現在の定規単位（`rulerType`）で表示・入力し、内部では pt に換算します。
