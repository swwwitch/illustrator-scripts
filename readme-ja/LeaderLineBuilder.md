### 概要

- 選択したパスやグループの外接矩形から、指定した角度の引き出し線を作成します。
- 引き出し線は「斜線＋水平線」の3点構成で、斜線の角度と方向をダイアログで指定します。
- 角度・方向・線のスタイル・先端マーカー・フチを、プレビューしながら調整できます。
- 元のオブジェクトは引き出し線に置き換わります（基準となる図形を下書きとして使う想定）。

### 使い方

1. 引き出し線の基準にしたいパス（2点以上）またはグループを選択します。
2. スクリプトを実行し、ダイアログで設定します。
3. OK で確定します。選択したオブジェクトは引き出し線に置き換わります。

テキストフレームを一緒に選択すると、テキスト整列モードになります。オブジェクトとテキストの位置関係から方向を自動判定し、水平線の端をテキストの端にそろえ、折れ点をテキストから指定距離だけ離します。

### ダイアログの設定

| 項目 | 内容 |
| --- | --- |
| 適用範囲 | 「すべて更新」はダイアログの設定をすべて適用。「方向は維持」は方向だけ、選択中の引き出し線それぞれに保存された向きを使う |
| 角度 | 斜線の角度（0より大きく90未満）。30° / 45° / 60° のプリセットあり |
| 斜線の方向 | 引き出し線が伸びる向き（左上・左下・右上・右下） |
| 線のスタイル | 線色（黒／白／指定）、線幅、線端の形状（なし／丸型） |
| 先端マーカー | 先端に付ける円または矢印。塗り／線のみ、大きさを指定 |
| グループ化 | 線・先端マーカー・フチを1つのグループにまとめる |
| フチ | 線と先端マーカーの背面に、一回り太らせた同じ形を敷く。色も指定可 |
| テキスト | テキストとの距離（pt）。テキストを一緒に選択したときだけ有効 |
| ズーム | ダイアログを開いたまま表示倍率を変えられる。「簡易」ONでドラッグ中は再描画しない |

線幅と先端マーカーの大きさの単位は、環境設定の「線」の単位に従います。テキストとの距離は pt 固定です。

数値入力欄では ↑↓ キーで値を増減できます。Shift で大きく、Option（Alt）で細かく変わります。

### 再適用

「グループ化」をONにして作成した引き出し線には、元オブジェクトの外接矩形と方向がタグとして保存されます。この引き出し線を選択して再実行すると、保存された情報をもとに同じ位置へ作り直せます。

複数の引き出し線をまとめて選択したときは「方向は維持」が初期選択になり、方向以外の設定（色・線幅・先端マーカーなど）だけを一括で更新できます。

### 処理の流れ

1. ドキュメントと選択オブジェクトの有無を確認
2. 選択から対象（パス・グループ）とテキストフレームを収集
3. 対象ごとに外接矩形と線の属性を取得
4. ダイアログの設定から3点の座標を計算し、フチ・本体・先端マーカーを生成（プレビュー）
5. OK で確定し、元オブジェクトを削除して引き出し線と置き換え

### 注意点

- 元のオブジェクトは削除されます。残したい場合は複製してから実行してください。
- 角度は0より大きく90未満です。範囲外のときは確定できません。
- 「グループ化」をOFFにすると再適用用のタグが付かないため、あとから設定を変えられません。
- 先端マーカーが矢印のときは塗りのみです（線のみは選べません）。
- ドキュメントのカラースペース（CMYK／RGB）に合わせて色を生成します。
