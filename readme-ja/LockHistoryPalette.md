# ロックしたオブジェクトを履歴に残して戻す

[![Direct](https://img.shields.io/badge/Direct%20Link-LockHistoryPalette.jsx-ffcc00.svg)](https://github.com/swwwitch/illustrator-scripts/blob/master/jsx/select/LockHistoryPalette.jsx)

### 概要

パレットの［ロック］ボタンでオブジェクトをロックすると、そのまとまりを履歴に1件として記録する常駐スクリプトです。

Illustrator の「オブジェクト＞すべてをロック解除」は、ドキュメント内のロックをすべて一度に外してしまいます。このスクリプトは「いつ、どれをロックしたか」を1件ずつ覚えておくので、**直前にロックしたぶんだけを戻す**、といった操作ができます。

記録は各オブジェクトの**タグ**（`PageItem.tags`、タグ名 `LockHistoryPalette`）に書き込まれ、ドキュメントに保存されます。パレットを閉じても、ファイルを閉じて開き直しても、履歴は復元されます。

### 主な機能

- ［ロック］で、選択中のオブジェクトを履歴に1件として記録してからロック（option＋L）
- 「1回目（2個 / パス）」のように、ロックした順・個数・先頭オブジェクトの種類を一覧表示
- 一覧で選ぶと、その範囲を囲む赤い枠がドキュメント上に表示される
- ［ロック解除］で1件ずつロック解除
- ［すべてロック解除］で履歴にあるすべてを解除
- ［リストから外す］［すべてリストから外す］で、ロックは残したまま記録だけを破棄
- 記録はドキュメントに保存されるので、ファイルを開き直しても復元される
- 削除されたオブジェクトは、次の読み直しで自動的に消える
- すべてのボタンと一覧に、動作を説明するツールチップ
- 日本語／英語UI

### 使い方

1. ドキュメントを開きます。
2. `LockHistoryPalette.jsx` を実行するとパレットが表示されます。
3. ロックしたいオブジェクトを選び、パレットの［ロック］を押します。これで履歴に1件記録されます。
4. 戻したい履歴を選んで［ロック解除］を押します。
5. どこにあるか分からなくなったら、一覧で選んでください。そのぶん全体を囲む赤い枠が表示されます。

### ボタン

| ボタン | 動作 |
| --- | --- |
| ロック | 選択中のオブジェクトを履歴に1件として記録してからロックします |
| ロック解除 | 選んだ履歴のオブジェクトのロックを解除し、記録を削除します |
| すべてロック解除 | 履歴にあるすべてのオブジェクトのロックを解除し、記録を削除します |
| リストから外す | ロックはそのままに、選んだ履歴の記録だけを削除します |
| すべてリストから外す | ロックはそのままに、履歴にあるすべての記録を削除します |

### 注意点

- **`command`＋`2` でロックしたぶんは記録されません。** 記録が必要なものは、パレットの［ロック］から行ってください。Illustrator にはロック操作を通知する仕組みが無く、あとから状態を見て推測する方式は取りこぼすため、ロックそのものをパレットで行っています。
- **「選択＞選択範囲の保存」はスクリプトから実行できません。** メニューコマンドとして公開されておらず、保存された選択セットを読み書きする API もありません。同じ「ドキュメントに保存される」性質は `PageItem.tags` で実現しています。
- **記録はパレットをクリックしたときに読み直されます。** Illustrator には常駐タイマーがありません（`app.scheduleTask` は Adobe Bridge の API で、`$.setTimeout` もありません）。そのため読み直しは、パレットがアクティブになったときと各操作の直後に行われます。ドキュメントを編集するにはドキュメントウィンドウにフォーカスを移す必要があるので、パレットに戻れば最新の状態になります。
- **Illustrator はロック中のオブジェクトを選択できません。** そのため、一覧で選んだときは、選択のかわりに赤い枠で場所を示します。枠を描くあいだだけロックを外して範囲を測り、すぐに元の状態へ戻します。枠は最上位の一時レイヤー `LockHistoryPalette Preview` に描かれ、パレットに戻ると、レイヤーごと消えます。
- **option＋L はパレットにフォーカスがあるときだけ効きます。** ScriptUI のキーイベントは、パレットが前面でアクティブなときにしか届きません。アートボードで選択したまま押しても反応しないので、いったんパレットをクリックしてください。Illustrator 全体で効くショートカットにしたい場合は、macOS の システム設定 ＞ キーボード ＞ キーボードショートカット ＞ アプリケーション で、`ファイル > スクリプト` のメニュー項目名に割り当ててください。
- **タグはドキュメントに残ります。** 記録を消さずにファイルを渡すと、タグもいっしょに渡ります。不要なら［すべてリストから外す］または［すべてロック解除］で消してください。
- **DOM 処理はメインエンジンへ委譲しています。** 常駐パレット（`#targetengine`）のエンジンからは `app.activeDocument` が取得できないため、ロック・タグの読み書き・枠の描画はすべて BridgeTalk でメインエンジンへ渡して実行しています。結果は非同期で戻るので、ボタンを押してから一覧が更新されるまで一瞬の間があります。
- **常駐スクリプトです。** `#targetengine` を使っているため、スクリプトを書き換えた場合は**パレットを閉じてから再実行**しないと、修正前のコードが動き続けます。
