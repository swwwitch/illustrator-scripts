### 概要

距離・角度・スケールを指定して、ロングシャドウを生成します。

### 主な機能

- プレビュー付きダイアログ
- 必要に応じて「パスの単純化」を実行
- サンプリング方式で影の側面を生成し、必要に応じてパスファインダーで合体・穴埋め

### 使い方

1. 対象のオブジェクトを選択します。
2. スクリプトを実行します。
3. 距離・角度・スケールを指定し、プレビューを確認して［OK］をクリックします。

### 注意点

- 対象は閉パスの PathItem / CompoundPathItem / GroupItem / TextFrame です。
