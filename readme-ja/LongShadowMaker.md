### 概要

距離・角度・スケールを指定して、選択したオブジェクトからロングシャドウを生成します。プレビューを見ながら数値を調整し、［OK］で確定します。

元の形と、移動・拡大縮小した形の間を面でつないで影を作ります。影の塗りには、元のオブジェクトの塗りから彩度を落とした色を使います。

### 主な機能

- 距離・角度・スケールを、数値欄とスライダー（↑↓キーでも増減）で指定
- スケールと角度の組み合わせを一度に設定できる8種類のプリセット
- 影を太らせるオフセット（角の処理はマイター／ラウンド／ベベル）
- アンカーポイントを減らす「パスの単純化」
- 半透明のコピーを重ねて表示するプレビュー
- 日本語／英語UI

### 使い方

1. 対象のオブジェクトを1つ選択します。
2. `LongShadowMaker.jsx` を実行します。
3. 距離・角度・スケールを指定します。プリセットを選ぶと、スケールと角度がまとめて設定されます（距離は変わりません）。
4. 必要に応じて「オフセット」と「パスの単純化」をオンにします。
5. プレビューを確認して［OK］をクリックします。

### 設定項目

| 項目 | 内容 | 初期値 |
| --- | --- | --- |
| 距離 | 影を伸ばす長さ（pt） | 選択オブジェクトの幅＋高さ |
| 角度 | 影が伸びる向き（−180°〜180°） | 45° |
| スケール | 影の先端の大きさ（1%〜300%）。100%で元の形と同じ | 100% |
| オフセット | 生成した影を太らせる量（pt） | オフ（幅と高さの平均の1/20） |
| 形状 | 太らせたときの角の処理 | ラウンド |
| パスの単純化 | 影のアンカーポイントを減らす | オン |

### 注意点

- 対象は、閉パス（PathItem）、複合パス（CompoundPathItem）、閉パスのみで構成されたグループ（GroupItem）、テキスト（TextFrame）です。
- グループとテキストは、一時的に合体・アウトライン化した形をもとに影を生成します。元のオブジェクトはそのまま残ります。
- オフセットはプレビューには反映されません。［OK］で確定したときに適用されます。
- プリセットの「1% / 90°」は、極小の影にするため実際には 0.01% として処理します。
- 「パスの単純化」をオンにすると、Illustrator の仕様で単純化ダイアログが開きます。
- プレビューは Illustrator の取り消し（Undo）を利用しています。他の操作と混在すると、履歴が想定どおりにならない場合があります。
