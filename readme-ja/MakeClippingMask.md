### 概要

選択オブジェクトの状態に応じて、クリッピングマスクの作成と解除を切り替えて実行します.

### 主な機能

- クリッピングマスクが設定されていれば、解除してマスクを削除（グループ解除も含む）
- 配置画像やラスター画像には新たにクリッピングマスクを作成
- 配置画像1つとパス1つの選択では、そのパスでマスクを作成
- パスのみを複数選択した場合は、最前面のパスでマスクを作成
- 処理後は作成したクリッピングマスクを選択状態にする

### 使い方

1. 対象のオブジェクトを選択します。
2. スクリプトを実行します。
