### 概要

縦横のガイドの交点で区切られた区画に、塗りつぶした長方形を一括生成します。対象にするガイドと作成先はダイアログで指定できます。

### ダイアログ

#### 対象となるガイド

**ガイドの種類**

| 項目 | 内容 |
| --- | --- |
| すべてのガイド | ガイド化されているパスをすべて対象にします（初期値） |
| ルーラーガイドのみ | アートボードをまたぐ長さのガイドだけを対象にします |

**レイヤー**

| 項目 | 内容 |
| --- | --- |
| すべてのレイヤー | ドキュメント全体からガイドを探します（初期値） |
| 現在のレイヤーのみ | アクティブレイヤー配下のガイドだけを探します |

**絞り込み**

| 項目 | 内容 |
| --- | --- |
| 現在のアートボードのみ | 現在のアートボードの範囲内にあるガイドだけを使います（初期値：オフ） |
| ロックされたレイヤーを含む | ロックされたレイヤーを一時的に解除してガイドを集め、集め終わったらロックを戻します（初期値：オン） |

#### 作成する長方形

**作成先**

| 項目 | 内容 |
| --- | --- |
| 現在のレイヤー | アクティブレイヤーに作成します（初期値）。ロックまたは非表示の場合は中断します |
| 指定レイヤー | 入力欄で指定した名前のレイヤーに作成します。同名のレイヤーがすでにあれば再利用し、なければ作成します。既定の名前は `Generated Rectangles` |

**後処理**

| 項目 | 内容 |
| --- | --- |
| 長方形を1つに結合 | 作成した長方形をすべて合体して1つのパスにします（初期値：オフ） |
| シェイプに変換 | 結果をライブシェイプに変換します（初期値：オン）。結合する場合は結合後に変換します |

各パネルの上部には、現在の条件で見つかったガイドの本数（左）と、作成される長方形の数（右）が表示されます。設定を変えるたびに更新されるので、OKを押す前に結果を確認できます。

### 処理の流れ

1. 条件に合うガイドを集める（必要ならロックを一時解除）
2. 縦・横に分類し、重なった座標をまとめる
3. 作成先レイヤーを用意する
4. 区画ごとに長方形を作成する
5. 必要に応じて結合・ライブシェイプ化する

### 注意

- 長方形の塗りは、RGBドキュメントでは黒、それ以外ではK100になります。不透明度は50%です。
- ロックされたサブレイヤーは一時解除の対象外です。
- 「すべてのガイド」を選んだ場合、長方形などをガイド化したパスは1辺だけが対象になります。
- 「長方形を1つに結合」は選択中のすべての長方形を合体するため、離れた長方形もひとつにまとまります。
- 塗りの色・不透明度、既定のレイヤー名などは、スクリプト冒頭の「ユーザー設定」で変更できます。
