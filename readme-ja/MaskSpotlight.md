# マスクした複製で、ぼかし・ルーペ・部分拡大をつくる

[![Direct](https://img.shields.io/badge/Direct%20Link-MaskSpotlight.jsx-ffcc00.svg)](https://github.com/swwwitch/illustrator-scripts/blob/master/jsx/mask/MaskSpotlight.jsx)

[![English](https://img.shields.io/badge/README-English-4b8bbe.svg)](https://github.com/swwwitch/illustrator-scripts/blob/master/readme-en/MaskSpotlight.md)

[![Direct](https://img.shields.io/badge/Back%20to%20home-All%20scripts-cccccc.svg)](https://github.com/swwwitch/illustrator-scripts/blob/master/README.md)

### 概要

画像またはベクターオブジェクトのグループと、マスクに使うパスを選択して実行します。アートワークの複製をパスでマスクし、すりガラス風のぼかし、ルーペ（拡大鏡）、部分拡大（コールアウト）をプレビューしながら作ります。

元のアートワークとパスはそのまま残り、増えるのは複製1つとクリップグループだけです（「マスク外」をぼかしたときだけ、元のアートワークにぼかしが付きます）。

<img alt="ルーペとすりガラスダイアログの外観" src="../png/ss-926-918-144-20260920-202456.png" width="50%" />

### 主な機能

- ぼかす範囲を「なし／マスク内／マスク外」から選択（半径0〜1000px）
- 6種類のプリセット（前面をぼかす／背景をぼかす／マスクのみ＋ドロップシャドウ／ルーペ／部分拡大／部分拡大（背景をぼかす））
- 今の設定を保存して、次回から「保存した設定」として呼び出し
- クリップグループへの境界線と、ドロップシャドウ（不透明度・X・Y・ぼかし・濃さ）
- ルーペ：拡大率とマスクサイズ比での移動、実体の複製か［変形］効果かを選択
- 「拡大表示のコネクター」で、元の位置と拡大したコピーを線でつなぐ
- 元のアートワークを一時的に隠して差し替えるプレビュー
- 日本語／英語UI

### 使い方

1. 画像（配置画像・埋め込み画像）またはグループと、マスクに使うパス（または複合パス）を1つずつ選択します。
2. `MaskSpotlight.jsx` を実行します。
3. プリセットを選ぶか、各項目を指定します（初期状態は「背景をぼかす」）。
4. プレビューを確認して［OK］をクリックします。

### 設定項目

| 項目 | 内容 | 初期値 |
| --- | --- | --- |
| プリセット | よく使う設定をまとめて呼び出す。値を変えると「カスタム」に切り替わる | 背景をぼかす |
| ぼかす範囲 | なし／マスク内／マスク外 | マスク外 |
| 半径 | ぼかし（ガウス）の半径（0〜1000px） | 15px |
| 境界線を追加 | クリップグループに線を追加し、線に中マドを適用 | オフ |
| 拡大表示のコネクター | 元の位置と拡大したコピーを線でつなぐグラフィックスタイルを適用 | オフ |
| ドロップシャドウを追加 | クリップグループにドロップシャドウ（乗算）を適用 | オフ |
| 不透明度 | 影の不透明度（0〜100%） | 50% |
| X／Y（ドロップシャドウ） | 影をずらす量（±1000pt。正の値で右・下） | 5pt／5pt |
| ぼかし | 影のぼかし（0〜1000pt） | 8pt |
| 濃さ | 影の濃さ（0〜100%）。カラー指定ではなく「濃さ」で描く | 100% |
| ルーペを追加 | マスクを拡大して、拡大鏡のように重ねる | オフ |
| 複製 | 元のガラス部分を残したままルーペを増やす | オフ |
| 効果で拡大 | 拡大と移動を［変形］効果として適用し、オブジェクトは変形しない | オフ |
| スケール | ルーペの拡大率（100〜1000%） | 120% |
| X／Y（ルーペ） | ルーペの移動量。マスクの幅・高さに対する割合（±200%、下方向が正） | 0／0 |
| プレビュー | 設定の結果をドキュメント上で確認する | オン |

### 注意点

- 選択は「画像またはグループ」と「パス（または複合パス）」を1つずつです。数が合わないときは実行されません。
- ぼかす範囲が「マスク内」のときはルーペを使えません（拡大してもぼけたままになるため、パネルがディム表示になります）。
- 「拡大表示のコネクター」は、ルーペを複製するとき（「部分拡大」「部分拡大（背景をぼかす）」）だけ使えます。それ以外の設定ではディム表示です。
- コネクターは `graphiclibraryzoomin.ai` のグラフィックスタイル `zoomineffect` を使います。このファイルをスクリプトと同じ場所に置いていないときは、項目自体が表示されません。
- グラフィックスタイルは適用先のアピアランスを置き換えるため、コネクターは結果をグループ化してから適用します（線・ドロップシャドウ・［変形］効果は残ります）。
- 元がベクターのグループのときは、クリップグループにパスファインダー（効果）の「分割」を適用します。画像には分割するパスがないため適用しません。
- 「境界線を追加」はメニューコマンドを使うため、環境によっては実行できないことがあります。
- 保存した設定は `~/Library/Application Support/MaskSpotlight/settings.txt`（Windowsは `%APPDATA%\MaskSpotlight\settings.txt`）に置かれます。
