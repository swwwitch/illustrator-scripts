### 概要

選択したオブジェクトを、いちばん短い列へ順に詰めていくメイソンリーレイアウトで並べ直します。基準は選択オブジェクトか現在のアートボードで、アートボードのときは収まるように列数を決め、必要なら縮小します。結果はプレビューで確認できます。

### 主な機能

- 高さの異なるオブジェクトを、列の高さがそろうように順に詰めます。
- 列の幅より広いオブジェクトは、複数の列にまたがります。
- ［基準］で、並べる範囲を［選択オブジェクト］か［現在のアートボード］から選びます。
- ［選択オブジェクト］では、列数と列の幅を指定できます。開いたときの列の幅は最初のオブジェクトの幅で、列数は選択範囲の幅に入る数です。
- ［現在のアートボード］では、列の設定より収まりを優先します。オブジェクトができるだけ大きく収まる列数を自動で決め、原寸で収まらなければ線幅ごと縮小します。拡大はしません。
- 間隔は左右と上下を指定できます。リンクアイコンがオンのときは、2つの値が連動します（初期状態はオン）。
- 並べ始める位置は、左右（左から／右から）と上下（上から／下から）で選びます。
- 順序は［位置］（上の行から、行の中は左から）、［重ね順］（前面から）、［ランダム］から選びます。
- ［ランダム］のときは、［シャッフル］で別の並びを作り直せます。ほかの値を変えても、並びは変わりません。
- 確定後は1回の取り消しで元に戻せます。

### 使い方

1. オブジェクトを2つ以上選択します。
2. スクリプトを実行します。
3. ［基準］を選び、列・間隔・並べ方を調整します。
4. ［OK］で確定します。［キャンセル］で元に戻ります。

### 注意点

- グループは1つのオブジェクトとして動かします。ロックされたオブジェクトと非表示のオブジェクトは対象外です。
- 境界は環境設定の［プレビュー境界を使用］に従います。
- ［選択オブジェクト］では大きさを変えません。
- ［現在のアートボード］では、間隔は縮小しません。列数と列の幅の欄は使えなくなり、列数の欄には自動で決まった数が出ます。アートボードの端からの余白は取りません。
- ［現在のアートボード］から［選択オブジェクト］に戻すと、列数は選択範囲の幅に入る数に戻ります。
