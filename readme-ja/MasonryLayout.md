### 概要

選択したオブジェクトを、いちばん短い列へ順に詰めていくメイソンリーレイアウトで並べ直します。基準は選択オブジェクトかアートボードで、アートボードのときは余白の内側に収まるように列数と大きさを決めます。幅を列にそろえたり、順序をランダムにしたりもできます。結果はプレビューで確認できます。

### 主な機能

- 高さの異なるオブジェクトを、列の高さがそろうように順に詰めます。
- 列の幅より広いオブジェクトは、複数の列にまたがります。
- ［基準］で、並べる範囲を［選択オブジェクト］か［アートボード］から選びます（初期状態は［アートボード］）。
- ［選択オブジェクト］では、列数と列の幅を指定できます。開いたときの列の幅は最初のオブジェクトの幅で、列数は選択範囲の幅に入る数です。
- ［アートボード］では、列の設定より収まりを優先します。オブジェクトができるだけ大きく収まる列数を自動で決め、原寸で収まらなければ線幅ごと縮小します。
- ［アートボードにフィット］がオンのときは、拡大もしてアートボードいっぱいに並べます（初期状態はオン）。縦横比は保つので、幅か高さのどちらかに余りが残ります。
- ［幅を列にそろえる］をオンにすると、縦横比を保ったまま、すべてのオブジェクトの幅を列の幅にします。写真のコラージュなど、大きさが不ぞろいなときに向いています。
- ［列に入らないものを90°回転］をオンにすると、そのままでは複数の列にまたがり、90°回転すれば1列に入るオブジェクトだけを回転します（初期状態はオフ）。回転しても1列に入らないオブジェクトは、そのまま複数の列にまたがります。
- ［アートボード］では［余白］を指定できます。アートボードの端からその分だけ内側に並べます。
- 間隔は左右と上下を指定できます。リンクアイコンがオンのときは、2つの値が連動します（初期状態はオン）。
- 並べ始める位置は、左右（左から／右から）と上下（上から／下から）で選びます。
- ［アートボード］では［中央から］も選べます。並べた全体を、アートボードの左右中央・上下中央に置きます（初期状態は左右・上下とも［中央から］）。［選択オブジェクト］に戻すと、左・上に戻ります。
- 順序は［位置］（上の行から、行の中は左から）、［重ね順］（前面から）、［ランダム］から選びます（初期状態は［ランダム］）。
- ［ランダム］のときは、［シャッフル］で別の並びを作り直せます。ほかの値を変えても、並びは変わりません。
- 確定後は1回の取り消しで元に戻せます。

### 使い方

1. オブジェクトを2つ以上選択します。
2. スクリプトを実行します。
3. ［基準］を選び、列・間隔・並べ方を調整します。
4. ［OK］で確定します。［キャンセル］で元に戻ります。

### 注意点

- グループは1つのオブジェクトとして動かします。ロックされたオブジェクト、非表示のオブジェクト、ガイドは対象外です。
- 境界は環境設定の［プレビュー境界を使用］に従います。
- ［幅を列にそろえる］がオフなら、［選択オブジェクト］では大きさを変えません。
- ［幅を列にそろえる］は線幅も同じ倍率で変えます。幅の無い線は対象外です。
- ［幅を列にそろえる］がオンのときは、［列に入らないものを90°回転］は使えません。
- ［順序］の［位置］は、回転する前の位置で判定します。
- 初期状態では、開いた時点でオブジェクトの大きさと位置がプレビューで変わります。［キャンセル］で元に戻ります。順序が［ランダム］なので、実行するたびに並びが変わります。
- ［アートボード］は、選択オブジェクトがいちばん多くあるアートボードです。同数のときと、どのアートボードにもないときは、作業中のアートボードです。
- ［アートボード］では、間隔は拡大・縮小しません。列数の欄は使えなくなり、自動で決まった数が出ます。
- ［アートボード］の［列の幅］は原寸での基準です。回転の判定や、列とオブジェクトの比率に使います。全体を拡大・縮小するので、仕上がりの列の幅は入力した値と異なることがあります。
- ［アートボード］から［選択オブジェクト］に戻すと、列数は選択範囲の幅に入る数に戻ります。
