### 概要

選択したオブジェクトを、いちばん短い列へ順に詰めていくメイソンリーレイアウトで並べ直します。基準は選択オブジェクトか現在のアートボードで、アートボードのときは余白の内側に収まるように列数と大きさを決めます。幅を列にそろえたり、順序をランダムにしたりもできます。結果はプレビューで確認できます。

### 主な機能

- 高さの異なるオブジェクトを、列の高さがそろうように順に詰めます。
- 列の幅より広いオブジェクトは、複数の列にまたがります。
- ［基準］で、並べる範囲を［選択オブジェクト］か［現在のアートボード］から選びます。
- ［選択オブジェクト］では、列数と列の幅を指定できます。開いたときの列の幅は最初のオブジェクトの幅で、列数は選択範囲の幅に入る数です。
- ［現在のアートボード］では、列の設定より収まりを優先します。オブジェクトができるだけ大きく収まる列数を自動で決め、原寸で収まらなければ線幅ごと縮小します。拡大はしません。
- ［アートボードにフィット］をオンにすると、拡大もしてアートボードいっぱいに並べます。縦横比は保つので、幅か高さのどちらかに余りが残ります。
- ［幅を列にそろえる］をオンにすると、縦横比を保ったまま、すべてのオブジェクトの幅を列の幅にします。写真のコラージュなど、大きさが不ぞろいなときに向いています。
- ［現在のアートボード］では［余白］を指定できます。アートボードの端からその分だけ内側に並べます。
- 間隔は左右と上下を指定できます。リンクアイコンがオンのときは、2つの値が連動します（初期状態はオン）。
- 並べ始める位置は、左右（左から／右から）と上下（上から／下から）で選びます。
- ［現在のアートボード］では［中央から］も選べます。並べた全体を、アートボードの左右中央・上下中央に置きます。［選択オブジェクト］に戻すと、左・上に戻ります。
- 順序は［位置］（上の行から、行の中は左から）、［重ね順］（前面から）、［ランダム］から選びます。
- ［ランダム］のときは、［シャッフル］で別の並びを作り直せます。ほかの値を変えても、並びは変わりません。
- 確定後は1回の取り消しで元に戻せます。

### 使い方

1. オブジェクトを2つ以上選択します。
2. スクリプトを実行します。
3. ［基準］を選び、列・間隔・並べ方を調整します。
4. ［OK］で確定します。［キャンセル］で元に戻ります。

### 注意点

- グループは1つのオブジェクトとして動かします。ロックされたオブジェクトと非表示のオブジェクトは対象外です。
- 境界は環境設定の［プレビュー境界を使用］に従います。
- ［幅を列にそろえる］がオフなら、［選択オブジェクト］では大きさを変えません。
- ［幅を列にそろえる］は線幅も同じ倍率で変えます。幅の無い線は対象外です。
- ［現在のアートボード］では、間隔は拡大・縮小しません。列数と列の幅の欄は使えなくなり、列数の欄には自動で決まった数が出ます。
- ［現在のアートボード］から［選択オブジェクト］に戻すと、列数は選択範囲の幅に入る数に戻ります。
