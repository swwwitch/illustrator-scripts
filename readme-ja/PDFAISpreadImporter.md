# PDF/AIの各ページを見開き分割してアートボードに配置（PDFAIImporter に統合）

[![Direct](https://img.shields.io/badge/Back%20to%20home-All%20scripts-cccccc.svg)](https://github.com/swwwitch/illustrator-scripts/blob/master/README.md)

---

### 概要

このスクリプトは [PDFAIImporter.jsx](PDFAIImporter.md) に統合しました。

見開きの分割は、PDFAIImporter の［見開き］パネルで［左右に分割］をオンにして使います。新規ドキュメントへの配置、トリミングの選択、偶数ページの位置（PDF の綴じ方向から自動設定）も PDFAIImporter で指定できます。
