### 概要

Illustrator 付属のスウォッチライブラリ（パターン・グラデーション）や、ドキュメントのスウォッチを、長方形に1つずつ適用して並べた見本を作ります。
ライブラリは複数選べ、ライブラリごとのブロックが縦に並びます。

### 主な機能

#### スウォッチ

- ［ライブラリ］／［ドキュメント］で、使うスウォッチの出どころを選ぶ
- ［ドキュメント］のときは、［選択したスウォッチ］（スウォッチパネルで選択しているもの）か［すべてのスウォッチ］を選ぶ。カラー・パターン・グラデーションの種類を問わない（［なし］［レジストレーション］は除く）
- ［ライブラリ］のときは、種類を［パターン］［パターン（クラシック）］［グラデーション］［グラデーション（クラシック）］から選ぶ（［ドキュメント］のときはディム表示）

#### ライブラリ（右カラム）

- 選んだ種類のライブラリを、Illustrator の［スウォッチライブラリを開く］のメニューと同じ順にチェックボックスで並べる（クラシックは、ベーシック／自然／装飾などの切れ目に区切り線）
- チェックを入れたライブラリごとに見本のブロックを作り、縦に並べる（ブロックの間は［間隔］の2倍）
- option＋クリックで、クリックしたライブラリだけにチェックを入れる（もう一度 option＋クリックすると、すべてにチェック）
- ［すべてを選択］［選択を解除］で、表示中の一覧のチェックをまとめて切り替える。件数は「チェック数 / 全体」で表示

#### 長方形

- ［幅］［高さ］で長方形の大きさを指定（連動アイコンで幅と高さを連動）
- ［間隔］で長方形どうしの間隔を指定
- 1行に10個ずつ並べ、折り返す

#### 線

- ［線幅］を指定（0 で線なし）
- ［カラー］の色見本をクリックすると、Illustrator 標準のカラーピッカーで線の色を選べる（初期値は黒）

#### テキストを追加

- ［ライブラリ名（ドキュメント名）］で、各ブロックの左上の長方形の上にライブラリ名（ドキュメントのときはドキュメント名）を入れる（14 pt）
- ［スウォッチ名］で、各長方形の上にスウォッチ名を入れる（5 pt）
- フォントはヒラギノ角ゴシック W3（HiraginoSans-W3）。入っていない環境では既定のフォント。カーニングはメトリクス、プロポーショナルメトリクスはオン。日本語環境では文字組みアキ量設定を「ツメ組み」にする

#### 共通

- ［プレビュー（長方形のみ）］で、設定を変えるたびに長方形の並びをドキュメントに描いて確かめられる（初期値はオン）。プレビューでは塗らず、長方形・線・テキストだけを描く（線幅が 0 のときは 0.5 pt の線）
- 数値欄は∧∨と↑↓キーで増減できる（shift で10の倍数へ、option で0.1ずつ）。単位は、幅・高さ・間隔が定規の単位、線幅が線の単位
- 見本は作業中のアートボードの中央に置き、作ったオブジェクトを選択した状態で終わる
- 設定は Illustrator を終了するまで覚えている（ライブラリのチェックは種類ごと）

### 使い方

1. 見本を作るドキュメントを開きます（［ドキュメント］の［選択したスウォッチ］を使うときは、スウォッチパネルでスウォッチを選択しておきます）。
2. スクリプトを実行します。
3. 出どころ・種類と、右の一覧でライブラリを選び、長方形・線・テキストを指定して［OK］で確定します。

### 注意点

- ライブラリのスウォッチは、ライブラリの .ai を開いて読み込み、保存せずに閉じます。その間、ウインドウが一瞬開きます。読み込んだスウォッチは作業中のドキュメントのスウォッチパネルに追加されます。
- ［プレビュー（長方形のみ）］では、ライブラリのスウォッチ名だけを読み（ライブラリを開くのは、Illustrator を起動してから初めて表示したときだけです）、スウォッチは取り込みません。取り込んで塗るのは［OK］で確定したときだけです。［キャンセル］で閉じると、プレビューで描いたものを削除します。
- 作業中のレイヤー（またはその親）がロック・非表示のときは、新しいレイヤーに描きます。
- 英語版の Illustrator で、クラシックのフォルダー名（Patterns (Classic) など）は確認できていません。
- 各項目の初期値は、スクリプト冒頭の `DEFAULT_SQUARE_WIDTH`・`DEFAULT_SQUARE_HEIGHT`・`DEFAULT_SIZE_LINKED`・`DEFAULT_SQUARE_MARGIN`・`DEFAULT_STROKE_WIDTH`・`DEFAULT_ADD_TITLE`・`DEFAULT_SHOW_SWATCH_NAMES`・`DEFAULT_PREVIEW`、並べる数や文字の大きさは `SQUARES_PER_ROW`・`TITLE_FONT_SIZE`・`SWATCH_NAME_FONT_SIZE`・`TEXT_FONT_NAME` で変更できます。

### 更新履歴

- v1.1.2（2026-10-27）［OK］で「Target layer cannot be modified」のエラーになることがある問題を修正（同じ名前のスウォッチが作業中のドキュメントにあればそれを使い、無いものだけを一時的に足したレイヤーを通して取り込むようにした）。プレビューで読んだライブラリのスウォッチ名を Illustrator の終了まで覚え、次の実行からはライブラリを開かないようにした
- v1.1.1（2026-10-27）ライブラリの一覧で、option＋クリックでクリックしたものだけにチェック（もう一度ですべてにチェック）できるようにした。表示していない種類のライブラリのチェックも覚えるようにした。テキストのカーニングをメトリクス、プロポーショナルメトリクスをオンにし、日本語環境では文字組みアキ量設定をツメ組みにした。［OK］で MRAP エラーになることがある問題を修正。項目名を［選択したスウォッチ］［間隔］［ライブラリ名（ドキュメント名）］［すべてを選択］［選択を解除］に変更
- v1.1.0（2026-10-27）ダイアログボックスを追加。Illustrator 付属のスウォッチライブラリ（パターン・グラデーション、それぞれクラシックも）を右カラムの一覧から複数選べるようにした（ライブラリごとのブロックを縦に並べる）。ドキュメントのスウォッチは［選択したスウォッチ］／［すべてのスウォッチ］から選び、種類を問わず使えるようにした。長方形の［幅］［高さ］（連動）［間隔］、線の［線幅］［カラー］、［テキストを追加］（［ライブラリ名（ドキュメント名）］［スウォッチ名］）、［プレビュー（長方形のみ）］を追加。定規がアートボード基準のとき位置がずれる問題を修正
- v1.0.0（2026-10-27）初版リリース
