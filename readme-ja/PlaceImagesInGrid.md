# 画像を選んで長方形やアートボードにグリッド状に配置

### 概要

ファイル選択ダイアログボックスで選んだ画像（複数可）をリンクで配置し、選択中の長方形の中にグリッド状に並べます。何も選択していないときは、作業中のアートボードに並べます。

配置したあとのダイアログボックスで、列数・行数・マージン・最終行の揃えと、各画像のマスク（角丸・線）を、プレビューを見ながら調整できます。

### 主な機能

- 画像を複数まとめて選んで配置（リンク配置）
- 並べる対象は、選択中の長方形、または作業中のアートボード
- 対象がなるべく埋まる列数・行数を自動で計算（［自動］）、または列数・行数を手動で指定（［手動］）
- 各画像を縦横比を保ったままセルに収まる大きさに拡大・縮小
- 画像どうしの間隔（［間隔］）と、並べる範囲の外周の余白（［外周］）を指定
- 余った分は上下（左右）に均等に振り分け
- 端数の出た最終行を［左揃え］または［中央揃え］にする
- ［シャッフル］で並び順をランダムに入れ替え
- 各画像をマスク（［セル］／［画像］）し、角丸を効果として指定
- マスクの長方形に線（線幅・色）を付ける
- ダイアログボックスの設定を次回に引き継ぐ
- 設定をプリセットとして保存・読み込み・削除。組み込みのプリセット（黒 0.3pt・角丸なし／白 1pt・角丸 2pt／白 1pt・角丸 50pt）付き
- 入力と同時に更新されるプレビュー
- ステップボタン（∧∨）・↑↓キーによる数値の増減
- マージンはIllustratorのルーラー単位で入力
- 日本語／英語UI

### 使い方

1. 画像を並べたい長方形を1つ選択します。アートボードに並べるときは、何も選択しません。
2. `PlaceImagesInGrid.jsx` を実行します。
3. ファイル選択ダイアログボックスで画像を選びます（複数可）。
4. 配置後に開くダイアログボックスで、プレビューを見ながら設定します。
   - ［プリセット］: 保存した設定・組み込みのプリセットを読み込み、今の設定を保存（保存アイコン）、選んだプリセットを削除（ゴミ箱アイコン）
   - ［グリッド］: ［自動］／［手動］、列数、行数、最終行（［左揃え］／［中央揃え］）
   - ［マージン］: 間隔、外周
   - ［マスク形状］: ［なし］／［セル］／［画像］
   - ［マスクのオプション］: 角丸、線幅、線（色）
5. 必要に応じて［シャッフル］で並び順を入れ替えます。
6. ［OK］をクリックして確定します。

### 注意点

- 長方形1つ以外（複数のオブジェクトやパス以外）を選択しているときは、ファイルを選ぶ前にメッセージを表示して止まります。
- 長方形は、パスの外接矩形（線幅を含まない）を枠として使います。長方形は削除せず、配置した画像は長方形のすぐ前面に置きます。
- 縦横比が異なる画像が混ざっているときは、横長の画像は幅が、縦長の画像は高さがセルに合うため、大きさはそろいません。
- 行数を指定したときは、それに合う列数になります。画像は左上から行ごとに詰めるため、作れない行数（16枚で5行など）は飛ばします。
- マージンが大きすぎて並べる範囲がなくなるときは、等倍のまま横一列に並べます。
- マスク形状の［セル］では、各画像をセルを覆う大きさに拡大・縮小し、セルの長方形でクリップします。セルからはみ出した部分は隠れ、大きさがすべてそろいます。
- マスク形状の［画像］では、セルに収めた画像の大きさのままクリップします。切り抜かれる部分はなく、角丸や線を付けたいときに使います。
- 角丸は、クリップグループに［効果］→［スタイライズ］→［角を丸くする］として掛けます。あとからアピアランスパネルで半径を変えられます。
- 角丸と線幅は、それぞれのチェックボックスをオンにしたときだけ付けます。マスク形状が［なし］のときは使えません。
- 線はクリップパスに付けます。線幅は環境設定の線の単位で入力します。［線］の色見本をクリックすると、標準のカラーピッカーで色を選べます。
- 設定は［OK］で確定したときに保存し、次に実行したときの初期値にします（列数は［手動］のときだけ引き継ぎます）。
- プリセットには、列数・行数・マージン・最終行・マスク形状・角丸・線をまとめて保存します。保存先は `Folder.userData/illustrator-scripts/PlaceImagesInGridPresets.json` で、Illustrator を再起動しても残ります。
- 組み込みのプリセットは、マスクの線と角丸だけを変えます（ほかの設定は今のまま）。マスク形状が［なし］のときは［セル］にします。組み込みのプリセットは削除できず、同じ名前では保存できません。
- ［キャンセル］すると、配置した画像を取り除きます。
- 作業中のレイヤーがロックまたは非表示のときは配置できません。
