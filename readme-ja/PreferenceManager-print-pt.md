### 概要

単位と数値インクリメントを、ダイアログから指定・変更します。

### 主な機能

- 現在の単位設定を読み取って初期値に反映
- 単位と数値インクリメントをまとめて変更
- Illustratorのバージョンに応じた内部マッピングで、GUIからの補正を不要に

### 使い方

1. スクリプトを実行します。
2. 単位と数値インクリメントを指定して［OK］をクリックします。

### 注意点

- AppleScript や Keyboard Maestro を使わずに、直接設定できます。
