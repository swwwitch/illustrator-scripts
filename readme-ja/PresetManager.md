# 環境設定をまとめて変更

[![Direct](https://img.shields.io/badge/Direct%20Link-PresetManager.jsx-ffcc00.svg)](https://github.com/swwwitch/illustrator-scripts/blob/master/jsx/preference/PresetManager.jsx)

[![Direct](https://img.shields.io/badge/Back%20to%20home-All%20scripts-cccccc.svg)](https://github.com/swwwitch/illustrator-scripts/blob/master/README.md)

---

### 概要

- Illustrator の環境設定のうち、よく触る項目だけを1枚のダイアログに集めたユーティリティ。
- ［一般］［テキスト］［ガイド］［パフォーマンス］［ファイル管理］など、本来は別々のカテゴリに分かれている項目を、行き来せずにまとめて変更できる。
- ダイアログを開いた時点では現在の環境設定を読み込んで表示する。ドロップダウンで［デフォルト］／［プリセット1］を選ぶと、一式の設定値をUIに流し込める。
- 操作中は環境設定に書き込まず、［OK］を押したタイミングでまとめて保存する（［キャンセル］なら何も変更されない）。

### 使い方

1. スクリプトを実行するとダイアログが開き、現在の環境設定が反映される。
2. 必要な項目を変更する。上部のドロップダウンから［デフォルト］／［プリセット1］を選ぶと、一式の値をまとめてUIに反映できる（この時点ではまだ保存されない）。
3. ［OK］で保存する。

### 設定できる項目

#### ［一般］カテゴリ

| 項目 | 環境設定キー |
| --- | --- |
| 詳細なツールヒントを表示 | showRichToolTips |
| 「ホーム画面」を表示 | Hello/ShowHomeScreenWS |
| 以前の「新規ドキュメント」インターフェイス | Hello/NewDoc |
| 「裁ち落としを印刷」生成AIボタンを表示 | enablePrintBleedWidget |

上の2項目はラベルが長いため表示を短くしてある。環境設定と同じ全文（「ドキュメントを開いていないときに「ホーム画面」を表示」「以前の「新規ドキュメント」インターフェイスを使用」）はツールチップに表示される。

#### ［選択範囲・アンカー表示］カテゴリ

| 項目 | 環境設定キー |
| --- | --- |
| 選択範囲へズーム | zoomToSelection |
| アンカーポイントのサイズ | anchorSizePref |

アンカーポイントのサイズは4段階のスライダー。書き込まれる値は 5 / 7 / 9 / 11 で、デフォルトは 5。現在の設定値がどの段階とも一致しない場合は、最も近い段階にスナップして表示する。

#### アートボード

| 項目 | 環境設定キー |
| --- | --- |
| ロックまたは非表示オブジェクトを一緒に移動 | moveLockedAndHiddenArt |
| アートボード名を表示 | showArtboardLabelOnCanvas |
| ハイライトのカラー | ArtboardBBColorRed / Green / Blue |
| ストロークの幅（1〜4） | ArtboardBBWidth |

ハイライトのカラーは、ライトブルー／サーモンピンク／グリーン／ミディアムブルー／マゼンタ／シアン／ホワイト／ブラック／イエローの9色から選ぶ。現在の設定値がどのプリセットとも一致しない場合は、RGB の差が最も小さいものを選択状態にして表示する。

#### ［テキスト］カテゴリ

| 項目 | 環境設定キー |
| --- | --- |
| 新規エリア内文字の自動サイズ調整 | text/autoSizing |
| 最近使用したフォントの表示数 | text/recentFontMenu/showNEntries |
| 見つからない字形の保護を有効にする | text/doFontLocking |
| 選択された文字の異体字を表示 | text/enableAlternateGlyph |

「最近使用したフォントの表示数」はチェックボックスと数値欄の組み合わせ。チェックを外すと数値欄が無効になり、0（非表示）として保存される。チェックを入れているときの入力範囲は 1〜30 で、範囲外や数値以外を入力した場合は 15 に補正される（チェックONのまま0を保存することはできない）。

#### ［ユーザーインターフェイス］カテゴリ

| 項目 | 環境設定キー |
| --- | --- |
| カンバスカラー（UIに合わせる／ホワイト） | uiCanvasIsWhite |

明るさ（`uiBrightness`）を4段階のスウォッチで選ぶUIは、**既定では表示されない**。値は連続値ではなく離散的なプリセット（0.0 / 0.5 / 0.50999999 / 1.0）で、`uiBrightness` に書き込むだけでは画面に反映されず、［OK］後に環境設定（ユーザーインターフェイス）を開いて矢印キー＋Return で確定する必要があるため。スクリプト冒頭の `SHOW_BRIGHTNESS_UI` を `true` にすると表示される。

#### ガイド

| 項目 | 環境設定キー |
| --- | --- |
| カラー（シアン／ライトブルー） | Guide/Color/red、green、blue |
| スタイル（ライン／点線） | Guide/Style（0=ライン / 1=点線） |

カラーはシアン（0, 1, 1）とライトブルー（0.29, 0.52, 1.0）の2択。現在の設定値がライトブルーと一致しない場合は、シアンを選択状態にして表示する。

#### スマートガイド

| 項目 | 環境設定キー |
| --- | --- |
| オブジェクトのハイライト表示 | smartGuides/showObjectHighlighting |

#### ［パフォーマンス］カテゴリ

| 項目 | 環境設定キー |
| --- | --- |
| アニメーションズーム | Performance/AnimZoom |
| ヒストリー数 | maximumUndoDepth |
| リアルタイムの描画と編集 | LiveEdit_State_Machine |

ヒストリー数は 1〜1000。範囲外や数値以外を入力した場合は 100 に補正される。`maximumUndoDepth` が読み取れず 0 が返る環境でも、0 は「キーが未登録」とみなして 100 として扱う。

#### ［ファイル管理］カテゴリ

| 項目 | 環境設定キー |
| --- | --- |
| 「オリジナルの編集」にシステムデフォルトを使用 | useSysDefEdit |
| Adobe Fonts を自動アクティベート | AutoActivateMissingFont |
| ファイルの保存先（コンピューター／クラウド） | AdobeSaveAsCloudDocumentPreference |
| リンクを更新（自動／手動／確認） | plugin/FileClipboard/linkoptions（0=自動 / 1=手動 / 2=確認） |

#### クリップボードの処理

| 項目 | 環境設定キー |
| --- | --- |
| SVGコードを含める | plugin/FileClipboard/copySVGCode |

#### パスに制限

| 項目 | 環境設定キー |
| --- | --- |
| オブジェクトの選択範囲をパスに制限 | hitShapeOnPreview |
| テキストオブジェクトの選択範囲をパスに制限 | hitTypeShapeOnPreview |

この2つのキーは 0 がON、1 がOFF と反転しているため、スクリプト側で読み書きを反転している。

### 処理の流れ

1. ダイアログを生成し、2カラムにパネルを配置する
2. 現在の環境設定を読み込んでUIに反映する（`loadPreferencesIntoUI`）
3. プリセットを選ぶと、定義済みの値でUIを上書きする（環境設定には書き込まない）
4. ［OK］で各環境設定キーへ書き込み、必要に応じて環境設定パネルを開く

チェックボックス項目は「環境設定キー・コントロール・プリセット項目」を1行にまとめた対応表を持ち、読み込み・保存・プリセット適用の3か所がその同じ表を参照する。項目を追加するときは対応表への登録も同時に済むため、追加したのに保存されないという取りこぼしが起きない。

### 注意

- 環境設定の変更は画面にすぐ反映されないことがあるため、［OK］時にズームアウト→ズームインを実行して強制的に再描画している（ドキュメントを開いていないときは実行しない）。
- 環境設定の読み書きは共通ラッパーで保護してあり、Illustrator のバージョンによって存在しないキーがあっても処理は止まらない。
- ただし Illustrator は未登録のキーを読んでも例外を投げず 0 / false を返す。そのため、そのバージョンに存在しないキーはOFF（または0）として表示され、［OK］でその値が書き込まれる。0 が正当な値ではないキー（ヒストリー数など）は、0 を「未登録」とみなして既定値に戻すようにしてある。
- ［キャンセル］で閉じた場合は、プリセットを選んでいても環境設定は一切変更されない。
