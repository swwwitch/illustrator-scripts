### 概要

アートボード名表示とアートボード枠線の表示設定を、ダイアログでまとめて切り替えます。

### 主な機能

- プリセット（デフォルト／強調／ライト）の切り替え
- アートボード名の表示
- ハイライトカラーとストローク幅の変更
- 補助操作として［ビデオ定規］ボタン

### 使い方

1. スクリプトを実行します。
2. 各項目を操作すると、その場で反映されます。
3. ［閉じる］でダイアログを閉じます。

### 注意点

- 操作した瞬間に環境設定へ反映されます。取り消しはできません。
- 起動時、現在の設定がいずれかのプリセットと一致していれば、そのラジオボタンが選択されます。
- ハイライトカラーは9色のプリセットから選びます。現在値に最も近い色が初期選択になります。
