### 概要

アートボード名表示とアートボード枠線の表示設定を、ダイアログでまとめて切り替えます。

### 主な機能

- プリセットの切り替え
- アートボード名の表示
- ハイライトカラーとストローク幅の変更

### 使い方

1. スクリプトを実行します。
2. 設定を指定して［OK］をクリックします。

### 注意点

- 常駐パレット型が好みの場合は PresetManager-artboards.jsx を使用してください。
