### 概要

選択したオブジェクトの位置・スケール・回転・不透明度・塗りカラーをランダムに変化させるスクリプト。ダイアログで振れ幅を指定すると即時プレビューされ、［中央に集める］［重なりを避ける］による再配置にも対応します。

<img alt="ランダム化ダイアログの外観" src="../png/ss-894-772-144-20260819-143910.png" width="50%" />

### 主な機能

- 移動距離を横・縦で個別に指定、または［連動］で同じ値を使用（単位はpt）
- スケール（幅・高さ）を%で指定、こちらも［連動］に対応
- 回転（0〜180°）、不透明度（0〜100%）をスライダーまたは数値で指定
- 塗りカラーの［シャッフル］（選択内の色を入れ替え）と［完全シャッフル］（ランダムな色を生成）
- ［中央に集める］で選択オブジェクトを全体の中心へ集約
- ［重なりを避ける］で、重ならない配置が見つかるまで移動範囲を広げながら再配置
- ↑↓キーで数値を増減（shiftで10単位、optionで0.1単位）
- プレビューは毎回ベース状態から再計算するため、変形が積み増しにならない
- ［リセット］／［キャンセル］でダイアログ起動前の状態へ復元（塗りカラーを除く）
- ダイアログの表示位置を記憶（Illustratorを終了すると忘れる）

### 処理の流れ

1. ドキュメントと選択状態を確認
2. ダイアログを表示（移動距離・スケール・回転・不透明度・カラーを指定）
3. 数値やスライダーを操作すると即時プレビュー
4. ［ランダム］で乱数を振り直す（カラーの反映もこのタイミング）
5. OKで確定、キャンセルで起動前の状態に復元

### メモ

- 振れ幅は「±指定値」の意味で、たとえば移動距離20ptなら-20〜20ptの範囲で動きます。
- 回転は0〜180°、不透明度は0〜100%が上限です。これを超える値を入力しても、その上限で頭打ちになります。
- チェックをONにすると入力欄に20が自動で入ります（縦のみ0のまま）。
- カラーは［ランダム］を押したときだけ反映されます。［シャッフル］は選択内の塗り色を入れ替え、［完全シャッフル］はドキュメントのカラーモードに合わせて色を生成します（CMYKのKは0〜30に抑えて暗くなりすぎないようにしています）。
- ［シャッフル］は2つ以上、［完全シャッフル］は1つ以上のオブジェクト選択が必要です。
- **塗りカラーは［リセット］／［キャンセル］では元に戻りません。** 位置・スケール・回転・不透明度は起動前の状態へ復元されますが、カラーだけは適用した時点で確定します。元に戻したいときは Illustrator 側で取り消し（command + Z）してください。
- 塗りカラーの対象は、パス／複合パス／テキスト／グループ（中の最初の対象）です。
- ［重なりを避ける］は、1オブジェクトあたり300回まで位置を試し、置ききれないときは移動範囲を最大20倍まで段階的に広げます（重なり判定には5ptの余白を見込みます）。置ききれた場合だけ、広げた結果が移動距離の入力欄に書き戻されます（失敗したときは入力値をそのまま残します）。
- ダイアログを開いている間はライブコーナーの表示を一時的に切り替えます（プレビューの妨げになるため）。
