### 概要

- 選択中の長方形や罫線を、その範囲いっぱいの矢印に置き換えます。回転した長方形や斜めの罫線にも対応します。
- 矢印は［塗り］［ホームベース］［線（線端なし）］［線（丸型線端）］の4種類から選び、太さ・高さ・角度はプレビューで確認しながら調整します。
- 向きの反転と両矢印は、アイコンか、種類のボタンの修飾キー＋クリックで切り替えます。

### 主な機能

#### 種類

- 矢印の形を描いたボタン（縦に4つ）で選びます。選択中は灰色の地と濃い枠になります
  - 塗り：1本の閉じたパスの矢印にします。先端の角度は［角度］で指定します。元のパスを書き換えるので、効果や重ね順はそのまま残ります
  - ホームベース：長方形の一端を、短辺いっぱいの幅でとがらせた形にします。先端の角度は［角度］で指定します。塗りと同じく元のパスを書き換えます
  - 線（線端なし）：軸の直線とくの字の矢じりを、線端なし・マイター結合の線で組みます
  - 線（丸型線端）：同じく、丸型線端・ラウンド結合の線で組みます
- ↑↓キーでも種類を切り替えられます。開いた直後は数値欄にカーソルがないので、そのまま使えます。数値欄をクリックしたあとは、↑↓はその欄の増減になります
- 線の2種類は、線ごとに［パスのアウトライン］効果を掛けてグループにし、グループに［パスファインダー（合体）］効果を掛けます。アピアランスのままなので、あとから線幅などを編集できます
- 向き：長辺（罫線は線そのもの）に沿わせ、水平寄りなら右向き、垂直寄りなら上向きになります。回転していなければ、横長は右向き、縦長は上向きです。正方形は水平に近い辺に沿わせ、45°のときは右上向きになります
  - 正方形は［方向］で［水平］／［垂直］を選べます（初期値は水平。［垂直］で上向き）。長方形・罫線には効かず、正方形が選択されていないときはディム表示になります
  - ボタンを option（Alt）＋クリックすると、向きが逆になります。もう一度で元に戻ります
  - ボタンを ⌘＋option（Ctrl＋Alt）＋クリックすると、両矢印のオン／オフを切り替えます
  - 種類のボタンの下の［両矢印］（リンク）と［反転］（⇄）のアイコンでも切り替えられます。両矢印のときは反転を使えません
  - 向きと両矢印は4種類で共通です。ボタンの絵も今の向きに合わせて変わります

#### 太さ

- 塗りは軸の太さを、長方形の短辺に対する％で指定します（1〜100%、初期値 45%）
- 線の2種類は線幅を、環境設定の［線］の単位で指定します。初期値は、1つ目の対象の短辺の 15% を換算した値です（1つ目が罫線なら、その罫線の線幅）
- 種類を切り替えると、欄の単位も％と線の単位で切り替わります。種類ごとに値を覚えるので、切り替えても調整した値は消えません
- ∧∨ボタンと↑↓キーで増減できます（shift＋で次の10の倍数へ、option＋で0.1ずつ）
- ホームベースでは使いません（欄はディム表示）

#### 高さ

- 矢印の高さ（矢じりの幅）を、長方形の短辺に対する％で指定します（1〜500%、初期値 100%）。塗りと線の3種類で共通で、ホームベースでは使いません
- 軸の太さ・線幅は変わりません。塗りの矢印で高さが軸の太さより小さいときは、軸を高さに合わせます
- 矢じりの長さも高さに合わせて変わります（塗りは［角度］、線は直角を保ちます）

#### 角度

- 塗りの矢じりとホームベースの先端の角度を、軸に対する斜辺の角度で指定します（1〜89°、初期値 45°）。45° で直角の先端になり、値を小さくするほど鋭くなります。塗りとホームベースで共通で、線の2種類では使いません
- 長方形が短くて指定の角度で収まらないときは、片側は全長、両側は全長の半分までに抑えるので、先端は鈍くなります

#### 白フチ

- ［白フチ］パネルでオンにすると、矢印の背面に白い複製を置き、［パスのオフセット］効果で矢印の周りに白いフチを付けます（初期値はオフ）。4種類すべてで使えます
- ［オフセット］：フチの幅（［パスのオフセット］の値）を定規の単位で指定します。初期値は、線の2種類では線幅の1/2、塗りとホームベースでは1つ目の対象の短辺の1/10です
- ［オフセット］は、線の2種類では［太さ］を変えると線幅の1/2に合わせて変わります
- ［角の形状］：マイター／ラウンドをラジオボタンで選びます。種類を選ぶと、線（丸型線端）はラウンド、ほかはマイターに切り替わります
- 塗りとホームベースでは、白い複製に［合体］と［パスのオフセット］効果を掛けます。矢印と白フチはグループにし、グループに［分割］効果を掛けます。分割・拡張すると、白フチは矢印と重ならない形に分かれます
- 線の2種類では、オンにすると［分割・拡張］もオンになります（白フチがオンのあいだ［分割・拡張］はオフにできません）。分割・拡張してできたパスを白で複製して背面に置き、［パスのオフセット］効果を掛けます。矢印と白フチはグループにします
- 白フチは複製なので、あとから矢印を編集しても追従しません

#### 先端補正（分割・拡張に連動）

- 線の2種類で［分割・拡張］がオンのとき（白フチでオンになったときも）、軸の矢じり側の端を線幅の1/10だけ短くします。両矢印では両端とも短くします。オフのときは短くしません。チェックボックスはありません
- 軸の端が矢じりの線と重ならないので、［アピアランスを分割］したときに余分なアンカーポイントができにくくなります

#### 分割・拡張

- 線の2種類で、確定時に［アピアランスを分割］し、効果のない1つのパスにします（初期値はオフ）。プレビューには反映しません
- 分割後、曲線の部分（丸型線端・ラウンド結合の丸み）を90°以下の円弧に置き換えて、アンカーポイントを減らします

#### 罫線

- 長方形のほか、直線のオープンパス（2点）も対象です。短辺が 0 なので、線の長さの 1/4 を短辺として扱います。斜めの線も、線に沿った矢印になります
- 1つ目の対象が罫線のときは、［線（線端なし）］を選んだ状態でダイアログボックスが開きます

#### 形と色

- 矢じりは直角で、長さは高さの半分です。長方形が短いときは、片矢印は全長、両矢印は全長の半分までに抑えます
- 線の矢印は、線幅のぶんだけパスを内側へ詰め、線端や先端の角も含めて長方形の範囲に収めます。線幅が太いほど、矢じりはひと回り小さくなります
- 色は、元の長方形の塗りの色を使います。塗りがなしか白のときは線の色、塗りも線もなしのときは黒にします

#### プレビュー

- プレビューは常にオンです（ダイアログボックスを開いた時点から反映）。複製を矢印にして見せ、元の長方形はプレビューの間だけ隠します。キャンセルすると元に戻ります

### 使い方

1. 矢印にしたい長方形や罫線を選択します（グループの中のものも対象。複数選択も可）
2. スクリプトを実行し、ダイアログボックスで種類・太さ・高さ・角度（ホームベースは角度だけ、線は角度なし）を設定します
3. ［OK］で置き換えます

### 注意点

- 対象は長方形（ハンドルのない4点で、角がすべて直角。回転していてもよい）と、罫線（ハンドルのない2点のオープンパス。斜めでもよい）です。角丸の長方形・平行四辺形・曲線・ロック中や非表示のものは対象外です
- 線の矢印にすると、元の長方形に付いていた効果は引き継がれません
- 線の矢印の線幅は、どの長方形にも同じ値を使います（塗りの軸の太さは長方形ごとの短辺に対する％）
- 線の矢印は、プレビューのたびにメニューコマンドで効果を掛けるため、長方形が多いと描き直しに時間がかかることがあります
