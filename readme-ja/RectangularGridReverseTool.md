# 水平線・垂直線を長方形グリッドとして再構成

### 概要

選択した水平線・垂直線（外枠の長方形を含む）を解析し、長方形グリッドとして組み直します。

罫線の端を交点にそろえ、行・列の間隔を均等にして、結合セルを含む表も整った格子にします。

### 主な機能

ダイアログボックス上部の［簡易］［詳細］でモードを切り替えます。前回のモードが今の選択で使えればそのモードで、使えなければ［簡易］で開きます。

#### 簡易モード

外枠の長方形の中にある罫線を、外枠の中で均等に並べ直します。外枠の長方形はそのまま残します。

- ［横罫を平均化］［縦罫を平均化］を個別に指定（option＋クリックでもう一方も同じ状態に）
- ［長さを揃える］：罫線の端を外枠の辺にそろえる。オフのときは長さを変えずに位置だけ動かす
- 塗りのある外枠や、アンカーポイントが3つ以上の罫線も対象

#### 詳細モード

- 前処理：外枠の長方形を上下左右4本の線に分割して扱う
- 配置モード：均等配置しない／均等に（強制）／均等＋結合セル対応
  - 結合セル対応では、同じ位置の線を1行・1列にまとめ、線の端を近い交点にそろえる
- 均等配置の対象：縦罫（列の幅）・横罫（行の高さ）を個別に指定。それぞれ1列目・1行目を固定して残りをそろえることもできる
  - ［縦罫］［横罫］を option＋クリックすると、もう一方も同じ状態になる
- 線：突出線端、破線→実線
- 線幅：最大・最小・平均・指定にそろえる
  - ［指定］の入力欄は∧∨ボタンと↑↓キーで増減でき、計算式や単位付きの値（「1 mm」など）も入力できる
- 後処理：外枠を長方形に変換、ポイント文字をセル内で上下中央、グループ化
- プレビュー：ダイアログを閉じずに結果を確認

### 使い方

1. 表の罫線（水平線・垂直線、外枠の長方形）を選択します。グループの中の線も対象です。
2. スクリプトを実行します。
3. モードを選び、各オプションを指定し、プレビューを見ながら［OK］で確定します。［キャンセル］で元に戻ります。

### 注意

- 簡易モードは、選択した中でいちばん大きい閉じたパスを外枠とし、その辺の20%以上の長さがある内側の線を罫線とみなします。ロック中・非表示のパスは対象外です。
- 詳細モードでは、塗りのあるパス（長方形を除く）と、アンカーポイントが2つでない線は対象外です。塗りのある長方形は外枠として扱い、塗りは背景として残します。水平線・垂直線がそれぞれ2本以上必要です。
- ［ポイント文字をセル内で上下中央］は、選択に関係なく、グリッドの範囲内にあるポイント文字を移動します。

### 更新履歴

- v1.4.0（2026-10-20）［簡易］［詳細］のモード切り替えを追加。簡易モードは AverageRulesInRectangle.jsx の機能（外枠の長方形の中で罫線を均等に並べ直す。長さを保ったまま位置だけ動かすこともできる）。モードに合わせてダイアログボックスの大きさを変えるようにした。塗りのある長方形を外枠にしたとき、表全体が縮む不具合を修正（塗りは背景として残す）。アンカーポイントが5つ以上ある長方形（辺上の点や閉じる位置に重なった点があるもの）や、座標がわずかにずれた長方形も外枠として扱い、表全体が縮まないようにした
