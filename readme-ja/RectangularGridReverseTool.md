### 概要

選択した水平線・垂直線（外枠の長方形を含む）を解析し、長方形グリッドとして組み直します。

罫線の端を交点にそろえ、行・列の間隔を均等にして、結合セルを含む表も整った格子にします。

### 主な機能

- 前処理：外枠の長方形を上下左右4本の線に分割して扱う
- 配置モード：均等配置しない／均等に（強制）／均等＋結合セル対応
  - 結合セル対応では、同じ位置の線を1行・1列にまとめ、線の端を近い交点にそろえる
- 均等配置の対象：縦罫（列の幅）・横罫（行の高さ）を個別に指定。それぞれ1列目・1行目を固定して残りをそろえることもできる
  - ［縦罫］［横罫］を option＋クリックすると、もう一方も同じ状態になる
- 線：突出線端、破線→実線
- 線幅：最大・最小・平均・指定にそろえる
  - ［指定］の入力欄は∧∨ボタンと↑↓キーで増減でき、計算式や単位付きの値（「1 mm」など）も入力できる
- 後処理：外枠を長方形に変換、ポイント文字をセル内で上下中央、グループ化
- プレビュー：ダイアログを閉じずに結果を確認

### 使い方

1. 表の罫線（水平線・垂直線、外枠の長方形）を選択します。グループの中の線も対象です。
2. スクリプトを実行します。
3. 各オプションを指定し、プレビューを見ながら［OK］で確定します。［キャンセル］で元に戻ります。

### 注意

- 塗りのあるパスと、アンカーポイントが2つでない線は対象外です。
- 水平線・垂直線がそれぞれ2本以上必要です。
- ［ポイント文字をセル内で上下中央］は、選択に関係なく、グリッドの範囲内にあるポイント文字を移動します。
