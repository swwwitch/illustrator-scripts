### 概要

- 選択中のオブジェクトがグループ内にある場合、親グループをたどって所属レイヤーの直下へ移動します。
- 重ね順の逆転を避けるため、選択オブジェクトは逆順（後ろから）に処理します。

### 使い方

1. グループ内のオブジェクトを選択する
2. スクリプトを実行する
