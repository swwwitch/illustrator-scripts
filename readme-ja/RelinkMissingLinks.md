### 概要

リンク切れの配置画像を検出し、指定したフォルダーから同名ファイルを探して自動的に再リンクします。

### 主な機能

- リンク切れの配置画像を一括検出
- 再リンク用フォルダーをダイアログで指定
- 照合方法を「拡張子まで完全一致」「ファイル名のみ」「拡張子優先」から選択

### 使い方

1. リンク切れのあるドキュメントを開きます。
2. スクリプトを実行します。
3. 再リンク元のフォルダーと照合方法を指定します。

### 注意点

- 同名ファイルが見つからないリンクは、そのまま残ります。
