### 概要

アートボード上に表示オブジェクトが存在しないアートボードを検出し、まとめて削除します。

### 主な機能

- 非表示のレイヤー／オブジェクトを「占有あり」とみなすかを切り替え可能（既定はON＝無視）
- トグルに応じて対象数の表示が即時更新

### 使い方

1. 対象のドキュメントを開きます。
2. スクリプトを実行します。
3. 対象数を確認して実行します。

### 注意点

- 非表示判定は祖先を遡って行うため、グループ内の非表示アイテムや、非表示グループ／レイヤー配下のアイテムも同じ扱いになります。
