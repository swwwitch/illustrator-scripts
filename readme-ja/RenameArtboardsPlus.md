# アートボード名の一括変更

[![Direct](https://img.shields.io/badge/Direct%20Link-RenameArtboardsPlus.jsx-ffcc00.svg)](https://github.com/swwwitch/illustrator-scripts/blob/master/jsx/artboard/RenameArtboardsPlus.jsx)

[![Direct](https://img.shields.io/badge/Back%20to%20home-All%20scripts-cccccc.svg)](https://github.com/swwwitch/illustrator-scripts/blob/master/README.md)

---

書き出しファイル名がアートボード名で決まる以上、アートボード名は「あとで直せばいい」ものではありません。とはいえ、［アートボード］パネルでひとつずつダブルクリックして打ち直すのは、枚数が増えるほど現実的でなくなります。

このスクリプトは、**ファイル名・接頭辞・元の名前・連番・接尾辞を組み合わせた命名ルール**をダイアログで組み立て、プレビューで結果を確かめてから一括で適用します。

![](https://www.dtp-transit.jp/images/ss-1210-1120-72-20250713-080350.png)

## 使い方

1. アートボードのあるドキュメントを開く
2. スクリプトを実行
3. 各パネルで命名ルールを組み立て、プレビューを確認して［OK］

ドキュメントを開いていないときは、何もせずに終了します。

## 名前の組み立て

新しいアートボード名は、次の順に連結されます。

```
［接頭辞］＋［アートボード名と番号］＋［区切り文字］＋［連番］＋［接尾辞の文字列］
```

連番形式が「なし」のときは、［区切り文字］と［連番］が入りません。

## 接頭辞

| 項目 | 内容 |
| --- | --- |
| ファイル名 | 「参照する」でドキュメント名（拡張子を除く）を先頭に付ける |
| 区切り文字 | ファイル名と後ろの文字列の間に入れる文字（なし／-／_）。「参照する」のときだけ操作できます |
| 文字列 | 任意の文字列 |

## アートボード名と番号

| 選択 | 生成される文字列 |
| --- | --- |
| なし | （何も入りません） |
| 番号 | アートボードの並び順（1, 2, 3...） |
| 名称 | 変更前のアートボード名 |
| 番号-名称 | `1-元の名前` |
| 番号_名称 | `1_元の名前` |

ここでいう「番号」はアートボードの位置そのものです。接尾辞側の「開始番号」「増分」の影響は受けません。

## 接尾辞

| 項目 | 内容 |
| --- | --- |
| 区切り文字 | 連番の直前に入れる文字（なし／-／_）。連番形式が「なし」のときはディムします |
| 連番形式 | なし／数字／アルファベット（大文字）／アルファベット（小文字） |
| 開始番号 | 連番の開始値。数字なら `1` や `001`、アルファベットなら `A` や `ab` |
| 増分 | 連番の増え幅。連番形式が「数字」のときだけ有効です |
| 文字列 | 末尾に付ける任意の文字列 |

### ゼロ埋め

「開始番号」に入力した桁数が、そのままゼロ埋めの桁数になります。`001` と入力すれば `001` `002` `003`…、`1` なら `1` `2` `3`… です。桁数を指定するための専用の項目はありません。

### アルファベットの連番

`A` → `B` → … → `Z` → `AA` → `AB` … と続きます。増分は使わず、常にひとつずつ進みます。開始値には `A` のような1文字でも、`ab` のような複数文字でも指定できます。

## プレビュー

設定を変えるたびに、先頭から最大15件の結果を表示します。16件目以降は「...（以下省略）」とまとめます。

開始番号や増分に数字以外が混ざっているなど入力が正しくないときは「※数値が正しくありません」と表示し、［OK］を押しても警告して先に進みません。前後の空白は無視します。

## プリセット

ドロップダウンから内蔵プリセットを選ぶと、各項目がまとめて設定されます。

| プリセット | 結果の例 |
| --- | --- |
| ファイル名+連番3 | `ファイル名-001` |
| アートボード名と連番 | `元の名前-1` |

［プリセット書き出し］を押すと、現在の設定を1行のテキスト（UTF-8）として保存できます。保存したファイル名が、そのままプリセット名になります。

書き出したテキストは、スクリプト内の `BUILTIN_NAMING_PRESETS` に貼り付けると内蔵プリセットとして追加できます。ファイルから読み込む機能はありません。

## 補足

- 連番を付けない設定で名前が空になる場合は、警告してリネームしません
- 名前は常に「変更前のアートボード名」を起点に組み立てます
- Illustratorが名前を受け付けなかったときは警告を表示し、ダイアログを開いたままにします
- 日本語・英語のUIに対応します（Illustratorのロケールで自動的に切り替わります）
- ExtendScript（ES3）互換
