# 選択した文字の字形と異体字を切り換える

[![Direct](https://img.shields.io/badge/Direct%20Link-ReplaceAlternateGlyphs.jsx-ffcc00.svg)](https://github.com/swwwitch/illustrator-scripts/blob/master/jsx/text/ReplaceAlternateGlyphs.jsx)

### 概要

- 選択した文字の字形（JIS78字形・JIS90字形・旧字体など）を、ダイアログボックスで選んでその場で切り換える。
- 「高」→「髙」のような異体字（別の文字）への置き換えや、異体字と符号位置を並べた一覧の作成もできる。

### 主な機能

- ダイアログボックスの上に、選択した文字と符号位置を「葛 U+845B」の形で表示する（5文字まで。異体字に置き換えると更新）
- 「字形」（左）
  - 標準字形・JIS78字形・JIS83字形・JIS90字形・JIS04字形・旧字体・エキスパート字形・等幅全角字形・等幅半角字形・等幅三分字形・等幅四分字形
  - 開いたときは、選択した文字に共通の字形が選ばれている。クリックするとすぐに反映する
  - フォントが持っていない字形（選択した文字のどれでも標準字形と同じ形になるもの）はディム表示にする。調べるのは先頭の10文字まで
- 「異体字」（右）
  - 選択の中に、登録された異体字のある文字があれば候補を「髙  U+9AD9」の形で並べる。クリックすると、選択内の同じ文字をすべてすぐに置き換える
  - 異体字のある文字が複数あるときは「高 → 髙  U+9AD9」のように元の文字を添える
  - 候補には元の文字も含むので、選び直せば戻せる
- ［一覧を作成］
  - ダイアログボックスを閉じて、レイヤー「// glyphs」（無ければ最前面に作る）に一覧を作る。選択した文字ごとに「横組み用」「縦組み用」の2行で、11種類の字形と登録された異体字のうち、形が異なるものだけを大きな字・符号位置・字形の名前で並べる（フォントに無い字形は標準字形と同じ形になるので出さない）。登録された異体字にも11種類の字形とプロポーショナル字形を試し、縦組みでの字形（音引きの縦組み用の字形など）も並べる。続けて、元の文字と異体字のそれぞれに異体字セレクタ（U+E0100〜）を付けた IVS を順に試し（IVS は符号位置ごとに登録されるので、辺から始めても邉の IVS まで並ぶ）、字形パネルに出る異体字のうち IVS で呼び出せるものも並べる（添え書きはセレクタの符号位置）
  - 置き場所は元のテキストの右。見本の字は元の文字のフォントとサイズを引き継ぎ、符号位置・字形の名前はヒラギノ角ゴシック W3
  - 一覧の背面に、黒い長方形（不透明度30%）を敷く
  - 作った一覧を選択し、ウインドウの65%ほどに収まるよう表示する
  - それまでの字形・異体字の切り換えは残る
- 「一覧」パネル（ボタンの上）
  - ［［// glyphs］レイヤーに作成］：前回までの一覧を残したまま、同じレイヤーに作る
  - ［［// glyphs］レイヤーを削除してから作成］（既定）：前回の一覧のレイヤーを消してから作り直す。選択中の文字がそのレイヤーにあるときは消さない
  - ［一覧を作成］ボタン
- ［キャンセル］で、途中で反映した字形と異体字を元に戻す
- 日本語／英語の自動切り替え

### 使い方

1. 文字ツールで文字を選択する（テキストオブジェクトを選択してもよい）
2. スクリプトを実行する
3. 字形のラジオボタン、または異体字の候補をクリックする
4. ［OK］をクリックする

### オプション

スクリプト冒頭の「ユーザー設定」で変えられる。

- `ITAIJI_GROUPS`：異体字の組。1つの文字列に互いに異体字の文字を並べる（例 `"辺邊邉"`）。行を足すだけで増やせ、同じ文字を含む組は実行時にまとめる
- `GLYPH_FORM_CHECK_MAX`：字形の対応を調べる文字の数（既定 10。多いと開くのが遅くなる）
- `GLYPH_LIST_LAYER_NAME`：一覧を作るレイヤー名（既定 `// glyphs`）
- `GLYPH_LIST_CODE_RATIO`：符号位置の大きさ（見本の字に対する比率、既定 0.25。字形の名前はその3/4）
- `GLYPH_LIST_LABEL_MIN_SIZE`：符号位置・字形の名前の最小の大きさ（pt、既定 6）
- `GLYPH_LIST_LABEL_FONT_NAMES`：符号位置・字形の名前のフォント（PostScript 名。前から順に探し、無ければ元の文字のフォント）
- `GLYPH_LIST_IVS_MAX` / `GLYPH_LIST_IVS_MISS_LIMIT`：試す異体字セレクタの数（既定 64）と、新しい形が続けて出なければ打ち切る回数（既定 3）
- `DELETE_LIST_LAYER_DEFAULT`：true なら［［// glyphs］レイヤーを削除してから作成］、false なら［［// glyphs］レイヤーに作成］を選んで開く（既定 true）
- `GLYPH_LIST_BACK_OPACITY` / `GLYPH_LIST_BACK_PADDING`：背面の黒い長方形の不透明度（%、既定 30）と余白（1行目の見本の字に対する比率、既定 1）
- `GLYPH_LIST_COLUMNS`：一覧の1行に並べる数（既定 5。超えたら折り返す）
- `GLYPH_LIST_FIT_PERCENT`：作った一覧がウインドウに占める割合（%、既定 65）

### 注意点

- 字形の対応は、開くときに一時レイヤーで字をアウトライン化して調べる
- 一覧は文字ごとに「横組み用」「縦組み用」の2行に分け、行の左に見出しを付ける。見本は5つずつで折り返す。縦組み用の行には横組みと形が異なるものだけを、縦組みのポイント文字で並べる（無ければ行ごと出さない）
- 一覧の IVS の見本は、フォントが IVS に対応しているときだけ出る。IVS の割り当てが無い異体字（字形パネルにだけ出るもの）は、スクリプトからは呼び出せないので一覧に出ない
- ［一覧を作成］はダイアログボックスを閉じるので、続けて切り換えるときはもう一度実行する
- 互換漢字（例 U+FA45）を含む異体字は、フォントによっては表示できない
- 空白・改行は対象にしない。連結したテキストはストーリー全体をまとめて扱い、ロック中・非表示のテキストは対象にしない
