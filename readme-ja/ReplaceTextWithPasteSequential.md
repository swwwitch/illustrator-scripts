## 概要

クリップボードにある複数行のテキストから1行目だけを取り出して、選択中のテキストフレームに適用するスクリプトです。

適用した行はクリップボードから取り除かれるため、繰り返し実行すると次の行へ順に進みます。空行は読み飛ばすので、行間を空けたリストでもそのまま使えます。名簿やリストを1つずつ流し込む用途を想定しています。

テキストフレームを選択していないときは、1行目をウィンドウ中央へ貼り付けます。2行目以降はクリップボードに残るため、繰り返し実行すると1行ずつ配置していけます。流し込み先を用意する起点として使えます。

`ReplaceTextWithPaste.jsx` から派生したスクリプトです。あちらは同じテキストをまとめて適用しますが、こちらは1行ずつ消費しながら進みます。

## 主な機能

- クリップボードの1行目を、選択中のテキストフレームへ適用
- 適用した行をクリップボードから取り除き、次の実行で続きから再開
- 選択がないときは、1行目をウィンドウ中央へ貼り付け（2行目以降はクリップボードに残る）
- 段落改行（CR）、強制改行（LF）、CRLF のいずれも行の区切りとして認識
- 空行（空白だけの行を含む）は読み飛ばし、テキストフレームを空にしない
- グループ、クリップグループ内のテキストフレームを再帰的に処理
- 最後の行を適用したときに通知
- 処理の前後で選択状態を保持
- 日本語／英語UI

## 使い方

1. 流し込みたい複数行のテキストをコピーします。
2. 1行目を入れたいテキストフレームを選択します。
3. `ReplaceTextWithPasteSequential.jsx` を実行します。
4. 次のテキストフレームを選択して、もう一度実行します。行がなくなるまで繰り返します。

ショートカットに割り当てておくと、「選択 → 実行」の繰り返しだけで進められます。

## 処理の流れ

1. 現在の選択を退避します。対象のテキストフレームが1つも無い場合は、貼り付けたテキストフレームを1行目だけに切り詰めてウィンドウ中央へ移動し、2行目以降をクリップボードへ書き戻して終了します（以降の手順は行いません）。
2. 選択を解除してから通常のペーストを2回実行し、2回目に貼り付けられたテキストフレームから文字列を取得します（1回目はIllustratorの内部クリップボードを最新にするためのもので、貼り付いたオブジェクトはすぐ削除します）。
3. 貼り付けたオブジェクトを削除し、退避した選択を復元します。グループとして貼り付いた場合は、その中のテキストフレームを探します。
4. 取得した文字列から空行を取り除き、最初の改行を境に1行目と残りに分割します。
5. 選択中のテキストフレームの内容を1行目で置き換えます。
6. 残りがあれば、一時テキストフレーム経由でクリップボードへ書き戻します。残りがなければ通知して終了します。

## 対象

| 区分 | 対象 |
| --- | --- |
| 対象 | テキストフレーム、グループ・クリップグループ内のテキストフレーム |
| 非対象 | 画像、図形、ロックされたオブジェクト |

## 注意事項

- 選択がない場合（選択にテキストフレームが1つも含まれない場合を含む）は、貼り付けたテキストフレームを1行目だけに切り詰めてウィンドウ中央へ置き、2行目以降をクリップボードへ書き戻します。選択中のテキストフレームへ適用する場合と同じように、1回の実行で1行を消費します。
- 貼り付けた内容にテキストフレームが含まれない場合（画像や図形など）は、行の取り出しもクリップボードの書き戻しも行わず、そのままウィンドウ中央へ置きます。
- 配置の基準は表示中のウィンドウの中心（`activeView.centerPoint`）です。Illustratorのペースト先も同じ位置ですが、1行目に切り詰めるとフレームの大きさが変わるため、切り詰めたあとに測り直して中央へ置き直します。複数のオブジェクトが貼り付いた場合は、全体を同じ量だけ動かして並びを保ちます。
- 複数のテキストフレームを選択した場合は、すべてに同じ1行目が入ります。1回の実行で消費する行は常に1行です。
- 最後の行を適用したあとはクリップボードを書き換えません。その状態でもう一度実行すると、同じ行が再適用されます。
- 書き戻しにIllustratorのコピーを使うため、実行後のクリップボードはIllustratorオブジェクト形式になります。途中で他アプリに貼り付けると、テキストではなく図形として貼られます。
- コピー元が「1つの複数行テキストフレーム」ではなく「1行ずつの別々のテキストフレーム」の場合、最初の1つしか読み取れません。
- 空行（空白だけの行を含む）は読み飛ばします。書き戻すクリップボードからも取り除かれるため、2回目以降の実行でも空行は現れません。
- Illustratorは自分がコピーした内容を内部に保持しているため、他アプリでコピーした直後の1回目のペーストでは古い内容が貼り付きます。これを避けるため、内部では2回ペーストして2回目の結果を使います。
- 文字揃えや文字スタイルは元のテキストフレームの設定が保持されます。置き換わるのは内容だけです。
- Illustratorには取り消しをグループ化するAPIがなく、内部で一時テキストフレームの作成と削除も行うため、取り消しは複数ステップに分かれます。
