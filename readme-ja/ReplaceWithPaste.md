# クリップボードの内容で選択を置き換える

## 概要

クリップボードにあるテキストで、選択中のテキストフレームの内容をまとめて置き換えるスクリプトです。

選択がない場合は、貼り付いた位置（画面の中央）に既定の書式で新しいテキストフレームを作成します。グループを選択した場合は、その中のテキストフレームをすべて対象にします。

クリップボードの中身がテキスト以外（図形や画像など）の場合は、選択した各オブジェクトをその内容で置き換えます。貼り付けた内容は元のオブジェクトに中心をそろえ、大きさは「大きさ保持」「長辺に合わせる」「短辺に合わせる」から選べます（合わせる場合は縦横比を保ったまま拡大・縮小します）。

1行ずつ順に流し込みたい場合は、派生版の [ReplaceTextWithPasteSequential.jsx](ReplaceTextWithPasteSequential.md) を使ってください。あちらは選択がないときに、クリップボードの内容をアートボード中央へそのまま貼り付けます。

## 主な機能

- 選択したテキストフレームの内容を一括置換
- 選択なしのときは、貼り付いた位置（画面の中央）に既定の書式で新規テキストフレームを作成
- グループ、クリップグループ内のテキストフレームを再帰的に処理
- クリップボードがテキスト以外のときは、選択したオブジェクトをその内容で置き換え（大きさ保持・長辺に合わせる・短辺に合わせるを選択、中心そろえ、重ね順を引き継ぐ）
- ポイント文字・エリア内文字・パス上文字に対応
- 処理の前後で選択状態を保持
- 日本語／英語UI

## 使い方

1. 置き換えたいテキスト、またはオブジェクトをコピーします。
2. 置き換え先のテキストフレームやオブジェクトを選択します（テキストの場合、選択しなければ新規作成されます）。
3. `ReplaceWithPaste.jsx` を実行します。

## 処理の流れ

1. 現在の選択を退避します。
2. 選択を解除してから通常のペーストを2回実行し、2回目に貼り付けられたテキストフレームから内容と座標を取得します（1回目はIllustratorの内部クリップボードを最新にするためのもので、貼り付いたオブジェクトはすぐ削除します）。
3. 貼り付けたオブジェクトを削除し、退避した選択を復元します。グループとして貼り付いた場合は、その中のテキストフレームを探します。
4. テキストが見つかれば、選択があれば各テキストフレームの内容を置き換え、なければ新規テキストフレームを作成します。
5. テキストが見つからなければ、選択した各オブジェクトの位置にもう一度ペーストし、選んだ大きさの扱いで拡大・縮小してから元のオブジェクトを削除します。選択がなければ通常のペーストと同じく画面の中央へ貼り付けます。

## 対象

| 区分 | 対象 |
| --- | --- |
| 対象（テキストをコピー） | テキストフレーム、グループ・クリップグループ内のテキストフレーム |
| 対象（テキスト以外をコピー） | 選択したオブジェクト（テキストフレームも含む） |
| 非対象 | ロックされたオブジェクト |

## 設定

スクリプト冒頭の「ユーザー設定」で切り替えます。どちらもテキスト以外で置き換えるときだけ使われます。

| 変数 | 値 | 内容 |
| --- | --- | --- |
| `SHOW_SIZE_DIALOG` | `true`（既定）／`false` | 大きさの扱いを選ぶダイアログを開くか。ダイアログの［プレビューを表示］（初期値ON）で、選んだ大きさの結果をその場で確認できる |
| `DEFAULT_SIZE_MODE` | `"keep"`／`"long"`（既定）／`"short"` | 大きさ保持／長辺に合わせる／短辺に合わせる。ダイアログを開かないときはこの扱いで実行し、開くときは初期選択になる |

キーボードショートカットでダイアログなしに実行したい場合は、`SHOW_SIZE_DIALOG` を `false` にします。

## 注意事項

- 内部で通常のペーストを実行します。何も貼り付かない場合は、その旨を通知して終了します。
- 文字を選択して編集中にテキスト以外をコピーしていた場合は、置き換えずに通知して終了します。
- 文字を選択せずカーソルを立てただけの場合は、［書式なしでペースト］でカーソル位置へ挿入します（置き換えは行いません）。
- テキスト以外で置き換えるとき、グループを選択していればグループごと置き換えます（中のテキストだけを差し替えるのはテキストをコピーしたときだけです）。
- Illustratorは自分がコピーした内容を内部に保持しているため、他アプリでコピーした直後の1回目のペーストでは古い内容が貼り付きます。これを避けるため、内部では2回ペーストして2回目の結果を使います。
- 新規作成されるテキストフレームの位置は、Illustratorのペースト先（画面の中央）です。コピー元の座標そのものではありません。
- 新規作成されるテキストフレームは既定の書式になります。コピー元のフォントやサイズは引き継ぎません。
- 文字揃えや文字スタイルは元のテキストフレームの設定が保持されます。置き換わるのは内容だけです。
- Illustratorには取り消しをグループ化するAPIがないため、この処理の取り消しは複数ステップに分かれます。
