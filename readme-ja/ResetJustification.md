### 概要

選択したテキストの段落に対して、ジャスティフィケーション関連の設定（ワードスペース、文字間、グリフスケーリング）を初期値に戻します。

### 主な機能

- ワードスペース: 80 / 100 / 133
- 文字間とグリフスケーリングも既定値へ

### 使い方

1. 対象のテキストを選択します。
2. スクリプトを実行します。
