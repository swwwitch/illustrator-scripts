### 概要

- テキストに対して、回転／シアー（せん断）／比率を安全にリセット
- BBoxリセットと左上基準の位置復元により、見た目の位置を安定して維持

### 主な機能

- テキスト：回転・シアー・水平/垂直比率（100%）のリセット

### 処理の流れ

1) 選択されたテキストに対して処理を即時適用（回転／シアー／比率のリセット）

### 注意点

- スケールの微調整（Alt+↑↓による0.1%増減）は廃止
