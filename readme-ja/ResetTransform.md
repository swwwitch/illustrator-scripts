# 回転・シアー・スケール・縦横比をリセット

### 概要

- 配置画像・テキスト・長方形（パス）・クリップグループ・直線パスに対して、回転／シアー（せん断）／スケール／縦横比を安全にリセットします。
- バウンディングボックスをリセットしたあと元の中心位置へ戻すため、見た目の位置は変わりません。

### 主な機能

- **配置画像／ラスター**：回転・シアー・縦横比（小さい軸を大きい軸へ揃え、％は四捨五入の整数）・反転（上下／左右）・スケール（指定％、下限20%）の個別／同時リセット。
- **テキスト**：回転・シアー・水平比率／垂直比率（100%）・トラッキング（0）のリセット。
- **長方形（4点パス）**：軸から0.5〜44°ずれている場合に、最も近い軸へ最小の回転量でスナップ。
- **直線（2点パス）**：同じ判定で、最も近い軸（0°／90°）へスナップ。
- **クリップグループ**：配置画像とマスクパスの回転・反転をまとめてリセットし、配置画像から導出した等比化の差分を両方へ同時に適用。
- **選択の解釈**：グループ・複合パスは中身を再帰的にたどって対象を集めます。クリップグループの中のオブジェクトを選択した場合は、最上位のクリップグループを対象として一度だけ処理します。
- **UI**：2カラム、対象別パネル、ホットキー（S＝スケール／F＝反転）、スケール数値入力（↑↓＝±1／Shift＋↑↓＝10の倍数へスナップ）、ダイアログ位置・不透明度の記憶。

### 処理の流れ

1. ドキュメントと選択を確認し、グループ・複合パスの中身までたどって対象を収集。対象外のパネルは自動でディム表示。
2. パネルで操作項目を選択して［リセット］。
3. 種別ごとのハンドラーが変形を適用 → バウンディングボックスをリセット → 元の中心位置へ再配置。
4. 処理後、開始時の選択状態を復元。

### 注意点

- 長方形・直線の補正は、軸から **0.5〜44°** ずれている場合のみ行います。45°など意図的な角度は補正しません。
- 長方形は、最も近い軸へ**最小の回転量**で戻します。幅と高さが入れ替わることはありません。
- クリップグループは配置画像を代表として判定します。**配置画像を含まない（ベクターのみの）クリップグループは対象外**となり、他に対象がなければ「リセットできる対象が選択されていません。」と表示されます。
- テキストの比率・トラッキングのリセットは、テキストフレーム全体に適用されます。
- 複合パスの中身はサブパス単位で補正されるため、複数のサブパスからなる複合パスでは形状が崩れることがあります。
- スケールの指定値は整数％に丸められ、20% を下回る場合は 20% になります。
