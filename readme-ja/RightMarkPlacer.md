## 概要

選択した複数のオブジェクトを左から順に見て、隣り合うオブジェクト同士の「アキ」の中央に記号を配置するスクリプトです。

レイアウトの流れや関係性を視覚的に示したいときに使います。

## 主な機能

- 9種類の記号を作成（`▶` / `>` / `>>` / `─` / `→` / `➡` / `＿\` / `＋` / `×`）
- 複数選択時、隣り合うすべての組に同じ記号を自動配置
- 幅は「最も狭いアキ」を基準に安全側で自動決定（手動入力も可能）
- 入力した幅は、そのまま記号の描画幅（実寸）になります
- 高さ（％）、線幅、位置（左右／上下）を調整可能
- 位置調整は負の値にも対応し、矢印キーでも増減可能
- 単位は現在の定規設定（線幅は線幅の単位設定）に追従
- `▶` は「凹み」で形状を変形（幅の80%まで）、「角丸」で角丸に変更
- `＿\` は角度で斜線の傾きを調整、先端形状（なし／丸型）と左右反転に対応
- `>` / `>>` は「天地を水平に」で塗りの形状に切り替え（幅は線・塗りで共通）
- `➡` は線幅から寸法が決まり、矢じりの天地が線幅の3倍になります
- プレビューは即時更新され、ダイアログ終了時に確実に片付け
- 日本語／英語UI

## 使い方

1. 対象のオブジェクトを2つ以上選択します。
2. `RightMarkPlacer.jsx` を実行します。
3. ダイアログで形状とオプションを設定します（［プレビュー］で結果を確認できます）。
4. ［OK］をクリックして実行します。

## ［形状］パネル

| 記号 | 内容 |
| --- | --- |
| `▶` | 塗りの三角形。［凹み］で左辺をへこませ、［角丸］で角を丸められます。 |
| `>` | 線の山形。［天地を水平に］で塗りの形状になります。 |
| `>>` | 線の山形2つ。［間隔］で2つの距離を指定します。［天地を水平に］に対応。 |
| `─` | 横線。 |
| `→` | 線の矢印（軸＋矢じり）。 |
| `➡` | 塗りの矢印。軸を線幅で描き、アウトライン化して矢じりと合体します。 |
| `＿\` | 横線＋斜線。［角度］で斜線の傾きを指定します。 |
| `＋` | 十字。 |
| `×` | 斜め十字（＋を45°回転した形）。 |

- ［左右逆］で、作成した記号を左右反転します（`─` / `＋` / `×` では無効）。
- `>>` の［幅］は山形1つ分です。全体の幅は「幅 × 2 ＋ 間隔」になります。
- `×` の［幅］だけは `＋` と揃えた腕の長さを表し、描画幅はその約0.707倍になります。

## ［先端］パネル

線の先端と角の形状を［なし］［丸型］から選びます。塗りだけで描く形状（`▶` / `➡`）では無効になります。

## ［オプション］パネル

| 項目 | 内容 |
| --- | --- |
| 高さ | 隣り合う2つのオブジェクトの合計高さに対する割合（％）。200% まで。`─` / `＋` / `×` / `➡` では使いません。 |
| 幅 | 記号の描画幅。空欄にすると「最も狭いアキ」を基準に自動計算します。 |
| 凹み | `▶` の左辺のへこみ。幅の80%が上限です。 |
| 間隔 | `>>` の2つの山形の距離。負の値も指定できます。 |
| 線幅 | 線の太さ。下限は 0.25pt 相当で、警告は表示中の単位で示されます。`▶` は塗りのみのため使いません。 |
| 角度 | `＿\` の斜線の傾き（度）。89°が上限です。 |
| 天地を水平に | `>` / `>>` を、天地が水平な塗りの形状にします。 |
| 角丸 | `▶` の角を丸めます（凹みの有無に関係なく適用）。 |

- その形状で使わない項目は、ラベルと単位表記も含めてディム表示になります。
- 幅を手入力すると自動計算は止まります。空欄に戻すと自動計算に戻ります。
- 高さ・幅・線幅・角度・位置調整は、形状を切り替えるとその形状の初期値に戻ります。

### `➡` の寸法

`➡` は線幅だけで大きさが決まります。［高さ］は使いません。

| 入力（線幅） | 軸の太さ | 矢じりの天地 | 矢じりの奥行き |
| --- | --- | --- | --- |
| 3.6pt（初期値） | 3.6pt | 10.8pt | 5.4pt |
| 5pt | 5pt | 15pt | 7.5pt |

- 矢じりの天地は線幅の3倍（`ARROW3_HEIGHT_TO_STROKE_RATIO`）です。
- 矢じりの奥行きは天地の半分ですが、幅の90%（`MAX_ARROW_HEAD_RATIO`）を超えないよう抑えられます。
- `→` も同様に、矢じりが［幅］をはみ出さないよう奥行きだけを抑えます（天地は［高さ］のままです）。

## ［位置調整］パネル

| 項目 | 内容 |
| --- | --- |
| 左右 | 記号を左右にずらす量。負の値も指定できます。 |
| 上下 | 記号を上下にずらす量。負の値も指定できます。 |

- 形状を切り替えると 0 に戻ります。

## キーボード操作

| キー | 動作 |
| --- | --- |
| `F` | 先端を［なし］に |
| `R` | 先端を［丸型］に |
| `V` | ［左右逆］を切り替え |
| `↑` / `↓` | 入力欄の値を1段階ずつ増減 |
| `Shift` + `↑` / `↓` | 10段階分の倍数へ丸めながら増減 |
| `Option`（`Alt`） + `↑` / `↓` | 1/10段階ずつ増減 |

- `F` / `R` / `V` は、修飾キー（`command` / `control` / `option` / `shift`）と一緒に押したときは働きません（`command` + `V` などを妨げないためです）。
- 1段階の量は単位に合わせて決まります。％・度・pt・px・mm・Q・H は `1`、cm は `0.1`、inch は `0.01` です。

## 設定変数

スクリプト冒頭の「ユーザー設定」で変更できます。

| 変数 | 初期値 | 内容 |
| --- | --- | --- |
| `MARK_COLOR_CMYK` | `[0, 0, 0, 100]` | 記号の色（CMYK） |
| `MAX_HEIGHT_PERCENT` | `200` | 高さ（％）の上限 |
| `MIN_STROKE_WIDTH_PT` | `0.25` | 線幅の下限（pt） |
| `MAX_INSET_RATIO` | `0.8` | 凹みの上限（幅に対する割合） |
| `TRI_CORNER_RADIUS_RATIO` | `0.12` | `▶` の角丸半径の割合 |
| `SLASH_ANGLE_DEFAULT` / `SLASH_ANGLE_MAX` | `35` / `89` | `＿\` の斜線の角度と上限 |
| `ARROW3_HEIGHT_TO_STROKE_RATIO` | `3` | `➡` の矢じりの天地が線幅の何倍か |
| `MAX_ARROW_HEAD_RATIO` | `0.9` | `→` / `➡` の矢じりの奥行きが幅に占める割合の上限 |
| `AUTO_WIDTH_GAP_RATIO` | `0.7` | 幅を自動計算するときのアキに対する割合 |
| `AUTO_WIDTH_GAP_RATIO_SMALL` | `0.35` | `＋` / `×` の自動幅に使う割合 |
| `AUTO_WIDTH_CHEVRON_HEIGHT_RATIO` | `0.5` | `>` / `>>` の自動幅に使う、高さに対する割合 |

## 注意事項

- ドキュメントが開かれていない場合、オブジェクトの選択が2つ未満の場合は警告を表示して終了します。
- 作業レイヤーがロックまたは非表示の場合は、警告を表示して終了します。
- **オブジェクトが重なっている場合やアキがない場合、その組には記号を作成しません。** どの組にも作成できない場合は、ダイアログを開く前に警告を表示して終了します。
- 記号は左右方向の並びを前提にしています。オブジェクトは中心のX座標で左から右に並べ替えて処理します。
- テキストは、アウトライン化した状態のバウンズで計測します（計測用の複製は自動的に削除されます）。計測結果はダイアログを閉じるまで保持するため、プレビュー更新のたびに測り直すことはありません。
- 記号は作業中のレイヤーに作成され、作成後は選択状態になります。
- ［プレビュー］がONの状態で［OK］をクリックすると、プレビューで作成済みのオブジェクトをそのまま結果として使います。
- `➡` は［アウトラインを作成］と［合体］のメニューコマンドを使うため、処理中に選択状態が一時的に変わります（処理後に元へ戻します）。
- 表示桁数は単位に合わせて変わります（pt / mm などは小数点以下2桁、inch や cm はより細かい桁数）。
