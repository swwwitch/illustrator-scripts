# 選択したオブジェクトから枝分かれするサンキー図を作る

[![Direct](https://img.shields.io/badge/Direct%20Link-SankeyFlowMaker.jsx-ffcc00.svg)](https://github.com/swwwitch/illustrator-scripts/blob/master/jsx/shape/SankeyFlowMaker.jsx)

### 概要

選択したオブジェクトを左端のノードにして、そこから枝分かれしていく流れ図（サンキー図）を作ります。帯の太さは値に合わせて決まります。

ラベルのテキストを先に並べておくと、テキストは動かさず、その位置と文字サイズに合わせて帯を引きます。

### 主な機能

- ノードは選択中のキーオブジェクト（無ければ一番左のオブジェクト）
- フローは「数値 名前」を1行ずつ書き、字下げで枝分かれ
- 帯の太さは値に比例／平方根に比例から選択
- 並べてあるラベルのテキストに帯を合わせる（テキストは動かさない）、またはテキストを帯の位置へ動かす
- テキストのノードには背面に角丸長方形を作成
- 分岐点に円／長方形を置き、分岐点名のテキストを囲む（1段目と2段目以降で別の設定）
- 末端を矢印に
- 帯の色は単色／1段目の枝ごと、不透明度は帯1本ずつ
- 帯のグループに［パスのアウトライン］と［パスファインダー（合流）］の効果を適用
- プレビュー、前回の設定を記憶
- 日本語／英語UI

### 使い方

1. ノードにするオブジェクトと、ラベルにするテキストを選択します。ノードはキーオブジェクトにしておくと確実です。
2. `SankeyFlowMaker.jsx` を実行します。
3. ［フロー］にフローを入力し、サイズと分岐点を調整します。設定を変えるとプレビューが描き直されます。
4. ［作成］をクリックします。図は「Sankey Flow」グループとして、選択したオブジェクトの背面に作られます。

### フローの書き方

1行に「数値 名前」を書きます。数値は行頭でも行末でも構いません（`9280 inside sandbox`／`inside sandbox, 9280`）。字下げ（スペース）を深くした行が、直前の浅い行の枝になります。`#` で始まる行は無視します。

```
9280 inside sandbox
720 auto-reviewed
  713 approved and continue
  7 denied
    4 continue via safer alternative
    3 stop and ask user
```

### ラベルのテキストの扱い

選択中のテキスト（ノード以外）は、次のように使います。照合では大文字・小文字、空白、桁区切りのカンマ、記号の違いを無視します。

| テキスト | 扱い |
| --- | --- |
| 「数値 名前」か「名前」が枝と一致 | その枝のラベル。テキストは動かさず、帯の中心・カーブの終わり・矢印の先端をテキストに合わせます。 |
| 数値を含まない残りのテキスト | 分岐点名。左にあるものから順に分岐点へ当て、テキストの位置に分岐点を置きます。 |
| 一致するテキストが無い枝 | ラベルを新しく作ります。書式は選択中のラベルのテキストに合わせます。 |

### ［サイズ］パネル

| 項目 | 内容 |
| --- | --- |
| 太さ | 値に比例／平方根に比例。平方根に比例にすると、小さい値の帯も太めに見えます。 |
| ノードの高さ | テキストのノードの背面に作る角丸長方形の高さ。図形のノードはその高さで固定です。 |
| 出口の高さ | ノードの高さに対する、帯の出口の高さ（1段目の帯の太さの合計、％）。ノードの大きさは変わりません。 |
| カーブの長さ | 枝分かれのカーブ部分の横の長さ。 |
| 直線の長さ | カーブのあとの直線部分の長さ。 |
| 枝の間隔 | 隣り合う枝の間隔。 |
| 最小の太さ | これより細くなる帯は、この太さにします。 |
| 文字サイズ | 新しく作るラベルの文字サイズ。ラベルのテキストを選択しているときは、その文字サイズで固定です。 |

位置を合わせるテキストがある枝では、カーブの長さ・直線の長さよりテキストの位置が優先されます。

### ［オプション］パネル

| 項目 | 内容 |
| --- | --- |
| ラベルに数値を付ける | 新しく作るラベルを「9,280 inside sandbox」の形にします。オフなら名前だけです。 |
| 末端を矢印に | 子の無い帯の末端を尖らせます。 |
| ラベルを動かす | オンにすると、帯を設定の長さと間隔で配置し、選択中のラベルのテキストをその位置へ移します（分岐点名は分岐点の中心へ）。オフ（初期値）はテキストを動かさず、帯をテキストに合わせます。キャンセルすると元の位置に戻ります。 |

### ［分岐点1］［分岐点2］パネル

［分岐点1］は1段目の枝の先、［分岐点2］は2段目以降の枝の先の分岐点の設定です。

| 項目 | 内容 |
| --- | --- |
| 円／長方形／なし | 分岐点に置く形。分岐点名のテキストがあれば、それが収まる大きさで囲みます。 |
| 大きさで指定／余白で指定 | 幅・高さの意味。大きさで指定は形そのものの大きさ、余白で指定は分岐点名のテキストの左右・上下の余白です。 |
| 幅・高さ | 形の大きさ、または余白。どちらも 0 は自動（テキストが収まる大きさ）です。 |
| 連動（リンクアイコン） | 幅と高さを同じ値にします。初期値はオンです。 |

帯の中に入らない途中の枝のラベルは、新しく作るときは分岐点の形の中に入れます。

### ［カラー］パネル

| 項目 | 内容 |
| --- | --- |
| 単色／1段目の枝ごと | 帯の色の付け方。1段目の枝ごとは、パレット（`BAND_PALETTE`）の色を1段目の枝に順に振り、その先の枝は同じ色を引き継ぎます。 |
| 色 | 単色のときの帯の色。色見本をクリックすると、標準のカラーピッカーで選べます。グレーは CMYK ドキュメントでは K だけの色になります。 |
| 不透明度 | 帯1本ずつの不透明度（%）。重なった帯が透けて見えます。 |

### ボタン

| 項目 | 内容 |
| --- | --- |
| ［リセット］ | フロー以外の設定を初期値に戻します。ノードの高さはダイアログボックスを開いたときの値、ラベルから取った文字サイズはそのままです。 |

### 設定変数

スクリプト冒頭の「ユーザー設定」で初期値を変更できます。

| 変数 | 初期値 | 内容 |
| --- | --- | --- |
| `DEFAULT_SETTINGS` | — | ダイアログボックスの初期値（2回目からは前回の設定） |
| `BAND_PALETTE` | 10色 | 1段目の枝ごとに順に振る帯の色（#RRGGBB）。CMYK ドキュメントではカラー設定で変換します |
| `LABEL_TINT` | `100` | 新しく作るラベルの色（手本のテキストが無いとき） |
| `OUTLINE_TINT` | `30` | 分岐点の形・ノードの角丸長方形の線の色 |
| `OUTLINE_STROKE_WIDTH` | `0.75` | その線幅（pt） |
| `NODE_HEIGHT_PER_FONT_SIZE` | `16` | テキストのノードの高さの初期値（文字サイズの倍数） |
| `NODE_BOX_SIDE_PADDING` | `2` | ノードの角丸長方形の左右の余白（文字サイズの倍数） |
| `NODE_BOX_CORNER_RADIUS` | `1.5` | ノードの角丸の半径（文字サイズの倍数） |
| `JUNCTION_PADDING` | `0.6` | 分岐点の形と分岐点名の間の余白（文字サイズの倍数） |
| `JUNCTION_POSITION_RATIO` | `0.6` | 位置の決まらない分岐点を、出発点から子の右端までのどこに置くか |
| `GROUP_NAME` | `"Sankey Flow"` | 作るグループの名前 |

K の濃度で指定する色は、RGB ドキュメントでは同じ濃さのグレーになります。

### 注意点

- キーオブジェクトは、整列コマンドを実際に実行して判定します（すぐ元の位置に戻します）。
- テキストのノードは、帯がノードの中心から出るので、背面に白い角丸長方形を作って隠します。図形のノードに塗りが無いと、帯の根元が透けて見えます。
- フローの入力欄ではタブを入力できないので、字下げはスペースで入れてください。
- ［パスのアウトライン］効果は、帯のグループを一時的に選択してメニューコマンドで掛けます。
- 設定は `Folder.userData` の `illustrator-scripts/SankeyFlowMaker.json` に保存します。
