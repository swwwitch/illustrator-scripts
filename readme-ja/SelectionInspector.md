## 概要

「このドキュメント、テキストは何個あるんだろう」「アンカーポイントはいくつ？」「リンク切れは残っていない？」——納品前のチェックや、作業量の見積もりで知りたくなる数字は、Illustratorの標準パネルには揃っていません。ドキュメント情報パネルにはあるものの、選択中と全体を並べて見比べることはできません。

このスクリプトは、**選択中とドキュメント全体の数字を並べて表示する常駐パレット**です。開いたまま選択を切り替え、［更新］を押すたびに集計し直します。属性パネルの「メモ」欄も、同じパレットから確認・編集できます。

## 使い方

1. スクリプトを実行（パレットが表示されます）
2. 数えたいオブジェクトを選択
3. ［更新］（⌘R）を押す

何も選択していないときは、ドキュメント全体だけを集計します。パレットは開いたままなので、選択を変えるたびに［更新］を押せば数字が入れ替わります。

すでにパレットが開いている状態で再実行すると、いったん閉じてから開き直します（多重起動の防止）。

## 表示される数字

数値はすべて **「選択 / 全体」** の形式です（アートボードだけは全体の数のみ）。

パレットは2カラム構成です。

### 左カラム

| パネル | 項目 |
| --- | --- |
| 基本 | アートボード（全体のみ）、オブジェクト |
| テキスト | テキスト、ポイント文字、エリア内文字、パス上文字 |
| 文字・段落 | 文字数、段落数、強制改行 |
| 配置画像 | リンク、埋め込み、リンク切れ |
| メモ | 選択オブジェクトのメモ（読み取り専用） |

### 右カラム

| パネル | 項目 |
| --- | --- |
| グループ | グループ、クリップグループ |
| 透明 | 不透明度<100、描画モード≠通常 |
| パス | パス、オープンパス、クローズパス、アンカーポイント、ハンドル、複合パス、複合シェイプ |
| ガイド | ルーラーガイド、アートボードガイド、その他のガイド |

パレット下部のステータス行に、集計結果（「選択 3 件を集計」など）やエラーが表示されます。

## 集計のルール

数え方には、いくつか決まりがあります。

- **オブジェクト数（全体）** は、グループや複合パスの中身も含めて数えます。
- **テキストとパスの統計** は、グループ内を再帰的にたどります。グループを1つ選んだだけでも、中のテキストやパスが数えられます。
- **ガイド**（`guides=true` のパス）は、パスの統計から除外します。ガイドはガイドパネルとして別に数えます。
- **強制改行** は、テキストの内容に含まれる改行コードの数です。
- **ハンドル** は、アンカーポイントから離れている方向線の本数です（1つのアンカーで最大2本）。
- **リンク切れ** は、リンク画像のうちファイルが見つからないものです。リンクの数にも含まれます。
- **複合シェイプ** は、`PluginItem` のうち名前に「Compound Shape」を含むもので判定します。

### ガイドの分類

ガイドは、形状とアートボードのサイズから3つに分けます。判定できるのは、水平または垂直の2点パスだけです。

| 種類 | 判定 |
| --- | --- |
| ルーラーガイド | 長さが、いちばん大きいアートボードの辺より長い |
| アートボードガイド | 長さが、いずれかのアートボードの幅または高さと一致する（誤差0.5pt） |
| その他のガイド | 上のどちらでもない |

図形から作ったガイドなど、2点パス以外のガイドは「その他のガイド」になります。

## メモの編集

［メモ］タブでは、選択オブジェクトの「メモ」（属性パネルのメモ欄）を編集できます。

- 選択オブジェクトの数だけ入力欄が並びます。
- 並び順は、オブジェクトの位置（上から下、同じ高さなら左から右）です。
- 各行の［適用］を押すと、そのオブジェクトにメモが書き込まれ、自動で再集計されます。

［情報］タブの「メモ」パネルには、メモが1つだけのときはその内容が、複数あるときは「複数のメモがあります」と表示されます。

［適用］を押したあとに選択が変わっていると、「選択が変わりました。更新してください」と表示され、書き込みは行われません。

## 書き出し

［書き出し］を押すと、集計結果をテキストファイルとしてデスクトップに保存します。

- ファイル名：`count-ドキュメント名-YYYYMMDD.txt`
- 内容：パレットと同じ項目を、セクションごとに並べたもの。空でないメモも含みます。

## キーボードショートカット

| キー | 動作 |
| --- | --- |
| ⌘R | 更新（再集計） |
| ⌥I | ［情報］タブ |
| ⌥M | ［メモ］タブ |
| Esc | 閉じる |

Enterキーは、メモの編集と衝突するため割り当てていません。

## 仕様・注意

- 常駐パレット（`#targetengine`）のため、パレット側のエンジンからはドキュメントを直接操作できません。集計とメモの書き込みは、BridgeTalkでメインエンジンに委譲しています。
- 選択の変更は自動では検知しません。［更新］（⌘R）を押してください。
- ドキュメントが開かれていないときは、ステータス行にその旨を表示し、数値は「-」になります。
- Illustratorから10秒以内に応答がない場合は、「Illustrator から応答がありません」と表示します。
- パレットの位置はIllustratorの起動中のみ保持し、再起動でリセットされます。
