## 概要

選択したオブジェクトから、新規レイヤー・新規アートボード・新規ドキュメントを作成するスクリプトです。

何を作成するかはダイアログのラジオボタンで選び、名前を指定して実行します。

## 主な機能

- 作成対象を選ぶダイアログ（レイヤー／アートボード／ドキュメント）
- 新規レイヤー名・アートボード名・ドキュメント名をダイアログで指定
- ［元のオブジェクトを残す］で、移動と複製を切り替え
- レイヤー: 選択オブジェクトを収めた新規レイヤーを作成
- アートボード: 既存の並びを引き継ぎ、方向と間隔を指定して新規アートボードを作成
- ドキュメント: 選択オブジェクトだけを残した複製ドキュメントを作成
  - ロック・非表示オブジェクトを残すかどうかを選択可能
- 元の重ね順を保ったまま処理
- `L` / `A` / `D` キーで作成対象を切り替え
- 全コントロールにツールチップ
- ダイアログの設定を保持（Illustratorの起動中）
- 日本語／英語UI

## 使い方

1. 対象のオブジェクトを選択します。
2. `SelectionToNew.jsx` を実行します。
3. ダイアログで作成対象を選び（`L` / `A` / `D` キーでも可）、名前を入力します。
4. 必要に応じてオプションを設定します（アートボードの方向・間隔、元のオブジェクトを残す、など）。
5. ［OK］をクリックして実行します。

## 作成対象ごとの動作

| 作成対象 | 動作 |
| --- | --- |
| レイヤー | 最前面に新規レイヤーを作成し、選択オブジェクトを移動（複製）します。同名のレイヤーがある場合は「名前 2」のように連番を付けます。 |
| アートボード | アクティブアートボードと同じサイズの新規アートボードを作成し、相対位置を保ったまま選択オブジェクトを移動（複製）します。既存の並び（行・列）を解析し、そのピッチと列数を引き継いで挿入します。方向と間隔はダイアログで指定します。 |
| ドキュメント | 別名保存で複製ドキュメントを作り、複製側で選択範囲を反転して削除し、現在のアートボード以外を削除します。元ファイルは保存時のまま残るので、処理後に開き直します。 |

## ［作成するものと名前］パネル

作成対象のラジオボタンと、その名前の入力欄が1行に並びます。選択中の対象の入力欄だけが有効になり、他はディム表示になります。

| 作成対象 | 名前の初期値 |
| --- | --- |
| レイヤー | 「新規レイヤー」（英語環境では "New Layer"） |
| アートボード | アクティブアートボード名 ＋ `_new` |
| ドキュメント | 元のファイル名 ＋ `_selection`（拡張子は元ファイルと同じものが右に表示されます） |

- 空欄のまま実行した場合は初期値が使われます。
- 作成対象は `L`（レイヤー）／`A`（アートボード）／`D`（ドキュメント）のキーで切り替えられます。名前を入力中はショートカットが無効になり、通常の文字入力になります。
- レイヤー名は、同名のレイヤーがある場合に「名前 2」のように連番が付きます。
- ドキュメントは元ファイルと同じ場所に作成されます。元ファイルと同じ名前は指定できません。同名のファイルがある場合は上書き確認が出ます。

## ［アートボードの配置］パネル

［アートボード］選択時のみ有効です。

| 項目 | 内容 |
| --- | --- |
| 方向 | 新規アートボードを現在のアートボードの［右］（横並び）と［下］（縦並び）のどちらに置くかを選びます。 |
| 間隔 | アートボードどうしの間隔。定規の単位で入力します。初期値は既存の並びから自動推定した値（アートボードが2枚未満の場合は環境設定の値）です。 |

間隔の入力欄は↑↓キーで増減できます（Shiftで±10かつ10の倍数にスナップ、Option/Altで±0.1）。

## ［オプション］パネル

| チェックボックス | 有効になる対象 | 動作 |
| --- | --- | --- |
| 元のオブジェクトを残す | レイヤー／アートボード | ONで元のオブジェクトを残し、複製を配置します。OFF（初期値）では移動します。 |
| ロックされたオブジェクトを含める | ドキュメント | ロックされたオブジェクト（ロックされたレイヤー上のものを含む）を削除せず残します。 |
| 非表示オブジェクトを含める | ドキュメント | 非表示のオブジェクト（非表示レイヤー上のものを含む）を削除せず残します。 |

［ドキュメント］は元のドキュメントを残す＝常に複製になるため、［元のオブジェクトを残す］はディム表示になります。逆に［レイヤー］［アートボード］では対象範囲を定義できないため、［〜を含める］の2つがディム表示になります。

ディム表示になる理由や各項目の詳細は、コントロールにマウスを重ねるとツールチップで表示されます。

［〜を含める］でオブジェクトを残す場合の注意:

- **現在のアートボード上にあるものだけ**が残ります。アートボード外にあるものは削除されます。
- 対象は**最上位のオブジェクト**（レイヤーの直下にあるもの）だけです。グループや複合パスの内側にあるロック・非表示オブジェクトは、親グループの扱いに従います（親が残れば残り、親が削除されれば一緒に削除されます）。

## ユーザー設定

スクリプト冒頭の「ユーザー設定 / User settings」で、アートボードの挙動を変更できます。

| 変数 | 初期値 | 内容 |
| --- | --- | --- |
| `ARTBOARD_INSERT_AFTER_CURRENT` | `true` | `true` は現在のアートボードの次、`false` は末尾に挿入 |
| `ARTBOARD_DIRECTION_AXIS` | `0` | ダイアログの［方向］の初期選択。`0` は右（横並び）、`1` は下（縦並び） |
| `ARTBOARD_NAME_SUFFIX` | `"_new"` | アートボード名の初期値に付ける接尾辞 |
| `DOCUMENT_NAME_SUFFIX` | `"_selection"` | ドキュメント名の初期値に付ける接尾辞 |
| `SHORTCUT_TARGETS` | `{L, A, D}` | 作成対象を切り替えるショートカットキー |

## 注意事項

- ドキュメントが開かれていない場合、オブジェクトが選択されていない場合は警告を表示して終了します。
- ［アートボード］の方向と間隔はダイアログで指定します。間隔の初期値は既存の並びから自動推定し、アートボードが2枚未満の場合は環境設定の値を使います。
- ［アートボード］は選択オブジェクトの中心が載っているアートボードを基準に相対位置を算出します。どのアートボードにも載っていない場合はアクティブアートボードを基準にします。
- ［アートボード］は**選択オブジェクトが1つのアートボード上にあること**を前提とします。複数のアートボードにまたがる選択では、移動量を単一の値で求めているため正しく配置できません。
- ［ドキュメント］ではガイドも削除されます。ガイドは選択対象にならないため、反転選択で削除対象に含まれます。
- ［アートボード］は移動・複製ともオブジェクトの階層（所属レイヤー・グループ）を変更しません。座標を移動するだけです。
- ［アートボード］で既存の並びが指定方向と一致しない場合や、アートボードが1枚のみの場合は、既存の並びを動かさず、挿入位置の直前のアートボードを基準に配置します。
- ［ドキュメント］は保存済みのドキュメントでのみ実行できます。未保存・変更ありの場合は、開き直したときに変更が失われるため、警告を表示して終了します。
- ［ドキュメント］の複製は、ダイアログで指定した名前で元ファイルと同じ場所に作成します。**複製ドキュメントはこのファイルに紐づいた状態で開きます。**
- ［ドキュメント］は処理の過程で元ドキュメントをいったん閉じ、同じファイルを開き直します。ディスク上の内容は変わりませんが、**元ドキュメントの取り消し（Undo）履歴は失われます。**
- ［ドキュメント］はスウォッチ・シンボル・ドキュメント設定をそのまま引き継ぎます。選択オブジェクト以外を削除するだけなので、空になったレイヤーは残ります。レイヤーの表示・ロック状態は元ドキュメントのまま維持されます（非表示レイヤーは非表示のまま残ります）。
- ［ドキュメント］は選択範囲の反転で削除対象を求めます。反転はロック・非表示のオブジェクトを拾わないため、いったんすべて解除してから削除し、レイヤーの状態だけを元に戻しています。
- ［レイヤー］は選択オブジェクトを新規レイヤーへ**移動**するため、**グループや複合パスの内側にあるオブジェクトを選択して実行すると、そのオブジェクトは親グループから外れます。**グループの構成が変わるため、外観（重なりや不透明度グループなど）が変化する場合があります。グループごと移動したい場合は、グループ自体を選択してください。
- ［レイヤー］の重ね順は、レイヤーとコンテナ内の並び順（zOrderPosition）を基準に並べ替えてから処理します。グループ内のオブジェクトと最前面のオブジェクトが混在する選択では、完全な重ね順の再現にならない場合があります。
- ダイアログの設定（作成対象・方向・オプション）はIllustratorの起動中のみ保持され、再起動でリセットされます。名前と間隔は毎回、ドキュメントに応じた初期値に戻ります。
- ［ドキュメント］は保存・削除・再オープンに時間がかかるため、処理中は進捗パレットを表示します。
