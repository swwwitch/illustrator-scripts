### 概要

指定したレイヤーをテンプレート化し、レイヤー名に接頭辞を付けます。

### 使い方

1. 対象のドキュメントを開きます。
2. スクリプトを実行します。
3. 対象のレイヤーを指定して実行します。

### 注意点

- 「指定」を選んだときの対象レイヤー名は `specifiedLayerName`（既定は「下絵」）で決まります。
- レイヤー名に付ける接頭辞は `COMMENT_PREFIX`（既定は `// `）で変更できます。
