### 概要

選択した見出し（テキストまたはグループ）の左右に二重線を引き、まわりに段組みの新聞ダミーを敷いて、新聞の紙面を切り取ったような画像を作るスクリプトです。

新聞ダミーは二重線の天地に合わせて段を割り、ぼかしをかけます。全体は［変形］効果で傾け、回転しても角が欠けない長方形でマスクします。ダイアログの設定はそのままプレビューに反映され、閉じずに確認できます。

### 主な機能

- 見出しの左右に二重線（0.6pt）を作成。上下への伸び、見出しとの距離、2本の間隔を指定
- 二重線の天地を段数で割り、左右に縦組みの新聞ダミーを作成（段の間は1文字分空けて区切り罫）
- 字詰（1行の文字数）から文字サイズを自動計算。垂直比率85%の平体、ヒラギノ明朝 W3
- 上下に、左右の幅いっぱいの段を追加
- 上下の段と左右の段の行がそろうよう、二重線の左右の間隔を自動で微調整
- 左右の新聞ダミーは行の整数倍の幅に切り詰め、二重線とのアキを左右でそろえる
- 新聞ダミーの背面に紙色の長方形（Y10 K25）
- 新聞ダミーだけにぼかし（ガウス）。見出しと二重線はくっきり残す
- 全体をグループ化し、［変形］効果で回転（中心基準）
- 回転後も角が欠けない最大の長方形で全体をマスク（ぼかしでにじむ縁も外に出す）
- ダイアログを閉じずに結果を確認できるプレビュー（原本には触らず、複製で表示）
- 日本語／英語UI

### 使い方

1. 見出しのテキスト（縦組み）またはグループを1つ選択します。
2. `ShimbunTitleMaker.jsx` を実行します。
3. ［左右の二重線］［新聞ダミー］［オプション］の各パネルで設定し、プレビューで確認します。
4. 「OK」をクリックして作成します。

### オプション

| パネル | 項目 | 初期値 | 内容 |
| --- | --- | --- | --- |
| 左右の二重線 | 上下の伸び | 5pt | 二重線を見出しの上端／下端から伸ばす量 |
| 左右の二重線 | 見出しとのアキ | 8pt | 見出しと内側の線との距離。新聞ダミーの行をそろえるため、少し広がることがある |
| 左右の二重線 | 線の間隔 | 5pt | 内側の線と外側の線の間隔。0なら1本だけ |
| 新聞ダミー | 字詰 | 11文字 | 1段の1行に入れる文字数 |
| 新聞ダミー | 段数 | 3段 | 二重線の天地を分ける段数。0で新聞ダミーを作らない |
| 新聞ダミー | 上下に追加 | 1段 | 上と下にそれぞれ足す、左右の幅いっぱいの段の数 |
| 新聞ダミー | 左右の幅 | 30mm | 左右それぞれの新聞ダミーの幅（行の整数倍に切り詰める） |
| 新聞ダミー | ぼかし | 8px | 新聞ダミーにかけるぼかし（ガウス）の半径。0でかけない |
| オプション | 回転 | 3° | 全体に［変形］効果で適用する回転角度。0で効果を付けない |

長さの欄は定規の単位で表示されます。数値欄は↑↓キーで増減できます（Shiftで±10かつ10の倍数にスナップ、Optionで±0.1）。回転以外は負の値を受け付けません。

### 新聞ダミーの寸法

| 項目 | 値 |
| --- | --- |
| 1文字の送り | 二重線の天地 ÷（段数 × 字詰 ＋ 段数 − 1） |
| 文字サイズ | 1文字の送り ÷ 垂直比率（85%） |
| 行送り | 文字サイズ × 1.4 |
| 段の間 | 1文字分。中央に区切り罫（0.3pt） |
| 二重線とのアキ | 1文字分 |
| フォント | ヒラギノ明朝 W3（見つからないときは既定のフォント） |
| 背景 | Y10 K25 の長方形 |

罫の色・背景色・フォント・垂直比率・行送りなどは、スクリプト冒頭の「ユーザー設定」で変更できます。RGBドキュメントでは、CMYKの値を単純換算したRGBの色を使います。

### 作成されるオブジェクト

前面から次の順に重なり、全体がクリップグループにまとまります。

1. マスクの長方形
2. 回転（［変形］効果）をかけたグループ
   - 見出し
   - 二重線（`左右二重線`）
   - 新聞ダミー（`新聞ダミー`、ぼかしつき）
   - 背景の長方形

### 注意点

- Illustrator 2024〜2026に対応しています。
- テキストオブジェクトまたはグループを1つだけ選択して実行してください。
- 見出しは縦組みを想定しています（二重線は左右に引きます）。
- 新聞ダミーの文字列は「吾輩は猫である」の冒頭を繰り返します。約物・小書きかな・長音は、行頭禁則で行がずれるため入れていません。
- ぼかしと回転はライブエフェクトなので、あとから［アピアランス］パネルで調整できます。
- プレビュー中は選択した見出しを一時的に隠し、複製で表示します。キャンセルすると元の状態に戻ります。
