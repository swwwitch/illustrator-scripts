### 概要

PDF/AIファイルを指定したページ範囲で配置し、各ページを個別のアートボードとして展開します。

横長ページは見開きとみなして左右に分割し、綴じ方向に応じた順序で配置できます。

### 主な機能

- ページ範囲の指定
- 見開きページの自動分割と、右綴じ／左綴じの切り替え
- PDFのトリミング設定を選択
- 選択中の配置画像または指定ファイルからページ数を推定してページ範囲欄へ反映

### 使い方

1. スクリプトを実行します。
2. 読み込む PDF/AI ファイルとページ範囲を指定します。
3. 綴じ方向とトリミング設定を指定して実行します。

### 注意点

- ダイアログ位置はセッション中のみ記憶します。
- 新規ドキュメントへ展開したい場合は PDFAISpreadImporter.jsx を使用してください。
