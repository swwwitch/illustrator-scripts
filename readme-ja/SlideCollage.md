### 概要

アクティブなドキュメントに、選んだ .ai / .pdf のアートボード（PDF はページ）をグリッド状に並べ、ポートフォリオ用のサムネイル一覧を作成します。アートボードに収まる大きさは自動で計算します。

### 主な機能

- 読み込み：範囲（例 `1-20`、`1,3,5`）と総数を指定。総数が範囲より多いときは範囲を繰り返す
- アイテム：PDF の配置範囲（アート／トリミング／仕上がり／裁ち落とし）、角丸
- 見開き：横長のページを左右の片ページに分け、片ページの大きさで並べる。偶数ページを置く側（右／左）は PDF の綴じ方向から自動で設定
- グリッド：方向（横／縦／ランダム）、列数（1〜30）、間隔
- 偶数列：［＋1スロット］で偶数列にスロットを1つ追加。［ずらし］で偶数列を上下にずらす（オンにすると半マス分を自動で入れる）
- レイアウト：スケール（自動で合わせた大きさに対する倍率）、回転（全体を回してアートボードの中央へ）、横・縦の位置調整
- アートボードとマスク：背景色（色見本をクリックすると Illustrator 標準のカラーピッカー、HEX でも指定可）、マスク（OK のときマージンの内側でクリップ）、マスク角丸
- 画面にフィット：アートボードが指定の割合でウィンドウに収まるよう表示を合わせる

### 使い方

1. ドキュメントを開いて実行します。PDF / AI の配置画像を選択しておくと、そのファイルを読み込みファイルにします
2. ［ファイルを選択...］で .ai / .pdf を選びます。範囲と総数が自動で入ります
3. ［読み込み］でプレビューします
4. 各設定を調整し（プレビューに反映されます）、［OK］で確定します

### 注意点

- 範囲・総数の変更は［読み込み］で反映されます。配置範囲や見開きの分割を変えたときは、自動で読み込み直します
- 角丸・マスク・マスク角丸はプレビューには出ず、［OK］のときにかかります
- 数値欄は ∧∨ または ↑↓ キーで増減します。次の整数へ（1.5→2）、Shift で次の10の倍数へ、Option で0.1ずつ動きます
- ［リセット］はファイルと範囲以外の設定を戻します（列数4・回転オフ・ずらしオフ。横方向の位置はグリッドが中央に来るよう計算）
- ［キャンセル］すると、配置したアイテムを消して表示も元に戻します
- ダイアログは前回閉じた位置で開き、選択中のオブジェクトに重なるときは左右にずらします
