# アートボード名を最前面のテキストや特定のレイヤーのテキストに設定

### 概要

- 接頭辞・接尾辞と参照テキスト（最前面のテキスト、指定レイヤーのテキスト、元のアートボード名、任意の文字列）を組み合わせて、アートボード名を一括で変更するスクリプト。
- 設定を変更するたびに、ダイアログ右側の一覧が「元の名前 → 新しい名前」のプレビューとして自動更新される。
- アートボードの並び替えや、1件ずつの手動リネームも同じダイアログで行える。

### 主な機能

#### リネーム条件（左カラム）

- 接頭辞・接尾辞にトークンボタンで要素を挿入
    - 連番（1／01）、ファイル名（#FN）、日付（#DT、yyyyMMdd）、区切り文字（- ／ _）
    - 「x」ボタンで対象フィールドをクリア
- 連番は入力した数字を開始値として1ずつ増加（「01」のようにゼロ埋めすると桁数を維持）
    - 接頭辞・接尾辞に含まれる**最初の数字**が連番として扱われる。「A4_」のような固定文字列も「A4_ → A5_ → A6_」と増加するため、連番にしたくない数字は入れない
- 参照テキストは4つのモードから選択
    - **元のアートボード名**：ダイアログを開いた時点の名前を参照（［更新］後の名前ではない）
    - **指定**：入力した任意の文字列を参照（空にすれば参照テキストなし）
    - **最前面のテキスト**：レイヤー／グループ階層を再帰して、各アートボードで最初に見つかったテキストを参照
    - **レイヤー**：指定レイヤー配下（サブレイヤー・グループ含む）のテキストを結合して参照
- 非表示・ロックされたレイヤーやオブジェクトは無視
- 同名が重複する場合のみ "_1", "_2" を自動付加（重複しない名前はそのまま）。リネーム対象外のアートボード名との衝突も回避する
- アートボードが重なっている場合、テキストは中心を含む**いちばん小さいアートボード**に紐付く

#### 対象アートボード（右カラム上段）

- 「すべて」または「指定範囲」（"1-3,5" 形式）から選択。存在しない番号は無視、"5-1" のような逆順指定は昇順として扱う
- 並び替え／リネームパネルのチェックボックスと双方向に連動（チェック操作で「指定範囲」が自動更新、全選択時は「すべて」へ自動切替）

#### 並び替え／リネーム（右カラム下段）

- 各アートボードの「元の名前 → 新しい名前」を一覧表示し、リネーム条件のプレビューがそのまま反映
- チェックを付けた行のみ「新しい名前」を手動で上書き可能（手動編集後はプレビューに上書きされない）
- チェックを付けた行を「↑ 先頭へ／↑ 上へ／↓ 下へ／↓ 末尾へ」で並び替え（並び替え後の位置を基準にリネーム対象も再構築）
- チェックボックス上で Option+クリックすると全行の ON/OFF を一括切替
- アートボードが12枚を超える場合はスクロールバーで一覧をスクロール（並び替え時は移動した行を追って自動スクロール）

#### ボタン

- ［更新］：現在の設定と手動編集・並び替えをアートボードに即時反映（プレビュー結果を確定）
- ［キャンセル］：ダイアログ表示前のアートボード名と並びに戻す

### 処理の流れ

1. ダイアログで接頭辞・接尾辞・参照テキスト・対象アートボードを指定
2. 右カラムのプレビューで結果を確認し、必要に応じて並び替えや手動リネームを行う
3. ［更新］で途中経過を確定、［OK］で最終的な設定をアートボード名に適用

### 対象外

- ドキュメントが開かれていない場合（何もせず終了）
- 非表示・ロックされたレイヤーとオブジェクト（参照テキストの収集対象外）
- 指定レイヤーが見つからない／非表示の場合（警告を表示してリネームを中止）

### 更新履歴

- v1.0 (20250509) : 初期バージョン
- v1.5.2 (20260508) : ［更新］ボタンで右カラムの手動編集名と並び替えも確定するように変更
- v1.5.3 (20260508) : 同名重複時、最初のアートボードから "_1" を付加するように変更（重複しない名前はそのまま）
- v1.5.4 (20260807) : プレビューとリネームの処理を共通化し、命名・レイアウト・コメントを整理
    - ［更新］後に［OK］すると並び替えが二重適用され、リネーム対象外のアートボード名が戻る不具合を修正
    - 並び替え後に［更新］すると右カラムの「元の名前」とプレビューが行ずれする不具合を修正
    - 並び替え後にチェックした行と、実際にリネームされるアートボードがずれる不具合を修正
    - 並び替えた状態での連番を、canvas上の順ではなく一覧の表示順で振るように変更
    - チェックをすべて外しても「指定範囲」の文字列が残り、確定時に選択が復活する不具合を修正
    - キャンセル時にアートボードの並び（矩形）も表示前の状態へ戻すように変更
    - アートボードが多いときに一覧が見切れないよう、スクロールバーを追加
    - 「レイヤー」モードで、グループやサブレイヤー内のテキストが二重に連結される場合があったのを修正
    - 接頭辞・接尾辞に数字があると重複回避（"_1", "_2"）が無効になっていたのを修正（常に有効）
    - 「最前面のテキスト」モードで、アートボードが重なっているときに別のアートボードのテキストを参照する場合があったのを修正
    - 「指定範囲」で存在しない番号・重複指定・逆順指定を安全に扱うように変更
