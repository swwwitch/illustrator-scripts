### 概要

開いているドキュメントやフォルダー内の Illustrator ファイル（.ai / .svg / .eps）をまとめて読み込み、1つのドキュメントに、全体が正方形に近いグリッドで並べます。

### 主な機能

- **読み込み対象**
  - 開いているドキュメント、またはフォルダーを指定（サブフォルダーも含められる）
  - ファイル形式（AI / SVG / EPS）とファイル名の正規表現で絞り込み。件数はラジオボタンの後ろに表示
- **読み込み先**
  - 現在のドキュメント（既存のアートボードの下に並べる）、または新規ドキュメント
  - 新規ドキュメントは［設定...］で、プロファイル（プリント・Web など）・カラーモード・解像度・サイズ（プリセット、mm / px）を指定
  - ［分割］で、指定したファイル数ごとに別の新規ドキュメントに分けられる
- **読み込みオプション**
  - ［アートボード単位］：アートボードごとに、元の大きさと内容の位置を保って読み込む。ロック・非表示のオブジェクトも含める。対象は［1のみ］［すべて］［指定（例: 1, 3-5）］から選ぶ
  - ［ファイル名をラベルとして追加］：読み込んだ内容の下に、元のファイル名を「_label」レイヤーに追加
  - ［ガイドを含める］：ルーラーガイドを除き、横はアートボードの短辺以下、縦は長辺以下の長さのガイドを読み込む。［ガイドをロック］がオンでも読み込める
  - ［拡大・縮小］：内容とアートボードを指定の％で拡大・縮小（線幅も同じ比率）
  - ［間隔］：並べるアイテムどうしの間隔（定規の単位）
  - ［読み込み後］：開いているドキュメントを閉じるか、開いたままにするか
- ［コピー元のレイヤーにペースト］がオンのときは、元のレイヤー構成を保つ
- 進捗バーを表示し、途中で中止できる（ここまでの分は残る）
- 日本語・英語の UI

### 使い方

1. 読み込むドキュメントを開いておくか、フォルダーを用意します。
2. スクリプトを実行し、読み込み対象・読み込み先・オプションを選んで［OK］を押します。
3. 読み込みが終わると、全体が収まるように表示されます。

### 注意点

- ［読み込み後］が［閉じる］のときは、元のドキュメントを保存せずに閉じます。未保存の変更があるときは確認します
- フォルダーから開いたファイルは、読み込み後に常に閉じます
- ［アートボード単位］がオフのときは、表示中でロックされていないオブジェクトだけを読み込みます
