### 概要

対象のオブジェクトが少ない場合には、地道にグループ化したり、マスクすればいいのですが、数が増えたら絶望的です。

オブジェクトのまとまりごとにグループ化したり、マスクするスクリプトを作ってみました。

重なりや距離、縦の列・横の行でまとまりを判定し、まとまりごとにグループ化またはクリッピングマスクを作成します。［OK］をクリックする前に、できるグループの数をダイアログで、範囲を赤い枠（［プレビューを表示］がONのとき）で確認できます。

旧 SmartAutoGroup.jsx と SmartAutoGroup-yoko.jsx の機能は、このスクリプトに統合しました（v1.0.7）。

<img alt="クリップとグループ化ダイアログの外観" src="../png/ss-492-1078-144-20260922-010658.png" width="40%" />

### 主な機能

- 重なり・近接度・上下方向（列）・左右方向（行）の4つの条件でグループ化
- 重なっているまとまりごとに、最前面／最背面のパスを型にしてクリップ
- 配置画像を1つずつ、同じ大きさの長方形でクリップ
- 作成されるグループの数と範囲を、実行前に件数表示とプレビューの枠で確認
- アートボードごとに分けてグループ化
- 元のレイヤーと重ね順を保ったままグループ化
- 日本語／英語インターフェース対応

### 使い方

1. グループ化・クリップしたいオブジェクトをすべて選択
2. スクリプトを実行
3. モードを選び、必要に応じて［しきい値］やチェックボックスを調整
4. 件数と、［プレビューを表示］がONのときはプレビューの枠を確認して［OK］をクリック

プレビューの枠は、ダイアログを閉じると消えます。作成されたグループは選択された状態になります。

### オプション

**クリッピングマスク**

| モード | 内容 |
| --- | --- |
| 最前面でクリップ | 重なっているまとまりごとに、最前面のパスを型にしてクリップします |
| 最背面でクリップ | 重なっているまとまりごとに、最背面のパスを型にしてクリップします |
| 配置画像のみをクリップ | 画像を1つずつ、同じ大きさの長方形でクリップします |

- 型になるのはパスだけです。パスを含まないまとまりはクリップしません。
- ［配置画像のみをクリップ］でクリップグループを選ぶと、元のマスクだけを削除して、中の画像をクリップし直します。テキストなど画像以外のものはそのまま残ります。
- 選択がすべて画像のときは、［配置画像のみをクリップ］が最初から選ばれます。

**グループ化**

| モード | 同じグループになる条件 |
| --- | --- |
| 重なり | 外枠が重なっているか、接している |
| 近接度 | 向きを問わず、すき間が［しきい値］以内 |
| 上下方向 | 同じ縦の列に並んでいる（左右のずれが［しきい値］以内。上下の距離は問わない） |
| 左右方向 | 同じ横の行に並んでいる（上下のずれが［しきい値］以内。左右の距離は問わない） |

上下方向・左右方向のポイントは、**並ぶ向きの距離をいっさい問わない**ことです。たとえば左右方向なら、上下さえ揃っていれば、アートボードの左端と右端のように大きく離れていても同じ行として1つのグループになります。［しきい値］を 0 にすると、実際に重なっているものだけがまとまります。

**しきい値**

同じグループとみなす距離です。近接度・上下方向・左右方向で使います。単位は pt です（初期値 10 pt、範囲 0〜100 pt）。

**間隔が空いたら分ける**

上下方向・左右方向で使います。ONにすると、列（行）の途中で、すき間が［しきい値］より大きく空いたところでグループを分けます。このとき、つなぐのは揃って並んでいるもの（列なら左右の範囲が重なるもの）だけです。

たとえば［しきい値］10 pt で、縦1列に A・B（間隔 5 pt）、100 pt 空けて C・D（間隔 5 pt）と並んでいる場合、OFFなら A〜D で1グループ、ONなら A・B と C・D の2グループになります。

OFFのときの［しきい値］は「列（行）に入るかどうかの、左右（上下）のずれの許容量」、ONのときは「並ぶ向きのすき間の上限」を表します。

**アートボードごと**

グループ化の4つのモードで使います。ONにすると、**別のアートボードにあるオブジェクトは、条件を満たしていても別々のグループ**になります。どのアートボードに属するかは、オブジェクトの中心点がどのアートボードの矩形に含まれるかで判定します。

このチェックボックスの初期状態は、状況に応じて自動で決まります。

| 状況 | 初期状態 |
| --- | --- |
| アートボードが1つだけ | ディム（グレーアウト）してOFF固定 |
| 選択が複数のアートボードにまたがっている | ON |
| 上記以外（アートボードは複数あるが選択は1つのアートボード内） | OFF |

なお、どのアートボードにも中心が乗っていないオブジェクトは、アートボードのまたぎ判定の集計からは除外されます。

**プレビューを表示**

ONにすると、作成されるグループの範囲を赤い枠（塗りなし、線 10 pt、不透明度 50%）で表示します。モードや設定を変えると描き直し、ダイアログを閉じると消えます。初期状態はONです。

### 注意点

- まとまりの判定は、隣り合ったもの同士をたどって連結していく方式です。A と B、B と C がそれぞれ条件を満たせば、**A と C が条件を満たしていなくても同じグループ**になります。少しずつずれたオブジェクトが並んでいると、数珠つなぎに1つのまとまりになることがあります。この場合は［しきい値］を小さくして調整してください。
- メンバーが1つしかないまとまりはグループ化しません。
- 判定には、線幅を含まない外枠（`geometricBounds`）を使います。図形の実際の形ではなく、外枠で重なりや距離を見ます。
- グループは、まとまりの中で最前面のオブジェクトがあった位置（レイヤーと重ね順）に作られます。まとまりの中の重ね順も保ちます。
- プレビューの枠は、最上位に一時的に作る専用レイヤー「SmartClipAndGroup Preview」に描くので、どのオブジェクトよりも手前に表示されます。この描画は取り消しの履歴にも残ります。
- 選択が300個を超えるときは、スライダーをドラッグしている間は件数とプレビューを更新せず、指を離したときに更新します。

**旧スクリプトからの移行**

| 旧スクリプトの設定 | このスクリプトでの設定 |
| --- | --- |
| SmartAutoGroup：重なり（のみ） | 重なり（接しているものもまとめます） |
| SmartAutoGroup：垂直方向 | 上下方向＋間隔が空いたら分ける |
| SmartAutoGroup：水平方向 | 左右方向＋間隔が空いたら分ける |
| SmartAutoGroup：近接度 | 近接度 |
| SmartAutoGroup-yoko：縦のズレ許容 | 左右方向の［しきい値］ |
| SmartAutoGroup-yoko：アートボードごと | アートボードごと |
