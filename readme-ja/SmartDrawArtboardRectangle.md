# アートボードと同じサイズの長方形を描く

[![Direct](https://img.shields.io/badge/Direct%20Link-SmartDrawArtboardRectangle.jsx-ffcc00.svg)](https://github.com/swwwitch/illustrator-scripts/blob/master/jsx/artboard/SmartDrawArtboardRectangle.jsx)

### 概要

アクティブまたはすべてのアートボードと同じサイズの長方形を、オフセットを考慮して描画します。カラー・配置位置・対象をダイアログ上のライブプレビューで確かめながら指定し、［OK］で確定します。描画後に「ガイドに変換」「ライブシェイプ化」を適用できます。

### 主な機能

- オフセット指定（負の値で内側へ縮小）。↑↓キーで増減（Shift＝10、Option＝0.1）
- 裁ち落としプリセット（mm＝3、Q・H＝12、pt＝9。それ以外の単位は3mm相当を換算）
- カラー指定（なし／K100・不透明度15%／HEX／CMYK）
- 配置位置（最前面／最背面／bgレイヤー、デフォルトは最前面）
- 対象（現在のアートボード／すべてのアートボード）
- 描画後のオプション（ガイドに変換：デフォルトOFF／ライブシェイプ化：デフォルトON）
- ライブシェイプ化したときは中心の○（中心点）を表示
- ライブプレビュー（専用レイヤー `_preview` に1ptの破線・50%グレーで描画）
- ホットキー（F／B／L／C／A／G）
- アウトライン表示とプレビュー表示の切り替えボタン
- 日本語／英語UI

### 使い方

1. ドキュメントを開きます。
2. スクリプトを実行します。
3. オフセット・カラー・配置位置・対象を指定し、プレビューを確認して［OK］をクリックします。

### オプション

**オフセット**

| 項目 | 内容 |
| --- | --- |
| オフセット | アートボード境界から外側へ広げる量。負の値で内側へ縮小。単位はドキュメントの定規単位に従う |
| 裁ち落とし | 単位に応じた裁ち落とし相当の値を自動入力。ONの間はオフセット入力欄が無効になり、OFFに戻すと直前の手入力値へ戻る |

**カラー**

| 項目 | 内容 |
| --- | --- |
| なし | 塗りも線もなし |
| K100、不透明度15% | ドキュメントのカラースペースに合わせた黒を不透明度15%で適用 |
| HEX | `#RRGGBB`。`#RGB` `#RG` `#R` の短縮、色名（`red` `orange` など）、`gray0`〜`gray100` も可 |
| CMYK | 各チャンネル0〜100。未入力は0として扱う |

**配置位置**

| 項目 | 内容 |
| --- | --- |
| 最前面 | 描画先レイヤーの最前面へ |
| 最背面 | 描画先レイヤーの最背面へ |
| bgレイヤー | `bg` レイヤーを作成（既存があれば使用）し、レイヤーの最背面へ移動して描画 |

**対象**

| 項目 | 内容 |
| --- | --- |
| 現在のアートボード | 作業中のアートボードのみ |
| すべてのアートボード | 全アートボード（アートボードが1つのときは選択不可） |

**オプション**

| 項目 | 内容 |
| --- | --- |
| ガイドに変換 | 描画した長方形をガイド化し、オブジェクト名を `<ガイド>` に変更（デフォルトOFF） |
| ライブシェイプ化 | メニューコマンドでライブシェイプへ変換し、中心の○を表示（デフォルトON） |

**ホットキー**

| キー | 内容 |
| --- | --- |
| F / B / L | 最前面／最背面／bgレイヤー |
| C / A | 現在のアートボード／すべてのアートボード |
| G | ガイドに変換のON・OFF |

入力欄にフォーカスがあるときは無効です。

### 注意点

- プレビューは `_preview` レイヤーへ一時描画し、［OK］／［キャンセル］のどちらでもレイヤーごと削除します。
- 描画先は、アクティブレイヤーが編集可能ならそのレイヤー、そうでなければ最初の編集可能なレイヤーです。テンプレートレイヤー・ロックされたレイヤー・`_preview` レイヤーは対象外で、見つからない場合は `_auto_draw` レイヤーを新規作成します。
- 中心の○は API から設定できないため、記録済みアクションを一時ファイルとして読み込み、再生することで適用します（アクションセット名 `SmartDrawArtboardRectangle`）。
- 「ガイドに変換」と「ライブシェイプ化」は同時に指定できます（ライブシェイプ化のあとにガイド化されます）。
