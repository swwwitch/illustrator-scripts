# 囲み罫とグリッドを一括生成

### 概要

長方形の選択、またはアートボードを基準に、囲み罫とグリッドを一括生成します。

外枠（辺の伸縮・線端・角丸）、タイトルエリア、内側エリアのオフセットと列／行の分割、線種、裁ち落としに対応したフレームを、プレビューを見ながら1つのダイアログで設定できます。

### 主な機能

- 長方形を選択して実行、または選択なしでアートボードを基準に生成
- アートボード基準時のマージン指定（上下左右・連動）
- 外枠の辺の伸縮、線端（なし／丸型／突出）、角丸
- タイトルエリア（上・下・左・右の位置、幅／高さ、塗り、仕切り線、線の伸縮）
- 内側エリアのオフセット（上下左右・連動）、列数／行数と間隔、セルの塗り、分割線
- 分割線の線の種類（実線／破線／点線）
- 裁ち落とし（3mm）に対応したフレーム（アートボード基準時のみ）
- ［画面表示］タブのズーム・パンと表示コマンド（アートボードを全体表示／100%表示／すべてのアートボードを全体表示）
- 数値欄は↑↓キーで増減（Shiftで±10かつ10の倍数にスナップ、Optionで±0.1）
- 各項目にツールチップ（マウスオーバーで説明を表示）
- プレビュー付きダイアログ
- 数値はIllustratorの定規単位で入力
- 再実行時に前回のダイアログ設定を復元（Illustratorの再起動でリセット）
- 日本語／英語UI

### 使い方

1. 基準にする長方形を選択します。アートボードを基準にする場合は、選択を解除したまま実行します。
2. `SmartGridMaker.jsx` を実行します。
3. ダイアログのタブで設定します。
4. プレビューを確認しながら数値を調整します。
5. ［OK］をクリックして生成します。

### タブと主な設定

| タブ | 主な設定 |
| --- | --- |
| アートボード | マージン（上下左右・連動）、フレーム（幅・裁ち落とし・角丸） |
| 外枠 | 外枠を残す、角丸、辺の伸縮、線端、タイトルエリア |
| 内側エリア | オフセット（上下左右・連動）、列数／行数、間隔、塗り、分割線、線の種類 |
| 画面表示 | ズーム、左右／上下のパン、表示コマンド |

［アートボード］タブは、長方形を選択して実行したときは表示されません（マージンとフレームはアートボード基準時のみ有効）。

### 注意点

- 角丸と辺の伸縮は同時に使えません。一方をONにすると他方が自動でOFFになります。
- 辺の伸縮が0以外のときは、外枠を4辺の直線に分解し、元の長方形は削除します。
- 線端は、外枠を4辺に分解するとき（［外枠を残す］＋辺の伸縮≠0）だけ指定できます。
- タイトルエリアの角丸は、外枠の［角丸］の値を位置に応じた2角だけに適用します（内側エリアには適用しません）。
- タイトルエリアの初期サイズは、上下に置くときは高さの1/5、左右に置くときは幅の1/5です。
- ［線の伸縮］は、＋で仕切り線の両端を短く、−で長くします。
- 内側エリアの［塗り］がOFFのときは、セルの塗りを生成しません（プレビューと生成結果は一致します）。
- 列数・行数の上限は100です。
- 裁ち落としはフレームにのみ適用し、基準の長方形には適用しません。
- 数値の単位はIllustratorの定規単位に従い、各項目の初期値はmm基準の値を現在の単位に換算して表示します。
- キャンセルすると、生成物の削除に加えて、選択していた長方形の塗り・線と画面表示も元に戻します。
- アートボード基準で実行したとき、アクティブなレイヤーがロックまたは非表示だと基準の長方形を作成できないため、アラートを表示して終了します。
- 実行後は選択を解除します。生成物に付けた内部タグは「メモ」にのみ残し、レイヤーパネルに出る名前はクリアします。
- ダイアログの設定はIllustratorの起動中のみ保持されます。
