## 概要

長方形またはアートボードを基準に、囲み罫とグリッドをまとめて生成するスクリプトです。

外側エリア（辺の伸縮・線端・角丸）、タイトルエリア、内側エリアのオフセット、列／行の分割と間隔、塗り・分割線・線種、裁ち落とし対応のフレームを、プレビューを見ながら一括で設定できます。

## 主な機能

- 長方形の選択、またはアートボード基準での生成
- アートボード基準時のマージン指定（上下左右／連動）
- 外側エリアの辺の伸縮、線端（なし／丸型／突出）、角丸
- タイトルエリア（上下左右の位置、幅／高さ、塗り、線、辺の伸縮）
- 内側エリアのオフセット（上下左右・連動）
- 列数／行数と間隔の指定、分割線の描画
- 線の種類を実線／点線／ドット点線から選択
- 裁ち落としに対応したフレーム（アートボード基準時のみ）
- 画面表示タブからのズーム・パン操作と表示コマンド（アートボード全体表示／100%表示／全アートボード全体表示）
- プレビュー付きダイアログ
- 数値はIllustratorの単位設定（ルーラー単位）で入力
- 再実行時に前回のダイアログ設定を復元（Illustratorの再起動でリセット）
- 日本語／英語UI

## 使い方

1. 基準にする長方形を選択します。アートボードを基準にする場合は、選択を解除したまま実行します。
2. `SmartGridMaker.jsx` を実行します。
3. ダイアログのタブで設定します。
   - ［マージン］: アートボードからのマージン（アートボード基準時のみ）
   - ［外側エリア］: 辺の伸縮、線端、角丸、タイトルエリア、フレーム
   - ［内側エリア］: オフセット、列／行、間隔、塗り、分割線、線の種類
   - ［画面表示］: ズームとパン、表示コマンド
4. プレビューを確認しながら数値を調整します。
5. ［実行］をクリックして生成します。

## タブと主な設定

| タブ | 主な設定 |
| --- | --- |
| マージン | 上下左右のマージン、連動 |
| 外側エリア | 辺の伸縮、線端、角丸、タイトルエリア、フレーム（裁ち落とし） |
| 内側エリア | オフセット（上下左右・連動）、列数／行数、間隔、塗り、分割線、線の種類 |
| 画面表示 | ズーム、左右／上下のパン、表示コマンド |

## 注意事項

- 長方形を選択して実行した場合、フレームパネルは無効になり、マージンパネルは表示されません（いずれもアートボード基準時のみ有効）。
- 裁ち落としはフレームにのみ適用されます。
- タイトルエリアの角丸は、外側エリアの［角丸］の値を位置に応じて2箇所に適用します（内側エリアには適用しません）。
- タイトルエリアの［線］がOFFのとき、［辺の伸縮］はディム表示になります。
- タイトルエリアをONにしたときの初期の高さは、外側エリアの高さの1/5です。
- 数値の単位は、Illustratorのルーラー単位の設定に従います。
- ダイアログの設定はIllustratorの起動中のみ保持されます。
