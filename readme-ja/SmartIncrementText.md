### 概要

選択したテキストフレーム内の数字や英字を検出し、指定した数だけ下方向へ複製しながら値を増分します。

### 使い方

1. 元になるテキストフレームを選択します。
2. スクリプトを実行します。
3. 複製数と増分を指定して実行します。

### 注意点

- すでにある連番を振り直したい場合は SmartRenumber.jsx を使用してください。
