### 概要

選択したオブジェクトを一時アートボードに収め、PNG として書き出します。

背景・マージン・罫線・書き出しサイズ・ファイル名をダイアログで指定でき、設定した内容はアートボード上にそのままプレビューされます。よく使う組み合わせはプリセットとして呼び出せます。

### 主な機能

- 選択オブジェクトを写した作業用レイヤーを作り、他のオブジェクトを写り込ませずに書き出し
- テキストは複製をアウトライン化して実際の字形で範囲を測定（元のテキストはそのまま）
- 背景は「透過」「黒」「白」「透明グリッド」「カラー指定」から選択。透明グリッドは1マスの大きさを％で指定（100%で8pt角）
- カラー指定は `#RRGGBB` / `R255G255B255` / `C0M100Y100K0` の3書式に対応
- マージンは上・下・左・右を個別に指定（値は現在の定規単位）。［連動］をオンにすると「上」の値を四辺に適用
- ［サイズの微調整］で書き出し範囲の丸め方を「ピクセルグリッドに最適化」「現在の単位で値を整数値に」「何もしない」から選択
- 罫線は［線幅］チェックで有効化し、線幅とカラー（黒／白／カラー指定）を指定。書き出し範囲の内側に、最小1pxで描画
- 書き出しサイズは 1x〜4x、倍率指定（％）、横幅指定（px）から選択。1x〜4x にはマージンを含めた書き出しピクセル数を併記し、マージンを変えると再計算
- ファイル名はドキュメント名の参照有無・区切り文字（なし／`-`／`_`）・接尾辞の組み合わせで構成し、結果をプレビュー表示
- 倍率・横幅の値は接尾辞に自動で流用
- ファイル名の禁則文字（`¥ / : * ? " < > |`）と空白類は区切り文字に置換
- 書き出し先は「デスクトップ」「ファイルと同じ場所」から選択
- 書き出し後にフォルダーを開く（macOS のみ）
- 組み込みプリセット4種と、現在の設定をテキストファイルとして書き出すプリセット保存
- 数値入力欄は ↑↓ キーで増減（shift で10単位、option で0.1単位）

### 使い方

1. 書き出したいオブジェクトを選択します。
2. スクリプトを実行します。
3. ダイアログで背景・マージン・罫線・書き出しサイズ・ファイル名・書き出し先を設定します。設定はアートボード上にプレビューされます。
4. ［OK］で書き出します。［キャンセル］ならプレビューは破棄され、ドキュメントは元の状態に戻ります。

### オプション

| 項目 | 内容 |
| --- | --- |
| プリセット | 組み込みの設定を呼び出します。［プリセットを保存］で現在の設定をデスクトップにテキスト書き出しします |
| 背景色 | 透過／黒／白／透明グリッド（％）／カラー指定 |
| マージン | 上・下・左・右（現在の定規単位）、［連動］で四辺を同じ値に、［サイズの微調整］で丸め方を選択 |
| 罫線 | ［線幅］チェック＋線幅（現在の定規単位）、黒・白・カラー指定 |
| 書き出しサイズ（px） | 1x〜4x／倍率指定（％）／横幅指定（px） |
| 書き出しファイル名 | ファイル名の参照有無、区切り文字、［接尾辞］チェック＋接尾辞 |
| 書き出し先 | デスクトップ／ファイルと同じ場所、書き出し後にフォルダーを表示 |

### 注意点

- 書き出し範囲は［サイズの微調整］に従って外側へ広げられるため、オブジェクトが欠けることはありません。既定の［ピクセルグリッドに最適化］では整数ptに丸められ、倍率100％のとき 1pt＝1px です。
- 罫線は書き出し範囲の内側に描かれます。罫線の分だけオブジェクトに近づくため、必要に応じてマージンを併用してください。
- 未保存のドキュメントで［ファイルと同じ場所］を選んだ場合は、デスクトップに書き出します。
- ［書き出し後、フォルダーを表示］は macOS のみ有効です。
- 書き出し倍率の上限は 776.19% です。横幅指定などで上限を超える場合は、上限の倍率で書き出したうえでお知らせします。
- 透明グリッドの％を小さくしすぎるとマスの数が増えすぎるため、一定を超えるとマスの大きさが自動的に調整されます。
- テキストの計測用に一時的な複製をアウトライン化しますが、計測後に削除するため元のテキストには影響しません。
- 一時的にレイヤーを非表示にして処理するため、実行中は画面表示が変化します。処理後は元の状態に戻ります。
