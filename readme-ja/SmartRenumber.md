# 数字・英字・漢数字をソートして連番を振り直す

### 概要

選択した数字・英字・漢数字のテキストを、指定した並び順でソートして連番を振り直します。ダイアログでの操作はそのままプレビューに反映されます。

### 主な機能

- ［基準となる値］のラジオで書式を選びます（`123` ／ `ABC` ／ `abc` ／ `一二三` ／ `I II III` ／ `壱弐参`）。選ぶと［開始値］に `1` / `A` / `a` / `一` / `I` / `壱` が入ります
- ［開始値］に直接入力しても書式は切り替わります（`C` と入れれば C, D, E…）
- 英字は `Z` の次が `AA`、`AB`…と桁が増えます
- 漢数字は `十`、`二十一`、`百三`、`一万`…と位を組み立てます
- ローマ数字は `I, II, III, IV`…（小文字で入力しても大文字で書き出します）
- 大字は `壱, 弐, 参, 四 … 九, 拾, 拾壱`…（法令で定められた 壱弐参拾 を使い、四〜九と百千万は通常の字のままです）
- ［開始値］は `0` やマイナス（`-3`）も指定できます
- 並び順は6通り（現在の値順／水平方向／垂直方向／Z方向／N方向／重ね順）
- ［逆順］で並びを逆さにしてから振り直し
- ［開始値］に入力した桁数は常に保ちます（`01` → 01, 02, 03）
- ［ゼロ埋め］でいちばん桁数の多い番号まで桁を広げます（桁数が変わらないときはディム表示）
- ［重ね順調整（OK時）］で、振り直した番号の順に重ね順を並べ替え（［並び順］パネルの下、初期値はON）
- ［接頭辞］［接尾辞］で番号の前後に文字列を追加
- ［開始値］の初期値は、選択の中のいちばん小さい値（英字なら英字、漢数字なら漢数字）
- ↑↓キーで値を増減（数字はShiftで±10かつ10の倍数にスナップ、Optionで±0.1／英字・漢数字は1つずつ）
- 各項目にツールチップ（マウスオーバーで説明を表示）
- プレビュー付きダイアログ（［キャンセル］で元に戻します）
- 日本語／英語UI

### 使い方

1. 対象のテキストをまとめて選択します。
2. `SmartRenumber.jsx` を実行します。
3. ［基準となる値］の［開始値］と［並び順］を指定します（プレビューで確認できます）。
4. ［OK］で確定します。

### 主な設定

| 項目 | 内容 |
| --- | --- |
| 書式（123／ABC／abc／一二三／I II III／壱弐参） | 書き出す書式。選ぶと［開始値］にその書式のいちばん若い値が入ります |
| 開始値 | 振り直しの最初の値。数字（`1`／`0`／`-3`）、英字（`A`／`a`）、漢数字（`一`）、ローマ数字（`I`）、大字（`壱`）を指定できます |
| 並び順 | 番号を振っていく順序（下表） |
| 逆順 | 並び順を逆さにしてから振り直します |
| ゼロ埋め | いちばん桁数の多い番号まで桁を広げます（数字のときだけ）。入力した桁数はこのチェックに関わらず保たれます |
| 重ね順調整（OK時） | 振り直した番号の順に重ね順を並べ替えます（番号の小さいものが前面）。初期値はONです |
| 接頭辞 | 番号の前に付ける文字列 |
| 接尾辞 | 番号の後ろに付ける文字列 |

### 並び順

| 並び順 | 内容 |
| --- | --- |
| 現在の値順 | いま入っている値の小さい順（英字はアルファベット順、漢数字は換算した数の順） |
| 水平方向（左から右） | 左にあるものから順 |
| 垂直方向（上から下） | 上にあるものから順 |
| Z方向（左→右、上→下） | 行ごとに左から右へ、行を上から下へ進みます |
| N方向（上→下、左→右） | 列ごとに上から下へ、列を左から右へ進みます |
| 重ね順（前面から） | 重ね順の前面にあるものから順 |

### 注意点

- 対象は「中身が数字だけ」「英字だけ」「漢数字だけ」のテキストオブジェクトです。`No.1` や `3行目`、`A1` のように混ざったものは対象になりません。接頭辞・接尾辞を付けたあとに再実行しても拾えないため、付け直したいときは番号だけの状態に戻してから実行してください。
- 全角の数字（`１`）は対象外です。
- `I` や `X` は英字ともローマ数字とも読めるため、どちらとして扱うかは［I II III］ラジオの選択で決まります。
- 大字の `四`〜`九`・`百`・`千`・`万` は通常の漢数字と同じ字なので、どちらの書式で続けるかは［一二三］／［壱弐参］ラジオの選択で決まります。
- 既存のローマ数字は［現在の値順］では英字として並びます（位置で並べる場合は問題ありません）。
- ［重ね順調整］はプレビューに反映されません（重ね順は画面上の見え方が変わらないため、［OK］のときだけ実行します）。
- ［キャンセル］や×で閉じたときは、控えておいた元の文字列を書き戻して復元します。
- ［重ね順調整］でレイヤーやグループをまたいで選択している場合は、それぞれの中での並べ替えになります。
- Z方向・N方向は、座標の差が10pt以内なら同じ行・同じ列と見なします。
- 位置の比較には、各テキストの左上（`left` / `top`）を使います。
- 新しく連番を作りながら複製したい場合は SmartIncrementText.jsx を使用してください。
