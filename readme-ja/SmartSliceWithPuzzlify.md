### 概要

選択した画像やオブジェクトを、グリッド（格子）またはジグソーパズル形状のピースに分割し、各ピースでマスクします。

![](https://assets.st-note.com/img/1749270024-NV1Z3LkiMF9CqzrOHvPd8gup.png?width=1200)

### 主な機能

- 分割方法は「グリッド」と「パズル」の2種類。パズルは突起を規則的に並べる「トラディショナル」と、向きをランダムにする「ランダム」から選べます
- ピース数を指定すると、選択オブジェクトの縦横比から、各ピースがおおよそ正方形になる列数・行数を自動で計算
- 配置画像・シンボルは、ピースごとに複製してマスク（クリップグループ）を作成
- 埋め込み画像とベクターオブジェクト（パス・グループ・複合パス）はシンボルに変換してから分割。複数選択はグループ化してシンボルにまとめます（重ね順は保持）
- オフセット、オーバーラップ、バラけ、ケイ線、角丸で仕上がりを調整
- 日本語／英語 UI

### 使い方

1. 分割したい画像やオブジェクトを選択します
2. スクリプトを実行し、ダイアログで分割方法とオプションを指定します
3. ［OK］で分割します。処理中はプログレスバーが表示され、終わるとダイアログが閉じます

### オプション

| 項目 | 使える分割方法 | 内容 |
|---|---|---|
| 分割方法 | — | グリッド／パズル |
| ピース数 | パズル | 作るピースのおおよその数。オブジェクトを1つ選択しているときは、縦横比から列数・行数を決めます |
| 列数・行数 | 両方 | 横・縦に並べるピースの数。片方を 0 にすると、もう一方と縦横比から決めます |
| 形状 | パズル | トラディショナル／ランダム |
| オフセット | パズル | ピースの輪郭をずらします。マイナスで内側に縮みます |
| オーバーラップ | グリッド | 隣り合うピースを重ねる幅。継ぎ目のすき間を防ぎます（元の範囲からははみ出しません） |
| バラけさせる | パズル | ピースを中央寄りのランダムな量でずらします。数値は最大移動量 |
| ケイ線を追加 | 両方 | 各ピースに線を追加します |
| 角丸 | グリッド | 各ピースに効果［角を丸くする］を適用します。数値は半径 |

- 距離の値は定規の単位で入力します
- 数値欄は左のステップボタン（∧∨）または ↑↓ キーで増減できます。1ずつではなく次の整数へ（1.5→2）、shift を併用すると次の10の倍数へ、option を併用すると ±0.1（ピース数・列数・行数は整数のみ）
- 分割方法を切り替えると、各オプションは初期値に戻ります

### 注意点

- 分割後、元のオブジェクトは削除されます
- 埋め込み画像・ベクターオブジェクト・複数選択は、シンボルに変換されるため、［シンボル］パネルにシンボルが追加されます
- 上記以外のオブジェクト（テキストなど）を選択したときは、マスク用のパスだけを作成し、元のオブジェクトは残します
- オフセットは効果［パスのオフセット］を適用してから分割（アピアランスを分割）しています
