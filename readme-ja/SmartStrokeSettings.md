[![Direct](https://img.shields.io/badge/Direct%20Link-SmartStrokeSettings.jsx-ffcc00.svg)](https://github.com/swwwitch/illustrator-scripts/blob/master/jsx/stroke-table/SmartStrokeSettings.jsx)

### 概要

- 選択したパスに、よく使う矢印と線の設定（線幅・線端・角の形状・カラー・破線）をまとめて適用します。
- 矢印は Illustrator の DOM から操作できないため、一時アクション（ai_plugin_setStroke）を生成して実行します。
- [SetStrokeAndArrowheads](SetStrokeAndArrowheads.md) をもとに、SetStrokeAlignment の線端・角の形状と、[DashGapCalculator](DashGapCalculator.md) の破線の計算を取り込んだ改編版です。

### 主な機能

ダイアログボックスは、上にプリセット、左の列に［線］［矢印］、右の列に［破線］を並べています。

#### プリセット

- ドロップダウンで、保存した設定（線・矢印・破線）を読み込みます
- 保存アイコン（トレイに下向きの矢印）で今の設定に名前を付けて保存します。同じ名前は確認してから上書きします
- 削除アイコン（ゴミ箱）で、選んでいるプリセットを削除します
- プリセットは Illustrator を再起動しても残ります（Folder.userData/illustrator-scripts/SmartStrokeSettingsPresets.json）。旧名 FavoriteArrow で保存したプリセットも読み込めます。カラーはプリセットに含みません

#### 線

- 線幅：初期値は選択しているパスの線幅（線が無ければ一般の単位に合わせた値）。右の▼で、よく使う線幅（0.25〜100 pt）から選べます
- 線端（なし／丸型／突出）・角の形状（マイター／ラウンド／ベベル）：線パネルと同じ絵のアイコンで選びます。丸型線端を option＋クリックすると、角の形状もラウンドになります
- カラー：色見本をクリックすると、Illustrator 標準のカラーピッカーが開きます
  - 色見本は、選択しているパスの線の色から始まります（線が無ければ塗りの色）
  - カラーを変えなければ、パスごとに元の色（線があれば線の色、線が無ければ塗りの色）を線の色にします
  - カラーを変えたときは、選択中のすべてのパスにその色を付けます

#### 矢印

- ［なし］とよく使う矢印（矢印 8・11・13・21・27）を、矢印の形を描いたアイコン（3行2列）で選びます。選択中は灰色の地になります
  - ［なし］を選ぶと、両端の矢印を外します
  - option＋クリックで始点と終点を入れ替え、⌘＋option＋クリックで［終点も同じ］を切り替えます
- 矢印ごとに、倍率・先端位置・線幅・線端と角の形状が切り替わります（起動時は矢印 11）

  | 矢印 | 倍率 | 先端位置 | ほか |
  |---|---|---|---|
  | 8 | 25% | パスの終点に配置 | 線幅を 300% に（ほかの矢印を選ぶと元に戻す） |
  | 11 | 100% | パスの終点に配置 | |
  | 13 | 100% | | 線端を丸型・角の形状をラウンドに |
  | 21 | 33% | | 線端を丸型・角の形状をラウンドに |
  | 27 | 100% | パスの終点から配置 | |

  13・21 以外の矢印を選ぶと、線端は「なし」、角の形状は「マイター」に戻ります
- それ以外の矢印は、ポップアップメニューから選びます（倍率は 100%）
- 倍率：矢印の大きさ（%）です
- オプション（アイコンを1行に並べます。名前はツールチップに出ます。矢印が［なし］のときはディム）
  - ［終点も同じ］（リンクアイコン）：終点にも始点と同じ矢印を付けます。オンのときは、矢印のアイコンも両端の絵になります。オフのときは終点の矢印を外します
  - ［始点と終点を入れ替え］（⇄アイコン）：矢印を始点ではなく終点に付けます（［終点も同じ］がオンのときはディム）
  - 先端位置（左：パスの終点から配置／右：パスの終点に配置）

#### 破線

- ［なし］［破線］［ドット点線］を選びます
  - ［破線］［ドット点線］を選ぶと、線幅から決めた分割数・間隔・線分が入り、矢印は［なし］になります
  - ［なし］のときは、元のパスに付いていた破線も外して実線にします
- 破線の計算：分割数・間隔・線分から破線を求めます。複数のパスを選んでいるときは、パスごとに長さを見て計算します
- 計算方法：間隔 → 線分／線分 → 間隔
- ドット点線は、点（長さ0）の間隔を分割数から求め、線端を丸型に固定します
- 角に合わせる（アイコンで選択。左：線分の長さを保持／右：両端を調整）：［両端を調整］では、オープンパスで両端が線分（点）で終わるように配分します

#### プレビュー・ボタン

- プレビューは常にオンです（ダイアログボックスを開いた時点から反映）。線幅は入力中も即時に反映し、矢印を含む設定はアクションの実行と取り消しで反映します。キャンセルすると元に戻ります
- 左下の［「線」パネルを開く］：ダイアログボックスを閉じて（キャンセルと同じく元に戻して）、Illustrator の［線］パネルを開きます

### 使い方

1. 線を設定したいパスを選択します（グループ・複合パスの中のパスも対象）
2. スクリプトを実行し、ダイアログボックスで線・矢印・破線を設定します（保存したプリセットからも選べます）
3. ［OK］で適用します

### 注意点

- 矢印名・先端位置名・線端と角の形状の名前は、Illustrator の UI 表示名と一致している必要があります（言語に依存）。
- 矢印の倍率キー（asc1 / asc2）は推定値です。
- 破線と線の色は、アクションのあとに DOM で設定しています。
- よく使う矢印と、その倍率・先端位置・線幅の倍数・線端と角の形状は、スクリプト冒頭の `FAVORITE_ARROWS` で変更できます。
