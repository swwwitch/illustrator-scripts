# テキストの検索・置換・整形

[![Direct](https://img.shields.io/badge/Direct%20Link-SmartTextFindReplace.jsx-ffcc00.svg)](https://github.com/swwwitch/illustrator-scripts/blob/master/jsx/text/SmartTextFindReplace.jsx)

### 概要

- テキストから文字列をまとめて検索・削除・置換し、英字の大文字・小文字の変換や、スペース・記号・かな・数字の整形も行います。
- 検索した文字列に一致する文字を、カンバス上で1つずつ、またはまとめて選択できます。
- 「検索・置換」「英文」「整形」の3つのタブに分かれています。対象（選択中のオブジェクト・現在のアートボード・ドキュメント全体）とオプションは3つのタブで共通です。
- 変わった文字だけを書き換えるので、残った文字の書式（色・フォント・サイズなど）は変わりません。
- シンボル内のテキストや、非表示・ロックされたテキストも対象にできます。

### 主な機能

#### 検索・置換タブ

<img alt="検索・置換タブ" src="../png/ss-1038-1334-144-20260930-030009.png" width="50%" />

検索

- 検索する文字列を5つまで指定（空欄は無視し、上の欄から順に処理）
- 欄ごとに、対象範囲で見つかった数を表示（入力中・対象の切り替え時に更新）
- 正規表現、大文字と小文字の区別
- 改行は `\n`、強制改行は `@#` で指定（ボタンまたはショートカットでカーソル位置に挿入）
- 文字ツールで文字を選択して実行すると、その文字列を1行目に入れる（選択ツールでテキストオブジェクトを1つだけ選んでいるときは、その1行目）

削除・置換

- 欄ごとに置換後の文字列を指定（空欄なら削除。正規表現では `$1`・`\1` や `$&`・`\0` などで一致した部分を参照）
- 正規表現の検索結果を参照する `\0` `\1` `\2` をボタンまたはショートカットで挿入
- 削除で空になった行（段落）と、空になったテキストの削除
- ダイアログを閉じずに結果を確かめるプレビュー（正規表現のとき）

選択

- ［次を選択］：次に一致する文字を選択（最後まで行くと最初に戻る）。そのテキストが画面に大きく収まるよう表示を合わせることもできる
- ［すべてを選択］：一致する文字を含むテキストオブジェクトをすべて選択
- どちらもカーソルのある行（左端に ▶ を表示）の文字列で選択する

- 入力内容と設定を次回に引き継ぐ

#### 英文タブ

<img alt="英文タブ" src="../png/ss-992-1284-144-20260926-234613.png" width="50%" />

- すべて大文字に／すべて小文字に／単語の先頭を大文字／文頭のみ大文字／英語タイトル形式
- 変換結果の見本をボタンの右に表示

#### 整形タブ

<img alt="整形タブ" src="../png/ss-1038-1334-144-20260930-030306.png" width="50%" />

- タブ：削除／スペースに
- スペースの削除：行頭・行末／和欧間／連続／まとめて
- スペースの追加：.と,の後
- スペースや記号の変換：スペース・アンダースコア・ハイフンの相互変換
- かな・数字の変換：ひらがな／カタカナ／半角カナ、半角数字／全角数字（漢数字も算用数字にする）
- リストの除去：行頭の箇条書き記号・番号を取り除く

#### 共通

- 対象範囲：選択中のオブジェクト（グループ内も含む）／現在のアートボード（一部でも重なるもの）／ドキュメント全体
- 何も選択していないときは、対象を自動でドキュメント全体に
- 非表示・ロックされたレイヤーやオブジェクト内のテキストも処理（処理のあいだだけ解除して元に戻す）
- シンボル内のテキストも処理（シンボルの定義を書き換え）

### 使い方

削除・置換する

1. 対象を選択するか、何も選択せずにスクリプトを実行する
2. 「検索・置換する文字列」の左の欄に文字列を入力する（置換するときは「→」の右の欄にも入力。一致数は右端に出る）
3. 対象とオプションを選び、正規表現のときは必要ならプレビューで結果を確かめてから、［すべてを置換］を押す（Enter でも可）。ダイアログは閉じないので、続けて別の処理ができる。終わったら［閉じる］

探して選択する

1. 探したい文字を文字ツールで選択するか、テキストオブジェクトを1つだけ選んでスクリプトを実行する（1行目に入る）。または欄に文字列を入力する
2. 探したい行にカーソルを置き（左端に ▶ が出る）、［次を選択］を押すたびに次の一致を選択する。まとめて選ぶときは［すべてを選択］
3. ［閉じる］で閉じると、選択はそのまま残る

### ダイアログ

| 項目 | 説明 |
| --- | --- |
| ▶ | カーソルのある行の目印。［次を選択］［すべてを選択］はこの行の文字列で選択する |
| 検索・置換する文字列 | 左は検索する文字列（5欄）。空欄は無視し、上の欄から順に処理する。「→」の右は置換後の文字列で、空欄なら削除する。右端の数字は対象範囲で見つかった数で、「!」は正規表現の誤り |
| 改行 | カーソルのある入力欄に `\n`（改行）を挿入する。command（Ctrl）＋ Enter でも挿入できる |
| 強制改行 | カーソルのある入力欄に `@#`（強制改行）を挿入する。Shift ＋ Enter でも挿入できる |
| 検索結果すべて | カーソルのある入力欄に `\0`（一致した部分全体）を挿入する。option（Alt）＋ 0 でも挿入できる。正規表現のときだけ使える |
| 検索結果1・検索結果2 | カーソルのある入力欄に `\1`・`\2`（1つ目・2つ目の `( )` に一致した部分）を挿入する。option（Alt）＋ 1・2 でも挿入できる。正規表現のときだけ使える |
| 正規表現 | 入力を JavaScript の正規表現として扱う。`^` と `$` は段落の先頭・末尾に一致する。置換欄では `$1`〜`$99`・`$&`・`$$` と、`\0`（一致全体）・`\1`〜`\9`（グループ）・`\\`（`\` そのもの）が使える |
| プレビュー | 正規表現のときだけ使える。ON の間、ダイアログを閉じずに結果を表示する。入力・対象・オプションを変えると表示を更新する。設定は保存せず、開くときは常に OFF。正規表現を OFF にすると、プレビューも OFF になる |
| 大文字と小文字を区別 | ON で英字の大文字と小文字を別の文字として検索する。OFF なら同じ文字として扱う |
| 空になった行を削除 | 削除で段落が空になったら、その改行も削除して空行を残さない。元から空の行は残す。初期値は ON |
| 空になったテキストを削除 | 今回の削除で空になったテキストを削除する。元から空のテキストと、スレッドテキスト（連結）のフレームは残す |
| 選択時に拡大表示 | ［次を選択］で選んだ文字を含むテキストが画面に大きく収まるよう、表示倍率と位置を変える（最大400%）。初期値は ON |
| 次を選択 | ▶ の行の文字列に次に一致する文字を選択する。最後まで行くと最初に戻る。非表示・ロックされたテキストとシンボル内は飛ばす |
| すべてを選択 | ▶ の行の文字列に一致する文字を含むテキストオブジェクトを、すべて選択する。非表示・ロックされたテキストとシンボル内は選択しない |
| 条件をリセット | 入力欄を空にし、対象とオプションを初期値に戻す。プレビューの ON/OFF はそのまま |
| すべてを置換 | 対象の範囲で一致する部分をすべて置換する（置換欄が空なら削除）。結果のメッセージは出さず、一致数の表示が更新される。ダイアログは閉じない |
| 英文タブのボタン | 押すとすぐに、対象範囲のテキストを変換する（「非表示のレイヤーを検索」などのオプションに従う）。右は対象範囲の最初のテキストを変換した見本 |
| 整形タブのボタン | 押すとすぐに、対象範囲のテキストを整形する（「非表示のレイヤーを検索」などのオプションに従う）。「スペースや記号の変換」は変換前・変換後を選んでから［変換］を押す |
| 選択中のオブジェクト | 選択したテキスト（グループ内も含む）が対象。何も選択していないときは選べない |
| 現在のアートボード | アクティブなアートボードに一部でも重なるテキストが対象 |
| ドキュメント全体 | ドキュメント内のすべてのテキストが対象 |
| 非表示のレイヤーを検索 | 非表示のレイヤー・オブジェクト内のテキストも対象にする。処理のあいだだけ表示し、終わったら元に戻す |
| ロックされたレイヤーを検索 | ロックされたレイヤー・オブジェクト内のテキストも対象にする。処理のあいだだけロックを解除し、終わったら元に戻す |
| シンボルを検索 | 対象範囲にあるシンボルの中のテキストも対象にする |

### 注意事項

- 欄ごとの一致数は、ほかの欄による削除・置換を考慮していません。欄同士の文字列が重なっていると、実際に処理される数と異なることがあります。
- 置換した文字列は、下の欄の検索対象になります。
- 置換した文字は、一致した部分の先頭の文字の書式になります。一致した部分の中で書式が異なっていても、置換後は1つの書式にそろいます。
- 検索欄・置換欄の `\n` は改行、`@#` は強制改行として扱います（正規表現でも同じ）。正規表現で `\` と `n` の2文字を探すときは `\\n` と書きます。
- 選択した文字（テキストオブジェクトを1つだけ選んでいるときはその1行目）を1行目に入れるとき、前回の入力内容は空になります。複数のオブジェクトを選んでいるときは入れません。［正規表現］が ON なら、`.` や `(` などの記号は文字として探すよう `\` を付けて入れます。
- ［次を選択］［すべてを選択］は、表示中でロックされていないテキストだけを選択します。シンボル内のテキストは選択できません。
- ［次を選択］［すべてを選択］で選択すると、ダイアログを閉じたあとも、その選択が残ります。
- ［次を選択］［すべてを選択］を押すと、表示中のプレビューはいったん消えます。入力や対象を変えると、また表示されます。
- プレビューは、表示中でロックされていない独立したテキストだけに表示されます。シンボル内・非表示・ロック中のテキストと、スレッドテキスト（連結）は、プレビューでは変わりませんが［すべてを置換］では処理されます。
- 「シンボルを検索」はシンボルの定義そのものを書き換えます。対象範囲の外にある同じシンボルのインスタンスも変わります。
- シンボルは作り直して差し替えるため、基準点・9スライスなどのシンボルオプションは初期値に戻ります。
- 「シンボルを検索」が ON のときは、一致数を数えるためにダイアログ内でシンボルを一時的に展開します。シンボルが多いドキュメントでは、ダイアログの表示に時間がかかることがあります。
- ［すべてを置換］したときと［閉じる］で閉じたときに、入力内容と設定が保存され、次回のダイアログに引き継がれます。
- ［すべてを置換］と「英文」「整形」タブのボタンは押した時点で処理します。戻すときはダイアログを閉じてから取り消してください。
- 「英文」「整形」タブを開いているときは、Enter を押しても［すべてを置換］は実行されません。
- 変換で文字数が変わるとき（半角カナの濁点・漢数字など）は、変わった部分がその部分の先頭の文字の書式になります。スペースを足したときは、直前の文字の書式になります。
- 「箇条書き」「番号リスト」は、Illustrator の箇条書き・番号付きリストをいったん［テキストに変換］（メニューのコマンドを実行）してから、行頭の記号・番号を取り除きます。本文として入力された記号・番号もそのまま取り除きます。変換のために一時的にテキストを選択しますが、ダイアログを閉じると元の選択に戻ります。
