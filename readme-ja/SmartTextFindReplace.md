# テキストから指定した文字列を削除・置換

[![Direct](https://img.shields.io/badge/Direct%20Link-SmartTextFindReplace.jsx-ffcc00.svg)](https://github.com/swwwitch/illustrator-scripts/blob/master/jsx/text/SmartTextFindReplace.jsx)

[![English](https://img.shields.io/badge/README-English-4b8bbe.svg)](https://github.com/swwwitch/illustrator-scripts/blob/master/readme-en/SmartTextFindReplace.md)

[![Direct](https://img.shields.io/badge/Back%20to%20home-All%20scripts-cccccc.svg)](https://github.com/swwwitch/illustrator-scripts/blob/master/README.md)

### 概要

- 入力した文字列を、テキストからまとめて削除します。置換欄に入力すると、その文字列に置き換えます。
- 入力欄は5つあり、上の欄から順に処理します。正規表現も使えます。
- 対象は「選択中のオブジェクト」「現在のアートボード」「ドキュメント全体」から選べます。シンボル内のテキストも対象にできます。
- 1文字ずつ削除するので、残った文字の書式（色・フォント・サイズなど）は変わりません。置換した文字は、一致した部分の先頭の文字の書式になります。

### 主な機能

- 削除する文字列を5つまで指定（空欄は無視）
- 欄ごとに置換後の文字列を指定（空欄なら削除。正規表現では `$1` `$&` などで一致した部分を参照）
- 欄ごとに、対象範囲で見つかった数を表示（入力中・対象の切り替え時に更新）
- 正規表現、大文字と小文字を区別しない検索
- 対象範囲：選択中のオブジェクト（グループ内も含む）／現在のアートボード（一部でも重なるもの）／ドキュメント全体
- 何も選択していないときは、対象を自動でドキュメント全体に
- 削除で空になったテキストの削除
- 非表示・ロックされたレイヤーやオブジェクト内のテキストも処理（処理のあいだだけ解除して元に戻す）
- シンボル内のテキストも処理（シンボルの定義を書き換え）
- 結果として、欄ごとの削除・置換数・変更したテキストの数・削除したテキストの数・書き換えたシンボルの数を表示
- 入力内容と設定を次回に引き継ぐ

### 使い方

1. 対象を選択するか、何も選択せずにスクリプトを実行する
2. 「削除・置換する文字列」の左の欄に文字列を入力する（置換するときは「→」の右の欄にも入力。一致数は右端に出る）
3. 対象とオプションを選び、OK で実行する

### ダイアログ

| 項目 | 説明 |
| --- | --- |
| 削除・置換する文字列 | 左は検索する文字列（5欄）。空欄は無視し、上の欄から順に処理する。「→」の右は置換後の文字列で、空欄なら削除する。右端の数字は対象範囲で見つかった数で、「!」は正規表現の誤り |
| 正規表現 | 入力を JavaScript の正規表現として扱う。`^` と `$` は段落の先頭・末尾に一致する。置換欄では `$1`〜`$99`・`$&`・`$$` が使える |
| 大文字と小文字を区別しない | 英字の大文字と小文字を同じ文字として検索する |
| 選択中のオブジェクト | 選択したテキスト（グループ内も含む）が対象。何も選択していないときは選べない |
| 現在のアートボード | アクティブなアートボードに一部でも重なるテキストが対象 |
| ドキュメント全体 | ドキュメント内のすべてのテキストが対象 |
| 空になったテキストを削除 | 今回の削除で空になったテキストを削除する。元から空のテキストと、スレッドテキスト（連結）のフレームは残す |
| 非表示のレイヤーを検索 | 非表示のレイヤー・オブジェクト内のテキストも対象にする。処理のあいだだけ表示し、終わったら元に戻す |
| ロックされたレイヤーを検索 | ロックされたレイヤー・オブジェクト内のテキストも対象にする。処理のあいだだけロックを解除し、終わったら元に戻す |
| シンボルも検索 | 対象範囲にあるシンボルの中のテキストも対象にする |

### 注意事項

- 欄ごとの一致数は、ほかの欄による削除・置換を考慮していません。欄同士の文字列が重なっていると、実際に処理される数と異なることがあります。
- 置換した文字列は、下の欄の検索対象になります。
- 置換した文字は、一致した部分の先頭の文字の書式になります。一致した部分の中で書式が異なっていても、置換後は1つの書式にそろいます。
- 「シンボルも検索」はシンボルの定義そのものを書き換えます。対象範囲の外にある同じシンボルのインスタンスも変わります。
- シンボルは作り直して差し替えるため、基準点・9スライスなどのシンボルオプションは初期値に戻ります。
- 「シンボルも検索」が ON のときは、一致数を数えるためにダイアログ内でシンボルを一時的に展開します。シンボルが多いドキュメントでは、ダイアログの表示に時間がかかることがあります。
- OK で実行すると、入力内容と設定が保存され、次回のダイアログに引き継がれます。
