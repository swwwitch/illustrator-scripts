### 概要

選択したテキストフレームを、書式を保ったまま1文字ごとのテキストフレームへ分割します。

### 使い方

1. 分割したいテキストフレームを選択します。
2. スクリプトを実行します。

### 注意点

- 分割は常に「単一文字」単位です。単語や行単位の分割はできません。
- 行や段落で分割したい場合は TextBreakSplitMergePallete.jsx を使用してください。
