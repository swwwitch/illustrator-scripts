# テキストに吹き出しのしっぽ付きの下線・囲みを描く

### 概要

選択したテキストに、吹き出しのしっぽ（V字・斜線・すぼまり）の付いた下線・コの字・囲みを描きます。線は上下左右のどの側にも描け、カラー・線端・角丸・影も指定できます。設定はダイアログボックスでプレビューしながら決め、プリセットとして保存できます。

### 主な機能

ダイアログボックスは、上部の中央に［プリセット］、その下の左に［しっぽ］と［テキストに関してのオプション］、右に［線/枠］のパネルが並びます。ボタンの行の左端に［プレビュー］があります。

#### プリセット

- ドロップダウンで選ぶと、しっぽと線/枠の設定をまとめて切り替えます。
- 最初から12種類（シンプルな吹き出し、ひろがりカーリー、下線・V字、下線・V字（右下）、下線・斜線（右下・左下）、コの字・斜線、角丸のコの字・V字、囲み・斜線、角丸の囲み・斜線、囲み・V字（影）、カーリーブラケット（波括弧））を用意しています。最初からあるプリセットの寸法は、1文字目の文字サイズに合わせて決めます。
- 保存のアイコンで今の設定に名前を付けて保存し、ごみ箱のアイコンで選んでいる保存したプリセットを削除します（最初からあるものは削除できず、同じ名前も使えません）。保存したプリセットは寸法を保存したときの値のまま持ち、Illustrator を終了しても残ります。
- 設定を手で変えると、プリセットの選択は外れます。

#### しっぽ

- 形状：［V字］は線を折ってしっぽを作ります（1本のパスのまま）。［斜線］は線から斜線を出します。［すぼまり］は AiCurlyBracketMaker のカーリーブラケット（波括弧）の中央のように、線から曲線ですぼまってとがらせます。
- 向き：［真下］［右下］［左下］から選びます。
  - V字・すぼまりの［真下］は先端が付け根の中央、［右下］は付け根の左端から右へ［幅］だけ離れた所、［左下］は付け根の右端から左へ［幅］だけ離れた所が先端です。
  - 斜線は［右下］［左下］へ［角度］で傾けます（［真下］はまっすぐ）。
- 角度（斜線で右下・左下のとき）：線から測った角度です（初期値 45°、5〜90°。90°で真下）。斜線の横方向の長さは［高さ］と［角度］で決まります。
- 根元（斜線で右下・左下のとき）：［中央］は切れ目の中央から斜線を出して線と離し、［端］は切れ目の端から出して線とつなげます。
- 位置：線の始まりを 0%、終わりを 100% として、数値欄かその下のスライダーで指定します（初期値 50%。スライダーは shift を押しながらで10%刻み）。しっぽが線からはみ出す位置では、内側へ寄せます。
- 切れ目：しっぽのところで線を切る幅です。V字・すぼまりでは付け根の幅です。斜線を 0 にすると、線を切らずに斜線だけを付けます。
- 幅（V字・すぼまりで右下・左下のとき）：先端の横方向のずれです。
- 高さ：線から外へ伸びるしっぽの長さです。

#### 線/枠

- 形状：［下線］は字面の下に線を引きます。［コの字］は線の両端を文字の側へ立ち上げます。［囲み］は字面を長方形で囲みます。コの字で［角丸の半径］と［立ち上がり］を同じ値にすると、両端がカーリーブラケット（波括弧）と同じ形になります。
- 配置：線を描く側を、上下左右に並んだ［上］［下］［左］［右］から選びます。ダイアログボックスを開くたびに、1つ目のテキストが横組みなら［下］、縦組みなら［右］を選んでおきます（配置を決めていないプリセットを選んだときも同じ）。
  - ［上］では、しっぽが上へ出ます。
  - ［左］［右］では線の始まりが上になり、しっぽの［右下］は下寄り、［左下］は上寄りになります。
- 間隔：字面から線までの距離です。囲みでは上下の余白です。
- 左右の伸び：字面の端から線を伸ばす長さです（マイナスで縮めます）。囲みでは左右の余白です。
- 立ち上がり（コの字のとき）：両端を立ち上げる長さです。
- 角丸の半径（コの字・囲みのとき）：角の丸みです（0 で角をとがらせます）。
- 影（囲みのとき）：囲みの右と下に、この間隔で2本目の線を重ねます（0 で影なし）。影の両端は囲みの角丸が始まる位置でそろえ、しっぽの右の辺は平行にずらして先端の高さで止め、左の辺の手前では間隔をあけて止めます。
- 線幅：線としっぽの線幅です。
- 線のカラー：［文字色］（初期値）はテキストごとに1文字目の塗りと同じカラー（塗りが無ければ黒）、色見本の付いたもう一方のラジオボタン（カスタム）はその色見本のカラーです。色見本をクリックすると Illustrator 標準のカラーピッカーが開き、選ぶとカスタムに切り替わります。
- 線端：［なし］（初期値）か［丸型］を選びます。［なし］は角をとがらせ、［丸型］は角も丸めます。

#### テキストに関してのオプション

- エリア内文字は枠を基準にする（初期値はオン。エリア内文字を選んでいるときだけ使えます）：エリア内文字は、字面ではなく枠に沿って描きます（［間隔］［左右の伸び］は 0 として扱い、選択がすべてエリア内文字ならこの2つの欄はグレーになります）。ポイント文字・パス上文字は字面が基準です。プリセットにも保存されます。
- エリア内文字にして中央に配置（囲みのとき）：テキストを囲みの長方形と同じ大きさのエリア内文字にして、左右・天地中央に揃えます。ポイント文字はエリア内文字に変換し、エリア内文字は枠の大きさと位置を合わせます（パス上文字はそのまま）。
- テキストとグループ化：線としっぽをテキストと一緒にグループにします（オフのときは、線としっぽだけのグループをテキストのすぐ前面に置きます）。

#### そのほか

- プレビュー（ボタンの行の左端）：結果を画面で確かめられます（初期値はオン）。
- 実行中は、プレビューを見やすくするため［境界線を隠す］と［バウンディングボックスを隠す］を切り替え、終了時に元に戻します。
- 長さは環境設定の［単位］の［一般］、線幅は［線］の単位で入力します。
- 初めて開いたときの寸法は、1文字目の文字サイズから決めます。［OK］で閉じたときの設定（カスタムのカラーも含む）は Illustrator を終了するまで覚えていて、次に開いたときに使います（［配置］だけは開くたびにテキストから選び直します）。

### 使い方

1. テキストを選択します（複数可。グループの中のテキストも対象です）。
2. スクリプトを実行し、プリセットを選ぶか、しっぽと線/枠の形・寸法を指定して［OK］をクリックします。

### 注意点

- 線は、テキスト全体の字面（エリア内文字を枠の基準にするときは枠）を囲む範囲に対して1組だけ描きます。複数行の下線は最終行の下（配置が左右なら外側の列の外）に描きます。
- エリア内文字への変換と天地中央揃えは［OK］のあとに行うので、プレビューには出ません。
- ロック・非表示のテキストと、空白だけのテキストは対象外です。
