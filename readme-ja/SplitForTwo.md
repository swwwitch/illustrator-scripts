# 外接矩形を2分割した2色の背景に置き換え

[![Direct](https://img.shields.io/badge/Direct%20Link-SplitForTwo.jsx-ffcc00.svg)](https://github.com/swwwitch/illustrator-scripts/blob/master/jsx/stroke-table/SplitForTwo.jsx)

[![English](https://img.shields.io/badge/README-English-4b8bbe.svg)](https://github.com/swwwitch/illustrator-scripts/blob/master/readme-en/SplitForTwo.md)

[![Direct](https://img.shields.io/badge/Back%20to%20home-All%20scripts-cccccc.svg)](https://github.com/swwwitch/illustrator-scripts/blob/master/README.md)

### 概要

- 1つのオブジェクト（テキスト、パス、グループなど）を選択して実行すると、その外接矩形を左右または上下に2分割し、2色の背景に置き換えます（元のオブジェクトは削除します）。
- 分割方法の初期値は、オブジェクトが縦長なら上下、それ以外は左右です。
- 分割位置・塗り・線・角丸はダイアログで指定し、プレビューを見ながら調整して［OK］で確定します。

### 主な機能

- 分割位置：［バランス］で左右（上下）それぞれの幅と割合（%）を、数値とスライダーで指定します。［正方形］をオンにすると、その側が正方形になる位置で分けます。
- 塗り：左右（上下）それぞれに塗りを付けるかどうかと色を指定します。色見本をクリックすると、白・黒・RGB・CMYK・グレーを選べるカラー選択が開きます。初期値は左（上）が明るいグレー（RGB 220）、右（下）が濃いグレー（RGB 128）です。
- 線：全体を囲む外枠と、分割の境目の区切り線を追加できます。線幅と色も指定できます。
- 角丸：4つの角を個別に丸めるか、［ピル形状］で両端を半円にします。［連動］をオンにすると、左上の設定を4つの角に使います。
- 正確な計測：テキストはアウトライン化した複製で測るので、サイドベアリングで背景がずれません（複製はすぐに削除します）。クリップグループはマスクの範囲を基準にします。
- 配置：元のオブジェクトがあったレイヤーに作ります。塗りはレイヤーの最背面、外枠と区切り線は最前面に置き、［グループ化］がオンなら1つのグループにまとめます（グループはレイヤーの最前面に置かれます）。

### 使い方

1. オブジェクトを1つ選択する
2. スクリプトを実行する
3. プレビューを見ながら値を調整し、［OK］をクリックする

### オプション

- ［分割方法］：［左右］［上下］。H キーで左右、V キーで上下に切り替えられます
- ［バランス］：左（上）と右（下）の幅（定規の単位）と割合（%）。どれかを変えると残りも連動します。スライダーでも指定でき、option を押しながらドラッグすると整数、shift+↑↓で範囲の10%ずつ動きます
- ［正方形］：その側が正方形になる位置で分けます
- ［塗り］：［左］［右］（上下分割では［上］［下］）のオン・オフと色
- ［線］：［外枠］［区切り線］（F キー・D キーでも切り替え）、［線幅］（環境設定の線の単位）、［カラー］。外枠も区切り線も使わないときは、線幅と色は薄く表示されます
- ［角丸］：［ピル形状］、［連動］、［左上］［左下］［右上］［右下］と半径（定規の単位）
- ［グループ化］：作ったオブジェクトを1つのグループにまとめます（初期値はオン）
- 数値の入力欄では、↑↓キーで±1、shift+↑↓で±10（10の倍数にそろえる）、option+↑↓で±0.1 ずつ増減できます

### 注意点

- ［OK］で確定すると、元のオブジェクトは削除されます。キャンセルすると元のまま残り、選択も戻ります。
- ダイアログを開いている間は元のオブジェクトを隠し、プレビューを専用のレイヤー（`__SplitForTwo__PreviewLayer__`）に描きます。このレイヤーはダイアログを閉じると削除します。
- 外枠か区切り線を使うのに、線幅が不正な値のまま［OK］を押すと、線幅の欄に戻ります。
- ［ピル形状］では、塗りと外枠にライブパスファインダー（合体）をかけます。
- 塗り・線・角丸の設定とダイアログの位置は、Illustrator を終了するまで保持します。分割方法と［バランス］は開くたびにオブジェクトに合わせて決め直し、［グループ化］は毎回オンから始まります。
