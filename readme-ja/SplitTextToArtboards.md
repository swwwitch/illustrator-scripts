# 段落ごとにテキストを分けてアートボードへ順に配置

### 概要

複数行のテキストを、1段落ずつ別々のアートボードに置きたいことがあります。スライドの見出し、名札、タイトル案の比較などです。手作業では、段落ごとに複製して不要な行を消し、アートボードに合わせて拡大縮小し、中央にそろえる作業を何度も繰り返すことになります。

このスクリプトは、選択したテキストを1段落ごとのテキストオブジェクトに分けます。指定したアートボードから順番に配置し、それぞれをアートボードの幅に合わせて中央にそろえます。アートボードが足りないときは、既存の並びに合わせて追加します。

### 主な機能

- 選択したテキストを段落ごとに分けて、1段落ずつ別のテキストオブジェクトにする。書式はそのまま残る
- 指定したアートボードから順番に1段落ずつ配置
- 各テキストを、縦横比を保ったままアートボード幅の指定した割合（既定は90%）に拡大縮小し、上下左右の中央に配置
- アートボードが足りないときは自動で追加。列数と間隔は既存の並びから読み取って初期値にする
- 空の段落（空白と改行だけの段落）は読み飛ばす
- 元のテキストを残すか削除するかを選べる

### 使い方

1. 複数の段落を含むテキストオブジェクトを選択します（文字を部分選択しているときは、そのテキストオブジェクトが対象になります）
2. スクリプトを実行し、ダイアログで設定を確認して［OK］

実行すると、作ったテキストオブジェクトがすべて選択された状態になります。

ダイアログの下には、対象になる段落の数と現在のアートボードの枚数が出ます。

### オプション

| 項目 | 内容 |
|---|---|
| どのアートボードから | 1段落目を置くアートボードの番号（1から数える） |
| アートボードの幅 | アートボードの幅に対する仕上がり幅（%）。100でアートボード幅ぴったり |
| 追加時の列数 | アートボードを追加するときの横の列数。既存の並びから読み取れたときはその値が入る（読み取れないときは6） |
| アートボードの間隔 | 追加するアートボードどうしの間隔（pt）。既存の並びから読み取れたときはその値が入る（読み取れないときは20pt） |
| 元のテキストを残す | オンにすると、分ける前のテキストを削除せずに残す（初期値はオフ） |

数値の欄は ↑↓ キーで1ずつ、shift + ↑↓ で10単位で増減できます。

スクリプト冒頭のユーザー設定では、次の項目も変えられます。

| 設定 | 内容 |
|---|---|
| `USE_PREVIEW_BOUNDS` | `true` でプレビュー境界（線幅・効果込み）、`false` で幾何境界で計測（初期値 `true`） |
| `CENTER_VERTICALLY` | `false` にすると、上下は中央にそろえず元の縦位置のまま（初期値 `true`） |
| `SKIP_EMPTY_PARAGRAPHS` | `false` にすると、空の段落にもアートボードを1枚使う（初期値 `true`） |

### 注意点

- 対象は選択の中で最初に見つかったテキストオブジェクト1つだけです
- 追加するアートボードの大きさは、最後のアートボードと同じです。最後のアートボードの右に続けて並べ、指定した列数で折り返します
- アートボードはカンバスの外には追加できません。カンバスの端に達して置ききれなかったときは、置けた段落数を知らせて、そこまでで止めます
- 仕上がり幅は幅だけを基準にしています。縦長のアートボードでは、高さからはみ出すことがあります
