### 概要

選択中の2つのテキストオブジェクトの内容を入れ替えます。
ダイアログで入れ替える対象（文字列 / 書式 / 座標）を選択できます。

<img alt="テキストの入れ替えダイアログの外観" src="../png/ss-430-496-144-20261009-131915-s.png" width="25%" />

- 文字列：文字列だけを入れ替えます。書式と位置はそのままです。一部の文字だけ書式が異なるテキストは、先頭の文字の書式にそろいます。
- 書式：フォント・サイズ・文字カラー・線カラー・線幅・トラッキング・行送り・水平／垂直比率・ベースラインシフト・大文字小文字を入れ替えます。文字列と位置はそのままです。
- 座標：位置だけを入れ替えます。基準は次の2つから選べます。
  - 左上：テキストの外枠の左上をそろえます。
  - 基点：テキストの基点（ベースライン上の行揃えの位置）をそろえます。大きさや行揃えが異なるポイント文字でも、元の基点の位置に収まります。

### 注意

- 選択は2つ、かつ両方ともテキストオブジェクトである必要があります。条件を満たさない場合はアラートを表示します。
- 自動行送りの％や行揃えなどの段落の書式は、書式の入れ替えの対象外です。
