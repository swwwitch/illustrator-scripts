### 概要

選択中の2つのテキストオブジェクトの内容を入れ替えます。
ダイアログで入れ替える対象（文字列 / スタイル / 座標）を選択できます。

- 選択は2つ、かつ両方ともテキストオブジェクトである必要があります。
- 条件を満たさない場合はアラートを表示します。
