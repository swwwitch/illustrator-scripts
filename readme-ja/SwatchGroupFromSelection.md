### 概要

選択しているオブジェクトの塗り色を、配置順（左→右、上→下）で抽出してスウォッチグループに登録します。

### 主な機能

- グループ／複合パス／テキストを再帰的に処理
- 線色（ストローク）も対象
- 抽出した色はすべてグローバルカラー（プロセス）として登録

### 使い方

1. 色を抽出したいオブジェクトを選択します。
2. スクリプトを実行します。

### 注意点

- `SwatchGroupFromSelection.jsx` / `SwatchGroupFromSelection-v2.jsx` / `スウォッチグループ.jsx` は同一内容のファイルです。
