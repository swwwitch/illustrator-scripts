### 概要

選択したシンボルインスタンスのリンクを解除し、通常のオブジェクトとして扱える状態に整えます。

解除後の階層と名前を整理するためのオプションを備えています。

### 主な機能

- 選択範囲内のシンボルを、グループ内も含めてまとめて処理
- static シンボル／dynamic シンボルの解除結果を整理
- 解除後のアイテム名に元のシンボル名を引き継ぐ
- 名前の接頭辞を付けるかどうかを選択
- 解除結果が単一テキストの場合、テキスト内容を名前に使う
- 1アイテムだけのグループを自動的に解除

### 使い方

1. リンクを解除したいシンボルインスタンスを選択します。
2. スクリプトを実行します。
3. 名前と階層のオプションを指定して［OK］をクリックします。

### 注意点

- リンク解除だけを手早く行いたい場合は AiBreakLink.jsx を使用してください。
