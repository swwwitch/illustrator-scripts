# シンボルに登録して一致するオブジェクトを置き換え

### 概要

- 選択オブジェクトをシンボルとして登録し、ドキュメント内の一致するオブジェクトをそのインスタンスに置き換え

### 主な機能

- シンボル名と基準点をダイアログで指定（空欄や既存シンボルと同じ名前は指定できません）
- 基準点は、□9個のウィジェットをクリックして選びます
- 置換対象は選択の種類で変わります
  - テキストフレーム：フォント・スタイル・文字列が一致するテキストフレーム。シンボル名の初期値はその文字列（改行は半角スペースに置き換え）。［フォントサイズ違いも対象にする］を ON にすると、サイズの違いを無視します
  - 複数のグループ：選択したすべてのグループを 1 つのシンボルに置き換えます（最前面のグループがシンボルの中身になります）
  - それ以外のオブジェクト：グローバル編集で見つかる類似したオブジェクト
- 指定した基準点で元オブジェクトの位置に揃えて、シンボルインスタンスに置き換えます
- 置換後は、新しいシンボルインスタンスを選択した状態のままにします
- ロック／非表示などで置換できなかった件数を報告します

### 使い方

1. 置き換えのもとにするオブジェクトを選択します（テキストフレーム、1つのオブジェクト、または複数のグループ）
2. スクリプトを実行し、シンボル名と基準点を指定します
3. ［OK］でシンボルを作成し、一致するオブジェクトを置き換えます

### 注意点

- 複数選択は、すべてがグループのときだけ実行できます
- 元オブジェクトのほかに一致するものが無いときは、作成したシンボルを削除して終了します
- 文字ツールで文字を選択しているときは何もしません
- シンボルの種類（ダイナミック／スタティック）は指定できません
