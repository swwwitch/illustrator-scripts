# 選択したオブジェクトをシンボルとして登録

### 概要

選択したオブジェクトを1つずつ、またはまとめてシンボルとして登録し、元のオブジェクトをシンボルインスタンスに置き換えます。
名前はテキスト内容・レイヤー名・メモ・連番から自動で付けるか、Illustrator 標準の［新規シンボル］ダイアログで確認しながら登録できます。

### 主な機能

- 選択範囲をまとめて1つのシンボルに、またはオブジェクトごとに個別のシンボルに登録
- 自動登録では、シンボル名を次の順で決定
  1. テキスト内容（テキストフレーム、またはグループ内で最初に見つかったテキストフレーム）
  2. レイヤー名（「レイヤー 1」などの既定の名前は除く）
  3. メモ（［属性］パネル）
  4. 接頭辞＋連番
- 同じ名前のシンボルがあるときは `_2`、`_3` … を付けて重複を回避
- 元のオブジェクトの位置（左上）と重なり順に合わせてインスタンスを配置
- リンク画像は、埋め込んで登録するか対象から外すかを選択
- 選択中の既存シンボルインスタンスは、そのまま残す
- 完了後に、作成したシンボル数・スルーした数・失敗の件数と詳細を表示

### 使い方

1. シンボルとして登録したいオブジェクトを選択します。
2. スクリプトを実行します。
3. ダイアログで各項目を指定し、［OK］をクリックします。

### オプション

- ［選択範囲の扱い］：［まとめて1つのシンボルにする］／［オブジェクトごとにシンボル化］
- ［登録方法］
  - ［標準ダイアログで確認］：対象ごとに Illustrator の［新規シンボル］ダイアログを開き、名前と基準点をその都度指定します
  - ［自動登録］：下の［シンボル名］と［基準点］の設定に従い、確認なしで登録します
- ［シンボル名］（自動登録のときのみ有効）
  - ［接頭辞］：テキスト内容・レイヤー名・メモから名前を取れないときに使います（空欄時は `Symbol_`）
  - ［連番］：接頭辞に続ける番号の桁数（0／00／000）
  - ［テキスト内容をシンボル名に使う］：オフにすると、レイヤー名から判定します
- ［基準点］：9軸で指定（自動登録のときのみ有効）
- ［リンク画像］
  - ［無視］：選択に残したまま、登録の対象から外します
  - ［埋め込んで登録］：埋め込んでからシンボルにします

### 注意点

- ［まとめて1つのシンボルにする］を選ぶと、登録方法は［標準ダイアログで確認］に固定されます。
- ［標準ダイアログで確認］では、対象ごとに画面を寄せて表示し、終わると元の表示に戻します。
- 連番は選択内の並び順で振るため、既存のシンボルインスタンスなど対象外のアイテムがあると番号が飛びます。
- 接頭辞・連番の桁数・各項目の初期選択は、スクリプト冒頭の「ユーザー設定」で変更できます。
- 書類内の一致するアイテムまで置き換えたい場合は [SymbolizeAndReplace](SymbolizeAndReplace.md) を使用してください。
