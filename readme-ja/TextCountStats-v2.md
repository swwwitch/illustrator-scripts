### 概要

トリミング表示を切り替え、ガイドを表示します。

### 使い方

1. 対象のドキュメントを開きます。
2. スクリプトを実行します。

### 注意点

- ファイル名に反して、TextCountStats.jsx とは無関係の2行のスクリプトです。`TrimView` と `showguide` のメニューコマンドを実行するだけです。
