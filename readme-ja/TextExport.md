### 概要

ドキュメント内のテキストを収集して一覧表示し、ファイルへ書き出します。

### 主な機能

- 対象テキストをアートボード単位（現在のアートボード／すべてのアートボード）で指定
- レイヤー単位での絞り込み
- ［ドキュメント全体を対象に］で範囲を広げる
- ［重複を削除］で同じ内容をまとめる

### 使い方

1. スクリプトを実行します。
2. 対象範囲と絞り込みを指定して一覧を確認します。
3. 書き出しを実行します。

### 注意点

- 収集したテキストをその場で編集したい場合は TextScopeEdit.jsx を使用してください。
