# 文字にマーカー・アンダーライン・取り消し線を引く

[![Direct](https://img.shields.io/badge/Direct%20Link-TextHighlighter.jsx-ffcc00.svg)](https://github.com/swwwitch/illustrator-scripts/blob/master/jsx/text/TextHighlighter.jsx)

### 概要

- 文字ツールで選んだ文字、または選択したテキストオブジェクトに、字面（文字のアウトラインの形）に合わせて、マーカー・アンダーライン・取り消し線などの線や、長方形・円・六角形・傍点を描きます。
- 文字の背面にも前面にも描けます。複数行のテキストは行ごとに描きます。
- 種類・カラー・線幅などはダイアログボックスで選び、プレビューで確かめられます。設定はプリセットとして保存できます。
- 線や図形は効果を掛けたパスなので、あとからアピアランスパネルで調整できます。

### 主な機能

ダイアログボックスは、左に［プリセット］、右に［設定］と［文字］のパネルが並びます。

#### 種類

［設定］の先頭のドロップダウンで選びます。選んでいる種類の説明は、ドロップダウンのツールチップに出ます。

- 線で引く種類
  - アンダーライン：字面のすぐ下に、線の上端を合わせて引きます。
  - マーカー：字面の下端を線の中心にして引きます（初期値）。
  - 直線＋シアー：マーカーと同じ位置で、［パスの自由変形］効果で両端を斜めにします（傾けても左右の中心はずれません）。
  - ギザギザ：マーカーと同じ位置で、［ジグザグ］効果を掛けます。
  - 手書き風：マーカーと同じ位置で、［ラフ］効果で縁を揺らします。
  - 塗りつぶし：字面の範囲を塗りつぶします（線幅は字面の高さ）。
  - 取り消し線：字面の上下中央に引きます。
  - 二重取り消し線：字面の上下中央に2本引きます。
- 図形
  - 長方形：字面を囲む長方形を、行（縦組みは列）ごとに1つ描きます。
  - 円：［長方形］と同じ範囲に内接する楕円を描きます。
  - 六角形：［長方形］と同じ範囲の左右（縦組みは上下）に、60° でとがった先を足した六角形を描きます。
  - 1文字ずつ（ドロップダウンの右）：図形を1文字ずつ描きます。高さは行の字面にそろえ、幅は字面の幅か高さの大きいほう（漢字・かなはほぼ正方形。縦組みは縦横が逆）です。［円］は長い辺を直径にした円、［六角形］は長い辺を平らな辺どうしの間隔にした正六角形です。句読点・括弧・スペースは飛ばします。
- 傍点：1文字ずつ、字の上（縦組みは右）に丸い点を置きます。句読点・括弧・スペースには付けません。

#### 設定（左の列）

- 塗りのカラー：［塗りつぶし］［傍点］と、図形の［塗り］に使います。白・文字色・カスタムから選びます（初期値は文字色）。
- 線のカラー：線で引く種類と、図形の［線］に使います。黄色（Y100）・赤（M100Y100）・文字色・カスタムから選びます（初期値は黄色）。
  - 文字色は対象の先頭の文字の塗り、カスタムは色見本をクリックして Illustrator 標準のカラーピッカーで指定します。
  - 使わないほうのカラーはディム表示になります。
- 不透明度：線・図形の不透明度です（初期値 100%）。
- 線幅：初期値は字面の高さの 40% です。単位は環境設定の［線］の単位です。
- 位置調整：種類ごとの位置から、線や図形を上下にずらします（プラスで上、マイナスで下。縦組みは左右で、プラスで左）。
- 線の種類：［直線］［破線］［ドット］から選びます。
  - 破線：［分割数］の数の線分を［間隔］をあけて、両端が線分で終わるように並べます（線分の長さを線の長さに合わせて調整）。［分割数］が空欄なら、線幅の約2倍の線分になる数にします。
  - ドット：線幅の大きさの丸い点を、点のあいだが［間隔］に近くなるように、両端に点が来るように並べます（線端は丸型になります）。
  - 間隔の初期値は線幅と同じです。
- 線端：［なし］［丸型］から選びます。

#### 設定（右の列）

- 重ね順：［前］［後］から選びます。［後］（初期値）は文字の背面に、［前］は文字の前面に描きます。
- テキスト：［白抜きに］をオンにすると、対象の文字の塗りを白にします。
- 図形：［塗り］［線］をそれぞれオンオフします。塗りは［塗りのカラー］、線は［線のカラー］［線幅］［線の種類］を使います。
- 角度：［直線＋シアー］の両端の傾き（-80〜80°、プラスで右上がり）。
- 大きさ・折り返し・ポイント：［ギザギザ］の山の高さ、端から端までの折り返しの数、［滑らか］（波線）か［直線的］（ギザギザ）。［大きさ］は［手書き風］の揺れにも使います。
- 余白：図形は字面のまわりの余白、［傍点］は字面から点までの距離です（マイナスで内側へ寄せる）。
- 角丸の半径：［長方形］の角の丸み（0 で角丸なし）。
- 複数行：複数行にわたる角丸の長方形を1続きに見せます。先頭の行の左端と最後の行の右端だけを角丸にし、行の継ぎ目は角にします（縦組みは先頭の列の上端と最後の列の下端）。
- 回転：図形を1つずつ、その中心で回転します（-360〜360°、プラスで反時計回り）。
- 線の間隔：［二重取り消し線］の2本のあいだ（初期値は字面の高さの 1/5）。
- 点の大きさ：［傍点］の点の直径。
- 行長：［揃える］をオンにすると、複数行のとき、文字数が少ない行の線や図形も、いちばん長い行の長さにそろえます（縦組みは列の長さ）。

使わない項目はディム表示になります。

#### 文字

対象の文字の書式を変えます。プレビューにも反映し、線や図形は書式を変えたあとの字面に合わせて描きます。

- カーニング：［変更しない］［0］［自動］［オプティカル］から選びます。［0］は自動カーニングを切り、手動のカーニングも 0 にします。［0］［オプティカル］はプロポーショナルメトリクスをオフにします。
- トラッキング：1/1000 em で指定します。空欄なら変更しません。
- カーニング（前）・カーニング（後）：対象の先頭の文字の前と、最後の文字の後ろに手動カーニングを入れます（1/1000 em）。空欄なら変更しません。

#### プリセット

- 左のリストでクリックすると、その設定を読み込みます。リストの下のアイコンで、今の設定に名前を付けて保存・削除できます。保存したプリセットは Illustrator を再起動しても残ります。
- 最初から用意したプリセット：アンダーライン、ドットのアンダーライン、波線、黄色のマーカー、斜めの蛍光ペン、文字色の取り消し線、二重取り消し線、角丸の長方形、囲み罫、墨消し、1文字ずつの長方形、1文字ずつの円、1文字ずつの六角形、傍点。
  - ［墨消し］［アンダーライン］［1文字ずつの長方形］以外は、線幅などの長さを先頭の対象の字面の高さに合わせます。
  - ［1文字ずつの長方形］［1文字ずつの円］［1文字ずつの六角形］［角丸の長方形］は［テキスト］の［白抜きに］がオンです。［重ね順］は［墨消し］が［前］、ほかは［後］です。
  - 最初からあるプリセットは削除できません。同じ名前で保存すると、保存したほうを使います。

#### プレビュー

オンのあいだは選択を外して、線や図形を表示します。ダイアログボックスを閉じると、元の選択に戻します。

### 使い方

1. 文字ツールで文字を選択する（またはテキストオブジェクトを選択する）
2. スクリプトを実行する
3. 左のリストでプリセットを選ぶ（または右の［設定］で種類・カラー・線幅などを選ぶ）
4. ［OK］をクリックする

### 注意点

- テキストオブジェクトを選んだときは、それぞれのすべての文字を対象にします。グループの中のテキストも対象です。ロック・非表示のテキストは除きます。
- 線幅などの初期値は、先頭の対象の1行目の字面の高さから決めます。
- 縦組みでは、線で引く種類は列ごとに縦の線を引きます。アンダーライン・マーカーなど字面の下端に合わせる種類は、字面の右端に合わせます（Illustrator の下線と同じ側）。［直線＋シアー］は上下の端を斜めにします。
- 線や図形は、元のテキストのすぐ背面（［重ね順］が［前］なら前面）に置きます。
- 実行中は［表示］＞［境界線を隠す］を切り替え、終わったら元に戻します。
- スペースや改行だけを選んだときは、字形が無いので描けません。
- ［文字色］は、対象の先頭の文字が塗りなしのときは選べません。
- プリセットに保存できるカスタムの色は RGB・CMYK・グレーだけです。
- 線幅・位置調整・間隔・ギザギザの大きさ・余白・角丸の半径・線の間隔・点の大きさは、文字の大きさに関係なく指定した長さです。
