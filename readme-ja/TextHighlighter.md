# 文字にマーカー・アンダーライン・取り消し線を引く

[![Direct](https://img.shields.io/badge/Direct%20Link-TextHighlighter.jsx-ffcc00.svg)](https://github.com/swwwitch/illustrator-scripts/blob/master/jsx/text/TextHighlighter.jsx)

### 概要

- 文字ツールで選んだ文字、または選択したテキストオブジェクトに、字面（文字のアウトラインの形）の範囲に合わせて線を引きます。線は文字の背面にも前面にも置けます。
- 種類（マーカー・アンダーライン・取り消し線・塗りつぶしなど）、カラー、線幅はダイアログボックスで選び、プレビューで確かめられます。
- 線は効果を掛けたパスなので、あとからアピアランスパネルで調整できます。

### 主な機能

- 種類
  - アンダーライン：字面のすぐ下に、線の上端を合わせて引きます。
  - マーカー：字面の下端を線の中心にして引きます（初期値）。
  - 直線＋シアー：マーカーと同じ位置で、［パスの自由変形］効果で両端を斜めにします。傾きは［角度］で指定します（-80〜80°、プラスで右上がり）。
  - ギザギザ：マーカーと同じ位置で、［ジグザグ］効果を掛けます。［大きさ］（山の高さ）と［折り返し］（端から端までの数）、［ポイント］（［滑らかに］で波線、［直線的に］でギザギザ）で指定します。
  - 手書き風：マーカーと同じ位置で、［ラフ］効果で縁を揺らします。揺れは［大きさ］で指定します。
  - 塗りつぶし：字面の範囲を塗りつぶします（線幅は字面の高さ）。
  - 取り消し線：字面の上下中央に引きます。
  - 二重取り消し線：字面の上下中央に2本引きます。2本のあいだは［線の間隔］で指定します。
  - 長方形：字面を囲む長方形を、行（縦組みは列）ごとに1つ描きます。
  - 囲み罫：［長方形］と同じ範囲を、塗りなし・線だけで囲みます。［線幅］［線の種類］を使います。
  - 円：［長方形］と同じ範囲に内接する楕円を描きます。
  - 六角形：［長方形］と同じ範囲の左右（縦組みは上下）に、60° でとがった先を足した六角形を描きます。
  - ［長方形］［囲み罫］［円］［六角形］は、まわりの余白を［余白］（マイナスで内側へ寄せる）で、［長方形］［囲み罫］は角の丸みを［角丸の半径］（0 で角丸なし）で指定します。
  - 1文字ずつ：［長方形］［囲み罫］［円］［六角形］を1文字ずつ描きます。高さは行の字面にそろえ、幅は字面の幅か高さの大きいほう（漢字・かなはほぼ正方形。縦組みは縦横が逆）で、［円］は長い辺を直径にした円、［六角形］は長い辺を平らな辺どうしの間隔にした正六角形です。傍点と同じく句読点・括弧・スペースを飛ばします。
  - 傍点：1文字ずつ、字の上（縦組みは右）に丸い点を置きます。点の直径は［点の大きさ］、字面からの距離は［余白］で指定します。句読点・括弧・スペースには付けません。
- カラー
  - 黄色（Y100）・赤（M100Y100）
  - 文字色：対象の先頭の文字の塗りを使います。
  - カスタム：色見本をクリックし、Illustrator 標準のカラーピッカーで指定します。
- 不透明度：線・長方形の不透明度です（初期値 100%）。どのカラーでも使えます。
- 線幅：初期値は字面の高さの 40% です。単位は環境設定の［線］の単位です。
- 上下位置：種類ごとの位置から、線を上下にずらします（プラスで上、マイナスで下）。
- 線の種類：［直線］［破線］［ドット］から選びます。破線は線幅の間隔で線幅の約2倍の線分を両端が線分で終わるように（線分の長さを線の長さに合わせて調整）、ドットは線幅の大きさの丸い点を線幅の約2倍の間隔で両端に点が来るように並べます（ドットは線端が丸型になります）。
- 線端：［なし］［丸型］から選びます。
- 重ね順：［前］［後］から選びます。［後］（初期値）は文字の背面に、［前］は文字の前面に描きます。
- 文字（対象の文字の書式。プレビューにも反映）
  - 自動カーニング：［変更しない］［0］［メトリクス］［オプティカル］から選びます。［0］は自動カーニングを切り、手動のカーニングも 0 にします。［0］［オプティカル］はプロポーショナルメトリクスをオフにします。
  - トラッキング：1/1000 em で指定します。空欄なら変更しません。
  - 文字を白抜きに：オンにすると、対象の文字の塗りを白にします。
  - 線や図形は、書式を変えたあとの字面に合わせて描きます。
- 線で引く種類は、線に［パスのアウトライン］効果を掛けます。［長方形］は塗りの長方形、［円］は塗りの円、［六角形］は塗りの六角形、［囲み罫］は線の長方形、［傍点］は塗りの円をグループにします。
- プリセット：ダイアログボックスの左のリストでクリックすると、その設定を読み込みます。リストの下のアイコンで、今の設定に名前を付けて保存・削除できます。保存したプリセットは Illustrator を再起動しても残ります。
  - 最初から用意したプリセット：墨消し、アンダーライン、ドットのアンダーライン、黄色のマーカー、斜めの蛍光ペン、波線、1文字ずつの長方形（ピンク）、1文字ずつの円（ピンク）、1文字ずつの六角形（青）、角丸の長方形（青）、手書き風のマーカー、囲み罫、傍点、二重取り消し線、文字色の取り消し線。［墨消し］［アンダーライン］［1文字ずつの長方形（ピンク）］以外は、線幅などの長さを先頭の対象の字面の高さに合わせます。［1文字ずつの長方形（ピンク）］［1文字ずつの円（ピンク）］［1文字ずつの六角形（青）］［角丸の長方形（青）］は［文字を白抜きに］がオンです。［重ね順］は［墨消し］が［前］、ほかは［後］です。削除はできず、同じ名前で保存すると保存したほうを使います。
- プレビュー：オンのあいだは選択を外して線を表示します。ダイアログボックスを閉じると、元の選択に戻します。

### 使い方

1. 文字ツールで文字を選択する（またはテキストオブジェクトを選択する）
2. スクリプトを実行する
3. 左のリストでプリセットを選ぶ（または右の［設定］で種類・カラー・線幅などを選ぶ）
4. ［OK］をクリックする

### 注意点

- テキストオブジェクトを選んだときは、それぞれのすべての文字に1本ずつ引きます。グループの中のテキストも対象です。ロック・非表示のテキストは除きます。
- 複数行のテキストでは、線で引く種類はすべての行をまとめた範囲に対して1本引きます（行ごとには分けません）。長方形の仲間と傍点は行ごとに描きます。
- 線で引く種類は横組み向けです。縦組みでも横向きの線になります。
- 線は元のテキストのすぐ背面（［重ね順］が［前］なら前面）に置きます。
- スペースや改行だけを選んだときは、字形が無いので引けません。
- ［文字色］は、対象の先頭の文字が塗りなしのときは選べません。
- プリセットに保存できるカスタムの色は RGB・CMYK・グレーだけです。
- 線幅・上下位置・ギザギザの大きさ・余白・角丸の半径・線の間隔・点の大きさは、文字の大きさに関係なく指定した長さです。
