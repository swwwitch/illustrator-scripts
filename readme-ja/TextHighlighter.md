# 文字にマーカー・アンダーライン・取り消し線を引く

[![Direct](https://img.shields.io/badge/Direct%20Link-TextHighlighter.jsx-ffcc00.svg)](https://github.com/swwwitch/illustrator-scripts/blob/master/jsx/text/TextHighlighter.jsx)

### 概要

- 文字ツールで選んだ文字、または選択したテキストオブジェクトに、字面（文字のアウトラインの形）に合わせて、マーカー・アンダーライン・取り消し線などの線や、長方形・円・六角形・傍点を描きます。
- 文字の背面にも前面にも描けます。複数行のテキストは行ごとに描き、行頭や長さ、行送りの間隔をそろえることもできます。
- 種類・カラー・線幅などはダイアログボックスで選び、プレビューで確かめられます。設定はプリセットとして保存できます。
- 対象の文字のカラー・カーニング・トラッキングも一緒に変えられます。行ごとの図形では、図形の余白に合わせて前後のカーニングを自動であけられます（手で微調整も可）。
- 線や図形は効果を掛けたパスなので、あとからアピアランスパネルで調整できます。

### 主な機能

ダイアログボックスは、左に［プリセット］、右に［設定］と［文字］のパネルが並びます。

#### 種類

［設定］の先頭のドロップダウンで選びます。選んでいる種類の説明は、ドロップダウンのツールチップに出ます。

- 線で引く種類
  - アンダーライン：字面のすぐ下に、線の上端を合わせて引きます。
  - マーカー：字面の下端を線の中心にして引きます（初期値）。
  - 直線＋シアー：マーカーと同じ位置で、［パスの自由変形］効果で両端を斜めにします（傾けても左右の中心はずれません）。
  - ギザギザ：マーカーと同じ位置で、［ラフ］効果（大きさ 0）でポイントを足してから、［ジグザグ］効果（折り返し 0）を掛けます。線の長さにかかわらず、山の間隔がそろいます。
  - 塗りつぶし：字面の範囲を塗りつぶします（線幅は字面の高さ）。
  - 取り消し線：字面の上下中央に引きます。
  - 二重取り消し線：字面の上下中央に2本引きます。
- 図形
  - 長方形：字面を囲む長方形を、行（縦組みは列）ごとに1つ描きます。
  - 円：［長方形］と同じ範囲に内接する楕円を描きます。
  - 六角形：［長方形］と同じ範囲の左右（縦組みは上下）に、60° でとがった先を足した六角形を描きます。
  - 単位（［設定］の右の列）：［行］（初期値）は図形を行（縦組みは列）ごとに1つ、［1文字ずつ］は1文字ずつ描きます。［1文字ずつ］の高さは行の字面にそろえ、幅は字面の幅か高さの大きいほう（漢字・かなはほぼ正方形。縦組みは縦横が逆）です。［円］は長い辺を直径にした円、［六角形］は長い辺を平らな辺どうしの間隔にした正六角形です。句読点・括弧・スペースは飛ばします。
- 傍点：1文字ずつ、字の上（縦組みは右）に丸い点を置きます。句読点・括弧・スペースには付けません。

#### 設定（塗りと線。2つの列にまたがる行）

- 重ね順（［種類］の右）：［前］［後］から選びます。［後］（初期値）は文字の背面に、［前］は文字の前面に描きます。
- 塗り：［塗りつぶし］［傍点］と、図形の塗りのカラーです。カスタム・文字色・白から選びます（初期値は文字色）。先頭の［描画］をオンにすると、図形（長方形・円・六角形）を塗ります（初期値はオン）。
- 線：線で引く種類と、図形の線のカラーです。カスタム・文字色・黄色（Y100）・赤（M100Y100）から選びます（初期値は黄色）。先頭の［描画］をオンにすると、図形に線を付けます（［線幅］［線の種類］を使います。初期値はオフ）。
  - 文字色は対象の先頭の文字の塗り、カスタムは色見本をクリックして Illustrator 標準のカラーピッカーで指定します。
  - 使わないほうのカラーはディム表示になります。［描画］は図形のときだけ使えます。

#### 設定（左の列：線と効果）

- 線幅：初期値は字面の高さの 40% です。単位は環境設定の［線］の単位です。
- 線の種類：［直線］［破線］［ドット］から選びます。
  - 破線：［分割数］の数の線分を［間隔］をあけて、両端が線分で終わるように並べます（線分の長さを線の長さに合わせて調整）。［分割数］が空欄なら、線幅の約2倍の線分になる数にします。
  - ドット：線幅の大きさの丸い点を、点のあいだが［間隔］に近くなるように、両端に点が来るように並べます（線端は丸型になります）。
  - 間隔の初期値は線幅と同じです。
- 線端：［なし］［丸型］から選びます。
- 線の間隔：［二重取り消し線］の2本のあいだ（初期値は字面の高さの 1/5）。
- 角度：［直線＋シアー］の両端の傾き（-80〜80°、プラスで右上がり）。
- 大きさ・折り返し・ポイント：［ギザギザ］の山の高さ、線の長さ1インチ（25.4 mm）あたりの折り返しの数、［滑らか］（波線）か［直線的］（ギザギザ）。［折り返し］は［手書き風］の［ラフ］効果の詳細にも使います（［ギザギザ］と［手書き風］を一緒に使うと同じ数になります）。
- ラフ：［手書き風］をオンにすると、線や図形に［ラフ］効果（ポイントはギザギザ）を掛けて、縁を手書きのように揺らします（線で引く種類は、［パスのアウトライン］の前に中心線へ掛けます）。［サイズ］は線や図形の大きさに対する％（初期値 1%）で、詳細には［折り返し］の値（1インチあたりの数）を使います。［傍点］以外のすべての種類で使えます。

#### 設定（右の列：配置と大きさ）

- 不透明度：線・図形の不透明度です（初期値 100%）。
- 位置調整：種類ごとの位置から、線や図形を上下にずらします（プラスで上、マイナスで下。縦組みは左右で、プラスで左）。
- 余白（横）・余白（縦）：図形は字面のまわりの左右・上下の余白、［傍点］は字面から点までの距離です（横組みは［余白（縦）］、縦組みは［余白（横）］を使う。マイナスで内側へ寄せる）。右のリンクアイコンがオンのあいだは、2つを同じ値にします（初期値はオン）。
- 行長：複数行のときの、行ごとの線や図形のそろえ方です。
  - 行頭：線や図形の始まりを、いちばん前から始まる行にそろえます（縦組みは列の上端）。行末はそろえません。
  - 行頭行末：文字数が少ない行の線や図形も、いちばん長い行の長さにそろえます（縦組みは列の長さ）。
  - ［行頭］と［行頭行末］はどちらか一方だけをオンにできます。線で引く種類と、［単位］が［行］の図形で使えます。
- 行の高さ：［行送り基準］をオンにすると、線・図形・傍点の位置と大きさを、行の字面の高さ（縦組みは幅）ではなく行送りで決めます。どの行も同じ高さで、行の文字の中央に置き、続けて並ぶ行は行送りちょうどの間隔で並べます（段落前後のアキや空行のところは、そこから並べ直します）。すべての種類で使えます。［塗りつぶし］は行送りの太さ、［1文字ずつ］は行送りの大きさになります。
- 角丸の半径：［長方形］の角の丸み（0 で角丸なし）。
- 連続処理：［複数行］をオンにすると、複数行にわたる角丸の長方形を1続きに見せます。先頭の行の左端と最後の行の右端だけを角丸にし、行の継ぎ目は角にします。［線］の［描画］がオンなら、行の継ぎ目の辺（先頭の行以外の左辺と、最後の行以外の右辺）の線を開けます（縦組みは先頭の列の上端と最後の列の下端、継ぎ目は上辺・下辺）。
- 回転：図形を1つずつ、その中心で回転します（-360〜360°、プラスで反時計回り）。
- 点の大きさ：［傍点］の点の直径。

使わない項目はディム表示になります。

#### 文字

対象の文字の書式を変えます。プレビューにも反映し、線や図形は書式を変えたあとの字面に合わせて描きます。

- テキストカラー：線や図形を描いたあと、対象の文字の塗りを変えます。カスタム・変更しない（初期値）・白から選びます。カスタムは色見本をクリックして Illustrator 標準のカラーピッカーで指定します。
- カーニング：［変更しない］［0］［自動］［オプティカル］から選びます。［0］は自動カーニングを切り、手動のカーニングも 0 にします。［0］［オプティカル］はプロポーショナルメトリクスをオフにします。
- カーニング（前）・カーニング（後）：対象の先頭の文字の前と、最後の文字の後ろに手動カーニングを入れます（1/1000 em）。空欄なら変更しません。
- トラッキング：1/1000 em で指定します。空欄なら変更しません。
- 余白に合わせてカーニングを自動調整：［長方形］［円］［六角形］を［単位］の［行］で描くとき、カーニング（前・後）を［余白（横）］÷ 文字サイズ × 1000 にして、図形のぶん前後をあけます（初期値はオン。縦組みは［余白（縦）］。文字サイズは対象の先頭と最後の文字、余白が 0 以下なら変更しない）。オンのあいだは、カーニング（前・後）の欄に先頭の対象で計算した値を出します。欄の値を変えると、計算した値との差を微調整として控え、余白を変えても足し続けます（欄を空にすると微調整なし）。微調整はプリセットにも保存します。

#### プリセット

- 左のリストでクリックすると、その設定を読み込みます。リストの下のアイコンは、左端が［削除］、右端が［保存］（今の設定に名前を付けて保存）と［上書き保存］（選んでいるプリセットに、名前を尋ねず確認もせずに今の設定を書き込む）です。保存したプリセットは Illustrator を再起動しても残ります。
- 最初から用意したプリセット（［種類］の順）：アンダーライン、ドットのアンダーライン、黄色のマーカー、黄色のマーカー（手書き風）、斜めの蛍光ペン、波線、ギザギザ、文字色の取り消し線、二重取り消し線、角丸の長方形、行ごとに帯、行ごとに帯（隣接）、行ごとに帯（手書き風）、囲み罫、囲み罫（角丸）、囲み罫（行ごと）、囲み罫（行ごと）手書き風、墨消し、1文字ずつの長方形、1文字ずつの円、1文字ずつの六角形、傍点。
  - ［文字色の取り消し線］［二重取り消し線］は、線幅などの長さを先頭の対象の字面の高さに合わせます。ほかは決まった長さです。
  - ［角丸の長方形］［行ごとに帯］［行ごとに帯（隣接）］［行ごとに帯（手書き風）］［1文字ずつの長方形］［1文字ずつの円］［1文字ずつの六角形］は［テキストカラー］が白です。［重ね順］はどれも［後］です。
  - ［行ごとに帯］は行ごとの長方形を、すき間をあけて1続きに見せます（［複数行］オン）。［行ごとに帯（隣接）］はすき間なしで、［複数行］はオフです。どちらも［行頭］［行送り基準］がオンです。
  - ［囲み罫（角丸）］は［囲み罫］の［角丸の半径］を 1 mm にしたものです。
  - ［囲み罫（行ごと）］は［囲み罫］を、［行頭］をオン・［複数行］をオフにして行ごとに描きます。
  - 「手書き風」の付くプリセットは、［ラフ］の［手書き風］がオンです（［黄色のマーカー（手書き風）］はサイズ 1%・詳細 10、［行ごとに帯（手書き風）］は 0.7%・3、［囲み罫（行ごと）手書き風］は 0.4%・10）。
  - ［1文字ずつ］の3つは、［文字］の［カーニング］を［0］、［トラッキング］を 170 にします。行ごとに描く図形のプリセットは［余白に合わせてカーニングを自動調整］がオンです。
  - どのプリセットも、［行長］［行の高さ］［ラフ］と［文字］の設定を持っているので、選び直すとそれらも切り替わります。
  - 設定を変えるとリストの選択が外れ、同じプリセットをクリックし直すと、その設定に戻ります。選択が外れたあとも、［上書き保存］は直前に選んでいたプリセットに書き込み（ツールチップに名前が出ます）、［保存］の名前の初期値もそのプリセットの名前です。
  - 最初からあるプリセットを［上書き保存］すると、同じ名前の保存したプリセットになります。削除すると最初の設定に戻ります。
  - 最初からあるプリセットは削除できません。同じ名前で保存すると、保存したほうを使います。

#### プレビューとリセット

ダイアログボックスを開いているあいだは、選択を外して、線や図形を常にプレビューします。閉じると、元の選択に戻します。
［リセット］は、ダイアログボックスを開いたときの設定と、選んでいたプリセットに戻します。カーニング（前・後）とトラッキングは空欄にし、［余白に合わせてカーニングを自動調整］はオフにします。

#### 前回の状態

ダイアログボックスを閉じたとき（［OK］でも［キャンセル］でも）の設定と選んでいたプリセットを覚え、次に開いたときに戻します。覚えておくのは Illustrator を終了するまでで、起動して最初に開いたときは、プリセット［黄色のマーカー］を選んだ状態になります。

### 使い方

1. 文字ツールで文字を選択する（またはテキストオブジェクトを選択する）
2. スクリプトを実行する
3. 左のリストでプリセットを選ぶ（または右の［設定］で種類・カラー・線幅など、［文字］でテキストカラー・カーニングなどを選ぶ）
4. ［OK］をクリックする

### 注意点

- テキストオブジェクトを選んだときは、それぞれのすべての文字を対象にします。グループの中のテキストも対象です。ロック・非表示のテキストは除きます。
- 線幅などの初期値は、先頭の対象の1行目の字面の高さから決めます。
- 縦組みでは、線で引く種類は列ごとに縦の線を引きます。アンダーライン・マーカーなど字面の下端に合わせる種類は、字面の右端に合わせます（Illustrator の下線と同じ側）。［直線＋シアー］は上下の端を斜めにします。
- 線や図形は、元のテキストのすぐ背面（［重ね順］が［前］なら前面）に置きます。
- 実行中は［表示］＞［境界線を隠す］を切り替え、終わったら元に戻します。
- スペースや改行だけを選んだときは、字形が無いので描けません。
- ［文字色］は、対象の先頭の文字が塗りなしのときは選べません。
- プリセットに保存できるカスタムの色は RGB・CMYK・グレーだけです。
- 線幅・位置調整・間隔・ギザギザの大きさ・余白（横）・余白（縦）・角丸の半径・線の間隔・点の大きさは、文字の大きさに関係なく指定した長さです。
