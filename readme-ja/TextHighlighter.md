# 文字にマーカー・アンダーライン・取り消し線を引く

[![Direct](https://img.shields.io/badge/Direct%20Link-TextHighlighter.jsx-ffcc00.svg)](https://github.com/swwwitch/illustrator-scripts/blob/master/jsx/text/TextHighlighter.jsx)

### 概要

- 文字ツールで選んだ文字、または選択したテキストオブジェクトに、字面（文字のアウトラインの形）の範囲に合わせて線を引きます。線は文字の背面にも前面にも置けます。
- 種類（マーカー・アンダーライン・取り消し線・塗りつぶしなど）、カラー、線幅はダイアログボックスで選び、プレビューで確かめられます。
- 線は効果を掛けたパスなので、あとからアピアランスパネルで調整できます。

### 主な機能

- 種類
  - アンダーライン：字面のすぐ下に、線の上端を合わせて引きます。
  - マーカー：字面の下端を線の中心にして引きます（初期値）。
  - 直線＋シアー：マーカーと同じ位置で、［パスの自由変形］効果で両端を斜めにします。傾きは［角度］で指定します（-80〜80°、プラスで右上がり）。
  - ギザギザ：マーカーと同じ位置で、［ジグザグ］効果を掛けます。［大きさ］（山の高さ）と［折り返し］（端から端までの数）、［ポイント］（［滑らかに］で波線、［直線的に］でギザギザ）で指定します。
  - 手書き風：マーカーと同じ位置で、［ラフ］効果で縁を揺らします。揺れは［大きさ］で指定します。
  - 塗りつぶし：字面の範囲を塗りつぶします（線幅は字面の高さ）。
  - 取り消し線：字面の上下中央に引きます。
  - 二重取り消し線：字面の上下中央に2本引きます。2本のあいだは［線の間隔］で指定します。
  - 長方形：字面を囲む長方形を、行（縦組みは列）ごとに1つ描きます。
  - 円：［長方形］と同じ範囲に内接する楕円を描きます。
  - 六角形：［長方形］と同じ範囲の左右（縦組みは上下）に、60° でとがった先を足した六角形を描きます。
  - ［長方形］［円］［六角形］は、［図形］の［塗り］［線］をそれぞれオンオフできます。塗りは［塗りのカラー］、線は［線のカラー］で付け、線は［線幅］［線の種類］を使います。まわりの余白は［余白］（マイナスで内側へ寄せる）で、［長方形］は角の丸みを［角丸の半径］（0 で角丸なし）で指定します。［複数行］をオンにすると、複数行にわたる角丸の長方形を1続きに見せます（先頭の行の左端と最後の行の右端だけを角丸にし、行の継ぎ目は角にします。縦組みは先頭の列の上端と最後の列の下端）。［回転］（-360〜360°、プラスで反時計回り）で、図形を1つずつその中心で回転できます。
  - 1文字ずつ：［長方形］［円］［六角形］を1文字ずつ描きます。高さは行の字面にそろえ、幅は字面の幅か高さの大きいほう（漢字・かなはほぼ正方形。縦組みは縦横が逆）で、［円］は長い辺を直径にした円、［六角形］は長い辺を平らな辺どうしの間隔にした正六角形です。傍点と同じく句読点・括弧・スペースを飛ばします。
  - 傍点：1文字ずつ、字の上（縦組みは右）に丸い点を置きます。点の直径は［点の大きさ］、字面からの距離は［余白］で指定します。句読点・括弧・スペースには付けません。
- 塗りのカラー・線のカラー
  - 線のカラー：アンダーライン・マーカー・取り消し線などの線と、［長方形］［円］［六角形］の［線］に使います。
  - 塗りのカラー：［塗りつぶし］［傍点］と、［長方形］［円］［六角形］の［塗り］に使います。
  - 線のカラーは黄色（Y100）・赤（M100Y100）・文字色・カスタム、塗りのカラーは白・文字色・カスタムから選びます。文字色は対象の先頭の文字の塗り、カスタムは色見本をクリックして Illustrator 標準のカラーピッカーで指定します。初期値は、線のカラーが黄色、塗りのカラーが文字色です。
  - 使わないほうはディム表示になります。
- 不透明度：線・長方形の不透明度です（初期値 100%）。どのカラーでも使えます。
- 文字を白抜きに：オンにすると、対象の文字の塗りを白にします（プレビューにも反映）。［設定］の右の列の、［図形］の上にあります。
- 線幅：初期値は字面の高さの 40% です。単位は環境設定の［線］の単位です。
- 上下位置：種類ごとの位置から、線を上下にずらします（プラスで上、マイナスで下）。
- 線の種類：［直線］［破線］［ドット］から選びます。
  - 破線：［分割数］の数の線分を［間隔］をあけて、両端が線分で終わるように並べます（線分の長さを線の長さに合わせて調整）。
  - ドット：線幅の大きさの丸い点を、点のあいだが［間隔］に近くなるように、両端に点が来るように並べます（線端は丸型になります）。
  - 分割数・間隔：分割数（破線だけ）は線ごとの線分の数で、空欄なら線幅の約2倍の線分になる数にします。間隔は線分のあいだ・点のあいだの長さで、初期値は線幅と同じです。
- 線端：［なし］［丸型］から選びます。
- 行長を揃える：複数行のとき、文字数が少ない行の線や図形も、いちばん長い行の長さにそろえます（縦組みは列の長さ。線で引く種類は横組みだけ。［1文字ずつ］では使いません）。
- 重ね順：［前］［後］から選びます。［後］（初期値）は文字の背面に、［前］は文字の前面に描きます。
- 文字（対象の文字の書式。プレビューにも反映）
  - カーニング：［変更しない］［0］［自動］［オプティカル］から選びます。［0］は自動カーニングを切り、手動のカーニングも 0 にします。［0］［オプティカル］はプロポーショナルメトリクスをオフにします。
  - トラッキング：1/1000 em で指定します。空欄なら変更しません。
  - カーニング（前）・カーニング（後）：対象の先頭の文字の前と、最後の文字の後ろに手動カーニングを入れます（1/1000 em）。空欄なら変更しません。後ろに文字が無いときは、［カーニング（後）］は使いません。
  - 線や図形は、書式を変えたあとの字面に合わせて描きます。
- 線で引く種類は、線に［パスのアウトライン］効果を掛けます。［長方形］［円］［六角形］はその図形（［図形］に合わせて塗り・線）、［傍点］は塗りの円をグループにします。
- プリセット：ダイアログボックスの左のリストでクリックすると、その設定を読み込みます。リストの下のアイコンで、今の設定に名前を付けて保存・削除できます。保存したプリセットは Illustrator を再起動しても残ります。
  - 最初から用意したプリセット：アンダーライン、ドットのアンダーライン、波線、黄色のマーカー、斜めの蛍光ペン、文字色の取り消し線、二重取り消し線、角丸の長方形、囲み罫、墨消し、1文字ずつの長方形、1文字ずつの円、1文字ずつの六角形、傍点。［墨消し］［アンダーライン］［1文字ずつの長方形］以外は、線幅などの長さを先頭の対象の字面の高さに合わせます。［1文字ずつの長方形］［1文字ずつの円］［1文字ずつの六角形］［角丸の長方形］は［文字を白抜きに］がオンです。［重ね順］は［墨消し］が［前］、ほかは［後］です。削除はできず、同じ名前で保存すると保存したほうを使います。
- プレビュー：オンのあいだは選択を外して線を表示します。ダイアログボックスを閉じると、元の選択に戻します。

### 使い方

1. 文字ツールで文字を選択する（またはテキストオブジェクトを選択する）
2. スクリプトを実行する
3. 左のリストでプリセットを選ぶ（または右の［設定］で種類・カラー・線幅などを選ぶ）
4. ［OK］をクリックする

### 注意点

- テキストオブジェクトを選んだときは、それぞれのすべての文字に1本ずつ引きます。グループの中のテキストも対象です。ロック・非表示のテキストは除きます。
- 複数行のテキストでは、線で引く種類・長方形の仲間・傍点とも行ごとに描きます（縦組みの線で引く種類は、選んだ範囲全体に1本）。線幅などの初期値は、先頭の対象の1行目の字面の高さから決めます。
- 線で引く種類は横組み向けです。縦組みでも横向きの線になります。
- 線は元のテキストのすぐ背面（［重ね順］が［前］なら前面）に置きます。
- スペースや改行だけを選んだときは、字形が無いので引けません。
- ［文字色］は、対象の先頭の文字が塗りなしのときは選べません。
- プリセットに保存できるカスタムの色は RGB・CMYK・グレーだけです。
- 線幅・上下位置・ギザギザの大きさ・余白・角丸の半径・線の間隔・点の大きさは、文字の大きさに関係なく指定した長さです。
