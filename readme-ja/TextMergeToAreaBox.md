# PDFをイラレで開いたときのバラバラ文字を、ひとつのエリア内文字に再構成するスクリプト

### 概要

- PDFをIllustratorで開いたときのように、細かく分割されたテキストオブジェクトを1つのエリア内文字に再構成します。
- Y座標が近いオブジェクトを同じ行としてまとめ、行内は左から右の順に連結します。
- 元のテキストのフォント・サイズ・幅・行送りを引き継ぎます。
- 元のテキストオブジェクトは削除され、生成されたエリア内文字に置き換わります。

### 使い方

1. 再構成したいテキストオブジェクトをすべて選択します。
2. スクリプトを実行します。
3. 選択範囲がエリア内文字に置き換わり、そのまま選択状態になります。

テキストフレーム以外のオブジェクトが選択に含まれていても無視されます。テキストが1つも含まれていない場合は「変換できるテキストはありません。」と表示して終了します。

### 連結と改行のルール

行を連結するとき、直前の行の行末と次の行の行頭を見て処理を切り替えます。

| 直前の行の行末 | 次の行の行頭 | 処理 |
| --- | --- | --- |
| 英数字または `)` | 英数字または `(` | 半角スペースを挿入 |
| 英数字＋ハイフン | 英数字または `(` | ハイフンを削除して結合 |
| 「。」「！」「？」 | — | 改行する |
| 半角の「.」「!」「?」 | — | 改行する |
| 上記以外 | — | 改行せずそのまま連結 |

和文・欧文を問わず、行末が文末の約物で終わっていれば改行します。そのため「Fig.」「etc.」のような略語で行が終わっている場合は、文が続いていても改行が入ります。

### 引き継がれる書式

| 項目 | 内容 |
| --- | --- |
| フォント・サイズ | 一番上の行から引き継ぎます |
| 幅 | 選択範囲全体の外接矩形の幅から、フォントサイズ1文字分だけ狭くします（狭くなりすぎる場合は最低1文字分を確保） |
| 高さ | 選択範囲全体の外接矩形の高さを使い、最終行があふれる場合は下方向に伸ばします（上端は動きません） |
| 行送り | 1行目と2行目のY座標の差を行送りとして使います（自動行送りはOFF） |
| 行揃え | 両端揃え（最終行左揃え） |
| 禁則 | 「弱い禁則 v2」を適用します（テキスト全体に設定するため［段落］パネルにも反映されます）。この禁則がないバージョンでは「弱い禁則」にフォールバックします |
| 組み方向 | 縦組みのテキストも横組みに統一されます |

行送りが求めた値でフォントサイズを下回るときは、フォントサイズの1.2倍を使います。

### 1行だけを選択したとき

行が1つしかない場合は、エリア内文字には変換せず、左から右へ連結した1つのポイント文字にまとめて左揃えにします。

### 設定値

スクリプト冒頭の「ユーザー設定」で調整できます。

| 変数 | 初期値 | 内容 |
| --- | --- | --- |
| `LINE_Y_THRESHOLD` | 5 | 同じ行と見なすY座標差の閾値（pt） |
| `MIN_LEADING_RATIO` | 1.2 | 行送りの最小倍率（フォントサイズ基準） |
| `DEFAULT_KINSOKU` | `"Soft_v2"` | 適用する禁則（`None` / `Hard` / `Soft` / `Soft_v2`） |
| `FALLBACK_KINSOKU` | `"Soft"` | `DEFAULT_KINSOKU` が使えないバージョンで適用する禁則 |
| `AREA_TEXT_JUSTIFICATION` | 両端揃え（最終行左揃え） | 適用する行揃え |
| `MAX_HEIGHT_GROW_STEPS` | 20 | あふれ解消で枠を下に伸ばす最大回数（1回につき行送り1行分） |

行が意図せず分かれてしまう、または別の行が1行にまとまってしまう場合は `LINE_Y_THRESHOLD` を調整してください。

### 処理の流れ

1. ドキュメントが開いているか確認
2. 選択からテキストフレームだけを集め、Y座標で上から下へ並べる
3. Y座標が近いものを同じ行としてグループ化
4. 行ごとにX順で連結し、1行1フレームにまとめる
5. 行末・行頭のルールに従って全行を1つの文字列に連結
6. 全体の外接矩形から長方形を作り、エリア内文字に変換して流し込む
7. フォント・サイズ・行送り・行揃え・禁則を設定
8. テキストがあふれていれば枠を下に伸ばし、連結元のフレームを削除

### 注意点

- 元のテキストオブジェクトは削除されます。残したい場合は複製してから実行してください。
- 行送りは見かけのY座標差から計算するため、段落前後のアキには対応しません。
- 縦組みのテキストも横組みに変換されます。
- 行の判定はフレームの位置（左上）を基準にするため、同じ行でもフォントサイズが大きく異なると別の行と判定されることがあります。
- 略語（「Fig.」「etc.」など）で行が終わっていると、文が続いていても改行が入ります。
- あふれ解消で枠を伸ばすため、生成されるエリア内文字の下端は元の外接矩形より下がることがあります。
