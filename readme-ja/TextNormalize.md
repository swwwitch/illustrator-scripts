### 概要

選択したテキストを、ダイアログで指定したルールに従って整形します。

### 主な機能

- 行頭・行末のスペース削除
- ナンバリングの削除と振り直し
- 強制改行⇔改行の変換
- 空行の整理（連続改行の圧縮）
- タブ→半角スペース
- 全角英数字を半角に

### 使い方

1. 対象のテキストを選択します。
2. スクリプトを実行します。
3. 各パネルで処理を選び、プレビューを確認して適用します。

### 注意点

- ナンバリングは［リセット］でダイアログ初期状態へ戻し、再プレビューできます。
