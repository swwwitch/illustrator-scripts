### 概要

ドキュメント内のテキストを収集して一覧表示し、その場で編集してドキュメントへ書き戻します。

### 主な機能

- 対象テキストをアートボード単位（現在のアートボード／すべてのアートボード）で指定
- レイヤー単位での絞り込み
- ［同じ内容を一括編集］で、同一のテキストをまとめて書き換え
- ［ドキュメント全体を対象に］で範囲を広げる

### 使い方

1. スクリプトを実行します。
2. 対象範囲を指定して一覧を確認します。
3. 一覧上でテキストを編集し、適用します。

### 注意点

- 書き出しだけが目的の場合は TextExport.jsx を使用してください。
