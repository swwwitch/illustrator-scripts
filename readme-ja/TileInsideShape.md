# 大きいオブジェクトの形の内側に小さいオブジェクトを敷き詰める

### 概要

オブジェクトを2つ以上選択し、いちばん大きいものの形の内側に、ほかのオブジェクトを複製して敷き詰めます。
形からはみ出すものは残さず（マスクして残すこともできます）、元のオブジェクトはそのまま残します。

<img alt="オブジェクトの内側に敷き詰めダイアログボックスの外観" src="../png/ss-724-1090-144-20261027-130407-s.png" width="35%" />

### 主な機能

- パスの内側に収まるものだけを残す。曲線や凹んだ形、複合パスの穴にも対応。グループは構成するオブジェクトそれぞれの形の内側で判定（クリップグループはクリッピングパスの形）。テキストはアウトライン化した字形の内側で判定（複製をアウトライン化して測り、測ったあとは削除するので元のテキストは変わらない）。配置画像などそれ以外は外接矩形の内側で判定
- ［はみ出しも残してマスク］で、形からはみ出すタイルも残し、敷き詰め先の形でマスクできる（グループ・テキストのマスクは輪郭を折れ線にした複合パス）
- 並べ方を［グリッド］［レンガ状（横）］［レンガ状（縦）］［六角形］［ランダム（順番）］［ランダム（ランダム）］から選べる（初期値は［レンガ状（横）］）。［六角形］は行の間を詰めて円形のタイルを隙間なく並べる。2つの［ランダム］は間隔を空けて重ならないように置き、［密度］で残す割合を決められる。［再配置］で並び・ばらつき・選び方を引き直す
- ［中央にそろえる］で、並びを敷き詰め先の中心にそろえ、余白を均等にする（初期値はオン。中心にタイルを置くか間を置くかは、多く収まる方）
- ［並びの角度］で、並び全体をタイルごと回せる
- ［間隔（横）］［間隔（縦）］を別々に指定できる（リンクアイコンで連動）
- ［調整X］［調整Y］で、敷き詰める位置をずらせる（正の値で右・下へ。スライダーは中央がずらさない位置で、端で並びの周期の半分ずれる）
- ［個別に回転］パネルで、［回転］・［1つおきに180°回転］を指定できる。数値の項目の［回転］［大きさ］で、タイルごとの回転・大きさにランダムなばらつき（ゆらぎ）を付けられる（0 ならばらつかない）
- 敷き詰めるオブジェクトにテキストも使える。大きさ・間隔・収まりは文字の枠ではなく字形の範囲で判定し、字形の中心を置く位置に合わせる（グループの中のテキストも）
- 敷き詰めるオブジェクトを複数選ぶと、選択の前面から順に使う。［ランダム（ランダム）］のときだけ、どれを使うかもランダムに選ぶ
- ［スケール］［間隔］［オフセット］［調整X］［調整Y］［並びの角度］とゆらぎの［回転］［大きさ］、ランダムの［密度］は入力欄とスライダーのどちらでも変えられる。長さの単位はIllustratorのルーラー設定に追従
- 敷き詰め先のパスをオフセットした形に収める（負の値で内側に縮め、正の値ではみ出しを許す）
- ［スケール］のスライダーの右に、今の設定で置かれるタイルの数を表示。［プレビュー］はオフにもできる
- 元のオブジェクトはそのまま残す。［敷き詰め先］で、その不透明度を下げる・削除する・ガイド化することもできる
- シンボル化しての複製（初期値はオン）
- ［OK］で確定した設定を Illustrator の終了まで覚え、次に開いたときの初期値にする

### 使い方

1. 敷き詰め先のオブジェクトと、敷き詰めるオブジェクト（複数可）を選択します。いちばん大きいものが敷き詰め先になります。
2. スクリプトを実行します。
3. スケールや間隔などを指定して実行します。
