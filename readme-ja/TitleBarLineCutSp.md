### 概要

選択したオブジェクトの周りで、罫線を欠けさせます。

### 主な機能

- オフセットと線幅を指定
- 線端（なし／丸型線端）と角の形状（マイター／ラウンド／ベベル）を指定
- 日本語／英語UI

### 使い方

1. 対象のオブジェクトを選択します。
2. スクリプトを実行します。
3. オフセットと線の設定を指定して［OK］をクリックします。

### 注意点

- 帯（長方形）とセットで扱いたい場合は TitleBarLineCut.jsx を使用してください。
