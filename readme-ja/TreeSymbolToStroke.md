### 概要

選択したテキストのツリー記号（├─・└─・│ や tree コマンドの ├── など）をパスの罫線に変換し、字下げと名前・説明のあいだの空きをタブにします。
各行を囲み罫で囲むこともでき、罫線・タブストップ・囲み罫はプレビューを見ながら調整できます。

<img alt="ツリー記号を罫線に変換するダイアログの外観" src="../png/ss-1020-918-144-20261001-044120.png" width="50%" />

### 主な機能

- ├─・└─・│（太字の ┣・┗・┃・━、tree コマンドの ├── を含む）を、パスの罫線に変換
- 記号はテキストから削除し、名前の位置は変えない
- 行頭の字下げをタブにし、階層（レベル）ごとにタブストップを1つずつ置く
- 名前と説明のあいだに2つ以上続くスペースをタブにし、説明を1列にそろえる
- 縦線は行と行のあいだもつなぎ、子の └ は親の横線から、いちばん上の縦線は最初の項目の下から下ろす
- 各行を長方形の罫線で囲む（囲み罫）。右端はいちばん長い行にそろえるか、行ごとにするかを選べ、横線は囲みにつなげられる
- ダイアログを開いているあいだは、変換後の結果を常にプレビュー
- 日本語／英語UI

### 使い方

1. ツリー記号を含むテキストを選択します（グループの中のテキストや、文字を編集中のテキストでもかまいません）。
2. スクリプトを実行します。
3. 線や位置を調整し、［OK］をクリックします。［キャンセル］なら元のテキストと表示に戻ります。

罫線（囲み罫を含む）は、作業中のレイヤーに「ツリー罫線」という名前のグループで作られます。

### オプション

| パネル | 項目 | 内容 |
| --- | --- | --- |
| 罫線 | 線幅 | 罫線の太さ（単位は環境設定の［線］） |
| 罫線 | 線端 | 丸型／なし。角の形状は連動して、丸型ならラウンド、なしならマイター |
| 罫線 | カラー | ■をクリックすると標準のカラーピッカー。横の欄に16進数（RRGGBB）でも入力できる |
| 罫線 | 横線を囲み罫につなげる | 横線を囲み罫の左辺まで伸ばしてつなげる（［囲み罫］がオンのとき） |
| テキスト | 行送り | テキスト全体の行送り。変えると固定値になる |
| テキスト | 行頭の字下げをタブに変換 | 字下げをタブにして、名前の位置にタブストップを置く。オフのときは記号の跡をカーニングで埋める |
| テキスト | 連続したスペースをタブに変換 | 名前と説明のあいだの空きをタブにして、説明をそろえる |
| テキスト | 囲み罫 | 各行を長方形の罫線で囲む。線幅・線端・カラーは罫線と同じ |
| テキスト | 左右／上下 | 文字から囲み罫までの間隔（単位は定規、初期値は文字サイズの1/8）。右のリンクアイコン（連動）をオンにすると同じ値になる |
| テキスト | 右端を揃える | オンで囲み罫の右端をいちばん長い行にそろえる。オフなら行ごとの文字の右端で囲む |
| テキスト | 行ごとに分割 | テキストを行ごとに分割し、それぞれの囲み罫とグループ化する（プレビューには出ず、OKで実行） |
| タブストップ | レベル 1〜／説明 | 階層ごとの名前と、説明の列のタブストップの位置 |
| 縦罫 | 縦罫 1〜 | 縦線の横位置 |
| （下部） | 制御文字 | 制御文字の表示を切り替える |
| （下部） | 画面にフィット | プレビューが指定の割合で収まるよう表示倍率を合わせる |

- タブストップと縦罫は、隣の欄に追いつくと、隣を1だけ先へ押し出します。
- レベル3・縦罫3の右のリンクアイコン（均等に連動）をオンにすると、1と2の差の間隔で3以降が並びます。
- 各パネルの［リセット］で、自動で決めた位置に戻ります。
- 囲み罫があるとき、横線は囲みの左辺で止まります（［横線を囲み罫につなげる］がオンなら左辺まで届きます）。上の行につながらない縦線は、上の行の囲みの下辺から下ろします。

### 注意点

- 横組みのテキストが対象です。空のテキストは対象から外します。
- 囲み罫を行ごとに描けるのと、いちばん上の縦線を最初の項目まで伸ばせるのは、ポイント文字だけです。エリア内文字・パス上文字は、テキスト全体を1つで囲みます。
- 囲み罫の高さは、文字サイズがそろっている前提で行送りから割り出します。行ごとに文字サイズが違うときや、段落前後のアキがあるときはずれます。
- 角の記号（├・└・┣・┗）は、すぐ後ろに横線（─・━）が続くときだけ罫線にします。長音の「ー」は横線とみなさず、文字のまま残します。
- 変換した段落のタブストップは、スクリプトが置いた位置で置き換わります。
- 合字などで文字と字形の数が合わないテキストは、位置を測れないため変換しません（最後に件数を知らせます）。
- テキストが大きいと、値を変えたときのプレビューの描き直しに時間がかかることがあります。
