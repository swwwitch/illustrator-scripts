### 概要

選択したテキストのツリー記号（├─・└─・│）をパスの罫線に変換し、字下げと名前・説明のあいだの空きをタブにします。
罫線とタブストップの位置は、プレビューを見ながら調整できます。

### 主な機能

- ├─・└─・│（太字の ┃・━、長音の ー を含む）を、パスの罫線に変換
- 記号はテキストから削除し、名前の位置は変えない
- 行頭の字下げをタブにし、階層（レベル）ごとにタブストップを1つずつ置く
- 名前と説明のあいだに2つ以上続くスペースをタブにし、説明を1列にそろえる
- 縦線は行と行のあいだもつなぎ、子の └ は親の横線から下ろす
- ダイアログを開いているあいだは、変換後の結果を常にプレビュー
- 日本語／英語UI

### 使い方

1. ツリー記号を含むテキストを選択します（グループの中のテキストや、文字を編集中のテキストでもかまいません）。
2. スクリプトを実行します。
3. 線や位置を調整し、［OK］をクリックします。［キャンセル］なら元のテキストと表示に戻ります。

罫線は、作業中のレイヤーに「ツリー罫線」という名前のグループで作られます。

### オプション

| パネル | 項目 | 内容 |
| --- | --- | --- |
| 罫線 | 線幅 | 罫線の太さ（単位は環境設定の［線］） |
| 罫線 | 線端 | 丸型／なし。角の形状は連動して、丸型ならラウンド、なしならマイター |
| 罫線 | カラー | ■をクリックすると標準のカラーピッカー。横の欄に16進数（RRGGBB）でも入力できる |
| テキスト | 行送り | テキスト全体の行送り。変えると固定値になる |
| テキスト | 行頭の字下げをタブに変換 | 字下げをタブにして、名前の位置にタブストップを置く。オフのときは記号の跡をカーニングで埋める |
| テキスト | 連続したスペースをタブに変換 | 名前と説明のあいだの空きをタブにして、説明をそろえる |
| タブストップ | レベル 1〜／説明 | 階層ごとの名前と、説明の列のタブストップの位置 |
| 縦罫 | 縦罫 1〜 | 縦線の横位置 |
| （下部） | 制御文字 | 制御文字の表示を切り替える |
| （下部） | 画面にフィット | プレビューが指定の割合で収まるよう表示倍率を合わせる |

- タブストップと縦罫は、隣の欄に追いつくと、隣を1だけ先へ押し出します。
- レベル3・縦罫3の右のリンクアイコン（均等に連動）をオンにすると、1と2の差の間隔で3以降が並びます。
- 各パネルの［リセット］で、自動で決めた位置に戻ります。

### 注意点

- 横組みのテキストが対象です。
- 変換した段落のタブストップは、スクリプトが置いた位置で置き換わります。
- 合字などで文字と字形の数が合わないテキストは、位置を測れないため変換しません（最後に件数を知らせます）。
- テキストが大きいと、値を変えたときのプレビューの描き直しに時間がかかることがあります。
