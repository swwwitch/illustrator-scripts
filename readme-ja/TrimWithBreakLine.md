### 概要

- 画像と、その上に描いた帯状のパスを選択して実行すると、帯の範囲を省いた上下のパーツを作り、指定の間隔に詰めます。
- 長い画面キャプチャやメニューの一部を省略して見せたいときに使います。
- 切り口はワープ（旗・上昇）で曲げられ、切り口に沿った省略線も引けます。

### 主な機能

- 帯パスの幅で画像をトリミング（左右も切り詰め）
- 切り口の形を「旗」「上昇」から選択、カーブの量を%で指定
- 上下の切り口は同じ形なので、詰めたあとも一定の間隔でかみ合う
- 上下パーツの間隔を、定規の単位で指定
- 切り口に沿った省略線（実線／破線、分割数、線端）を追加
- 省略線を、その切り口のパーツとグループ化
- ダイアログを開いた時点からのライブプレビュー

### 使い方

1. 画像（配置画像／埋め込み画像）と、省略したい範囲を覆う長方形などのパスを描き、2つを選択する
2. スクリプトを実行する
3. ダイアログで切り口の形・間隔・省略線を指定する（プレビューを見ながら調整）
4. OK で確定する。元の画像と帯のパスは削除され、上下のパーツが選択された状態になる

パスは画像より前面にあるものを「帯」として扱い、その左右が仕上がりの幅になります。帯は画像の上端・下端より内側に描いてください。

### ダイアログ

| 項目 | 説明 |
| --- | --- |
| スタイル | 切り口の形。「旗」は波、「上昇」は右上がりのカーブ |
| カーブ | 切り口を曲げる量（0〜100%）。0で直線 |
| 間隔 | 詰めたあとの上下パーツのあいだの距離（定規の単位） |
| 罫線を追加 | 切り口に沿った省略線を引く |
| 線種 | 実線／破線 |
| 分割数 | 破線の線分の本数。線分と間隔は同じ長さで、両端が線分で終わる |
| 線端 | なし（線端なし）／丸型（丸型線端） |
| グループ化 | 省略線を、その切り口のパーツとひとつのグループにまとめる |

### キーボード操作

| キー | 動作 |
| --- | --- |
| ↑ / ↓ | 数値欄の値を1ずつ増減 |
| Shift + ↑ / ↓ | 10の倍数へスナップ |
| option + ↑ / ↓ | 0.1ずつ増減 |

### 注意事項

- 選択は「画像1つ」＋「パス1つ」の2つだけにしてください。
- 帯のパスが画像の上端・下端にかかっていると実行できません。
- 線幅と濃さはスクリプト冒頭の `RULE_STROKE_WIDTH` / `RULE_STROKE_GRAY` で変更できます。
- プレビューは複製で作っています。キャンセルすると複製は削除され、元の選択に戻ります。
