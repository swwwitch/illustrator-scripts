# 埋め込み画像をリンク画像に変換

[![Direct](https://img.shields.io/badge/Direct%20Link-UnembedRasterItems.jsx-ffcc00.svg)](https://github.com/swwwitch/illustrator-scripts/blob/master/jsx/link/UnembedRasterItems.jsx)

[![Direct](https://img.shields.io/badge/Back%20to%20home-All%20scripts-cccccc.svg)](https://github.com/swwwitch/illustrator-scripts/blob/master/README.md)

---

### 概要

- ドキュメント内のすべての埋め込みラスター画像をリンク画像に置き換えるスクリプト。
- 実行時のダイアログで、処理方法を「元ファイルに再リンク」「強制的に埋め込み解除」から選択。
- 「元ファイルに再リンク」では、埋め込み前のファイルが残っていれば書き出さずにそのファイルへリンクする（見つからない場合はPSDを書き出し）。
- 書き出し先は、Illustratorドキュメントと同じ階層の「Links」フォルダー（存在しない場合は自動作成）。
- 書き出すファイル名には、埋め込み前の元のファイル名を使用する（レイヤー名 → 拡張子付きの親グループ名 → XMPマニフェストの順に探索）。取得できない場合は image1、image2… の連番。
- 同名ファイルがある場合は連番の接尾辞（例：`myPhoto(2).psd`）を付けるため、既存ファイルを上書きしない。
- 配置サイズのまま書き出し、元の回転角・位置・重ね順を維持したままリンク画像として再配置する。
- 元の画像の解像度（ピクセル数）はそのまま保持される。

### 主な機能

- ドキュメント内の埋め込み画像を一括で処理（選択は不要）
- 処理方法をダイアログで選択
  - **元ファイルに再リンク**：XMPマニフェストのパスを辿り、実ファイルが存在すればそこへリンク。サイズが合わない場合はPSD書き出しに自動で切り替え
  - **強制的に埋め込み解除**：常にPSDを書き出して置き換え
- 元ファイル名の復元（次の順に探索）
  1. レイヤー名（名前を付けている場合）
  2. 拡張子付きの親グループ名
  3. XMPマニフェスト（`xmpMM:Manifest` に記録された埋め込み前のファイルパス）
  4. `image1`、`image2`… の連番
  - 拡張子を除去し、ファイル名に使えない文字（`\ / : * ? " < > |`）はアンダースコアに置換
- カラースペースは CMYK／RGB／グレースケールに対応（それ以外はスキップして結果に表示）
- サイズが変化した画像（効果の影響）を検出して警告、または変換せず元に戻す
- 処理結果（変換件数・警告・エラー）をまとめてアラート表示
- 日本語／英語の自動切り替え

### 処理の流れ

1. 埋め込み画像の変形マトリックスから、現在の拡大率と回転角を取得
2. 書き出し用の一時ドキュメントへ複製し、**倍率はそのまま**に回転だけ0°に戻す
3. アートボードを画像サイズに合わせ、配置倍率から逆算した実効解像度でPSDとして書き出し（倍率24%なら7200÷24＝300ppi。これで元のピクセル数が保持される）
4. 書き出したPSDをリンク配置し、回転角・位置・重ね順を元に合わせる（PSDが配置サイズそのままのため拡大縮小は不要）
5. 元の埋め込み画像を削除

### ユーザー設定

スクリプト冒頭の「ユーザー設定」ブロックで変更できます。

| 変数 | 既定値 | 内容 |
| --- | --- | --- |
| `LINKS_FOLDER_NAME` | `"Links"` | 書き出し先フォルダー名 |
| `USE_XMP_NAMES` | `true` | レイヤー名が空のとき、XMPマニフェストの元ファイル名を使う |
| `PRESERVE_RESOLUTION` | `true` | 配置倍率から実効解像度を逆算し、元の解像度（ピクセル数）を保持する |
| `EXPORT_RESOLUTION` | `300` | `PRESERVE_RESOLUTION` が `false` のときに使う固定解像度（ppi）。リサンプルされる |
| `SIZE_TOLERANCE` | `0.01` | サイズが一致するとみなす許容値（pt） |
| `SKIP_RESIZED_ITEMS` | `false` | `true` にすると、サイズが一致しない画像は変換せず元の埋め込み画像を残す |
| `KEEP_EXPORT_DOC_OPEN` | `false` | `true` にすると書き出し用の一時ドキュメントを閉じない（動作確認用） |

### 注意

- 効果（ドロップシャドウなど）が適用された埋め込み画像の変換は推奨しません。
  - 効果はラスタライズされてリンク画像に含まれる
  - 効果の解像度はドキュメントのラスタライズ設定ではなく、埋め込み画像側の解像度になる
  - 効果によっては、リンク画像の位置が元の埋め込み画像からずれることがある
- `PRESERVE_RESOLUTION` を `false` にすると、画像がリサンプル（拡大／縮小）されます。
- 実効解像度が2400ppiを超える画像は2400ppiに抑えて書き出し、結果に警告を表示します。
- 埋め込み画像に設定した不透明度・描画モードなどのアピアランスは、リンク画像に引き継がれません。
- XMPマニフェストからの名前取得は、**重複を除いた件数が埋め込み画像の件数と一致するときだけ**、上から順に対応づけます。マニフェストには過去の埋め込み履歴が残ることがあり、件数が合わない場合は連番（`image1`…）になります。

### オリジナルとの差異

- 書き出すファイル名に、埋め込み前の元のファイル名を使用（オリジナルは image1、image2… の連番のみ）。レイヤー名・親グループ名・XMPマニフェストの3つから探す
- 未対応のカラースペース、書き出し失敗、拡大率を取得できない画像をスキップし、結果にまとめて表示
- ドキュメント未オープン・未保存・埋め込み画像なしを実行前に判定して警告
- メッセージを日本語／英語に対応
- 効果などでサイズが変化した画像の扱いを、コード内の `if (false)` からユーザー設定 `SKIP_RESIZED_ITEMS` に変更
- 書き出しフォルダー名・解像度などをユーザー設定として冒頭に集約
- 処理を関数に分割し、全関数にJSDocを付与

### 対象外

- ドキュメントが開かれていない場合（警告を表示して終了）
- ドキュメントが未保存の場合（書き出し先が決まらないため、警告を表示して終了）
- 埋め込み画像が1件も無い場合（警告を表示して終了）
- CMYK／RGB／グレースケール以外のカラースペースの埋め込み画像（スキップして結果に表示）
- リンク画像（PlacedItem）
