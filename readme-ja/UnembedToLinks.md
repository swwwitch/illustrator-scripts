# 埋め込み画像をリンク画像に変換（アクション方式）

[![Direct](https://img.shields.io/badge/Direct%20Link-UnembedToLinks.jsx-ffcc00.svg)](https://github.com/swwwitch/illustrator-scripts/blob/master/jsx/link/UnembedToLinks.jsx)

[![Direct](https://img.shields.io/badge/Back%20to%20home-All%20scripts-cccccc.svg)](https://github.com/swwwitch/illustrator-scripts/blob/master/README.md)

---

### 概要

- 埋め込み画像（RasterItem）を、一時アクション（`adobe_placeDocument`）を動的に生成して実行し、リンク画像に置き換えるスクリプト。
- 「選択オブジェクトと置換」（rplc）で配置するため、位置・サイズ・回転角・重ね順はIllustrator側がそのまま引き継ぐ（スクリプトでの復元処理は不要）。
- 処理対象は「選択している画像のみ」「現在のアートボード上の埋め込み画像」「すべての埋め込み画像」から選択。
- 元ファイルが判明している画像はそのファイルへリンク。判明しない場合は、埋め込み画像自体をPSDに書き出してリンクする。
- 「再リンク後に収集」をオンにすると、リンク先をIllustratorドキュメントと同じ階層の「Links」フォルダーへコピーしてリンクを張り替える。

### 主な機能

- 処理対象をダイアログで選択
  - **選択している画像のみ**（グループの中も再帰的に探索）
  - **現在のアートボード上の埋め込み画像**（アクティブなアートボードと重なる画像。`geometricBounds` で判定するため、効果の広がりは含まない）
  - **すべての埋め込み画像**
- 対象ファイルの一覧表示（ファイル名／パスの2カラム）
  - **フルパス**：絶対パスのまま表示
  - **Dropboxパスを短縮**：`DROPBOX_PREFIX` 以下を相対表示。オフのときはホーム以下を `~` に短縮
- 元ファイルが不明な画像は「Links」フォルダーへPSDで書き出してリンク（常時有効）
  - 一覧には書き出し予定のファイル名（`○○.psd`）と「（PSDに書き出し）」を表示
  - 書き出し名は、レイヤー名 → 拡張子付きの親グループ名 → XMPマニフェスト → `image1`、`image2`… の順に探索
  - 拡張子を除去し、ファイル名に使えない文字（`\ / : * ? " < > |`）はアンダースコアに置換
  - 同名ファイルがある場合は連番の接尾辞（例：`myPhoto(2).psd`）を付けるため、既存ファイルを上書きしない
- 再リンク後の収集（同階層の「Links」フォルダーへコピー）
  - 同名で内容が異なるファイルがある場合は `-1`、`-2`… の連番を付ける
  - 同一とみなせるファイル（パスが同じ、またはサイズと更新日時が一致）は再コピーしない
- 処理結果（成功・スキップ・失敗の件数と明細）をまとめてアラート表示
- 一時アクションファイル（.aia）は実行後に必ず削除し、アクションセットもアンロードする

### 処理の流れ

1. 対象の埋め込み画像を集め、元ファイル不明時の書き出し名をドキュメント全体でまとめて決める
2. 各画像の元ファイルを取得（`item.file`）。取得できない場合は次の手順でPSDを書き出す
   1. 書き出し用の一時ドキュメントへ複製
   2. 拡大率100%・回転角0°に戻し、アートボードを画像サイズに合わせる
   3. 「Links」フォルダーへPSDとして書き出し、一時ドキュメントを閉じる
3. 対象の画像だけを選択し、`adobe_placeDocument` の一時アクションを生成して `loadAction` → `doScript` → `unloadAction`
4. 収集がオンで、かつ書き出したPSD以外の場合は「Links」フォルダーへコピーしてリンクを張り替え
5. 置き換え後のリンク画像を選択状態にして、結果を表示

### ユーザー設定

スクリプト冒頭の「設定」ブロックで変更できます。

| 変数 | 既定値 | 内容 |
| --- | --- | --- |
| `ACTION_SET_NAME` | `"UnembedToLinksTempSet"` | 一時アクションセット名 |
| `ACTION_NAME` | `"UnembedToLinksPlace"` | 一時アクション名 |
| `ACTION_FILE_NAME` | `"~/UnembedToLinksTemp.aia"` | 一時アクションファイルのパス |
| `LINKS_FOLDER_NAME` | `"Links"` | 収集先／書き出し先フォルダー名 |
| `EXPORT_RESOLUTION` | `72` | PSD書き出し解像度（ppi）。等倍に戻してから書き出すため、元のピクセル数が保持される |
| `USE_XMP_NAMES` | `true` | 名前が取得できない画像に、XMPマニフェストの元ファイル名を使う |
| `DROPBOX_PREFIX` | ローカルのDropboxパス | 一覧表示で取り除くプレフィックス。空文字にすると短縮機能は無効 |

### 注意

- ドキュメントが未保存の場合、「Links」フォルダーの場所を決められないため、収集とPSD書き出しは失敗します。
- ロックまたは非表示のレイヤー・画像は、アクションで置換できないため【失敗】として表示されます。
- PSD書き出しが対応するカラースペースは CMYK／RGB／グレースケールです。それ以外は【スキップ】として表示されます。
- 元ファイルが不明で、かつ処理対象が1件のみの場合は、書き出しに失敗したときにファイルの手動選択を促します。
- XMPマニフェストからの名前取得は、**重複を除いた候補の件数が名前未定の画像の件数と一致するときだけ**、上から順に対応づけます。件数が合わない場合は連番（`image1`…）になります。
- アートボード判定は矩形の重なりで行うため、複数のアートボードにまたがる画像はいずれのアートボードでも対象になります。
- 効果（ドロップシャドウなど）が適用された埋め込み画像は、PSD書き出し時に効果がラスタライズされて含まれます。
