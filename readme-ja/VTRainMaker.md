### 概要

雨のような罫線を生成します。

### 主な機能

- 雨の種類を「雨粒」「春雨」「五月雨」「鉄砲雨」から選択
- 粒の形状を「雨粒」「水玉」から選択
- 線幅・角度・密度・本数を指定
- 外側拡張、子罫オフセット、全体スケール、塗りを指定
- 日本語／英語UI

### 使い方

1. ドキュメントを開きます。
2. スクリプトを実行します。
3. 雨の種類とオプションを指定して実行します。

### 注意点

- ドキュメントが開いていないときは警告を表示して終了します。
