## 概要

CSV / タブ区切りテキストのデータを、Illustratorのテンプレートに流し込むデータ結合スクリプトです。

テキストフレーム内に置いた `<変数名>` 形式のタグをデータ値に置き換え、データ件数ぶんのアートボードとバリエーションを一度に生成します。名刺、席札、会員証、値札、賞状など「同じデザインで中身だけ違う」制作物に使えます。

元ドキュメントは別名保存で複製し、複製側に流し込むため、元ファイルは変更されません。

## 主な機能

- 開いているドキュメントと同じフォルダーにある CSV / TSV ファイルから選択
- 読み込んだデータをダイアログ内の一覧で確認
- `<変数名>` タグをデータ値へ置換（タグに設定した文字書式は保持）
- 変数の対応づけを「列名で自動対応」と「手動で対応づけ」から選択
- 手動で対応づけると、変数ごとに使うデータ列をポップアップメニューで選択（名前が一致する列は自動選択）
- 各ポップアップの右に、そのデータの1件目（ファイルの2行目）の値を表示
- ほかの変数で使用済みの列は、ポップアップメニュー内でディム表示
- 消費税の自動計算（税込金額の列から、税抜価格と税額を算出）
- データ件数ぶんのアートボードを自動生成
- グリッド全体が正方形に近くなる列数を自動計算、または列数を直接指定
- アートボード間隔の指定（10pt単位に丸め）
- 数値入力欄は↑↓キーで増減（shiftで10単位、optionで0.1単位）
- アートボード名に使うデータ列を選択（「名前」「御中」などを含む列を優先して初期選択）
- 保存するファイル名を設定（ベース名・接尾辞・区切り文字・日付・時刻）
- プレビュー（元ファイルを変更せず、複製ファイルで結果を確認）
- UTF-8（BOM有無どちらも）と Shift-JIS のデータファイルに対応
- 日本語／英語UI

## 使い方

1. 雛形にするデザインを **アートボード1** に作成します。差し替えたい箇所は、テキストフレーム内に `<氏名>` `<会社名>` のようにタグで書いておきます。
2. データファイル（CSV / タブ区切りテキスト）を、ドキュメントと **同じフォルダー** に置きます。1行目がヘッダー行です。列名がタグ名と一致していれば自動で対応づけられ、違っていてもダイアログで選び直せます。
3. ドキュメントを保存します（未保存だと実行できません）。
4. `VariableDataImport.jsx` を実行します。
5. ダイアログで設定します。
   - ［列名で自動対応］／［手動で対応づけ］: 対応づけの方法。自動対応では、`<変数名>` と同じ名前のデータ列をそのまま使います。手動を選ぶと、［変数とデータ列の対応］パネルが現れます。
   - ［ファイル］: 読み込むデータファイル
   - ［変数とデータ列の対応］: カンバス上の各 `<変数名>` に流し込むデータ列（名前が一致する列は自動で選ばれます。［（対応なし）］にすると、その変数は置換されずタグのまま残ります）
   - ［アートボード名］: 各アートボードの名前に使うデータ列
   - ［アートボード間隔］: 複製するアートボード同士の間隔（縦横とも同じ間隔、単位はpt）
   - ［列数］: 横に並べるアートボードの数。空欄にすると、グリッドが正方形に近くなるよう自動で決めます。
   - ［ファイル名］: 複製して保存するファイルの名前
6. ［プレビュー］をオンにすると、複製ファイルで結果を確認できます。オフにすると閉じます。
7. ［複製して流し込む］をクリックします。元ドキュメントが別名保存で複製され、複製側にデータが流し込まれます。

### 変数とデータ列の対応

［手動で対応づけ］を選ぶと、アートボード1のテキストから見つかった `<変数名>` が一覧で並びます。

- 各ポップアップメニューの右には、選んだ列に入っている **データの1件目（ファイルの2行目）** の値が表示されます。どの列を選んだかを、実際の値で確認できます。
- ほかの変数ですでに使っている列は、ポップアップメニュー内でディム表示になり選べません。
- 対応列を変更すると、プレビューは解除されます。もう一度［プレビュー］をオンにすると、新しい対応で作り直します。

### 消費税の自動計算

税込価格の列しかないデータから、税抜価格と税額を求められます。［変数とデータ列の対応］パネルの［消費税を自動計算］をオンにすると、ポップアップメニューに計算列が加わります。

| 項目 | 値 |
| --- | --- |
| `税込価格` | データの値そのまま |
| `税込価格（税抜）` | 四捨五入した `税込価格 ÷ 1.1` |
| `税込価格（税額）` | `税込価格 − 税抜` |

税抜と税額の合計は、必ず元の税込価格に一致します。3桁区切り・全角数字・`¥` を含む値も読み取り、元の値が3桁区切りなら結果にも区切りを付け直します。

計算列が出るのは、税込金額の列を1つに特定できたときだけです。列名に `税込` `金額` `価格` `料金` `定価` `合計` のいずれかを含む列を優先し、該当が無ければ数値の列が1つだけのときにその列を使います。候補が複数あって決められない場合、チェックボックスは無効になります。

### ファイル名

複製して保存するファイルの名前を組み立てます。

| 項目 | 内容 |
| --- | --- |
| ベース名 | 名前の本体。空にすると元のファイル名を使います |
| 接尾辞 | ベース名の後ろに、区切り文字を挟んで付ける文字列。既定は空で、付けません |
| 日付を付ける | 末尾に `YYYYMMDD` |
| 時刻を付ける | 末尾に `HHMMSS` |
| 区切り文字 | 各要素をつなぐ文字（ハイフン／アンダースコア） |

組み立てた結果は［保存名］に表示されます。`\ / : * ? " < > |` と前後の空白は自動で除去されます。

### 数値入力欄のキー操作

［アートボード間隔］と［列数］は、キーボードで値を増減できます。

| キー | 動作 |
| --- | --- |
| ↑ / ↓ | ±1 |
| shift + ↑ / ↓ | 10の倍数へスナップ |
| option + ↑ / ↓ | ±0.1 |

## データファイルの書式

| 拡張子 | 区切り文字 |
| --- | --- |
| `.csv` | カンマ（引用符 `"` と `""` エスケープに対応） |
| `.txt` | タブ |

```
氏名,会社名,役職
山田太郎,株式会社スイッチ,代表
鈴木花子,株式会社サンプル,デザイナー
```

このデータに対して、雛形のテキストフレームに `<氏名>` `<会社名>` `<役職>` と書いておくと、それぞれの値に置き換わります。

- 1行目のヘッダー名とタグ名が同じ場合は、自動で対応づけられます。名前が違う場合は、ダイアログの［変数とデータ列の対応］で列を選びます。
- 各値の前後の空白は自動で除去されます。
- 値が空の行は、アートボード名が `Data_1` `Data_2` … になります。

## 生成されるファイル

| 操作 | 生成されるファイル |
| --- | --- |
| ［複製して流し込む］ | ［ファイル名］パネルの設定どおり（既定は `元のファイル名_YYYYMMDD_HHMMSS.ai`） |
| ［プレビュー］ | `ベース名_preview_YYYYMMDD_HHMMSS.ai`（プレビューをオフにすると削除） |

いずれも元ドキュメントと同じフォルダーに作られます。元ファイルは変更されません。プレビュー用ファイルは、［日付を付ける］［時刻を付ける］の設定にかかわらず必ず日時付きの名前になり、保存名とぶつからないようにしています。

## 注意事項

- 雛形として複製されるのは、アートボード1上にある **ロックも非表示もされていない** オブジェクトだけです。ロックレイヤーの背景などはバリエーションに複製されません。
- ［プレビュー］はディスク上のファイルを複製するため、保存していない編集は反映されません。
- 引用符で囲まれたフィールド内の改行には対応していません。1レコード1行で書き出してください。
- アートボードの生成数は最大1000件です。データ件数がカンバスに収まらない場合は、アートボード間隔を小さくしてください。
- 1件目のデータは最後に処理します（雛形のタグが先に消えるのを避けるため）。
- タグはテキストフレームとグループ内のテキストフレームを対象に置換します。シンボルや埋め込み画像内のテキストは対象外です。
- ダイアログに並ぶ変数は、アートボード1のテキストから見つかった `<…>` です。テキストに書かれていない変数は一覧に出ません。
- 消費税の税率は10%固定です。
- ［列数］に指定した値で縦に収まらない場合は、データが多すぎる旨の警告が出ます。［列数］を空欄に戻すと自動配置になります。
