# 縦組みの欧文回転・縦中横・数字の書き換えをまとめて適用

### 概要

- 選択した縦組みのテキストに、［縦組み中の欧文回転］と［縦中横］をまとめて適用するスクリプト。
- 数字を全角・漢数字・和暦に書き換えたり、桁区切りや小数点を縦組み用の記号に変えたりもできる。
- ダイアログボックスで項目を選び、［変換の確認...］の一覧で結果を確かめてから実行する。
- ［縦組み中の欧文回転］と［縦中横］は DOM から設定できないため、一時アクション（ダイナミックアクション）で文字パネルの項目だけを適用する。フォントやサイズなど、ほかの書式は変わらない。

### 主な機能

- 「簡易」「詳細」「ウィザード」の3つのモード（ダイアログボックスの最上部の左で切り替え、既定は簡易）
  - **簡易**：欧文回転・数字の縦中横（2桁／3桁／4桁）・等幅字形・桁区切りと小数点の変換・1桁の数字と縦中横以外の数字と1文字の英字の全角だけを表示
  - **詳細**：すべての項目を表示
  - **ウィザード**：やりたいことをチェックボックスで選ぶだけで、詳細の項目をまとめて設定して処理する（詳細モードの設定は変わらない。チェックしていない項目はオフ、プリセットは使えない）。option キーを押しながらクリックすると、すべてオン（すべてオンのときは、クリックしたものだけオン）。使えるものを1つもチェックしていないときは OK を押せない
    - 英単語を回転して立てる（欧文回転。5文字以上の欧文は回転せず横倒しのまま）
    - 短い英単語と1文字の英字を正立させる（4文字以下を全角に。英単語の回転より優先）
    - 2〜3桁の数字を縦中横にする（字数に合わせた等幅字形。漢数字にするときは使えない）
    - 縦中横にしない数字を全角で正立させる（漢数字にするときは使えない）
    - 数字を漢数字にする（書き方は詳細モードの設定。「零」「一千」も引き継ぐ）
    - 西暦を和暦にする
    - 略称と「!?」を縦中横にする
    - 単位を組文字にする
    - 記号を縦組み用にする（「、」の桁区切り・「・」の小数点・「〜」・全角の記号・〝〟・番号のハイフン）
    - 段落を縦組み用に整える（弱い禁則v2・行末約物半角・行送り175%・プロポーショナルメトリクス）
    - エリア内文字の枠を文字に合わせる
    - 処理のあとに色分けして確かめる
  - 簡易モードでは表示している項目だけを処理する（表示しない項目はオフ、禁則・文字組みアキ量設定は変えない）。詳細モードの設定は保存したまま残る
  - 切り替えても、ダイアログボックスは同じ中心の位置で開き直す
- 「プリセット」
  - 組み込み（縦組みの数字表記の考え方にそって用意）
    - **標準**：2〜3桁を縦中横（字数に合わせた等幅字形）、桁区切りは「、」、小数点は「・」
    - **算用数字・2桁だけ縦中横**：2桁は縦中横、1桁は全角、3桁以上は1字ずつ縦に
    - **算用数字・2〜3桁縦中横（雑誌・広告）**：1桁は全角、単位は組文字（10cm → 10㌢）、長い欧文は横倒し、短い英単語は全角（縦中横は数字だけ）
    - **漢数字・万億兆（新聞・一般書）**：万・億・兆だけを入れる（25000 → 二万五〇〇〇）、桁区切りは取る
    - **漢数字・十百千（文芸）**：十・百・千も入れる（25000 → 二万五千）
    - **漢数字・1字ずつ＋読点**：単位語を入れず、3桁ごとに「、」（3,000 → 三、〇〇〇）
    - **欧文回転だけ**
    - 漢数字のプリセットでも、西暦の年は1字ずつ（二〇二六年）、電話番号・郵便番号は算用数字のまま
  - 保存アイコンで今の設定に名前を付けて保存、ゴミ箱アイコンで保存したプリセットを削除（組み込みは削除できない）
- 「欧文回転・縦中横」
  - **縦組み中の欧文回転**：選択したテキスト全体に適用（既定ON）。英単語がスペースや「&」でつながった2語以上のまとまり（Type & Layout、Adobe Illustrator、3語以上も同様）は常に回転せず横倒しのままにし、全角や記号の置き換えもしない。全角の英数字・全角スペース・「＆」が混ざっていてもまとまりとして扱い、半角に戻す（Design Ｗｅｅｋ → Design Week）
    - **○文字以上の欧文は除く**：指定した文字数（既定5）以上の欧文は回転せず横倒しのままにする。英字で始まる単語がスペースや . ' & - でつながったまとまりで数える（「Adobe Illustrator」は17文字）
  - **数字を縦中横**：［2桁］［3桁］［4桁］から選んだ桁数の半角数字に適用（既定ON、2桁・3桁がON）
    - **桁区切り・小数点の隣は除く**：「3,000」の「000」や「12.5」の「12」を縦中横にしない（既定ON）
  - **大文字の英字（2〜3字）を縦中横**：「PDF」「OK」など、すべて大文字の英字に適用
  - **「!!」「!?」を縦中横**：感嘆符・疑問符の2字の組に適用（全角の「！」「？」は半角にそろえてから適用）
  - **字数に合わせた等幅字形**：縦中横にした文字を、2字は等幅半角字形・3字は等幅三分字形・4字は等幅四分字形にして、ほぼ全角1字分に収める（既定ON）。フォントに字形が無いときは変わらない
- 「文字の変換」
  - **全角英数字を半角に**：「２０」「ＰＤＦ」も縦中横・欧文回転の対象にする
  - **桁区切り**：「,」「，」を「、」にする（3,000 → 3、000、既定）／取る（3,000 → 3000。つないだ数字を1つの数として縦中横・全角を判定）／そのまま
  - **小数点の「.」「．」を「・」に**：12.5 → 12・5（既定ON）
  - **範囲の「-」「~」→「〜」**：数字の間の「-」「~」「－」「～」を「〜」に（10-20 → 10〜20、既定ON）。電話番号・郵便番号は対象外
  - **記号を全角に**：半角の ( ) [ ] { } : ; / % & # @ * + = < > を全角にして正立させる（既定ON）
  - **引用符を〝〟に**：“ ” と半角の " " をチョンチョン（〝 〟）に（既定ON）
  - **「!」「?」を全角に**：縦中横にしない「!」「?」を全角に（既定ON）
  - **○文字以下の英単語を全角に**（詳細モード）：指定した文字数以下の英単語を全角にする（OK → ＯＫ）。文字数は［○文字以上の欧文は除く］の1つ下に連動（既定は5と4）。単位の組文字と大文字の縦中横の対象はそちらを優先
  - **1文字の英字を全角に**：「Aランク」の A など、1字だけの英字を全角に
- 「数字」
  - **1桁の数字を全角に**：「5人」の5を正立させる
  - **縦中横以外の数字を全角に**：縦中横にしない数字をすべて全角にして正立させる。桁区切り・小数点の隣や電話番号の数字も対象、漢数字にする数字は除く（既定OFF。ONのときは［1桁の数字を全角に］をディム表示）
  - **単位を組文字に**：数字の直後の mm・cm・km・m・mg・g・kg・t・ml・dL・kL・L・cal・kcal・cc を ㍉・㌢・㌖・㍍・㍉㌘・㌘・㌕・㌧・㍉㍑・㌥㍑・㌔㍑・㍑・㌍・㌔㌍・㏄ に、m2・cm3・m² などを ㎡・㎤ などにする（10cm → 10㌢）。数字と単位の間の半角スペースは詰め（5 mm → 5㍉）、全角の単位も対象。km/h・mmHg のように後ろに英字や「/」が続くものは変えない。字形の無いフォントもあるため既定OFF
  - **西暦を和暦に**：「2026年」→「令和8年」。月日が続けば改元の前後を月日で判定し（2019年4月30日 → 平成31年、2019年5月1日 → 令和元年）、月日が無い改元の年は新しい元号にする。1年は「元年」
  - **漢数字を算用数字にそろえる**：混じった漢数字を算用数字にしてから縦中横・全角を決める（2019年四月30日 → 2019年4月30日、三十日 → 30日）。対象は2字以上の漢数字と、月・日・時・分・秒の前の1字。「一緒」「十分」「数十万」「何百」などは変えない。［漢数字に変換］がONのときは使えない（漢数字にそろえるときは［漢数字に変換］の桁数を1〜にする）。既定OFF
  - **漢数字に変換**：桁数の範囲（既定 4〜20桁）の数字を漢数字にする
    - **1字ずつ**：2026 → 二〇二六、3,000 → 三、〇〇〇
    - **十・百・千を入れる**：2000 → 二千、3,000 → 三千、1234 → 千二百三十四（万・億・兆・京も入れる。小数部は1字ずつ）
    - **万・億・兆だけ**：25000 → 二万五〇〇〇、123456789 → 一億二三四五万六七八九
    - 直後が「年」の西暦は、書き方によらず1字ずつにする（2026年 → 二〇二六年）
    - **0を「零」に**：〇の代わりに零を使う（二〇〇六 → 二零零六）
    - **千を「一千」に**：十・百・千を入れるとき、1000 を「一千」と書く（1500 → 一千五百、10000000 → 一千万）
- **番号のハイフン**（詳細モード）：電話番号・郵便番号（数字-数字-数字、3桁-4桁）のハイフンを「‐」（ハイフン、既定）／「ー」（音引き）／そのまま、にする。番号は範囲の「〜」・縦中横・漢数字の対象にしない
- 「文字・段落」（詳細モード）
  - 禁則（なし／強い禁則／弱い禁則／弱い禁則v2）と文字組みアキ量設定（なし・行末約物全角/半角〜ベタ組み・ドキュメントのカスタムのセット）をドロップダウンで選ぶ（既定は弱い禁則v2・ベタ組み）
  - **行送り**：自動行送りの％で指定する（既定175%、50〜500%）。段落の自動行送り量を設定する。行送りは簡易・詳細のどちらのモードでも、処理の最後に常に「自動」にする（文字サイズに追従）。自動カーニングも処理の最後に常に「0」にする
  - 行揃えは常に「行頭行末揃え（最終行上）」
  - **全角英数字にプロポーショナルメトリクス**：全角の英数字（Ａ〜Ｚ・ａ〜ｚ・０〜９）に OpenType 機能の［プロポーショナルメトリクス］を適用（文字の書き換えのあと、既定ON）
  - **高さを文字サイズの整数倍に**：エリア内文字の枠の高さ（縦組みでは1行の長さ）を、文字サイズのいちばん近い整数倍にそろえる（内側の余白は除いて測る。既定ON、簡易モードでも常にかける）
  - **エリア内文字を自動サイズ調整**：処理のあと、エリア内文字に［エリア内文字オプション］の［自動サイズ調整］を適用して枠を文字に合わせる（既定ON、組み込みのプリセットもすべてON。連結したテキストは対象外）
- 「確認用の色分け」（詳細モード）
  - **処理のあとに文字を色分けする**：全角の英数字と「！？」を赤、半角を青、等幅字形の文字（縦中横の三分・四分など）を緑、ほかをベースの色（黒）で塗る（既定OFF）。色はスクリプト冒頭の変数（CHECK_*）で設定する。仕上がりの確認用で、元の色には戻らない（ColorCharactersByWidth の機能）
- 横組みのテキストは、常に縦組みにしてから処理する
- **変換の確認...**：「3,000 → 三千」「10［縦中横］ ×3」のように、今の設定で変わる箇所を別のダイアログボックスで一覧表示する
- 実行中はプログレスバーで進み具合を表示
- 設定は保存され、次に開いたときに戻る
- 日本語／英語の自動切り替え

### 使い方

1. 縦組みのテキストオブジェクトを選択する（文字ツールで範囲を選んでもよい）
2. スクリプトを実行し、ダイアログボックスで項目を選ぶ
3. ［変換の確認...］で変わる箇所の一覧を確かめ、［OK］をクリックする

### 処理の順序

1. すでに縦組みのテキストは横組み用に戻す（欧文回転・縦中横を外し、全角英数字・「、」の桁区切り・「・」の小数点・記号・〝〟・番号のハイフン・組文字の単位を戻し、等幅字形を標準に。HorizontalTextFormatter の既定の変換と同じ。範囲の「〜」は戻さない。漢数字・和暦は、前回それらをオンで処理したフレームだけ戻す）。一度処理したテキストにも、設定を変えて再実行できる
2. 横組みのテキストを縦組みに（常に）
3. 段落の設定（ベタ組み・弱い禁則v2・行頭行末揃え（最終行上））
4. ［縦組み中の欧文回転］をテキスト全体に適用（書き換えで変わる文字も、回転した書式を引き継ぐ）
5. 文字の書き換え（全角→半角、漢数字→算用数字、桁区切り・小数点、全角数字、和暦、漢数字）
6. ［縦中横］を対象の箇所ごとに適用

### 注意点

- すでに縦組みのテキストでは、「変換の確認」は横組み用に戻したあとの文字からの変化を表示する（全角の５ → 5 → ５ のように、結果が元と同じでも行が出る）
- 漢数字にする桁数と縦中横にする桁数が重なるときは、漢数字にする
- 西暦を和暦にしないときは、「2026年」の4桁も［4桁］がONなら縦中横になる
- 文字数が変わる書き換え（3,000 → 三千 など）では、書き換えた部分は先頭の文字の書式になる
- ロック中・非表示のテキストは対象にしない
