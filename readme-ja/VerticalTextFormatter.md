# 縦組みの欧文回転・縦中横・数字の書き換えをまとめて適用

### 概要

- 選択した縦組みのテキストに、［縦組み中の欧文回転］と［縦中横］をまとめて適用するスクリプト。
- 数字を全角・漢数字・和暦に書き換えたり、桁区切りや小数点を縦組み用の記号に変えたりもできる。
- ダイアログボックスで項目を選び、「変換の確認」の一覧で結果を確かめてから実行する。
- ［縦組み中の欧文回転］と［縦中横］は DOM から設定できないため、一時アクション（ダイナミックアクション）で文字パネルの項目だけを適用する。フォントやサイズなど、ほかの書式は変わらない。

### 主な機能

- 「プリセット」
  - 組み込み：**標準**／**1桁全角・2〜3桁縦中横・4桁以上漢数字**／**漢数字（十・百・千）・和暦**／**欧文回転だけ**
  - 保存アイコンで今の設定に名前を付けて保存、ゴミ箱アイコンで保存したプリセットを削除（組み込みは削除できない）
- 「欧文回転・縦中横」
  - **縦組み中の欧文回転**：選択したテキスト全体に適用（既定ON）
  - **数字を縦中横**：［2桁］［3桁］［4桁］から選んだ桁数の半角数字に適用（既定ON、2桁・3桁がON）
    - **桁区切り・小数点の隣は除く**：「3,000」の「000」や「12.5」の「12」を縦中横にしない（既定ON）
  - **大文字の英字（2〜3字）を縦中横**：「PDF」「OK」など、すべて大文字の英字に適用
  - **「!!」「!?」を縦中横**：感嘆符・疑問符の2字の組に適用（全角の「！」「？」は半角にそろえてから適用）
  - **字数に合わせた等幅字形**：縦中横にした文字を、2字は等幅半角字形・3字は等幅三分字形・4字は等幅四分字形にして、ほぼ全角1字分に収める（既定ON）。フォントに字形が無いときは変わらない
- 「文字の変換」
  - **全角英数字を半角に**：「２０」「ＰＤＦ」も縦中横・欧文回転の対象にする
  - **桁区切りの「,」「，」を「、」に**：3,000 → 3、000（既定ON）
  - **小数点の「.」「．」を「・」に**：12.5 → 12・5（既定ON）
- 「数字」
  - **1桁の数字を全角に**：「5人」の5を正立させる
  - **西暦を和暦に**：「2026年」→「令和8年」。月日が続けば改元の前後を月日で判定し（2019年4月30日 → 平成31年、2019年5月1日 → 令和元年）、月日が無い改元の年は新しい元号にする。1年は「元年」
  - **漢数字に変換**：桁数の範囲（既定 4〜20桁）の数字を漢数字にする
    - **1字ずつ**：2026 → 二〇二六、3,000 → 三、〇〇〇
    - **十・百・千を入れる**：2026 → 二千二十六、2000 → 二千、3,000 → 三千（万・億・兆・京も入れる。小数部は1字ずつ）
- 「段落」
  - **文字組みアキ量設定をベタ組みに**（既定ON）
  - **禁則を弱い禁則v2に**（既定ON）
  - **行揃えを行頭行末揃え（最終行上）に**（既定ON）
- **横組みのテキストを縦組みに**：横組みのテキストを縦組みにしてから処理する（既定ON）
- **縦組みのテキストだけを処理**：横組みのテキストを一緒に選んでいても変えない（既定ON。［横組みのテキストを縦組みに］がONのときは無効）
- **変換の確認**：「3,000 → 三千」「10［縦中横］ ×3」のように、変わる箇所を一覧で表示。項目や桁数を変えるたびに更新する
- 実行中はプログレスバーで進み具合を表示
- 設定は保存され、次に開いたときに戻る
- 日本語／英語の自動切り替え

### 使い方

1. 縦組みのテキストオブジェクトを選択する（文字ツールで範囲を選んでもよい）
2. スクリプトを実行し、ダイアログボックスで項目を選ぶ
3. 「変換の確認」で結果を確かめ、［OK］をクリックする

### 処理の順序

1. 横組みのテキストを縦組みに
2. 段落の設定（ベタ組み・弱い禁則v2・行頭行末揃え（最終行上））
3. ［縦組み中の欧文回転］をテキスト全体に適用（書き換えで変わる文字も、回転した書式を引き継ぐ）
4. 文字の書き換え（全角→半角、桁区切り・小数点、全角数字、和暦、漢数字）
5. ［縦中横］を対象の箇所ごとに適用

### 注意点

- 漢数字にする桁数と縦中横にする桁数が重なるときは、漢数字にする
- 西暦を和暦にしないときは、「2026年」の4桁も［4桁］がONなら縦中横になる
- 文字数が変わる書き換え（3,000 → 三千 など）では、書き換えた部分は先頭の文字の書式になる
- ロック中・非表示のテキストは対象にしない
