### 概要

アプリケーションフレーム・コントロールパネル・ガイド・グリッド・スナップなどの表示とオン・オフを、1つのダイアログボックスでまとめて切り替えます。

メニューの［表示］→［〜を表示］などは押すたびに反転するだけで、今どちらなのかを確かめないと意図しない切り替えが起きます。このスクリプトは今の状態を読んでからダイアログボックスを開くので、チェックを付けたとおりの状態に揃います。

### 主な機能

- **基本UI**：明るさ（暗／やや暗め／やや明るめ／明）、アプリケーションフレーム、アプリケーションバー、コンテキストタスクバー、コントロールパネル、ツールバー、ヘルプバー、生成メニュー
- **オブジェクト**：コーナーウィジェット、境界線、バウンディングボックス
- **アートボード**：境界線の表示、アートボード名の表示、生成AIボタンの表示
- **ガイド**：ガイドの表示、スマートガイドの表示、ロック、スナップ（［ポイントにスナップ］）
- **グリッド**：表示、スナップ
- **その他のスナップ**：ピクセル、グリフ
- **保存・書き出し**：バックグラウンド書き出し、バックグラウンド保存、復帰データの自動保存
- **ツール**：［シェイプ形成ツール］のカラー（ツールオプションの「次のカラーを利用」をスウォッチ／オブジェクトで切り替え）
- **プリセット**：チェックの組み合わせと明るさに名前を付けて保存し、ドロップダウンから呼び出せます。プリセットは Illustrator を再起動しても残ります

### 使い方

1. スクリプトを実行すると、今の状態を読んでダイアログボックスが開きます
2. 切り替えたい項目のチェックやラジオボタンを変えます
3. ［OK］を押すと、変えた項目だけが切り替わります

### 注意点

- メニューの ✓ を読む・クリックするために、補助アプリ `/Applications/SetAiMenuState.app` を使います。ソースは ai-scripts の `helpers/SetAiMenuState.applescript` で、`osacompile -o /Applications/SetAiMenuState.app helpers/SetAiMenuState.applescript` で作ります
- 補助アプリには［システム設定］→［プライバシーとセキュリティ］→［アクセシビリティ］の許可が要ります。作り直すと許可のやり直しが必要になることがあります
- 補助アプリが無いときは、環境設定のキーで読める項目だけを切り替えられます。読めない項目はグレー表示になります
- 一部の項目（ツールバー、ヘルプバー、明るさ、保存・書き出し、シェイプ形成ツールなど）は、スクリプトの終了後に補助アプリがメニューや環境設定、ツールオプションを操作して切り替えます。切り替わるまで Illustrator を操作しないでください
- ［シェイプ形成ツール］のカラーはドキュメントを開いているときだけ切り替えられます。切り替えると、選択中のツールが［シェイプ形成ツール］に替わります
- 明るさ・保存・書き出し・シェイプ形成ツールの切り替えは日本語版のみ対応です。英語版のメニュー名は未検証です
- macOS 専用です
