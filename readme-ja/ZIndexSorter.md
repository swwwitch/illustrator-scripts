### 概要

- オブジェクトの重ね順を位置（X/Y）やZインデックスで並べ替える
- 昇順／降順／ランダムに並べ替え可能

### 主な機能

- ダイアログで並べ替え軸と順序を指定
- キャンセル時には元の順序に復元
- 多言語対応（日本語／英語）

### 処理の流れ

- 選択アイテムを収集
- 並べ替え軸・順序の設定をダイアログで取得
- 並べ替え後、Zインデックス順に再配置
