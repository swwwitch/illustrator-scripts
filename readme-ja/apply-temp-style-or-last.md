### 概要

選択オブジェクトに、既存のグラフィックスタイル「temp_style」を適用します。

### 使い方

1. `temp_style` という名前のグラフィックスタイルを登録しておきます（register-temp-style.jsx で登録できます）。
2. 適用したいオブジェクトを選択します。
3. スクリプトを実行します。

### 注意点

- `temp_style` が存在しない場合は、直前に使ったスタイルを適用します。
