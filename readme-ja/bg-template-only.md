### 概要

- 一時的なアクションを読み込んで実行し、対象レイヤーに「テンプレート」属性（ロック・印刷不可・画像を薄く表示）を設定します。
- 実行後、一時アクションはアンロードされます。

### 使い方

1. 対象のレイヤーをアクティブにする
2. スクリプトを実行する

### 注意点

- ダイアログはありません。
- ON/OFF を切り替えたい場合は ToggleTemplateLayer.jsx を使います。
