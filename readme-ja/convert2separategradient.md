### 主な機能

- 追加するカラーストップ数を指定（1 以上の整数）
- セパレートグラデーション（縞模様）への変換
- 特色（スポットカラー）の RGB / CMYK 自動変換
- RGB / CMYK ドキュメントに対応

### 既定の挙動

- 単一オブジェクトのみ対象
- 塗りがグラデーション以外、またはストップが 2 つ未満の場合はアラートで終了
