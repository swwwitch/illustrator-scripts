### 概要

- アクティブなアートボードを PNG24 形式で書き出します。
- 解像度 200%、アートボードでクリップ、アンチエイリアスあり
- 背景は白に固定（透過なし）
- 保存先はドキュメントと同じフォルダー、ファイル名は「ドキュメント名.png」
- 書き出し中は「Guides Preview for Trim View」レイヤーを一時的に非表示にし、完了後に再表示
- 書き出し後、Mac では保存フォルダーを Finder で開きます

### 使い方

1. 書き出したいアートボードをアクティブにする
2. スクリプトを実行する
