### 概要

2つのオブジェクトを選択し、大きい方を「容器」、小さい方を「タイル」として、容器のバウンディングボックス内にタイルを等間隔で敷き詰めます。

### 主な機能

- 完全に内側に収まるタイルのみを残す（マスクは使わない）
- 元の2オブジェクトはそのまま残す
- 間隔の単位はIllustratorのルーラー設定に追従
- ［シンボル化］（既定ON）。プレビューは直接複製を使用
- ［基準］の X / Y でタイル数を指定（指定した軸はその枚数を優先、未指定の軸は自動計算）

### 使い方

1. 容器にするオブジェクトと、タイルにするオブジェクトを選択します。
2. スクリプトを実行します。
3. 間隔などを指定して実行します。
