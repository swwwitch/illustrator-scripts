### 概要

現在のアートボードにかかっているテキスト、またはドキュメント全体のテキストを一覧表示し、まとめてクリップボードにコピーします。

### 主な機能

- 対象を「現在のアートボード」「ドキュメント全体」から選択
- ［アートボード外を無視］で、どのアートボードにもかかっていないテキストを除外

### 使い方

1. スクリプトを実行します。
2. 対象を指定して一覧を確認します。
3. コピーを実行します。
