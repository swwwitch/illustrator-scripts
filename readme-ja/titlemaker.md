### 概要

- 選択中のテキストフレームを、指定した文字の直後で改行する
- 改行対象の文字（、。〜）をチェックボックスで選択
- 改行後、連続する改行を1つにまとめる
- 文字揃えを欧文ベースラインに設定

### 処理の流れ

1. ダイアログで改行対象文字を選択
2. 選択中の各テキストフレームの内容を走査
3. 対象文字の後ろに改行を挿入し、重複改行を整理
4. 欧文ベースラインを適用
