### 概要

「Guides Preview for Trim View」レイヤーを作成し、そのレイヤーをテンプレート化します。

### 使い方

1. 対象のドキュメントを開きます。
2. スクリプトを実行します。

### 注意点

- 作成するレイヤー名は、スクリプト冒頭の `NEW_LAYER_NAME` で変更できます。
