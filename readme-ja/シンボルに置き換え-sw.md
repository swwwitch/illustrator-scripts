### 概要

ドキュメントに登録されているシンボルを一覧から選び、選択したオブジェクトをそのシンボルインスタンスへ置き換えます。

### 使い方

1. 置き換えたいオブジェクトを選択します。
2. スクリプトを実行します。
3. 一覧からシンボルを選び、［OK］をクリックします。

### 注意点

- 一覧に表示するシンボルの数には上限があり、それを超える場合はスクロールして選択します。
- 選択数が多いときは処理に時間がかかることがあります。
- 原作は Toshiyuki Takahashi 氏（[graphicartsunit.com](http://www.graphicartsunit.com/)）による「シンボルに置き換え.jsx」です。
