### 概要

「下絵」という名前のレイヤーを探し、そのレイヤーをテンプレート化します。

### 使い方

1. 「下絵」レイヤーがあるドキュメントを開きます。
2. スクリプトを実行します。

### 注意点

- 対象のレイヤー名はスクリプト内の呼び出し（`setLayerTemplate(app.activeDocument, "下絵", true)`）で指定します。
- ダイアログから対象や ON/OFF を選びたい場合は SetTemplateLayer.jsx / ToggleTemplateLayer.jsx を使用してください。
