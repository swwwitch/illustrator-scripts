# 縦組みテキストを原稿用紙に組む

### 概要

選択した縦組みテキストの文字送りをマス目にそろえ、1文字分の間隔で横罫線を引き、全体の左右に縦罫線を添えるスクリプトです。

縦罫の伸張、横罫の線種、太くする間隔、十字線の有無をダイアログで指定します。設定を変えるたびに結果がプレビューされ、ダイアログを閉じずに確認できます。

### 主な機能

- 文字属性をマス目に合わせて自動調整（トラッキング、ツメ、プロポーショナルメトリクス、文字前後のアキ、水平・垂直比率、カーニング）
- 横組みのテキストは縦組みへ変換
- 1文字分の間隔で横罫線を作成（先頭文字の上から最後の文字の下まで）
- テキスト全体の左右に縦罫線を作成（上下へ伸ばす量を指定可能）
- 指定した文字数ごとに横罫線を太く
- 各マスの中央に十字線（破線）を追加
- ダイアログを閉じずに結果を確認できるプレビュー
- 罫線は専用レイヤー（`原稿用紙罫線`）に作成し、最背面へ配置
- 日本語／英語UI

### 使い方

1. 罫線を引く縦組みテキストを1つ選択します。
2. `原稿用紙.jsx` を実行します。
3. ダイアログで縦罫の伸張、横罫の線種、太くする間隔、十字線を設定します。
4. プレビューで結果を確認します（「プレビュー」をオフにすると非表示）。
5. 「OK」をクリックして罫線を作成します。

### オプション

| 項目 | 初期値 | 内容 |
| --- | --- | --- |
| 縦罫の上下の伸張 | 2mm | 縦罫線をマス目の上下へ伸ばす量 |
| 横罫 | 実線 | 横罫線を実線または破線（1mm／1mm）で作成 |
| n文字ごとに太く | オン／5 | 指定した文字数ごとに横罫線を太く（0.25mm） |
| 各文字に十字線を追加 | オン | 各マスの中央に破線の十字線を追加 |
| プレビュー | オン | ダイアログを閉じずに結果を表示 |

数値欄は↑↓キーで増減できます（Shiftで±10かつ10の倍数にスナップ）。

### 罫線の仕様

| 罫線 | 太さ | 濃度 |
| --- | ---: | ---: |
| 縦罫 | 0.25mm | 50% |
| 横罫 | 0.1mm | 50% |
| 太くした横罫 | 0.25mm | 50% |
| 十字線 | 0.1mm（破線1mm／1mm） | 30% |

RGBドキュメントでは、同じ濃度に相当するグレーのRGB値を使用します。

### 文字属性の調整

マス目に文字を合わせるため、次の属性を設定します。

| 属性 | 値 |
| --- | --- |
| トラッキング | 120 |
| ツメ | 0 |
| プロポーショナルメトリクス | オフ |
| 文字前後のアキ | 0 |
| 水平比率・垂直比率 | 90% |
| カーニング | 和文等幅 |

### 注意点

- Illustrator 2024〜2026に対応しています。
- テキストオブジェクトを1つだけ選択して実行してください。
- 罫線の間隔は先頭文字の文字サイズを基準にします。文字サイズが混在するテキストでは、意図した位置に罫線が引かれません。
- 再実行すると、`原稿用紙罫線`レイヤーの`罫線`グループを作り直します。
- プレビュー中は選択したテキストを一時的に複製して表示します。キャンセルすると元の状態に戻ります。
- 手動カーニングはDOMから設定できないため、自動カーニングを「和文等幅」にしています。
- 設定できなかった文字属性があるときだけ、実行後に属性名を通知します。
