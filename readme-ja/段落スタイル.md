### 概要

選択したテキストの体裁を、段落スタイルとして登録します。既存のスタイルを選んで上書きすることもできます。

### 使い方

1. 段落スタイルにしたいテキスト（またはテキストオブジェクト）を選択します。
2. スクリプトを実行します。
3. 新しいスタイル名を入力するか、上書きするスタイルを選んで実行します。

### 注意点

- ドキュメントが開かれていない場合、またはテキストを選択していない場合は警告を表示して終了します。
- 一覧には既定スタイル（標準段落スタイル）を除いたスタイルが並びます。
