### 概要

アートボード名を「行-列」形式に一括で更新します。

### 主な機能

- カンバス上の位置から行と列を割り出して命名
- 日本語／英語UI

### 使い方

1. 対象のドキュメントを開きます。
2. スクリプトを実行します。
3. ［アートボード名を 行-列 形式に更新］を有効にして実行します。

### 注意点

- アートボードが存在しない場合は警告を表示して終了します。
- 並び替えまで含めて行いたい場合は ReorderArtboardsByPosition.jsx を使用してください。
